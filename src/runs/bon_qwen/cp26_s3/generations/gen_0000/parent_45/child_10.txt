The problem is to pack 26 circles in a unit square to maximize the sum of radii. 
Mathematically, for a fixed number of circles and a fixed packing density, the sum of radii is maximized when all radii are equal (due to the concavity of the square root function in area calculations, or simply because $\sum r_i$ for fixed $\sum r_i^2$ is maximized when $r_i$ are equal). 
Thus, the optimal solution should consist of 26 equal circles of the largest possible radius.

Strategy:
1.  **Formulation**: Formulate the problem as maximizing the radius $r$ of 26 equal circles such that they fit in the unit square without overlapping.
    *   Variables: Centers $(x_i, y_i)$ for $i=1..26$ and a scalar radius $r$.
    *   Objective: Maximize $r$ (or minimize $-r$).
    *   Constraints:
        *   Boundary: $r \le x_i \le 1-r$ and $r \le y_i \le 1-r$.
        *   Non-overlap: Distance between any pair $(i, j)$ must be $\ge 2r$.
2.  **Initialization**: Start with a valid configuration of 26 circles with a small radius (e.g., $r=0.05$). A grid layout or a hexagonal grid perturbation works well. I will use a dense grid to pick 26 points that are reasonably spaced.
3.  **Optimization**: Use `scipy.optimize.minimize` with the `SLSQP` method. This method handles non-linear constraints well.
    *   To ensure robustness, I will run the optimization. The constraints will be defined explicitly.
    *   I will also include a small perturbation to the initial positions to avoid symmetry traps if the grid is too symmetric, although for $N=26$ a grid start is usually fine.
4.  **Post-processing**: Extract the final centers and radii. Since the optimization finds the max $r$ for equal circles, the radii array will be uniform.
5.  **Validation**: Ensure the returned solution passes the validation logic (non-negative radii, inside square, no overlaps).

This approach targets the theoretical upper bound for equal circles, which is likely very close to or exactly the global optimum for the sum of radii.

import numpy as np
import scipy.optimize

def run_packing():
    """
    Packs 26 circles in a unit square to maximize the sum of radii.
    Assumes optimal packing has equal radii.
    """
    n = 26
    
    # 1. Initial Guess Generation
    # We start with a valid packing of small circles.
    # A grid layout is a safe starting point.
    # Let's place 26 points on a grid that fits inside [0,1].
    # We can use a 5x5 grid (25 points) and add one, or a 6x5 subset.
    # A 6x5 grid (30 points) with spacing allows us to pick 26.
    
    # Let's generate points on a grid with spacing such that they don't overlap for small r.
    # If we pick r_init = 0.08, diameter is 0.16.
    # Spacing 0.2 works.
    # Grid points at 0.1, 0.3, 0.5, 0.7, 0.9 (5 points)
    # And maybe 0.2, 0.4, 0.6, 0.8 (4 points) for hexagonal?
    # Let's just use a simple rectangular grid for initialization, optimizer will fix it.
    
    # Create a grid of candidate points
    # 6 columns, 5 rows -> 30 points.
    # x in {0.1, 0.3, 0.5, 0.7, 0.9} -> 5 points? No, 0.1 to 0.9 step 0.2 is 5 points.
    # If we want 6 points, we need smaller spacing or wider range.
    # Let's use linspace to get good coverage.
    
    # Let's try to generate 26 points manually for a good start.
    # 5 rows. 
    # Row 0: 5 points
    # Row 1: 5 points
    # Row 2: 6 points
    # Row 3: 5 points
    # Row 4: 5 points
    # Total 26.
    
    centers_init = []
    y_spacing = 0.2 # Initial vertical spacing
    x_spacing = 0.2 # Initial horizontal spacing
    
    # Rows y coordinates
    ys = [0.1, 0.3, 0.5, 0.7, 0.9]
    
    # Counts per row
    counts = [5, 5, 6, 5, 5]
    
    # To fit 6 points in width 1 with radius margin, we need spacing ~1/7?
    # Let's just distribute them.
    for idx, count in enumerate(counts):
        y = ys[idx]
        # Distribute 'count' points in [0.1, 0.9] roughly
        # If count=5, points at 0.1, 0.3, 0.5, 0.7, 0.9
        # If count=6, points at 0.083, 0.266, 0.45, 0.633, 0.816, 1.0? No 1.0 is boundary.
        # Let's use linspace with bounds [0.1, 0.9]
        xs = np.linspace(0.1, 0.9, count)
        # For count=6, xs will be [0.1, 0.26, 0.42, 0.58, 0.74, 0.9]
        # Distances are ~0.16. With r=0.08, diameter 0.16. Tight but ok.
        for x in xs:
            centers_init.append([x, y])
            
    centers_init = np.array(centers_init)
    
    # Initial radius guess. 
    # With spacing ~0.16, max r is 0.08.
    # Let's start with 0.05 to be safe.
    r_init = 0.05
    
    # 2. Optimization Setup
    # Variables: [x1, y1, x2, y2, ..., x26, y26, r]
    # Total dimensions: 26*2 + 1 = 53
    
    x0 = np.concatenate([centers_init.flatten(), [r_init]])
    
    # Bounds: x, y in [0, 1], r in [0, 1]
    bounds = [(0, 1)] * (2 * n) + [(0, 1)]
    
    # Constraints Definition
    # We want to maximize r => minimize -r
    
    def objective(vars_vec):
        return -vars_vec[-1]
    
    # Constraint function returns values that must be >= 0
    # 1. Boundary: x >= r, 1-x >= r, y >= r, 1-y >= r
    # 2. Overlap: dist^2 >= (2r)^2 => dist^2 - 4r^2 >= 0
    
    def constraint_func(vars_vec):
        r = vars_vec[-1]
        centers = vars_vec[:-1].reshape(n, 2)
        
        cons = []
        
        # Boundary constraints
        for i in range(n):
            x, y = centers[i]
            cons.append(x - r)          # x >= r
            cons.append(1.0 - x - r)    # 1-x >= r
            cons.append(y - r)          # y >= r
            cons.append(1.0 - y - r)    # 1-y >= r
            
        # Overlap constraints
        # To save computation, we can vectorize or just loop. N=26 is small (325 pairs).
        # Loop is fine.
        for i in range(n):
            for j in range(i + 1, n):
                dx = centers[i, 0] - centers[j, 0]
                dy = centers[i, 1] - centers[j, 1]
                dist_sq = dx*dx + dy*dy
                cons.append(dist_sq - 4.0 * r * r)
                
        return np.array(cons)
    
    # Define constraints for SLSQP
    # NonlinearConstraint expects a function returning an array
    # lb=0, ub=inf means func(x) >= 0
    cons = scipy.optimize.NonlinearConstraint(constraint_func, 0, np.inf)
    
    # 3. Run Optimization
    # SLSQP is a good choice for non-linear constraints
    # maxiter should be sufficient to converge
    result = scipy.optimize.minimize(
        objective,
        x0,
        method='SLSQP',
        bounds=bounds,
        constraints=[cons],
        options={'maxiter': 2000, 'ftol': 1e-12, 'disp': False}
    )
    
    # 4. Extract Results
    if result.success:
        final_centers = result.x[:-1].reshape(n, 2)
        final_r = result.x[-1]
        final_radii = np.full(n, final_r)
        
        # Clip radii to be non-negative just in case (though constraints enforce r>=0 via x>=r and x<=1)
        # Actually constraint x-r >= 0 and 1-x-r >= 0 implies 2r <= 1 => r <= 0.5.
        # And x >= r implies if x is valid, r must be <= 1.
        # But we should ensure r >= 0.
        # If optimization fails to find positive r, we fallback.
        if final_r < 0:
            final_r = 0.0
            final_radii = np.zeros(n)
            # Fallback centers
            final_centers = np.tile([0.5, 0.5], (n, 1)) # Dummy
            
        return final_centers, final_radii, np.sum(final_radii)
    else:
        # If optimization fails, return the initial guess scaled or just initial
        # This shouldn't happen often with good init
        print("Optimization failed.")
        final_radii = np.full(n, r_init)
        return centers_init, final_radii, np.sum(final_radii)

# Helper to run
if __name__ == "__main__":
    c, r, s = run_packing()
