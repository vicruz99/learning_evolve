A hexagonal lattice is theoretically the densest packing in 2D, so we initialize our circles on a shifted hexagonal grid. Since we are maximizing the sum of radii (not minimizing the maximum radius), circles can vary in size to fill boundary gaps optimally.

We will use a penalty-based optimization approach with `scipy.optimize.minimize` (L-BFGS-B method):
1. **Objective**: Minimize $-\sum r_i + \lambda P$, where $P$ is the sum of squared constraint violations. This transforms the constrained problem into an unconstrained (bounded) one.
2. **Constraints**: 
   - Boundary: Circles must stay within $[0,1] \times [0,1]$.
   - Non-overlap: Distance between centers must be $\ge r_i + r_j$.
3. **Initialization**: Generate a base hexagonal packing, then create multiple perturbed starting configurations to escape local minima.
4. **Optimization**: Run L-BFGS-B on each start. The high penalty weight ($\lambda=1500$) ensures constraints are respected while the optimizer pushes radii upward.
5. **Robustness**: Use bounds for positions and radii, clip initial perturbations to feasibility, and track the best result across restarts.

import numpy as np
from scipy.optimize import minimize

def compute_loss(vars, n):
    """
    Computes the negative sum of radii plus a heavy penalty for constraint violations.
    """
    pos = vars[:2*n].reshape(n, 2)
    rad = vars[2*n:]
    
    # Boundary violations squared
    v_left = np.maximum(0, rad - pos[:, 0])
    v_right = np.maximum(0, rad + pos[:, 0] - 1.0)
    v_bottom = np.maximum(0, rad - pos[:, 1])
    v_top = np.maximum(0, rad + pos[:, 1] - 1.0)
    pen_bound = np.sum(v_left**2 + v_right**2 + v_bottom**2 + v_top**2)
    
    # Overlap violations squared (vectorized)
    diff = pos[:, None, :] - pos[None, :, :]
    dist = np.sqrt(np.sum(diff**2, axis=2))
    r_sum = rad[:, None] + rad[None, :]
    mask = np.triu(np.ones((n, n), dtype=bool), k=1)
    v_overlap = np.maximum(0, r_sum - dist)
    pen_overlap = np.sum(v_overlap[mask]**2)
    
    # Objective: maximize sum of radii => minimize negative sum
    # Penalty weight drives violations to near zero
    return -np.sum(rad) + 1500.0 * (pen_bound + pen_overlap)

def run_packing():
    n = 26
    r_init = 0.108
    dx = 2.0 * r_init
    dy = np.sqrt(3.0) * r_init
    
    # 1. Generate base hexagonal lattice
    centers = []
    y = r_init
    row = 0
    while len(centers) < n:
        x = r_init
        shift = row % 2 * r_init
        while x < 1.0 - r_init and len(centers) < n:
            centers.append([x + shift, y])
            x += dx
        y += dy
        row += 1
        
    c_base = np.array(centers[:n])
    r_base = np.full(n, r_init)
    
    # 2. Create multiple starting configurations
    starts = [np.concatenate([c_base.ravel(), r_base])]
    
    np.random.seed(42)
    for _ in range(15):
        c_pert = c_base + np.random.uniform(-0.02, 0.02, c_base.shape)
        # Ensure initial positions respect bounds roughly
        c_pert = np.clip(c_pert, r_base, 1.0 - r_base)
        r_pert = r_base + np.random.uniform(-0.008, 0.008, n)
        r_pert = np.maximum(r_pert, 0.05)
        starts.append(np.concatenate([c_pert.ravel(), r_pert]))
        
    best_sum = -1.0
    best_centers = None
    best_radii = None
    
    # Bounds for L-BFGS-B: x,y in [0,1], r in [0, 0.5]
    bounds = [(0.0, 1.0)] * (2*n) + [(0.0, 0.5)] * n
    
    # 3. Optimize from each start
    for x0 in starts:
        res = minimize(compute_loss, x0, args=(n,), method='L-BFGS-B', 
                       bounds=bounds, options={'maxiter': 8000, 'ftol': 1e-11})
        
        pos_opt = res.x[:2*n].reshape(n, 2)
        rad_opt = res.x[2*n:]
        s = np.sum(rad_opt)
        
        if s > best_sum:
            best_sum = s
            best_centers = pos_opt.copy()
            best_radii = rad_opt.copy()
            
    return best_centers, best_radii, float(best_sum)
