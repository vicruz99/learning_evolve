To maximize the sum of radii for 26 circles in a unit square, we treat this as a non-linear optimization problem. While equal circle packing is a strong baseline, allowing variable radii can theoretically utilize "wasted" space (gaps between larger circles) to increase the total sum of radii.

My strategy involves:
1.  **Initialization**: Generate a high-quality starting configuration using a hexagonal lattice pattern, which has a higher packing density than a square grid. This provides a solid baseline where circles are already packed tightly.
2.  **Optimization**: Implement a `scipy.optimize.minimize` solver. Instead of using hard constraints (which can be difficult for the solver to navigate), we use a penalty function approach. The objective is to maximize the sum of radii, which is equivalent to minimizing a cost function that penalizes:
    *   **Overlaps**: If circles intersect, a penalty is added proportional to the square of the overlap distance.
    *   **Boundary Violations**: If a circle extends beyond the unit square $[0,1] \times [0,1]$, a penalty is added proportional to the square of the protrusion.
3.  **Execution**: The optimizer adjusts the centers $(x, y)$ and radii $r$ of all 26 circles simultaneously to reduce the penalty and increase the objective sum.

This approach is robust, does not rely on pre-coding specific geometric patterns, and allows the circles to dynamically find the most efficient positions and sizes to satisfy the constraints.

import numpy as np
import scipy.optimize as opt

def run_packing() -> tuple[np.ndarray, np.ndarray, float]:
    """
    Optimizes the packing of 26 circles in a unit square to maximize the sum of radii.
    Returns (centers, radii, sum_radii).
    """
    n = 26
    
    # 1. Initialization: Hexagonal Lattice Pattern
    # This provides a much better starting point than a random or square grid.
    # We calculate positions based on a hexagonal packing density.
    initial_centers = []
    row = 0
    # Approximate radius for 26 circles in a square is roughly 0.09 - 0.10
    r_guess = 0.1 
    y_offset = 0.0
    
    # Generate enough rows to fit 26 circles
    while len(initial_centers) < n:
        x_start = r_guess + (row % 2) * r_guess # Stagger every other row
        x = x_start
        
        while x <= 1 - r_guess:
            if len(initial_centers) < n:
                initial_centers.append([x, y_offset + r_guess])
            x += 2 * r_guess
        
        y_offset += r_guess * np.sqrt(3)
        row += 1
        
    initial_centers = np.array(initial_centers[:n])
    initial_radii = np.full(n, r_guess)
    
    # 2. Define the Optimization Problem
    # Variables: [x1, y1, r1, x2, y2, r2, ..., x26, y26, r26]
    # Total 3 * n variables.
    # We flatten the arrays for scipy.optimize.
    
    def objective(vars_flat):
        """
        Objective function: Minimize (-Sum of radii) + Penalties.
        """
        centers = vars_flat[:2*n].reshape((n, 2))
        radii = vars_flat[2*n:]
        
        sum_radii = np.sum(radii)
        penalty = 0.0
        
        # Boundary penalty: Circle must be inside [0, 1]
        # Check x bounds
        dist_left = centers[:, 0] - radii
        dist_right = 1 - (centers[:, 0] + radii)
        dist_bottom = centers[:, 1] - radii
        dist_top = 1 - (centers[:, 1] + radii)
        
        # If distance is negative, it's a violation. 
        # We penalize the square of the negative part.
        penalty += np.sum(np.maximum(-dist_left, 0) ** 2)
        penalty += np.sum(np.maximum(-dist_right, 0) ** 2)
        penalty += np.sum(np.maximum(-dist_bottom, 0) ** 2)
        penalty += np.sum(np.maximum(-dist_top, 0) ** 2)
        
        # Overlap penalty: dist(i, j) >= r_i + r_j
        for i in range(n):
            for j in range(i + 1, n):
                d = np.sqrt(np.sum((centers[i] - centers[j]) ** 2))
                overlap = radii[i] + radii[j] - d
                if overlap > 0:
                    penalty += overlap ** 2
                    
        return -sum_radii + 100 * penalty

    # 3. Run Optimization
    # Using L-BFGS-B because it supports bounds, but our penalty function handles bounds.
    # However, we can enforce non-negative radii via bounds.
    x0 = np.concatenate([initial_centers.flatten(), initial_radii])
    
    # Bounds: x, y in [0, 1], r in [0, 0.5]
    bounds = []
    for _ in range(n):
        bounds.append((0, 1)) # x
        bounds.append((0, 1)) # y
        bounds.append((0, 0.5)) # r
    
    # Optimize
    result = opt.minimize(
        objective, 
        x0, 
        method='L-BFGS-B', 
        bounds=bounds, 
        options={'maxiter': 1000, 'ftol': 1e-9}
    )
    
    # 4. Extract Results
    optimized_centers = result.x[:2*n].reshape((n, 2))
    optimized_radii = result.x[2*n:]
    
    # Ensure radii are non-negative (clipping just in case)
    optimized_radii = np.maximum(optimized_radii, 0)
    
    # Clip centers to valid range if optimization drifted slightly
    optimized_centers[:, 0] = np.clip(optimized_centers[:, 0], 0, 1)
    optimized_centers[:, 1] = np.clip(optimized_centers[:, 1], 0, 1)
    
    total_sum = np.sum(optimized_radii)
    
    return optimized_centers, optimized_radii, total_sum

# Verification (if run as script, though function is what matters)
if __name__ == "__main__":
    centers, radii, s = run_packing()
    print(f"Sum of radii: {s}")
    
    # Quick validation check
    valid = True

                valid = False
    print(f"Valid packing: {valid}")
