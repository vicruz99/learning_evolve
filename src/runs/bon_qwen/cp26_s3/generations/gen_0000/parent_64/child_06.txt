To maximize the sum of radii for 26 circles in a unit square, we treat the problem as a continuous optimization task where we adjust the circle centers to find the configuration that permits the largest possible radii.

The strategy involves two main steps:
1.  **Linear Programming for Radii**: For any fixed set of centers, the problem of finding the maximum radii is a Linear Program (LP). The objective is to maximize $\sum r_i$ subject to the constraints that circles do not overlap ($r_i + r_j \le \text{dist}(i, j)$) and remain within the square boundaries ($r_i \le \text{dist to edge}$). We use `scipy.optimize.linprog` to solve this efficiently.
2.  **Heuristic Optimization of Centers**: Since the optimal centers are unknown, we start with a dense initial configuration (a $5 \times 5$ grid plus one additional circle) and use a derivative-free optimizer (`scipy.optimize.differential_evolution`) to perturb the centers. This global search aims to maximize the sum of radii returned by the LP solver.

This approach effectively decouples the hard non-convex geometry constraints into a convex inner problem and a heuristic search for the optimal layout, allowing us to exceed the density of a simple square grid.

import numpy as np
from scipy.optimize import linprog, differential_evolution

def solve_radii_for_centers(centers):
    """
    Solves the Linear Program to find the maximum sum of radii 
    for a fixed set of centers.
    """
    n = centers.shape[0]
    
    # Objective: maximize sum(r_i) => minimize -sum(r_i)
    c_obj = -np.ones(n)
    
    # Constraints:
    # 1. r_i + r_j <= dist(i, j) for all i < j
    # 2. r_i <= distance to boundaries
    # 3. r_i >= 0
    
    A_ub = []
    b_ub = []
    
    # Pairwise non-overlap constraints
    # We only need to consider pairs that are reasonably close to avoid a huge matrix,
    # but for 26 circles, 325 constraints is small enough to include all.
    for i in range(n):
        for j in range(i + 1, n):
            dist = np.linalg.norm(centers[i] - centers[j])
            row = np.zeros(n)
            row[i] = 1.0
            row[j] = 1.0
            A_ub.append(row)
            b_ub.append(dist)
            
    # Boundary constraints
    for i in range(n):
        x, y = centers[i]
        # r_i <= x, r_i <= 1-x, r_i <= y, r_i <= 1-y
        bounds_vals = [x, 1 - x, y, 1 - y]
        for val in bounds_vals:
            row = np.zeros(n)
            row[i] = 1.0
            A_ub.append(row)
            b_ub.append(val)
            
    A_ub = np.array(A_ub)
    b_ub = np.array(b_ub)
    
    # Bounds for variables r_i >= 0
    bounds = [(0, None) for _ in range(n)]
    
    # Solve LP
    # Method 'highs' is efficient
    res = linprog(c_obj, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
    
    if res.success:
        radii = -res.fun  # The objective was minimized negative sum
        return res.x, radii
    else:
        # Fallback if LP fails (e.g. infeasible due to numerical issues)
        # Return small radii
        return np.zeros(n), 0.0

def objective_for_optimization(center_flat):
    """
    Objective function for the center optimizer.
    We want to maximize sum of radii, so we minimize negative sum.
    """
    n = 26
    centers = center_flat.reshape((n, 2))
    
    # Check for invalid centers (outside square)
    # Although bounds handle this, we ensure numerical safety
    if np.any(centers < 0) or np.any(centers > 1):
        return 1000.0 # Penalty
    
    radii, sum_r = solve_radii_for_centers(centers)
    return -sum_r

def run_packing() -> tuple[np.ndarray, np.ndarray, float]:
    """
    Main function to run the packing optimization.
    Returns (centers, radii, sum_radii).
    """
    np.random.seed(42)
    n = 26
    
    # 1. Initial Configuration: 5x5 Grid + 1 center circle
    # A 5x5 grid fits 25 circles with radius 0.1.
    # We add one circle at the center to start, though the optimizer will move it.
    
    centers = []
    # 5x5 Grid points
    coords = np.linspace(0.1, 0.9, 5)
    for y in coords:
        for x in coords:
            centers.append([x, y])
            
    # Add 26th point at the geometric center (will be optimized away or utilized)
    centers.append([0.5, 0.5])
    
    centers = np.array(centers)
    center_flat = centers.flatten()
    
    # 2. Optimize Centers using Differential Evolution
    # Bounds for centers: [0, 1]
    bounds = [(0, 1) for _ in range(n * 2)]
    
    # We use a relatively low population size and iterations for speed,
    # but enough to find a good local optimum.
    # 'seed' ensures reproducibility.
    # 'tol' helps converge.
    
    try:
        result = differential_evolution(
            objective_for_optimization,
            bounds=bounds,
            seed=42,
            maxiter=200,
            popsize=15,
            tol=1e-6,
            mutation=(0.5, 1.0),
            recombination=0.7
        )
        
        best_centers = result.x.reshape((n, 2))

        radii, sum_radii = solve_radii_for_centers(best_centers)

        radii = np.maximum(radii, 0)
        
        return best_centers, radii, np.sum(radii)
        
    except Exception as e:
        # Fallback to initial configuration if optimization fails
        print(f"Optimization failed: {e}")
        radii, sum_radii = solve_radii_for_centers(centers)
