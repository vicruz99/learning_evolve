The problem is to maximize the sum of radii of 26 circles packed in a unit square. This is equivalent to finding a configuration of centers that maximizes the sum of the largest possible non-overlapping radii at those locations.

1.  **Formulation**: For any fixed set of centers, the optimal radii can be found by solving a Linear Programming (LP) problem. The objective is to maximize $\sum r_i$ subject to:
    *   $r_i \ge 0$
    *   $r_i \le x_i, r_i \le 1-x_i, r_i \le y_i, r_i \le 1-y_i$ (Boundary constraints)
    *   $r_i + r_j \le \text{dist}(c_i, c_j)$ for all pairs $i, j$ (Non-overlap constraints)

2.  **Optimization Strategy**:
    *   The function $F(C) = \text{max sum of radii for centers } C$ is the objective to maximize.
    *   Since $F(C)$ is not smooth, we use a derivative-free optimization method (Powell's method) on the 52 coordinates (26 centers).
    *   We initialize the centers in a hexagonal grid pattern, which is known to be dense for circle packing. A specific pattern of rows (6, 5, 6, 5, 4) sums to 26 circles.
    *   We run the optimizer to find the optimal positions.

3.  **Refinement**:
    *   The LP is solved inside the objective function evaluation.
    *   We ensure the LP solver (`scipy.optimize.linprog` with 'highs' method) is efficient.
    *   We return the optimal centers and radii.

This approach balances geometric intuition (hexagonal packing) with numerical optimization to escape local minima of the grid structure.

import numpy as np
from scipy.optimize import linprog, minimize
import math

def solve_lp(centers):
    """
    Solves the LP to find maximum sum of radii for fixed centers.
    Returns (sum_radii, radii_array).
    """
    n = len(centers)
    # Objective: Maximize sum(r_i) -> Minimize -sum(r_i)
    c = np.ones(n) * -1.0
    
    # Constraints: A_ub @ r <= b_ub
    # We collect rows for A and values for b
    A_rows = []
    b_vals = []
    
    # Boundary constraints: r_i <= min(x, 1-x, y, 1-y)
    for i in range(n):
        x, y = centers[i]
        # r_i <= x
        row = [0.0] * n
        row[i] = 1.0
        A_rows.append(row)
        b_vals.append(x)
        
        # r_i <= 1 - x
        row = [0.0] * n
        row[i] = 1.0
        A_rows.append(row)
        b_vals.append(1.0 - x)
        
        # r_i <= y
        row = [0.0] * n
        row[i] = 1.0
        A_rows.append(row)
        b_vals.append(y)
        
        # r_i <= 1 - y
        row = [0.0] * n
        row[i] = 1.0
        A_rows.append(row)
        b_vals.append(1.0 - y)
        
    # Non-overlap constraints: r_i + r_j <= dist(i, j)
    for i in range(n):
        for j in range(i + 1, n):
            dx = centers[i][0] - centers[j][0]
            dy = centers[i][1] - centers[j][1]
            dist = math.sqrt(dx*dx + dy*dy)
            
            row = [0.0] * n
            row[i] = 1.0
            row[j] = 1.0
            A_rows.append(row)
            b_vals.append(dist)
            
    A_ub = np.array(A_rows)
    b_ub = np.array(b_vals)
    bounds = [(0, None) for _ in range(n)]
    
    try:
        # Using 'highs' method is generally fast and robust
        res = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
        if res.success:
            radii = res.x
            return np.sum(radii), radii
        else:
            # Fallback in case of solver issues, though rare with valid bounds
            return 0.0, np.zeros(n)
    except Exception:
        return 0.0, np.zeros(n)

def objective(centers_flat):
    """
    Objective function for minimization: -sum of radii.
    """
    centers = centers_flat.reshape(-1, 2)
    sum_r, _ = solve_lp(centers)
    return -sum_r

def run_packing():
    n = 26
    
    # 1. Generate Initial Guess (Hexagonal-like pattern)
    # Pattern: 6, 5, 6, 5, 4 circles in rows
    centers = []
    
    dx = 0.16  # Horizontal spacing
    dy = dx * math.sqrt(3) / 2  # Vertical spacing for hexagonal packing
    
    # Row 0: 6 circles
    x_start = 0.12
    y_start = 0.10
    for i in range(6):
        centers.append([x_start + i * dx, y_start])
        
    # Row 1: 5 circles (offset by dx/2)
    x_offset = x_start + dx / 2
    for i in range(5):
        centers.append([x_offset + i * dx, y_start + dy])
        
    # Row 2: 6 circles
    for i in range(6):
        centers.append([x_start + i * dx, y_start + 2 * dy])
        
    # Row 3: 5 circles
    for i in range(5):
        centers.append([x_offset + i * dx, y_start + 3 * dy])
        
    # Row 4: 4 circles (centered)
    # Width of 4 circles span is 3*dx. Center at 0.5.
    x_start_r4 = 0.5 - 1.5 * dx
    for i in range(4):
        centers.append([x_start_r4 + i * dx, y_start + 4 * dy])
        
    centers_arr = np.array(centers)
    
    # 2. Optimize Centers
    # Bounds for centers must be within [0, 1]
    bounds_opt = [(0.0, 1.0) for _ in range(2 * n)]
    
    # Use Powell's method for derivative-free optimization
    # It works well for this type of problem
    res = minimize(objective, centers_arr.flatten(), method='Powell', 
                   bounds=bounds_opt, options={'maxiter': 2000, 'ftol': 1e-10})
    
    best_centers = res.x.reshape(n, 2)
    
    # 3. Compute final radii
    best_sum_r, best_radii = solve_lp(best_centers)
    
    return best_centers, best_radii, best_sum_r
