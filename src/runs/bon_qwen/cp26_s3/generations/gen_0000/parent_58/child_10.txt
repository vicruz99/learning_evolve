To maximize the sum of radii for 26 circles in a unit square, we formulate the problem as a constrained nonlinear optimization task. We directly optimize the circle centers and radii variables to maximize $\sum r_i$ subject to:
1. **Boundary constraints**: Each circle must lie within $[0,1]^2$, i.e., $0 \le x_i - r_i$ and $x_i + r_i \le 1$ (similarly for $y$).
2. **Non-overlap constraints**: For every pair $i < j$, the distance between centers must satisfy $\sqrt{(x_i-x_j)^2 + (y_i-y_j)^2} \ge r_i + r_j$.

We use `scipy.optimize.minimize` with the `SLSQP` method, which handles inequality constraints efficiently. To ensure convergence to a high-quality solution:
- We initialize the system with a **hexagonal lattice arrangement**, which approximates the optimal packing density for equal circles and provides a strictly feasible starting point.
- We set bounds on variables to keep centers inside the square and radii non-negative.
- The objective function is simply the negative sum of radii (for minimization).
- Constraint functions are vectorized for speed, evaluating all boundary and pairwise separation conditions in a single pass per iteration.

This approach pushes the radii until the constraints bind, naturally finding a dense packing configuration. The hexagonal start significantly reduces the risk of getting trapped in poor local minima.

```python
import numpy as np
from scipy.optimize import minimize

# Fixed number of circles as requested
N = 26

def objective(vars):
    """Maximize sum of radii (minimize negative sum)"""
    return -np.sum(vars[2::3])

def bound_constraints(vars):
    """Enforce circles stay within the unit square"""
    res = np.empty(4 * N)
    for i in range(N):
        base = i * 3
        x, y, r = vars[base], vars[base + 1], vars[base + 2]
        res[4 * i] = x - r          # left boundary
        res[4 * i + 1] = 1.0 - x - r # right boundary
        res[4 * i + 2] = y - r       # bottom boundary
        res[4 * i + 3] = 1.0 - y - r # top boundary
    return res

def overlap_constraints(vars):
    """Enforce non-overlap between all pairs of circles"""
    m = N * (N - 1) // 2
    res = np.empty(m)
    idx = 0
    for i in range(N):
        xi, yi, ri = vars[i*3], vars[i*3+1], vars[i*3+2]
        for j in range(i + 1, N):
            xj, yj, rj = vars[j*3], vars[j*3+1], vars[j*3+2]
            dx = xi - xj
            dy = yi - yj
            # Distance minus sum of radii must be >= 0
            res[idx] = np.sqrt(dx*dx + dy*dy) - ri - rj
            idx += 1
    return res

def run_packing():
    # 1. Initialize with a hexagonal lattice for a feasible, dense starting configuration
    r_init = 0.085
    coords = []
    y = r_init
    stagger = 0
    while y + r_init <= 1.0:
        x = r_init + stagger * r_init
        while x + r_init <= 1.0:
            coords.append((x, y))
            x += 2 * r_init
        if len(coords) >= N:
            break
        y += r_init * np.sqrt(3)
        stagger = 1 - stagger
        
    # Ensure exactly N coordinates
    while len(coords) < N:
        coords.append((0.5, 0.5))
    coords = coords[:N]
    
    # 2. Setup initial variables [x0, y0, r0, x1, y1, r1, ...]
    vars0 = np.zeros(3 * N)
    for i, (x, y) in enumerate(coords):
        vars0[3*i] = x
        vars0[3*i+1] = y
        vars0[3*i+2] = r_init
        
    # 3. Define bounds: centers in [0,1], radii in [0, 0.5]
    bounds = [(0.0, 1.0) if k % 3 != 2 else (0.0, 0.5) for k in range(3*N)]
    
    # 4. Define constraints
    cons = [
        {'type': 'ineq', 'fun': bound_constraints},
        {'type': 'ineq', 'fun': overlap_constraints}
    ]
    
    # 5. Run SLSQP optimizer
    res = minimize(
        objective, 
        vars0, 
        method='SLSQP', 
        bounds=bounds, 
        constraints=cons, 
        options={'maxiter': 3000, 'ftol': 1e-10, 'disp': False}
    )
    
    # 6. Extract and format results
    centers = res.x.reshape(N, 3)[:, :2]
    radii = res.x.reshape(N, 3)[:, 2]
    total_sum = np.sum(radii)
    
    return centers, radii, total_sum
```
