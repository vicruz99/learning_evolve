This approach decouples the optimization of circle positions (centers) from their sizes (radii), leveraging the fact that for fixed centers, finding the optimal radii is a linear problem.

### Strategy Overview
1.  **Initialization**: Start with a high-quality initial arrangement, such as a hexagonal grid, to ensure we begin in a favorable region of the search space.
2.  **Linear Programming (LP)**: For any fixed set of centers, the problem of maximizing the sum of radii becomes a linear optimization problem. Constraints are simply $r_i + r_j \le \text{dist}_{ij}$ (non-overlap) and $r_i \le \text{boundary}_i$. We use `scipy.optimize.linprog` to solve this exactly.
3.  **Local Search on Centers**: To improve the arrangement, we perform a local search (random walk) on the centers. We only accept new center positions if the resulting LP solution yields a higher sum of radii. This "Hill Climbing" on the centers allows us to navigate the non-linear constraints of circle packing.
4.  **Constraints**: We enforce strict boundary checks and non-negative radii within the LP formulation.

### Implementation Details
-   **LP Objective**: Maximize $\sum r_i$ (implemented as minimizing $-\sum r_i$).
-   **LP Constraints**: 
    -   Inequality constraints for pairwise distances: $r_i + r_j \le \sqrt{(x_i-x_j)^2 + (y_i-y_j)^2}$.
    -   Inequality constraints for boundaries: $r_i \le x_i, r_i \le 1-x_i, r_i \le y_i, r_i \le 1-y_i$.

import numpy as np
from scipy.optimize import linprog

def validate_packing(centers, radii):
    """
    Validate that circles don't overlap and are inside the unit square
    """
    n = centers.shape[0]

    if np.isnan(centers).any():
        return False
    if np.isnan(radii).any():
        return False

    for i in range(n):
        if radii[i] < 0:
            return False
        elif np.isnan(radii[i]):
            return False

    for i in range(n):
        x, y = centers[i]
        r = radii[i]
        if x - r < -1e-12 or x + r > 1 + 1e-12 or y - r < -1e-12 or y + r > 1 + 1e-12:
            return False

    for i in range(n):
        for j in range(i + 1, n):
            dist = np.sqrt(np.sum((centers[i] - centers[j]) ** 2))
            if dist < radii[i] + radii[j] - 1e-12:
                return False

    return True

            current_idx += 1
