

To maximize the sum of radii for 26 circles in a unit square, we use an alternating optimization strategy. This approach iteratively solves a Linear Programming (LP) problem to find the optimal radii for fixed centers, and then uses a non-linear optimizer to adjust center positions to resolve overlaps and boundaries.

### Strategy
1.  **Initialization**: Start with a dense, structured grid to ensure circles are well-distributed.
2.  **Alternating Optimization**:
    *   **LP Radius Update**: For fixed centers, solve an LP to maximize $\sum r_i$ subject to boundary and pairwise distance constraints.
    *   **Non-linear Center Update**: For fixed radii, use L-BFGS-B to move centers, minimizing a penalty function that penalizes overlaps and boundary violations.
3.  **Refinement**: Run multiple iterations of this loop, using the previous result as the starting point for the next.

<strategy>
1. **Initialization**: Place 26 centers in a 5x5 grid (25 points) plus one point in a high-density gap. This provides a valid, spread-out starting configuration.
2. **Linear Programming (LP) for Radii**: For a given set of centers, we want to find the largest possible radii $r_i$. This is a linear problem: maximize $\sum r_i$ subject to $r_i + r_j \le \text{dist}(c_i, c_j)$ and boundary constraints. We use `scipy.optimize.linprog` with the HiGHS solver for efficiency.
3. **Non-linear Optimization for Centers**: For a given set of radii, we adjust the centers to minimize "overlap energy." We define a penalty function that sums the squares of any distance deficits between circles and any boundary violations. We use `scipy.optimize.minimize` with the L-BFGS-B method.
4. **Iteration**: By alternating between these two steps, the packing improves iteratively. We perform multiple iterations to reach a high-quality local optimum.
</strategy>

import numpy as np
from scipy.optimize import linprog, minimize

def calculate_distance_matrix(centers):
    """Computes the pairwise distance matrix for given centers."""
    diff = centers[:, np.newaxis, :] - centers[np.newaxis, :, :]
    return np.linalg.norm(diff, axis=2)

def solve_radii_lp(centers):
    """
    Solves the Linear Programming problem to find the maximum sum of radii 
    for a fixed configuration of centers.
    """
    n = len(centers)
    c_obj = -np.ones(n)  # Maximize sum of radii -> Minimize -sum

    A_ub = []
    b_ub = []

    # 1. Pairwise distance constraints: r_i + r_j <= dist(c_i, c_j)
    dist_matrix = calculate_distance_matrix(centers)
    for i in range(n):
        for j in range(i + 1, n):
            row = np.zeros(n)
            row[i] = 1
            row[j] = 1
            A_ub.append(row)
            b_ub.append(dist_matrix[i, j])

    # 2. Boundary constraints: r_i <= dist(c_i, boundary)
    for i in range(n):
        x, y = centers[i]
        dists = [x, 1 - x, y, 1 - y]
        min_dist = min(dists)
        row = np.zeros(n)
        row[i] = 1
        A_ub.append(row)
        b_ub.append(min_dist)

    A_ub = np.array(A_ub)
    b_ub = np.array(b_ub)

    bounds = [(0, None) for _ in range(n)]

    res = linprog(c_obj, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
    
    if res.success:
        return res.x
    else:
        # Fallback to very small radii if LP fails
        return np.full(n, 1e-6)

def compute_overlap_penalty(centers, radii):
    """Computes the objective function for center optimization."""
    n = len(centers)
    diff = centers[:, np.newaxis, :] - centers[np.newaxis, :, :]
    dists = np.linalg.norm(diff, axis=2)
    
    # Overlap penalty for pairs
    radii_sum = radii[:, np.newaxis] + radii[np.newaxis, :]
    overlap = np.maximum(0, radii_sum - dists)
    penalty = np.sum(overlap ** 2)

    # Boundary penalty
    for i in range(n):
        x, y = centers[i]
        r = radii[i]
        violations = [
            max(0, r - x),
            max(0, x - (1 - r)),
            max(0, r - y),
            max(0, y - (1 - r))
        ]
        penalty += sum(v ** 2 for v in violations)
    
    return penalty

def optimize_centers(centers, radii):
    """
    Optimizes center positions to minimize overlap and boundary violations
    for fixed radii.
    """
    n = len(centers)
    flat_centers = centers.flatten()
    
    # Bounds for centers: [0, 1] (soft constraints handled by penalty)
    # We use [0, 1] as strict bounds to keep centers within the square
    bounds = [(0, 1)] * (2 * n)

    res = minimize(
        lambda x: compute_overlap_penalty(x.reshape(n, 2), radii),
        flat_centers,
        method='L-BFGS-B',
        bounds=bounds,
        options={'maxiter': 500, 'ftol': 1e-12}
    )
    
    return res.x.reshape(n, 2)

def run_packing() -> tuple[np.ndarray, np.ndarray, float]:
    n = 26
    
    # 1. Initialization: 5x5 Grid + 1 point
    grid_points = []
    for i in range(5):
        for j in range(5):
            grid_points.append([0.1 + i * 0.2, 0.1 + j * 0.2])
    grid_points.append([0.3, 0.7]) # 26th point
    centers = np.array(grid_points)
    radii = np.full(n, 0.01)

    # 2. Alternating Optimization Loop
    for _ in range(25):
        # Update Radii via LP
        radii = solve_radii_lp(centers)
        
        # Update Centers via Non-linear optimization
        centers = optimize_centers(centers, radii)
        
        # Re-solve LP after center movement to ensure consistency
        radii = solve_radii_lp(centers)
    
    # Final validation check and return
    total_radius = float(np.sum(radii))
    
    return centers, radii, total_radius

if __name__ == "__main__":
    centers, radii, s = run_packing()
    print(f"Sum of radii: {s}")
