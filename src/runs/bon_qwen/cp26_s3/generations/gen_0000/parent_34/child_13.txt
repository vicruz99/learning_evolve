    *   A random initialization might lead to infeasible starting points or poor convergence.
    *   We use a **hexagonal lattice** pattern to initialize the circle centers. Hexagonal packing is the densest known packing for equal circles, so starting near this configuration is advantageous.
    *   We assign a small initial radius (e.g., 0.04) to ensure all constraints are satisfied initially (no overlaps, inside boundaries).

3.  **Optimization**:
    *   We use `scipy.optimize.minimize` with the **SLSQP** (Sequential Least Squares Programming) method. SLSQP is well-suited for problems with inequality constraints and bounds.
    *   The variables are flattened into a single vector: $[x_1, y_1, r_1, x_2, y_2, r_2, \dots]$.
    *   The optimizer will iteratively adjust centers and radii to increase the sum of radii until the constraints become tight (circles touch each other or the boundaries).

4.  **Refinement & Creativity**:
    *   Unlike equal-circle packing problems, we allow radii to vary. This flexibility can sometimes yield a higher total sum of radii by allowing larger circles to dominate while smaller ones fill gaps, although for maximizing sum, circles tend to become roughly equal in size in optimal solutions.
    *   The optimization landscape is non-convex, so the initialization is crucial. The hexagonal start is a strong heuristic for high-density packings.

5.  **Constraints Implementation**:
    *   We define top-level helper functions for the objective and constraints to adhere to the rules (no closures, no lambdas).
    *   Boundary constraints are converted to $g(x) \ge 0$ form (e.g., $x - r \ge 0$).
    *   Overlap constraints are converted to $dist^2 - (r_i+r_j)^2 \ge 0$.
</strategy>

```python
import numpy as np
import scipy.optimize

# Helper functions must be top level and have no closures.

def calculate_objective(params):
    """
    Objective function: Maximize sum of radii => Minimize negative sum.
    params: array of shape (3*n) containing [x1, y1, r1, x2, y2, r2, ...]
    """
    # Radii are stored at indices 2, 5, 8, ... (step 3, start 2)
    radii = params[2::3]
    return -np.sum(radii)

def calculate_constraints(params):
    """
    Constraint function: Returns an array of values that must be >= 0.
    params: array of shape (3*n) containing [x1, y1, r1, x2, y2, r2, ...]
    """
    n = len(params) // 3
    xs = params[0::3]
    ys = params[1::3]
    rs = params[2::3]
    
    constraints = []
    
    # 1. Boundary Constraints
    # Circle i center (x, y) with radius r must satisfy:
    # x >= r  => x - r >= 0
    # x <= 1 - r => 1 - x - r >= 0
    # y >= r  => y - r >= 0
    # y <= 1 - r => 1 - y - r >= 0
    
    constraints.extend(xs - rs)
    constraints.extend(1.0 - xs - rs)
    constraints.extend(ys - rs)
    constraints.extend(1.0 - ys - rs)
    
    # 2. Non-overlap Constraints
    # For every pair (i, j), distance between centers >= r_i + r_j
    # Equivalent to: dist^2 >= (r_i + r_j)^2
    # Constraint: dist^2 - (r_i + r_j)^2 >= 0
    
    for i in range(n):
        for j in range(i + 1, n):
            dx = xs[i] - xs[j]
            dy = ys[i] - ys[j]
            dist_sq = dx * dx + dy * dy
            r_sum = rs[i] + rs[j]
            constraints.append(dist_sq - r_sum * r_sum)
            
    return np.array(constraints)

def run_packing() -> tuple[np.ndarray, np.ndarray, float]:
    """
    Main function to solve the circle packing problem.
    Returns (centers, radii, sum_radii).
    """
    n = 26
    
    # --- Initialization ---
    # We initialize with a hexagonal lattice pattern.
    # This is a good starting point because hexagonal packing has the highest density.
    # We use a small initial radius to ensure the configuration is valid (no overlaps).
    r_init = 0.04
    centers = np.zeros((n, 2))
    count = 0
    
    y = r_init
    row = 0
    # Generate hexagonal grid points
    while count < n:
        x = r_init
        # Offset every other row to create hexagonal structure
        offset = r_init if (row % 2 == 1) else 0.0
        
        while x + r_init <= 1.0 and count < n:
            centers[count] = [x + offset, y]
            count += 1
            x += 2.0 * r_init
        
        # Move to next row (vertical spacing in hexagonal packing is r * sqrt(3))
        y += r_init * np.sqrt(3)
        row += 1
        
    radii = np.full(n, r_init)
    
    # Flatten parameters into a vector for the optimizer
    # Order: x1, y1, r1, x2, y2, r2, ...
    initial_params = np.zeros(3 * n)
    for i in range(n):
        initial_params[3 * i] = centers[i, 0]
        initial_params[3 * i + 1] = centers[i, 1]
        initial_params[3 * i + 2] = radii[i]
        
    # Define bounds for variables
    # x, y in [0, 1]
    # r in [epsilon, 0.5]
    bounds = []
    for i in range(n):
        bounds.append((0.0, 1.0))
        bounds.append((0.0, 1.0))
        bounds.append((1e-9, 0.5))
    
    # Setup constraints for SLSQP solver
    # 'ineq' type requires function output >= 0
    constraint_dict = {
        'type': 'ineq',
        'fun': calculate_constraints
    }
    
    # Run Optimization
    # SLSQP (Sequential Least Squares Programming) is suitable for this problem
    result = scipy.optimize.minimize(
        fun=calculate_objective,
        x0=initial_params,
        method='SLSQP',
        bounds=bounds,
        constraints=constraint_dict,
        options={
            'maxiter': 5000,
            'ftol': 1e-12,
            'disp': False
        }
    )
    
    # Extract results
    optimal_params = result.x
    centers_opt = np.zeros((n, 2))
    radii_opt = np.zeros(n)
    
    for i in range(n):
        centers_opt[i, 0] = optimal_params[3 * i]
        centers_opt[i, 1] = optimal_params[3 * i + 1]
        radii_opt[i] = optimal_params[3 * i + 2]
        
    sum_radii = float(np.sum(radii_opt))
    
    return centers_opt, radii_opt, sum_radii
```
