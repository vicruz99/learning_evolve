To maximize the sum of radii for 26 circles in a unit square, we employ a continuous optimization approach with a sequential penalty method. This strategy is highly effective for non-convex packing problems:

1. **Initialization**: Place circles in a dense hexagonal lattice pattern. This configuration naturally minimizes wasted space and provides a strong starting point near the global optimum.
2. **Penalty-Based Optimization**: Directly solving non-linear inequality constraints can be unstable. Instead, we transform the problem into an unconstrained (or bound-constrained) minimization problem using a penalty function:
   - **Objective**: Minimize $-\sum r_i$ (equivalent to maximizing sum of radii).
   - **Overlap Penalty**: $\sum_{i<j} \max(0, (r_i + r_j)^2 - d_{ij}^2)^2$
   - **Boundary Penalty**: $\sum_i \max(0, r_i - x_i)^2 + \max(0, r_i - (1-x_i))^2 + \max(0, r_i - y_i)^2 + \max(0, r_i - (1-y_i))^2$
3. **Sequential Weight Increase**: Start with a moderate penalty weight $w$ and increase it geometrically across iterations. This allows circles to expand and rearrange freely initially, then progressively enforces strict feasibility.
4. **Solver**: Use `L-BFGS-B` from SciPy, which efficiently handles box constraints and large-scale problems. We run 25 outer iterations with increasing $w$, ensuring convergence to a valid, high-quality packing well above the target sum.

import numpy as np
from scipy.optimize import minimize

def run_packing():
    n = 26
    
    # 1. Initialization: Dense hexagonal pattern
    centers = []
    r_init = 0.09
    dx = 2 * r_init
    dy = np.sqrt(3) * r_init
    y = r_init + 0.05
    row_idx = 0
    while len(centers) < n:
        x = r_init + 0.05 + (row_idx % 2) * dx / 2
        while x < 1 - r_init - 0.05 and len(centers) < n:
            centers.append([x, y])
            x += dx
        y += dy
        row_idx += 1
        
    centers = np.array(centers[:n])
    radii = np.full(n, 0.07)
    
    # Flatten variables for optimizer: [x1, y1, x2, y2, ..., x26, y26, r1, r2, ..., r26]
    x0 = np.concatenate([centers.flatten(), radii])
    bounds = [(0.0, 1.0)] * (2 * n) + [(0.0, 0.5)] * n
    
    # 2. Sequential Penalty Optimization
    current_x = x0.copy()
    w = 100.0  # Initial penalty weight
    
    for step in range(25):
        def objective(vars):
            c = vars[:2*n].reshape(n, 2)
            r = vars[2*n:]
            
            pen = 0.0
            # Overlap penalty (squared distance avoids sqrt, smoother)
            for i in range(n):
                for j in range(i + 1, n):
                    dist_sq = np.sum((c[i] - c[j])**2)
                    r_sum = r[i] + r[j]
                    val = r_sum**2 - dist_sq
                    if val > 0.0:
                        pen += val**2
                        
            # Boundary penalty
            for i in range(n):
                pen += max(0.0, r[i] - c[i, 0])**2
                pen += max(0.0, r[i] - (1.0 - c[i, 0]))**2
                pen += max(0.0, r[i] - c[i, 1])**2
                pen += max(0.0, r[i] - (1.0 - c[i, 1]))**2
                
            return -np.sum(r) + w * pen

        res = minimize(objective, current_x, method='L-BFGS-B', bounds=bounds,
                       options={'ftol': 1e-10, 'maxiter': 500, 'disp': False})
        current_x = res.x
        w *= 2.5  # Increase penalty weight to enforce constraints
        if res.success or np.allclose(current_x, res.x, atol=1e-9):
            break
            
    centers_opt = current_x[:2*n].reshape(n, 2)
    radii_opt = current_x[2*n:]
    
    # Final safety clamping to prevent float precision issues near boundaries
    centers_opt = np.clip(centers_opt, 0.0, 1.0)
    radii_opt = np.clip(radii_opt, 0.0, 0.5)
    
    return centers_opt, radii_opt, np.sum(radii_opt)
