

To maximize the sum of radii for 26 circles in a unit square, we use a hybrid approach combining geometric initialization with linear programming and stochastic optimization. 

### Strategy
1. **Geometric Initialization**: We start with a hexagonal lattice configuration. Hexagonal packing is the most efficient way to arrange circles, providing a high-quality starting point for 26 items. We create rows of 6, 5, 6, 5, and 4 circles, offsetting odd rows to maximize space.
2. **Linear Programming (LP) for Radii**: For any fixed set of centers, the optimal radii can be found exactly. We define an LP to maximize the sum of radii ($\sum r_i$) subject to boundary and non-overlap constraints.
3. **Simulated Annealing**: We optimize the circle centers using a "Hill Climbing" approach. In each iteration, we perturb a random circle, recalculate optimal radii via LP, and accept the move if the sum of radii improves. A simulated annealing cooling schedule is used to help the optimization escape local minima.
4. **Validation**: The final solution is guaranteed to be valid because the LP constraints enforce the boundaries and distances, and our simulation keeps centers within $[0, 1]$.

```python
import numpy as np
from scipy.optimize import linprog

def solve_radii(centers):
    """Solves the LP to find optimal radii for a fixed set of centers."""
    n = len(centers)
    c = -np.ones(n) # Maximize sum of radii
    bounds = [(0, None) for _ in range(n)]
    A_ub = []
    b_ub = []

    # Boundary constraints: r_i <= x_i, 1-x_i, y_i, 1-y_i
    for i in range(n):
        x, y = centers[i]
        A_ub.extend([
            [0]*i + [1] + [0]*(n-i-1), # r_i <= x
            [0]*i + [1] + [0]*(n-i-1), # r_i <= 1-x
            [0]*i + [1] + [0]*(n-i-1), # r_i <= y
            [0]*i + [1] + [0]*(n-i-1)  # r_i <= 1-y
        ])
        b_ub.extend([x, 1 - x, y, 1 - y])

    # Separation constraints: r_i + r_j <= ||c_i - c_j||
    for i in range(n):
        for j in range(i + 1, n):
            dist = np.sqrt(np.sum((centers[i] - centers[j])**2))
            row = [0] * n
            row[i] = 1
            row[j] = 1
            A_ub.append(row)
            b_ub.append(dist)

    result = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
    if result.success:
        return result.x
    return np.zeros(n)

def run_packing() -> tuple[np.ndarray, np.ndarray, float]:
    np.random.seed(42)
    n = 26
    centers = np.zeros((n, 2))

    # 1. Hexagonal Initialization (6, 5, 6, 5, 4 pattern)
    row_counts = [6, 5, 6, 5, 4]
    x_base = 0.15
    y_base = 0.12
    idx = 0
    for r, count in enumerate(row_counts):
        offset = (x_base / 2) if (r % 2 == 1) else 0
        for c in range(count):
            centers[idx] = [x_base + c * x_base + offset, y_base + r * 0.15]
            idx += 1

    # 2. Simulated Annealing on Centers
    best_sum = 0.0
    best_centers = centers.copy()
    best_radii = np.zeros(n)

    temp = 0.1
    step_size = 0.05

    for i in range(5000):
        idx = np.random.randint(0, n)
        new_center = best_centers[idx] + np.random.uniform(-step_size, step_size, 2)
        new_center = np.clip(new_center, 0, 1)
        
        test_centers = best_centers.copy()
        test_centers[idx] = new_center
        
        radii = solve_radii(test_centers)
        current_sum = np.sum(radii)

        # Simulated Annealing acceptance
        if current_sum > best_sum or np.random.random() < np.exp((current_sum - best_sum) / temp):
            best_centers = test_centers
            best_radii = radii
            best_sum = current_sum
        
        # Cooling
        if i % 500 == 0 and i > 0:
            temp *= 0.8
            step_size *= 0.9

    return best_centers, best_radii, float(best_sum)
```
