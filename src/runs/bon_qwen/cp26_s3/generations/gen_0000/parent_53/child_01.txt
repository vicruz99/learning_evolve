

<strategy>
We formulate the circle packing problem as a constrained non-linear optimization problem. The goal is to maximize the sum of radii $\sum r_i$, which is equivalent to minimizing $-\sum r_i$. The constraints ensure that each circle lies within the unit square and that no two circles overlap. Specifically:
1. Boundary constraints: $x_i \ge r_i$, $1-x_i \ge r_i$, $y_i \ge r_i$, $1-y_i \ge r_i$.
2. Non-overlap constraints: $(x_i-x_j)^2 + (y_i-y_j)^2 \ge (r_i+r_j)^2$ for all $i < j$.

We use `scipy.optimize.minimize` with the `SLSQP` method, which handles inequality constraints efficiently. To avoid local minima, we run the optimization with 5 different random seeds, initializing the centers on a perturbed regular grid and radii at a small feasible value. The best result across all runs is returned. A small safety clamp ensures radii remain non-negative. This approach is robust and typically converges to a high-quality packing for $N=26$.

```python
import numpy as np
from scipy.optimize import minimize

N_CIRCLES = 26

def objective(vars):
    radii = vars[N_CIRCLES*2:]
    return -np.sum(radii)

def constraints_func(vars):
    centers = vars[:N_CIRCLES*2].reshape(N_CIRCLES, 2)
    radii = vars[N_CIRCLES*2:]
    
    c = []
    # Boundary constraints: distance to each edge must be >= radius
    for i in range(N_CIRCLES):
        c.append(centers[i, 0] - radii[i])
        c.append(1.0 - centers[i, 0] - radii[i])
        c.append(centers[i, 1] - radii[i])
        c.append(1.0 - centers[i, 1] - radii[i])
        
    # Pairwise non-overlap constraints: distance >= sum of radii
    for i in range(N_CIRCLES):
        for j in range(i+1, N_CIRCLES):
            dx = centers[i, 0] - centers[j, 0]
            dy = centers[i, 1] - centers[j, 1]
            dist_sq = dx*dx + dy*dy
            c.append(dist_sq - (radii[i] + radii[j])**2)
            
    return np.array(c)

def run_packing():
    # Bounds: x, y in [0, 1], r in [0, 0.5]
    bounds = [(0.0, 1.0)]*(N_CIRCLES*2) + [(0.0, 0.5)]*N_CIRCLES
    cons = {'type': 'ineq', 'fun': constraints_func}
    
    best_sum_r = -np.inf
    best_centers = None
    best_radii = None
    
    # Multiple restarts to escape local minima
    for seed in range(5):
        rng = np.random.RandomState(seed)
        
        # Generate a structured grid initialization
        grid_pts = []
        step = 0.15
        for i in range(int(1/step) + 1):
            for j in range(int(1/step) + 1):
                x = step/2 + i*step
                y = step/2 + j*step
                if x < 1 and y < 1:
                    grid_pts.append([x, y])
                    
        init_centers = np.array(grid_pts[:N_CIRCLES])
        # Add small random perturbation
        init_centers += rng.randn(N_CIRCLES, 2) * 0.02
        init_centers = np.clip(init_centers, 0.05, 0.95)
        
        init_radii = np.full(N_CIRCLES, 0.05)
        x0 = np.concatenate([init_centers.flatten(), init_radii])
        
        res = minimize(objective, x0, method='SLSQP', bounds=bounds, 
                       constraints=cons, options={'maxiter': 500, 'ftol': 1e-12, 'disp': False})
        
        if not np.isnan(res.fun) and -res.fun > best_sum_r:
            best_sum_r = -res.fun
            best_centers = res.x[:N_CIRCLES*2].reshape(N_CIRCLES, 2)
            best_radii = res.x[N_CIRCLES*2:]
            
    # Safety clamp to ensure strictly non-negative radii
    best_radii = np.maximum(best_radii, 1e-12)
    
    return best_centers, best_radii, float(np.sum(best_radii))
```
