The problem of packing 26 circles in a unit square to maximize the sum of radii is a classic non-convex optimization problem. The theoretical maximum for equal radii is approximately $r \approx 0.1014$, yielding a sum of $\approx 2.636$. Since maximizing the sum of radii for a fixed area constraint is optimized when all radii are equal (by Cauchy-Schwarz), the solution will naturally converge to nearly equal radii arranged in a dense lattice (hexagonal packing).

Strategy:
1. **Penalty-Based Optimization**: Formulate the problem as minimizing $-\sum r_i$ subject to boundary and non-overlap constraints. Instead of using hard constraints which can cause optimizer failures, I use a quadratic penalty method. The penalty function adds large costs when circles overlap or cross boundaries.
2. **Continuation Method**: Start with a small penalty weight $\mu$ to allow the optimizer to freely explore configurations and expand circles. Gradually increase $\mu$ over iterations to tightly enforce constraints, driving the solution to a valid packing.
3. **Multiple Random Restarts**: Initialize circles on a perturbed grid for several restarts to escape local minima. L-BFGS-B is used due to its efficiency with bound-constrained problems.
4. **Safety Post-Processing**: After optimization, a deterministic shrinkage loop guarantees that the returned configuration strictly satisfies the validation criteria (within numerical tolerance), preventing edge-case failures.
5. **Vectorization**: Pairwise distance and overlap calculations are vectorized using NumPy broadcasting for speed, avoiding slow Python loops during the optimization phase.

import numpy as np
from scipy.optimize import minimize

def compute_objective(Z, n, mu):
    """
    Computes the objective function: negative sum of radii plus penalty terms.
    """
    centers = Z[:2*n].reshape(n, 2)
    radii = Z[2*n:]
    
    # Objective: maximize sum of radii -> minimize negative sum
    obj = -np.sum(radii)
    
    # Boundary penalties: circles must stay within [0,1]x[0,1]
    # Penalty applied if radius extends beyond boundaries
    obj += mu * np.sum(np.maximum(0.0, radii - centers[:, 0])**2)
    obj += mu * np.sum(np.maximum(0.0, radii - (1.0 - centers[:, 0]))**2)
    obj += mu * np.sum(np.maximum(0.0, radii - centers[:, 1])**2)
    obj += mu * np.sum(np.maximum(0.0, radii - (1.0 - centers[:, 1]))**2)
    
    # Overlap penalties: circles must not overlap
    # Vectorized pairwise distance calculation
    diff = centers[:, np.newaxis, :] - centers[np.newaxis, :, :]
    dists = np.linalg.norm(diff, axis=2)
    
    r_sum = radii[:, np.newaxis] + radii[np.newaxis, :]
    # Ignore self-interaction
    np.fill_diagonal(r_sum, 0.0)
    np.fill_diagonal(dists, np.inf)
    
    overlaps = np.maximum(0.0, r_sum - dists)
    obj += mu * np.sum(overlaps**2)
    
    return obj

def run_packing():
    np.random.seed(42)
    n = 26
    best_sum_r = 0.0
    best_centers = None
    best_radii = None
    
    # Multiple restarts to find global optimum
    for restart in range(8):
        # Initialize positions on a grid with perturbation
        positions = np.zeros((n, 2))
        for i in range(n):
            row = i // 5
            col = i % 5
            positions[i, 0] = (col + 0.5) / 5.0
            positions[i, 1] = (row + 0.5) / 5.0
            if i >= 25:
                positions[i, 0] = 0.5 + 0.1 * np.random.randn()
                positions[i, 1] = 0.5 + 0.1 * np.random.randn()
        
        # Add random jitter and clip to feasible region
        positions += np.random.uniform(-0.03, 0.03, positions.shape)
        positions = np.clip(positions, 0.1, 0.9)
        
        radii_init = np.full(n, 0.04)
        x0 = np.concatenate([positions.flatten(), radii_init])
        
        bounds = [(0.0, 1.0)] * (2*n) + [(0.0, 0.5)] * n
        
        # Continuation method: gradually increase penalty weight
        mu = 100.0
        Z = x0.copy()
        
        for step in range(30):
            res = minimize(compute_objective, Z, args=(n, mu), method='L-BFGS-B', 
                           bounds=bounds, options={'maxiter': 500, 'ftol': 1e-15})
            Z = res.x
            mu *= 1.5
            if step > 20:
                break
                
        centers = Z[:2*n].reshape(n, 2)
        radii = Z[2*n:]
        
        # Ensure bounds are respected
        centers = np.clip(centers, 0.0, 1.0)
        radii = np.clip(radii, 0.0, 0.5)
        
        current_sum = np.sum(radii)
        if current_sum > best_sum_r:
            best_sum_r = current_sum
            best_centers = centers.copy()
            best_radii = radii.copy()
            
    # Post-processing safeguard to guarantee strict validity
    shrink_factor = 0.995
    for _ in range(50):
        valid = True
        for i in range(n):
            x, y = best_centers[i]
            r = best_radii[i]
            if x - r < 0 or x + r > 1 or y - r < 0 or y + r > 1:
                valid = False
                break
            for j in range(i + 1, n):
                dist = np.linalg.norm(best_centers[i] - best_centers[j])
                if dist < best_radii[i] + best_radii[j] - 1e-10:
                    valid = False
                    break
            if not valid:
                break
                
        if valid:
            break
        best_radii *= shrink_factor

    best_radii = np.maximum(best_radii, 0.0)
    return best_centers, best_radii, np.sum(best_radii)
