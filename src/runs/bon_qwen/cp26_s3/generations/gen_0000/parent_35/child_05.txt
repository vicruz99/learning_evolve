The objective is to pack 26 circles in a unit square to maximize the sum of their radii. This is a non-convex optimization problem because the feasible region for radii depends on the Euclidean distances between centers.

The strategy involves a two-level optimization approach:
1.  **Inner Optimization (LP):** For any fixed set of center coordinates, the problem of finding the optimal radii becomes a Linear Programming (LP) problem. We maximize the sum of radii subject to pairwise distance constraints ($r_i + r_j \le d_{ij}$) and boundary constraints ($r_i \le \min(x_i, 1-x_i, y_i, 1-y_i)$). This can be solved efficiently using `scipy.optimize.linprog`.
2.  **Outer Optimization (Heuristic Search):** We need to find the center coordinates that maximize the output of the inner LP. Since the objective landscape is rugged and non-smooth, we use a global optimization strategy. We will generate a hexagonal lattice as a robust initial configuration (as hexagonal packing is known to be dense) and then refine the positions using a custom hill-climbing algorithm with simulated annealing characteristics to escape local optima.

The code will include:
-   `solve_radii`: The LP solver for a given set of centers.
-   `evaluate`: Computes the objective function (sum of radii).
-   `optimize_centers`: The main optimization loop. It starts with a hexagonal grid, then iteratively perturbs circle positions to improve the packing.

def solve_radii(centers):
    """
    Solves the LP to find optimal radii for fixed centers.
    Maximizes sum(r_i) subject to r_i + r_j <= dist(i,j) and boundary constraints.
    """
    n = centers.shape[0]
    c = np.ones(n) * -1  # Maximize sum(r) -> Minimize -sum(r)
    
    A_ub = []
    b_ub = []
    
    # Boundary constraints: r_i <= min(x_i, 1-x_i, y_i, 1-y_i)
    for i in range(n):
        x, y = centers[i]
        row = np.zeros(n)
        row[i] = 1
        
        # r_i <= x
        A_ub.append(row)
        b_ub.append(x)
        
        # r_i <= 1-x
        A_ub.append(row)
        b_ub.append(1 - x)
        
        # r_i <= y
        A_ub.append(row)
        b_ub.append(y)
        
        # r_i <= 1-y
        A_ub.append(row)
        b_ub.append(1 - y)
        
    # Pairwise constraints: r_i + r_j <= dist(i, j)
    for i in range(n):
        for j in range(i + 1, n):
            dist = np.sqrt(np.sum((centers[i] - centers[j])**2))
            row = np.zeros(n)
            row[i] = 1
            row[j] = 1
            A_ub.append(row)
            b_ub.append(dist)
            
    A_ub = np.array(A_ub)
    b_ub = np.array(b_ub)
    
    bounds = [(0, None) for _ in range(n)]
    
    # Use 'highs' solver if available, it's fast. fallback to simplex.
    try:
        res = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
    except ValueError:
        res = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='simplex')
        
    if res.success:
        radii = res.x
        # Ensure non-negative (numerical noise)
        radii = np.maximum(radii, 0)
        return radii
    else:
        # Fallback to zero radii if LP fails (shouldn't happen with valid centers)
        return np.zeros(n)
