### Strategy

2. **Radii Calculation:** For any given center configuration, we calculate the "tightest" valid radius for each circle based on its distance to the four boundaries and its 25 nearest neighbors.
3. **Dual-Stage Optimization:**
    *   **Stage 1 (Repulsion):** We use a gradient-descent-based repulsion algorithm. Circles are "pushed" apart from each other and the boundaries to expand the gaps between them, allowing for larger radii.
    *   **Stage 2 (Expansion):** We iteratively increase all radii. When circles overlap, we apply repulsive forces proportional to the overlap depth to resolve conflicts while maintaining the expanded layout from Stage 1.
4. **Result Refinement:** The final configuration is sorted by radius and rounded to ensure numerical stability before validation.

def generate_initial_config(n=26):

            x = r_init + i * (2 * r_init)

            if x + r_init <= 1.0:
                centers[idx] = [x, y]
                idx += 1
        y += r_init * np.sqrt(3)

    if idx < n:
        centers[idx] = [0.5, 0.5]
        idx += 1
    return centers

        # Check pairwise distances
        for j in range(i + 1, n):

            max_r_pair = dist / 2.0
            radii[i] = min(radii[i], max_r_pair)
            radii[j] = min(radii[j], max_r_pair)
    return radii
