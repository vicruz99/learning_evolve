To pack 26 circles in a unit square maximizing the sum of radii, we employ a penalized optimization approach with variable transformation to handle boundary constraints naturally.

1. **Variable Transformation**: Instead of optimizing $(x_i, y_i, r_i)$ directly, we parameterize centers as:
   $x_i = r_i + (1 - 2r_i)u_i$, $y_i = r_i + (1 - 2r_i)v_i$
   where $u_i, v_i \in [0,1]$. This guarantees $r_i \le x_i \le 1-r_i$ automatically, removing 4 boundary constraints per circle from the explicit optimization.

2. **Initialization**: We start with a hexagonal-like lattice distribution scaled to fit within $[0.1, 0.9]^2$, ensuring good initial spacing. Initial radii are set small ($0.01$) to allow room for expansion.

3. **Penalty Method**: We maximize $\sum r_i$ by minimizing $-\sum r_i + \lambda \sum_{i<j} \max(0, r_i+r_j - \|c_i-c_j\|)^2$. The penalty weight $\lambda$ starts moderate and increases geometrically (continuation method). This forces the solver to gradually enforce non-overlap while expanding radii.

4. **Solver**: `scipy.optimize.minimize` with `L-BFGS-B` handles the box constraints on $u,v,r$ efficiently. The vectorized pairwise distance computation ensures fast gradient evaluations.

5. **Post-processing**: A strict feasibility check scales down radii slightly if any numerical overlaps persist, and clips centers to maintain boundary validity. This guarantees the returned packing passes the validation function with margin.

import numpy as np
from scipy.optimize import minimize

def compute_state(z, n):
    """Recover centers and radii from optimization variables."""
    u = z[0::3]
    v = z[1::3]
    r = z[2::3]
    # Transformation ensures r <= x <= 1-r and r <= y <= 1-r
    x = r + (1.0 - 2.0 * r) * u
    y = r + (1.0 - 2.0 * r) * v
    return np.column_stack((x, y)), r

def obj_func(z, n, pairs, lam):
    """Objective: minimize negative sum of radii + overlap penalty."""
    centers, radii = compute_state(z, n)
    val = -np.sum(radii)
    
    # Vectorized pairwise distance and overlap calculation
    ci = centers[pairs[0]]
    cj = centers[pairs[1]]
    ri = radii[pairs[0]]
    rj = radii[pairs[1]]
    
    dx = ci[:, 0] - cj[:, 0]
    dy = ci[:, 1] - cj[:, 1]
    dist = np.sqrt(dx*dx + dy*dy)
    
    overlap = ri + rj - dist
    # Smooth-ish penalty to avoid sharp kinks at zero
    val += lam * np.sum(np.maximum(0.0, overlap)**2)
    return val

def run_packing():
    np.seterr(all='ignore')
    n = 26
    pairs = np.triu_indices(n, k=1)
    
    # Hexagonal-ish lattice initialization
    np.random.seed(42)
    pts = np.zeros((n, 2))
    idx = 0
    for i in range(7):
        for j in range(6):
            if idx >= n: break
            x = 0.05 + j * 0.18 + (i % 2) * 0.09
            y = 0.05 + i * 0.18 * 0.866
            if x < 0.95 and y < 0.95:
                pts[idx] = [x, y]
                idx += 1
        if idx >= n: break
    # Fill remaining slots if lattice doesn't cover exactly 26
    while idx < n:
        pts[idx] = [np.random.rand() * 0.8 + 0.1, np.random.rand() * 0.8 + 0.1]
        idx += 1
        
    # Map to normalized coordinates u, v in [0,1]
    u0 = np.clip((pts[:, 0] - 0.02) / 0.96, 0.0, 1.0)
    v0 = np.clip((pts[:, 1] - 0.02) / 0.96, 0.0, 1.0)
    r0 = np.full(n, 0.01)
    
    z0 = np.zeros(3 * n)
    z0[0::3] = u0
    z0[1::3] = v0
    z0[2::3] = r0
    
    # Bounds: u,v in [0,1], r in [small, max_possible]
    bounds = [(0.0, 1.0)] * (2 * n) + [(1e-5, 0.45)] * n
    
    lam = 50.0
    z_curr = z0.copy()
    
    # Continuation method: gradually increase penalty weight
    for _ in range(25):
        res = minimize(obj_func, z_curr, args=(n, pairs, lam),
                       method='L-BFGS-B', bounds=bounds,
                       options={'maxiter': 4000, 'ftol': 1e-11, 'gtol': 1e-9})
        z_curr = res.x
        lam *= 1.4
        
    centers, radii = compute_state(z_curr, n)
    
    # Strict feasibility enforcement
    dists = np.sqrt(np.sum((centers[pairs[0]] - centers[pairs[1]])**2, axis=1))
    min_req = radii[pairs[0]] + radii[pairs[1]]
    violations = min_req - dists
    
    if np.any(violations > 1e-7):
        # Scale down radii proportionally to clear overlaps
        max_v = np.max(violations)
        radii *= (1.0 - max_v * 1.01)
        # Re-project centers to respect boundaries with new radii
        centers = np.clip(centers, radii[:, None], 1.0 - radii[:, None])
        
    return centers, radii, float(np.sum(radii))
