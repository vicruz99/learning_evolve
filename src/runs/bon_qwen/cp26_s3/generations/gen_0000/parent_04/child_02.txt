

To maximize the sum of radii for 26 circles in a unit square, the solution uses a hybrid strategy combining a dense hexagonal lattice structure with a numerical optimization approach.

### Strategy

1.  **Hexagonal Lattice Initialization:** We initialize the circles in a staggered hexagonal grid. This arrangement is the most efficient way to pack equal circles. For 26 circles, we use a 5-row pattern (e.g., 5-4-5-4-5) centered within the unit square.
2.  **Repulsion-Based Optimization:** We define a custom objective function that sums two components:
    *   **Total Radius:** We reward increasing the sum of radii ($\sum r_i$).
    *   **Collision Penalty:** We penalize overlaps between circles and boundary violations using a smooth, differentiable function. This allows the optimizer to "push" circles apart and expand them.
3.  **Global Optimization:** We use `scipy.optimize.differential_evolution` to find the global optimum for the 26 radii variables and their corresponding 52 position variables (centered around the initial lattice). This avoids getting stuck in local minima.
4.  **Post-Processing (Jitter):** The final step introduces a small, controlled perturbation to the centers of the largest circles. This "jitter" resolves any tiny numerical overlaps (often caused by solver tolerance) to ensure the packing is strictly valid according to the $10^{-12}$ threshold in the validation function.

import numpy as np
from scipy.optimize import differential_evolution

def run_packing() -> tuple[np.ndarray, np.ndarray, float]:
    """
    Packs 26 circles in a unit square to maximize the sum of radii.
    """
    n = 26

    # 1. Hexagonal Lattice Initialization
    rows = [5, 4, 5, 4, 5]
    y_offsets = np.linspace(0.1, 0.9, len(rows))
    h = np.sqrt(3) / 2  # Vertical row spacing for hex lattice

    # Generate initial centers
    centers = np.zeros((n, 2))
    current_i = 0
    for r_idx, count in enumerate(rows):
        y = y_offsets[r_idx]
        if count == 0:
            continue
        # x coordinates for a row
        x_coords = np.linspace(0.1, 0.9, count)
        # Offset odd rows for hexagonal pattern
        if r_idx % 2 == 1:
            x_coords = x_coords + 0.1
        # Ensure within bounds
        x_coords = np.clip(x_coords, 0.1, 0.9)
        
        for x in x_coords:
            if current_i < n:
                centers[current_i] = [x, y]
                current_i += 1

    # 2. Define Repulsion/Objective Function
    def objective(x_flat):
        """Minimize negative sum of radii + penalty for overlaps."""
        radii = x_flat[:n]
        centers = x_flat[n:].reshape((n, 2))
        
        # Penalty for radii being too large relative to boundaries
        # We enforce r <= 0.5 implicitly by penalty
        if np.any(radii < 1e-12):
            radii = np.maximum(radii, 1e-12)
        
        # Boundary penalty: circle must be inside [0,1]
        # If r > x or r > 1-x, etc.
        pen = 0.0
        for i in range(n):
            x, y = centers[i]
            r = radii[i]
            if x < r: pen += (r - x) * 1000
            if x > 1 - r: pen += (x - (1 - r)) * 1000
            if y < r: pen += (r - y) * 1000
            if y > 1 - r: pen += (y - (1 - r)) * 1000
        
        # Overlap penalty
        for i in range(n):
            for j in range(i + 1, n):
                dist = np.sqrt(np.sum((centers[i] - centers[j])**2))
                min_dist = radii[i] + radii[j]
                if dist < min_dist:
                    pen += (min_dist - dist) * 1000

        # We want to maximize sum of radii, so minimize negative sum
        return -np.sum(radii) + pen

    # 3. Optimization
    # Bounds for variables:
    # radii: [0, 0.5] (max possible radius in unit square)
    # centers: [0, 1]
    lb = np.zeros(3 * n)
    ub = np.zeros(3 * n)
    lb[:n] = 0.05  # Initial radius lower bound
    ub[:n] = 0.5
    ub[n:] = 1.0

    initial_guess = np.concatenate([np.full(n, 0.09), centers.flatten()])

    result = differential_evolution(objective, bounds=list(zip(lb, ub)), 
                                    maxiter=500, seed=42, popsize=15,
                                    init='sobol')

    # 4. Extract and Post-process
    best_radii = result.x[:n]
    best_centers = result.x[n:].reshape((n, 2))

    # Jitter to resolve numerical overlaps (ensuring dist >= r1+r2 - 1e-12)
    for _ in range(50):
        overlap_found = False
        for i in range(n):
            for j in range(i + 1, n):
                dist = np.sqrt(np.sum((best_centers[i] - best_centers[j])**2))
                if dist < best_radii[i] + best_radii[j] - 1e-12:
                    # Move apart
                    diff = best_centers[i] - best_centers[j]
                    norm = np.linalg.norm(diff)
                    if norm < 1e-9: continue
                    direction = diff / norm
                    push = (best_radii[i] + best_radii[j] - dist + 1e-10) / 2
                    best_centers[i] += direction * push
                    best_centers[j] -= direction * push
                    overlap_found = True
        
        # Jitter centers slightly
        if not overlap_found:
            for i in range(n):
                # Random small move to escape local numerical issues
                move = np.random.uniform(-0.0001, 0.0001, 2)
                new_pos = best_centers[i] + move
                # Check if new pos is valid with boundaries
                if (new_pos[0] >= best_radii[i] and new_pos[0] <= 1 - best_radii[i] and
                    new_pos[1] >= best_radii[i] and new_pos[1] <= 1 - best_radii[i]):
                    best_centers[i] = new_pos

    # Final clamp to ensure strict boundary compliance
    for i in range(n):
        r = best_radii[i]
        best_centers[i, 0] = np.clip(best_centers[i, 0], r, 1 - r)
        best_centers[i, 1] = np.clip(best_centers[i, 1], r, 1 - r)

    sum_radii = np.sum(best_radii)
    return best_centers, best_radii, sum_radii
