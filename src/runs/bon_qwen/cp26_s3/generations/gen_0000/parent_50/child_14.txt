### 1. Initialization
We initialize the 26 circles using a hexagonal grid pattern. This arrangement is geometrically optimal for packing density. We start with a radius of 0.05 to ensure the circles are non-overlapping and within the unit square boundaries.

### 2. Formulation
The problem is formulated as a non-linear programming task:
- **Objective**: Maximize the sum of radii ($\sum r_i$).
- **Variables**: $(x_i, y_i, r_i)$ for each of the 26 circles.
- **Constraints**:
    - **Boundary**: $r_i \le x_i \le 1-r_i$ and $r_i \le y_i \le 1-r_i$.
    - **Non-overlap**: $(x_i - x_j)^2 + (y_i - y_j)^2 \ge (r_i + r_j)^2$ for all $i \neq j$.

We use the Sequential Least Squares Programming (SLSQP) method from `scipy.optimize`. This method effectively handles the linear boundary constraints and the quadratic non-overlap constraints. The solver adjusts centers and radii simultaneously to find a local maximum where circles are as large as possible while touching neighbors or boundaries.

import numpy as np
from scipy.optimize import minimize

def run_packing() -> tuple[np.ndarray, np.ndarray, float]:
    n = 26
    
    # 1. Initial Configuration: Hexagonal Grid
    # Start with a small radius to guarantee a feasible initial state
    r_init = 0.05
    centers = []
    dx = 2 * r_init
    dy = r_init * np.sqrt(3)
    
    y = r_init
    row = 0
    # Generate points until we have at least 26
    while len(centers) < n:
        if row % 2 == 0:
            x = r_init
        else:
            x = 2 * r_init # Shift for hexagonal packing
        while x <= 1 - r_init:
            centers.append([x, y])
            x += dx
        y += dy
        row += 1
    
    centers = np.array(centers[:n])
    radii = np.full(n, r_init)
    
    # Flatten variables: [x1, y1, r1, x2, y2, r2, ...]
    x0 = np.zeros(3 * n)
    for i in range(n):
        x0[3*i] = centers[i, 0]
        x0[3*i+1] = centers[i, 1]
        x0[3*i+2] = radii[i]
        
    # 2. Optimization Setup
    # Objective: Maximize sum of radii (minimize negative sum)
    def objective(vars):
        return -np.sum(vars[2::3])
    
    # Bounds: x, y in [0, 1], r in [0, 0.5]
    bounds = []
    for i in range(n):
        bounds.extend([(0, 1), (0, 1), (0, 0.5)])
        
    # Constraints
    cons = []
    
    # Linear boundary constraints: r <= x <= 1-r, r <= y <= 1-r
    for i in range(n):
        idx = 3*i
        # x - r >= 0
        cons.append({'type': 'ineq', 'fun': lambda v, i=i: v[idx] - v[idx+2]})
        # 1 - x - r >= 0
        cons.append({'type': 'ineq', 'fun': lambda v, i=i: 1 - v[idx] - v[idx+2]})
        # y - r >= 0
        cons.append({'type': 'ineq', 'fun': lambda v, i=i: v[idx+1] - v[idx+2]})
        # 1 - y - r >= 0
        cons.append({'type': 'ineq', 'fun': lambda v, i=i: 1 - v[idx+1] - v[idx+2]})
        
    # Non-overlap constraints: dist^2 >= (r_i + r_j)^2
    for i in range(n):
        idx_i = 3*i
        for j in range(i + 1, n):
            idx_j = 3*j
            def overlap_con(v, i=i, j=j):
                xi, yi, ri = v[idx_i], v[idx_i+1], v[idx_i+2]
                xj, yj, rj = v[idx_j], v[idx_j+1], v[idx_j+2]
                return (xi - xj)**2 + (yi - yj)**2 - (ri + rj)**2
            cons.append({'type': 'ineq', 'fun': overlap_con})
            
    # 3. Run Optimization
    res = minimize(objective, x0, method='SLSQP', bounds=bounds, constraints=cons, 
                   options={'maxiter': 2000, 'ftol': 1e-12})
    
    # 4. Extract and Return Results
    best_vars = res.x
    final_centers = best_vars.reshape(n, 3)[:, :2]
    final_radii = best_vars.reshape(n, 3)[:, 2]
    
    return final_centers, final_radii, np.sum(final_radii)
