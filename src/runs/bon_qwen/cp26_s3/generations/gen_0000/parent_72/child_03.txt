The problem is a non-convex optimization task, but it can be decomposed effectively using an iterative approach combining Linear Programming (LP) and gradient-based center adjustment.

Strategy:
1.  **Decomposition**: For any fixed set of centers, the problem of finding optimal radii is a Linear Programming (LP) problem. We maximize $\sum r_i$ subject to $r_i + r_j \le \text{dist}(c_i, c_j)$ and boundary constraints $r_i \le \text{dist}(c_i, \text{boundary})$.
2.  **Dual Information**: The solution to the LP provides "shadow prices" (dual variables) for each constraint. These values indicate how much the objective (sum of radii) would improve if we relaxed a specific constraint (e.g., moved centers further apart or moved boundaries).
3.  **Iterative Refinement**:
    *   Initialize centers in a grid-like pattern.
    *   Solve the LP to get radii and dual variables.
    *   Calculate forces on each center based on the dual variables. Active constraints (where circles are touching or hitting walls) exert forces pushing centers apart or towards open space to allow radii to grow.
    *   Update centers using these forces.
    *   Repeat until convergence.
4.  **Implementation**: Use `scipy.optimize.linprog` for the LP steps and NumPy for vectorized force calculations. This approach efficiently navigates the configuration space to find a near-optimal packing.

This method leverages the structure of the problem (linear constraints on radii for fixed positions) to guide the non-linear optimization of positions.

import numpy as np
from scipy.optimize import linprog

def solve_lp(centers):
    """
    Given centers, solve LP to find radii maximizing sum(radii).
    Returns radii and dual variables (marginals).
    """
    n = len(centers)
    # Objective: maximize sum(r_i) => minimize -sum(r_i)
    c = -np.ones(n)
    
    # Constraints: A_ub @ r <= b_ub
    # 1. Boundary constraints for each circle i
    # r_i <= x_i
    # r_i <= 1 - x_i
    # r_i <= y_i
    # r_i <= 1 - y_i
    
    # We will build A_ub and b_ub row by row
    # To be efficient, we can preallocate, but for N=26 it's small.
    
    # Boundary constraints: 4 per circle
    A_ub_boundary = np.zeros((4 * n, n))
    b_ub_boundary = np.zeros(4 * n)
    
    for i in range(n):
        x, y = centers[i]
        row_idx_base = 4 * i
        
        # r_i <= x_i
        A_ub_boundary[row_idx_base, i] = 1.0
        b_ub_boundary[row_idx_base] = x
        
        # r_i <= 1 - x_i
        A_ub_boundary[row_idx_base + 1, i] = 1.0
        b_ub_boundary[row_idx_base + 1] = 1.0 - x
        
        # r_i <= y_i
        A_ub_boundary[row_idx_base + 2, i] = 1.0
        b_ub_boundary[row_idx_base + 2] = y
        
        # r_i <= 1 - y_i
        A_ub_boundary[row_idx_base + 3, i] = 1.0
        b_ub_boundary[row_idx_base + 3] = 1.0 - y

    # 2. Pairwise constraints: r_i + r_j <= dist(i, j)
    # Number of pairs
    n_pairs = n * (n - 1) // 2
    A_ub_pairwise = np.zeros((n_pairs, n))
    b_ub_pairwise = np.zeros(n_pairs)
    
    pair_indices = [] # To map back (i, j) to row index if needed, but we iterate
    
    p_idx = 0
    for i in range(n):
        for j in range(i + 1, n):
            dist = np.sqrt(np.sum((centers[i] - centers[j]) ** 2))
            
            # Row for r_i + r_j <= dist
            row = np.zeros(n)
            row[i] = 1.0
            row[j] = 1.0
            A_ub_pairwise[p_idx] = row
            b_ub_pairwise[p_idx] = dist
            
            pair_indices.append((i, j))
            p_idx += 1
            
    A_ub = np.vstack([A_ub_boundary, A_ub_pairwise])
    b_ub = np.concatenate([b_ub_boundary, b_ub_pairwise])
    
    # Bounds for radii: 0 <= r_i <= 0.5
    bounds = [(0, 0.5) for _ in range(n)]
    
    # Solve LP
    # Use 'highs' method which is robust and fast
    try:
        res = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
        if res.success:
            # Dual variables (marginals) correspond to the constraints in A_ub
            # Marginals are non-negative for <= constraints in minimization
            # A positive marginal means the constraint is active and binding the objective
            radii = res.x
            duals = res.ineqlin.marginals
            return radii, duals
        else:
            # Fallback to zero radii if LP fails
            return np.zeros(n), np.zeros(len(b_ub))
    except Exception:
        return np.zeros(n), np.zeros(len(b_ub))

def run_packing() -> tuple[np.ndarray, np.ndarray, float]:
    n = 26
    
    # 1. Initialization: Hexagonal-like grid or dense grid
    # We try to pack points somewhat evenly.
    # A 5x6 grid has 30 points, we need 26.
    # Let's place them in rows.
    
    centers = np.zeros((n, 2))
    idx = 0
    
    # Strategy: 6 rows.
    # Row lengths roughly 5, 4, 5, 4, 5, 3 (sum 26)
    # Or just fill a grid and pick first 26.
    
    # Let's use a grid that covers the square well
    # 5 columns, 6 rows? 
    # x in [0, 1], y in [0, 1]
    # To avoid boundary issues initially, keep some margin
    
    ny = 6
    nx = 5
    # Generate grid points
    ys = np.linspace(1/12, 11/12, ny) # 12 segments
    xs = np.linspace(1/10, 9/10, nx) # 10 segments
    
    # Fill centers
    count = 0
    for y in ys:
        for x in xs:
            if count < n:
                centers[count] = [x, y]
                count += 1
            else:
                break
        if count >= n: break
            
    # 2. Optimization Loop
    # We iterate: solve LP for radii -> compute forces on centers -> move centers
    
    current_centers = centers.copy()
    
    # Mapping for pairwise constraints indices
    # Constraints 0 to 4n-1 are boundary
    # Constraints 4n to end are pairwise
    num_boundary = 4 * n
    
    # Precompute pair indices mapping? 
    # We can just iterate and track index, but storing map is faster?
    # With N=26, iterating 325 pairs is cheap.
    
    best_sum_r = 0.0
    best_centers = None
    best_radii = None
    
    # Optimization parameters
    lr = 0.02 # Learning rate
    momentum = 0.5
    
    # Preallocate force array
    forces = np.zeros_like(current_centers)
    prev_centers = current_centers.copy()
    
    # Number of iterations
    n_iterations = 2000
    
    for step in range(n_iterations):
        # Solve LP
        radii, duals = solve_lp(current_centers)
        
        if radii is None:
            break
            
        current_sum = np.sum(radii)
        
        # Track best solution
        if current_sum > best_sum_r:
            best_sum_r = current_sum
            best_centers = current_centers.copy()
            best_radii = radii.copy()
            
        # Compute Forces
        forces[:] = 0.0
        
        # 1. Boundary Forces
        # Constraints: r_i <= x, r_i <= 1-x, r_i <= y, r_i <= 1-y
        # Marginals: lambda_left, lambda_right, lambda_bottom, lambda_top
        # Forces:
        # x-force += lambda_left - lambda_right
        # y-force += lambda_bottom - lambda_top
        
        # Reshape duals for easier access? Or just index
        # duals array is flat.
        
        # We can vectorize boundary forces
        # Indices 0..4n-1
        # For circle i: 4i, 4i+1, 4i+2, 4i+3
        
        # Extract marginals for boundaries
        m = duals[:num_boundary].reshape(n, 4)
        
        # m[:, 0] is r <= x
        # m[:, 1] is r <= 1-x
        # m[:, 2] is r <= y
        # m[:, 3] is r <= 1-y
        
        forces[:, 0] += m[:, 0] - m[:, 1]
        forces[:, 1] += m[:, 2] - m[:, 3]
        
        # 2. Pairwise Forces
        # Constraints start at num_boundary
        # Iterate over pairs to apply forces
        
        # This loop is O(N^2) which is fine for N=26
        pair_marginals = duals[num_boundary:]
        
        p_idx = 0
        for i in range(n):
            for j in range(i + 1, n):
                lam = pair_marginals[p_idx]
                if lam > 1e-9: # Only active constraints contribute significantly
                    # Distance
                    dx = current_centers[i, 0] - current_centers[j, 0]
                    dy = current_centers[i, 1] - current_centers[j, 1]
                    dist = np.hypot(dx, dy)
                    
                    if dist > 1e-9:
                        # Unit vector from j to i
                        ux = dx / dist
                        uy = dy / dist
                        
                        # Force on i: +lam * u (push away from j)
                        # Force on j: -lam * u (push away from i)
                        # Note: We want to increase distance to relax constraint.
                        # Increasing distance means moving i away from j.
                        
                        fi_x = lam * ux
                        fi_y = lam * uy
                        
                        forces[i, 0] += fi_x
                        forces[i, 1] += fi_y
                        
                        forces[j, 0] -= fi_x
                        forces[j, 1] -= fi_y
                p_idx += 1
        
        # Apply Forces with learning rate and momentum (simple)
        # Actually, simple gradient ascent: x += lr * grad
        # But we computed forces which are gradients of the LP value wrt centers?
        # Yes, approximately.
        
        # Normalize forces? 
        # The magnitude of forces depends on number of active constraints.
        # It's safer to clip or normalize, but let's try raw first with small LR.
        
        # To stabilize, we can limit max displacement
        step_size = lr
        update = step_size * forces
        
        # Momentum
        current_centers = current_centers + (1.0 - momentum) * update + momentum * (current_centers - prev_centers)
        
        # Project back to valid domain [epsilon, 1-epsilon]
        # Using 1e-5 to stay strictly inside
        current_centers = np.clip(current_centers, 1e-5, 1.0 - 1e-5)
        
        prev_centers = current_centers.copy()
        
        # Decay learning rate
        if step % 200 == 0 and step > 0:
            lr *= 0.8

    # Final refinement: Solve LP on best_centers to ensure consistency
    final_radii, _ = solve_lp(best_centers)
    
    # If best_radii is not set (should be), use final
    if best_radii is None:
        best_radii = final_radii
        best_centers = current_centers
        best_sum_r = np.sum(final_radii)
    else:
        # Recalculate sum for safety
        best_sum_r = np.sum(best_radii)

    return best_centers, best_radii, float(best_sum_r)
