

To maximize the sum of radii for 26 circles in a unit square, we must move beyond simple square grids (which are limited to a radius of 0.1 and a sum of 2.5 for 25 circles) and utilize the denser hexagonal lattice structure.

### Strategy
1.  **Hexagonal Lattice Initialization:** We start by generating a hexagonal pattern, which is the densest way to pack circles. This arrangement allows for more circles and larger radii compared to a square grid.
2.  **Force-Directed Expansion:** We implement an iterative "Expand and Relax" loop. 
    *   **Expansion:** In each step, we slightly increase the radius of every circle (scaling by a factor).
    *   **Relaxation:** We resolve overlaps by applying repulsive forces between circles. When two circles overlap, we move their centers apart along the line connecting them.
3.  **Boundary Constraints:** Circles are clamped to the unit square $[0,1] \times [0,1]$ boundaries, ensuring validity.
4.  **Optimization:** This process continues for a set number of iterations, allowing the circles to find a "jammed" state where they press against each other and the boundaries, effectively maximizing their total size.

```python
import numpy as np

def run_packing() -> tuple[np.ndarray, np.ndarray, float]:
    n = 26
    rng = np.random.default_rng(42)
    
    # Initialize with a hexagonal lattice to ensure dense, non-overlapping start
    centers = np.zeros((n, 2))
    radii = np.zeros(n)
    
    dx = 0.18
    dy = dx * np.sqrt(3) / 2
    idx = 0
    
    # Generate hexagonal grid points within the square
    y = 0.1
    row = 0
    while y < 1.0 and idx < n:
        x = 0.1
        if row % 2 == 1:
            x += dx / 2
        while x < 1.0 and idx < n:
            centers[idx] = [x, y]
            radii[idx] = 0.05  # Start with small radius
            x += dx
            idx += 1
        y += dy
        row += 1
    
    # If hexagonal grid didn't fill all spots (unlikely with n=26), add random ones
    while idx < n:
        centers[idx] = rng.uniform(0.2, 0.8, size=2)
        radii[idx] = 0.05
        idx += 1

    # Force-Directed Expansion and Relaxation
    for step in range(2500):
        # 1. Expansion: Slightly increase radii
        radii *= 1.0004
        
        # 2. Relaxation: Resolve overlaps and boundary collisions
        for _ in range(15):
            moved = False
            
            # Handle boundaries
            for i in range(n):
                r = radii[i]
                x, y = centers[i]
                
                if x - r < 0:
                    centers[i, 0] = r
                    moved = True
                elif x + r > 1:
                    centers[i, 0] = 1 - r
                    moved = True
                
                if y - r < 0:
                    centers[i, 1] = r
                    moved = True
                elif y + r > 1:
                    centers[i, 1] = 1 - r
                    moved = True
            
            # Handle pairwise overlaps
            for i in range(n):
                for j in range(i + 1, n):
                    r_i = radii[i]
                    r_j = radii[j]
                    diff = centers[j] - centers[i]
                    dist = np.linalg.norm(diff)
                    min_dist = r_i + r_j
                    
                    if dist < min_dist and dist > 1e-9:
                        overlap = min_dist - dist
                        dir_vec = diff / dist
                        move = dir_vec * overlap * 0.5
                        
                        centers[i] -= move
                        centers[j] += move
                        moved = True
            
            if not moved:
                break
    
    # Final clamping to ensure validity before return
    for i in range(n):
        r = radii[i]
        centers[i, 0] = max(r, min(1 - r, centers[i, 0]))
        centers[i, 1] = max(r, min(1 - r, centers[i, 1]))

    sum_radii = np.sum(radii)
    return centers, radii, sum_radii
```
