The problem of maximizing the sum of radii for 26 circles in a unit square is a non-convex nonlinear optimization problem. To solve it robustly:

1. **Formulation**: We treat the $x, y$ coordinates and radius $r$ of each circle as optimization variables. The objective is to maximize $\sum r_i$. Constraints ensure circles stay within $[0,1]^2$ and do not overlap: $(x_i-x_j)^2 + (y_i-y_j)^2 \ge (r_i+r_j)^2$.
2. **Initialization**: Circle packing landscapes have many local optima. We use multiple diverse starting points:
   - A 5×5 grid with one extra circle in the center (good baseline).
   - A hexagonal lattice arrangement (high theoretical density).
   - Several randomized configurations (to escape symmetry traps).
3. **Optimization**: We use `scipy.optimize.minimize` with the `SLSQP` method, which handles nonlinear inequality constraints efficiently. Squared distance constraints are used to maintain smoothness and avoid expensive square roots in gradient approximations.
4. **Multi-start & Robustness**: Running SLSQP from each initial guess and keeping the best result significantly increases the chance of reaching the global or near-global optimum. Tolerances are tightened, and bounds are set to prevent degenerate solutions.
5. **Post-processing**: A final projection step clips centers and radii to strictly satisfy boundary constraints within numerical tolerance, guaranteeing validity under the checker.

import numpy as np
from scipy.optimize import minimize

N = 26

def objective(x):
    """Objective function: minimize negative sum of radii."""
    return -np.sum(x[3*N:])

def constraints(x):
    """Constraint function: returns array of values that must be >= 0."""
    c = []
    # Boundary constraints: each circle must stay inside [0,1]^2
    for i in range(N):
        xi, yi, ri = x[3*i], x[3*i+1], x[3*i+2]
        c.append(xi - ri)          # x >= r
        c.append(1.0 - xi - ri)    # x + r <= 1
        c.append(yi - ri)          # y >= r
        c.append(1.0 - yi - ri)    # y + r <= 1
        
    # Overlap constraints: squared distance >= squared sum of radii
    for i in range(N):
        xi, yi, ri = x[3*i], x[3*i+1], x[3*i+2]
        for j in range(i+1, N):
            xj, yj, rj = x[3*j], x[3*j+1], x[3*j+2]
            c.append((xi - xj)**2 + (yi - yj)**2 - (ri + rj)**2)
            
    return np.array(c)

def run_packing():
    np.random.seed(42)
    
    best_sum = 0.0
    best_x = None
    
    # Prepare diverse initial configurations
    initial_configs = []
    
    # 1. Grid-like start (5x5 + 1 center)
    c_grid = np.zeros((N, 2))
    r_grid = np.full(N, 0.095)
    idx = 0
    for i in range(5):
        for j in range(5):
            c_grid[idx] = [0.1 + j * 0.2, 0.1 + i * 0.2]
            idx += 1
    c_grid[idx] = [0.5, 0.5]
    initial_configs.append((c_grid, r_grid))
    
    # 2. Hexagonal lattice start (higher density potential)
    c_hex = np.zeros((N, 2))
    r_hex = np.full(N, 0.09)
    idx = 0
    row = 0
    while idx < N:
        num = 6 if row % 2 == 0 else 5
        if idx + num > N:
            num = N - idx
        for col in range(num):
            c_hex[idx] = [(col + 0.5) * 0.2 + (row % 2) * 0.1, row * 0.1 * np.sqrt(3)]
            idx += 1
        row += 1
    # Scale hex to fit comfortably within [0,1]
    mx = c_hex.max()
    if mx > 0:
        c_hex /= mx * 1.15
    initial_configs.append((c_hex, r_hex))
    
    # 3. Random starts to escape symmetry/local optima
    for _ in range(4):
        c_rand = np.random.uniform(0.1, 0.9, (N, 2))
        r_rand = np.full(N, 0.08)
        initial_configs.append((c_rand, r_rand))
        
    # Variable bounds: x,y in [0,1], r in [1e-6, 0.5]
    bnds = [(0.0, 1.0) for _ in range(2*N)] + [(1e-6, 0.5) for _ in range(N)]
    
    constraint_dict = {'type': 'ineq', 'fun': constraints}
    
    for centers, radii in initial_configs:
        x0 = np.concatenate([centers.flatten(), radii])
        
        try:
            res = minimize(objective, x0, method='SLSQP', bounds=bnds,
                          constraints=constraint_dict,
                          options={'maxiter': 5000, 'ftol': 1e-12, 'disp': False})
            
            current_sum = -res.fun
            if current_sum > best_sum:
                best_sum = current_sum
                best_x = res.x.copy()
        except Exception:
            continue
            
    if best_x is None:
        centers, radii = initial_configs[0]
        return centers, radii, np.sum(radii)
        
    centers_opt = best_x[:3*N].reshape(N, 2)
    radii_opt = best_x[3*N:]
    
    # Final projection to guarantee strict feasibility within numerical tolerance
    radii_opt = np.maximum(radii_opt, 1e-6)
    centers_opt = np.clip(centers_opt, radii_opt[:, None], 1.0 - radii_opt[:, None])
    
    return centers_opt, radii_opt, np.sum(radii_opt)
