

To maximize the sum of radii for 26 circles in a unit square, we treat the problem as a **max-min distance optimization**. By arranging the circles in a hexagonal (triangular) lattice, we utilize space more efficiently than a square grid, allowing for a higher average radius.

### Strategy
1.  **Initial Configuration**: Generate a dense hexagonal lattice of 26 points inside the unit square. This serves as a strong starting point for the optimizer.
2.  **Objective Function**: Define the radius $R$ of equal circles as the minimum distance to the nearest boundary and the minimum distance to the nearest neighbor (divided by 2). 
3.  **Optimization**: Use `scipy.optimize.minimize` with the `Nelder-Mead` method (derivative-free and robust for non-smooth functions) to maximize this radius.
4.  **Radius Calculation**: Once optimal centers are found, the final radii are calculated based on the tightest constraints.

### Final Program

```python
import numpy as np
from scipy.optimize import minimize

def run_packing() -> tuple[np.ndarray, np.ndarray, float]:
    n_circles = 26

    # 1. Generate a hexagonal lattice initialization
    centers = []
    # Adjust row lengths to fit 26 circles in a rectangular hexagonal block
    # Pattern: 6, 5, 6, 5, 4 = 26
    row_counts = [6, 5, 6, 5, 4]
    
    y = 0
    for row_idx, count in enumerate(row_counts):
        x_start = 0.0
        for col_idx in range(count):
            # Add offset for alternating rows
            if row_idx % 2 == 1:
                x_start = 0.5
            centers.append([x_start + col_idx, y])
            if row_idx % 2 == 1 and col_idx < count - 1:
                x_start += 1.0
        y += np.sqrt(3) / 2

    centers = np.array(centers)
    
    # Scale and center initial configuration to fit in unit square
    min_c = centers.min(axis=0)
    max_c = centers.max(axis=0)
    scale = 0.9 / np.max(max_c - min_c) # Leave 10% margin for expansion
    centers = (centers - min_c) * scale + 0.5 * (1 - scale)

    # 2. Define the max-min distance objective
    # We want to maximize R, so we minimize -R
    # R = min( distance to boundary, 0.5 * distance between centers )
    def get_min_R(coords):
        c = coords.reshape(-1, 2)
        
        # Distance to boundary
        dist_boundary = np.minimum(
            np.minimum(c[:, 0], 1 - c[:, 0]),
            np.minimum(c[:, 1], 1 - c[:, 1])
        )
        min_dist_boundary = np.min(dist_boundary)

        # Distance between centers
        diffs = c[:, np.newaxis, :] - c[np.newaxis, :, :]
        dist_matrix = np.sqrt(np.sum(diffs ** 2, axis=2))
        # Set diagonal to infinity so it doesn't affect the minimum
        dist_matrix[np.eye(dist_matrix.shape[0], dtype=bool)] = np.inf
        min_dist_centers = np.min(dist_matrix) / 2.0

        return min(min_dist_boundary, min_dist_centers)

    def objective(coords):
        return -get_min_R(coords)

    # 3. Optimize
    # Nelder-Mead is suitable for non-smooth max-min problems
    result = minimize(objective, centers.flatten(), method='Nelder-Mead', 
                      options={'xatol': 1e-6, 'fatol': 1e-6, 'maxiter': 5000})
    
    final_centers = result.x.reshape(-1, 2)
    final_radius = get_min_R(result.x)

    # 4. Create radii array (equal radii for equal circles packing)
    radii = np.full(n_circles, final_radius)
    
    # Ensure all constraints are met and non-negative
    radii = np.clip(radii, 0, None)

    return final_centers, radii, np.sum(radii)
```
