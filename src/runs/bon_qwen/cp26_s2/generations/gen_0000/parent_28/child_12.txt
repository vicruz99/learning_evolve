

<strategy>
The problem is a non-convex nonlinear optimization problem: maximize $\sum r_i$ subject to quadratic distance constraints (non-overlap) and linear boundary constraints. 

Key considerations:
1. **Objective vs Constraints**: The objective is linear, constraints are quadratic. This fits well with Sequential Least Squares Programming (SLSQP).
2. **Local Optima**: Circle packing has many local optima. A single run from a random start often gets stuck. Multiple restarts from structured initializations (grid/hexagonal) are necessary.
3. **Vectorization**: Computing 325 pairwise distance constraints and 104 boundary constraints in pure Python loops is slow. We vectorize constraint evaluation using NumPy broadcasting to drastically speed up each optimizer iteration.
4. **Feasibility**: SLSQP may return solutions slightly violating constraints due to numerical tolerance. We enforce a strict check ($\ge -10^{-6}$) before accepting a solution.
5. **Initialization**: A dense $5 \times 5$ grid perturbed with small noise provides a feasible starting point where circles don't heavily overlap, allowing the optimizer to smoothly expand radii until the constraints bind.

Implementation plan:
- Define top-level helper functions for constraint evaluation and objective computation.
- Use `scipy.optimize.minimize` with `method='SLSQP'`.
- Run 10 restarts with different random seeds.
- Track the best valid solution found.
- Return the optimal centers, radii, and sum.
</strategy>

```python
import numpy as np
from scipy.optimize import minimize

def evaluate_constraints(vars, n):
    """
    Computes inequality constraints: g(x) >= 0
    Returns a 1D numpy array of constraint values.
    """
    C = vars.reshape(-1, 3)
    X = C[:, 0]
    Y = C[:, 1]
    R = C[:, 2]
    
    # Boundary constraints: r <= x <= 1-r, r <= y <= 1-r
    cons = np.concatenate([X - R, 1.0 - X - R, Y - R, 1.0 - Y - R])
    
    # Pairwise non-overlap constraints: ||c_i - c_j||^2 >= (r_i + r_j)^2
    X_diff = X[:, None] - X[None, :]
    Y_diff = Y[:, None] - Y[None, :]
    R_sum = R[:, None] + R[None, :]
    
    dist_sq = X_diff**2 + Y_diff**2
    rad_sq = R_sum**2
    
    # Only need upper triangle (i < j)
    triu_idx = np.triu_indices(n, k=1)
    overlap = dist_sq[triu_idx] - rad_sq[triu_idx]
    cons = np.concatenate([cons, overlap])
    
    return cons

def compute_objective(vars):
    """
    Minimizes negative sum of radii (equivalent to maximizing sum of radii)
    """
    return -np.sum(vars[2::3])

def constraint_wrapper(vars):
    """Wrapper to pass fixed n to constraint function"""
    return evaluate_constraints(vars, 26)

def run_packing():
    n = 26
    best_sum = -1.0
    best_centers = None
    best_radii = None
    
    # Variable bounds: x,y in [0,1], r in [0, 0.5]
    bnds = [(0.0, 1.0), (0.0, 1.0), (0.0, 0.5)] * n
    cons = {'type': 'ineq', 'fun': constraint_wrapper}
    
    # Multiple restarts to escape local optima
    for seed in range(10):
        rng = np.random.default_rng(seed)
        vars0 = np.zeros(3 * n)
        idx = 0
        
        # Structured initialization: 5x5 grid + remainder
        for row in range(5):
            for col in range(5):
                if idx < n:
                    vars0[3 * idx] = 0.1 + col * 0.18
                    vars0[3 * idx + 1] = 0.1 + row * 0.18
                    vars0[3 * idx + 2] = 0.08  # Initial feasible radius
                    idx += 1
                    
        # Fill remaining circles if any
        while idx < n:
            vars0[3 * idx] = rng.uniform(0.1, 0.9)
            vars0[3 * idx + 1] = rng.uniform(0.1, 0.9)
            vars0[3 * idx + 2] = 0.05
            idx += 1
            
        # Add small random perturbation to break symmetry
        vars0 += rng.normal(0, 0.02, size=vars0.shape)
        vars0[2::3] = np.clip(vars0[2::3], 0.01, 0.4)
        
        try:
            res = minimize(compute_objective, vars0, method='SLSQP', bounds=bnds, 
                           constraints=cons, options={'maxiter': 2000, 'ftol': 1e-10})
            
            if res.success:
                # Verify constraints are satisfied within numerical tolerance
                c_vals = evaluate_constraints(res.x, n)
                if np.min(c_vals) >= -1e-6:
                    current_sum = -res.fun
                    if current_sum > best_sum:
                        best_sum = current_sum
                        best_centers = res.x[:2 * n].reshape(n, 2)
                        best_radii = res.x[2 * n:]
        except Exception:
            continue
            
    # Fallback if optimization fails entirely (unlikely)
    if best_centers is None:
        centers = np.tile([0.5, 0.5], (n, 1))
        radii = np.full(n, 1e-4)
        return centers, radii, np.sum(radii)
        
    return best_centers, best_radii, best_sum
```
