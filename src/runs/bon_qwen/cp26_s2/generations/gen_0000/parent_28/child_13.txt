The problem is to pack 26 circles in a unit square to maximize the sum of radii. This is a non-convex optimization problem.

A robust strategy involves an alternating optimization approach:
1.  **Initial Configuration**: Start with a hexagonal lattice arrangement, which is known for high packing density. We will fit 26 circles into the square using this pattern.
2.  **Radius Optimization (LP)**: For a fixed set of centers, finding the optimal radii is a Linear Programming (LP) problem. We maximize $\sum r_i$ subject to non-overlap ($r_i + r_j \le \text{dist}_{ij}$) and boundary constraints ($r_i \le \text{dist to wall}_i$). This step is fast and exact.
3.  **Center Optimization (Forces)**: To improve the total sum of radii, we need to move centers to create more space. We apply a "repulsive force" heuristic:
    *   If a circle is constrained by a neighbor (i.e., $r_i + r_j \approx \text{dist}_{ij}$), it exerts a repulsive force pushing them apart.
    *   If a circle is constrained by a boundary (i.e., $r_i \approx \text{dist to wall}$), it pushes away from the wall.
    *   Moving circles in the direction of these forces increases distances, allowing the LP solver to find larger radii in the next iteration.
4.  **Refinement**: We run this loop for a set number of iterations. We can also add a perturbation step or run multiple restarts to escape local minima, but a well-initialized force-based relaxation often converges to a very good solution for this size.

This approach combines the exactness of LP for radii with a gradient-free heuristic for center placement.

def run_packing() -> tuple[np.ndarray, np.ndarray, float]:

    Optimizes the packing of 26 circles in a unit square to maximize sum of radii.
    
    Strategy:
    1. Initialize centers with a hexagonal grid pattern.
    2. Iteratively:
       a. Solve LP to find max radii for current centers.
       b. Calculate repulsive forces based on active constraints.
       c. Update centers.

        # Objective: Maximize sum(r) -> Minimize -sum(r)
        c_obj = -np.ones(n)

        # 1. r_i + r_j <= dist(i, j)
        # 2. r_i <= x_i, 1-x_i, y_i, 1-y_i
        
        num_constraints = (n * (n - 1)) // 2 + 4 * n
        A_ub = np.zeros((num_constraints, n))
        b_ub = np.zeros(num_constraints)
        
        constraint_idx = 0
        
        # Pairwise distance constraints
        # Precompute indices to speed up if needed, but n=26 is small
        for i in range(n):
            for j in range(i + 1, n):
                dist = np.sqrt(np.sum((centers[i] - centers[j])**2))
                A_ub[constraint_idx, i] = 1.0
                A_ub[constraint_idx, j] = 1.0
                b_ub[constraint_idx] = dist
                constraint_idx += 1
                
        # Boundary constraints
        for i in range(n):
            x, y = centers[i]
            # r_i <= x
            A_ub[constraint_idx, i] = 1.0
            b_ub[constraint_idx] = x
            constraint_idx += 1
            # r_i <= 1 - x
            A_ub[constraint_idx, i] = 1.0
            b_ub[constraint_idx] = 1.0 - x
            constraint_idx += 1
            # r_i <= y
            A_ub[constraint_idx, i] = 1.0
            b_ub[constraint_idx] = y
            constraint_idx += 1
            # r_i <= 1 - y
            A_ub[constraint_idx, i] = 1.0
            b_ub[constraint_idx] = 1.0 - y
            constraint_idx += 1
            
        bounds = [(0, None) for _ in range(n)]
