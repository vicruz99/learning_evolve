To maximize the sum of radii for 26 circles in a unit square, we will treat this as a non-linear optimization problem. 

**Strategy Overview:**
1.  **Initialization (Hexagonal Lattice):** We start with a valid "hexagonal" packing configuration. This is denser than a square grid and provides a strong starting point for the optimizer. We arrange the 26 circles into 6 rows (5, 4, 5, 4, 5, 3 circles respectively) with an initial radius of 0.05.
2.  **Objective & Constraints:** We define a loss function to maximize the sum of radii ($\sum r_i$). We enforce constraints ensuring circles remain inside the unit square and do not overlap with each other.
3.  **Optimization (SLSQP):** We use the Sequential Least Squares Programming (SLSQP) solver from `scipy.optimize`. This method handles the non-linear inequality constraints (distance between centers vs sum of radii) effectively.
4.  **Constraint Simplification:** Instead of defining ~400 separate constraint objects, we use the `minimize` function's ability to handle a single constraint function returning a vector of values. This is computationally more efficient.
5.  **Execution:** We run the optimizer for a fixed number of iterations. If it converges, we extract the final centers and radii.

This approach is deterministic and mathematically robust for finding a local optimum, which is typically very close to the global optimum for circle packing in a square.

```python
import numpy as np
from scipy.optimize import minimize

def run_packing() -> tuple[np.ndarray, np.ndarray, float]:
    """
    Optimizes the packing of 26 circles in a unit square to maximize the sum of radii.
    
    Returns:
        centers: np.array of shape (26, 2)
        radii: np.array of shape (26,)
        sum_radii: float
    """
    N = 26
    
    # 1. Initialization: Hexagonal-like layout
    # We arrange circles in 6 rows to distribute them efficiently.
    # Pattern: 5, 4, 5, 4, 5, 3 circles.
    # This utilizes the space better than a simple grid.
    
    centers = np.zeros((N, 2))
    radii = np.full(N, 0.05)  # Initial small radius
    
    idx = 0
    # Base radius estimate for geometry
    r_est = 0.1
    sqrt3 = np.sqrt(3)
    
    # Row configurations: (count, y_offset_multiplier)
    # y = r_est + k * r_est * sqrt(3)
    rows_config = [
        (5, 0), 
        (4, 1), 
        (5, 2), 
        (4, 3), 
        (5, 4),
        (3, 5)
    ]
    
    for k, (count, mult) in enumerate(rows_config):
        y = r_est + mult * r_est * sqrt3
        # Center y coordinate (adjusted to be inside [0,1])
        # If y is too high, we clamp it slightly for initialization safety, 
        # though the optimizer will fix it.
        if y + r_est > 1.0:
            y = 1.0 - r_est
            
        # x coordinates
        # Even rows (0, 2, 4) start at r_est. Odd rows (1, 3) start at 2*r_est (shifted).
        # However, our list indices don't strictly match parity of k in the logic above.
        # Let's adjust x based on row index to ensure staggering.
        
        if k % 2 == 0:
            # Standard offset
            x_start = r_est
        else:
            # Shifted offset
            x_start = 2 * r_est
            
        for j in range(count):
            x = x_start + j * (2 * r_est)
            
            # Boundary check for initialization
            if x + r_est > 1.0:
                x = 1.0 - r_est
            if x - r_est < 0.0:
                x = r_est
                
            centers[idx] = [x, y]
            idx += 1

    # 2. Setup Optimization Variables
    # Flatten (x, y, r) for each circle into a single vector
    # Order: x0, y0, r0, x1, y1, r1, ...
    x0 = np.zeros(3 * N)
    for i in range(N):
        x0[3 * i] = centers[i, 0]
        x0[3 * i + 1] = centers[i, 1]
        x0[3 * i + 2] = radii[i]

    # Bounds for variables
    # x, y in [0, 1], r in [0, 1]
    bounds = [(0.0, 1.0) for _ in range(3 * N)]
    
    # 3. Objective Function
    # Maximize sum of radii => Minimize negative sum
    def objective(vars):
        # Radii are at indices 2, 5, 8, ... (step 3, start 2)
        r = vars[2::3]
        return -np.sum(r)

    # 4. Constraint Function
    # Returns an array of constraint values. We require all >= 0.
    def constraints(vars):
        constraints_vec = np.zeros(0)
        
        # Extract variables
        xs = vars[0::3]
        ys = vars[1::3]
        rs = vars[2::3]
        
        # Wall Constraints
        # x - r >= 0
        # 1 - x - r >= 0
        # y - r >= 0
        # 1 - y - r >= 0
        # Using flat indexing for speed inside the function if needed, 
        # but numpy operations are vectorized.
        
        c1 = xs - rs
        c2 = 1.0 - xs - rs
        c3 = ys - rs
        c4 = 1.0 - ys - rs
        
        # Overlap Constraints
        # (xi - xj)^2 + (yi - yj)^2 >= (ri + rj)^2
        # => (xi - xj)^2 + (yi - yj)^2 - (ri + rj)^2 >= 0
        
        # Compute pairwise distances squared and radii sums squared
        # Using broadcasting for N=26 is efficient enough
        
        # Diff matrices
        dx = xs[:, np.newaxis] - xs[np.newaxis, :]
        dy = ys[:, np.newaxis] - ys[np.newaxis, :]
        dr_sum = rs[:, np.newaxis] + rs[np.newaxis, :]
        
        dist_sq = dx**2 + dy**2
        rad_sum_sq = dr_sum**2
        
        # We only need upper triangle (i < j)
        # Mask for upper triangle
        mask = np.triu(np.ones((N, N), dtype=bool), k=1)
        
        overlap_constraints = dist_sq[mask] - rad_sum_sq[mask]
        
        # Combine all constraints
        # Wall constraints
        constraints_vec = np.concatenate([c1, c2, c3, c4, overlap_constraints])
        
        return constraints_vec

    # 5. Run Optimization
    # Using SLSQP method which supports bounds and constraints
    # maxiter: Limit iterations to prevent long running times, though 26 circles is small.
    try:
        res = minimize(
            objective, 
            x0, 
            method='SLSQP', 
            bounds=bounds, 
            constraints={'type': 'ineq', 'fun': constraints},
            options={
                'maxiter': 2000, 
                'ftol': 1e-10,
                'disp': False
            }
        )
        
        if res.success:
            final_vars = res.x
        else:
            # If optimization fails, we still return the result (might be good enough)
            # or fallback to initial guess (unlikely to be better)
            final_vars = res.x 
    except Exception as e:
        # Fallback to initial guess if optimizer crashes
        final_vars = x0

    # 6. Extract Results
    final_centers = np.zeros((N, 2))
    final_radii = np.zeros(N)
    
    for i in range(N):
        final_centers[i, 0] = final_vars[3 * i]
        final_centers[i, 1] = final_vars[3 * i + 1]
        final_radii[i] = final_vars[3 * i + 2]
        
    sum_radii = np.sum(final_radii)
    
    return final_centers, final_radii, sum_radii
```
