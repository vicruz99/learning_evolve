

To maximize the sum of radii for 26 circles in a unit square, we use a force-directed layout algorithm. This method models the circles as nodes in a physical system where repulsive forces push centers apart until they are constrained by the square boundaries. By balancing these forces, the circles expand to fill the available space efficiently, resulting in a high total radius sum.

### Strategy
1.  **Initialization**: Start with a 5x5 grid layout to ensure a dense, non-overlapping starting configuration.
2.  **Repulsive Forces**: For each pair of circles, calculate a repulsive force inversely proportional to the distance between centers. This pushes overlapping circles apart and expands gaps.
3.  **Boundary Constraints**: Enforce a 0.05 buffer from the square edges to allow for optimal radius growth within the $[0, 1]^2$ domain.
4.  **Simulation**: Run the system for 10,000 iterations, using a step size that decreases over time to ensure convergence.
5.  **Validation**: Calculate final radii based on the minimum distance to any neighbor or boundary and return the configuration.

```python
import numpy as np

def run_packing() -> tuple[np.ndarray, np.ndarray, float]:
    n = 26
    np.random.seed(42)
    
    # Initialize centers in a dense 5x5 grid with slight random perturbation
    centers = np.zeros((n, 2))
    for i in range(5):
        for j in range(5):
            idx = i * 5 + j
            if idx < n:
                centers[idx] = [0.1 + 0.2 * i + np.random.uniform(-0.01, 0.01), 
                                0.1 + 0.2 * j + np.random.uniform(-0.01, 0.01)]

    # Optimization parameters
    step_size = 0.005
    decay = 0.9995
    min_step = 1e-6
    boundary_buffer = 0.05

    for step in range(10000):
        if step_size < min_step:
            break
        
        forces = np.zeros_like(centers)
        
        # Calculate repulsive forces between all pairs
        for i in range(n):
            for j in range(i + 1, n):
                diff = centers[i] - centers[j]
                dist_sq = np.sum(diff**2)
                dist = np.sqrt(dist_sq)
                
                if dist > 1e-9:
                    # Strong repulsion when close to allow packing to resolve overlaps
                    if dist < 0.3:
                        force_mag = (0.3 - dist) / (dist + 1e-6)
                    else:
                        force_mag = 0.0005 / (dist**2 + 1e-6)
                    
                    forces[i] += force_mag * diff / dist
                    forces[j] -= force_mag * diff / dist
        
        # Apply boundary forces (keep centers within a 0.05 buffer)
        for i in range(n):
            if centers[i, 0] < boundary_buffer:
                forces[i, 0] += (boundary_buffer - centers[i, 0])
            if centers[i, 0] > 1 - boundary_buffer:
                forces[i, 0] -= (centers[i, 0] - (1 - boundary_buffer))
            if centers[i, 1] < boundary_buffer:
                forces[i, 1] += (boundary_buffer - centers[i, 1])
            if centers[i, 1] > 1 - boundary_buffer:
                forces[i, 1] -= (centers[i, 1] - (1 - boundary_buffer))
        
        # Update centers
        centers += step_size * forces
        
        # Ensure centers stay within unit square
        np.clip(centers, boundary_buffer, 1 - boundary_buffer, out=centers)
        
        # Decay step size
        step_size *= decay

    # Calculate final radii based on closest neighbor and boundaries
    radii = np.zeros(n)
    for i in range(n):
        # Distance to boundaries
        r_bound = min(centers[i, 0], 1 - centers[i, 0], centers[i, 1], 1 - centers[i, 1])
        radii[i] = r_bound
        
        # Distance to other circles
        for j in range(i + 1, n):
            dist = np.sqrt(np.sum((centers[i] - centers[j])**2))
            radii[i] = min(radii[i], dist / 2)
            radii[j] = min(radii[j], dist / 2)

    sum_radii = float(np.sum(radii))
    return centers, radii, sum_radii
```
