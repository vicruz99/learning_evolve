

To maximize the sum of radii for 26 circles in a unit square, we employ a force-directed layout algorithm. This method starts with a valid initial packing (a slightly compressed grid) and iteratively expands radii while using repulsive forces to resolve overlaps and wall boundary violations. This heuristic allows circles to settle into a configuration that maximizes their collective size.

<strategy>
1. **Initialization**: Create a 6x5 grid of 26 circles. To ensure an initial valid state, scale the radii to be slightly smaller than the theoretical maximum for a 5-circle row (e.g., $r \approx 0.09$).
2. **Force-Directed Optimization**: Run an iterative solver (10,000 steps) that:
   - **Increases Radii**: Gradually attempts to grow each circle's radius.
   - **Applies Repulsion**: If circles overlap, apply a repulsive force proportional to the overlap to push centers apart.
   - **Enforces Boundaries**: Apply a strong force to pull centers back into the $[0, 1] \times [0, 1]$ unit square if they encroach on the edges.
   - **Adjusts Positions**: Update centers based on accumulated forces with a decaying step size to converge smoothly.
3. **Result**: Return the final centers, radii, and their sum.
</strategy>

import numpy as np

def run_packing() -> tuple[np.ndarray, np.ndarray, float]:
    n = 26
    np.random.seed(42)
    
    # 1. Initialize centers in a 6x5 grid pattern
    centers = np.zeros((n, 2))
    row_count = [6, 5, 6, 5, 4] # Sums to 26
    idx = 0
    for i, count in enumerate(row_count):
        for j in range(count):
            # Shift odd rows by 0.5 for a hexagonal-ish layout
            x_off = 0.5 if (i % 2 != 0) else 0.0
            centers[idx, 0] = 0.1 + j * 0.17 + x_off * 0.085
            centers[idx, 1] = 0.1 + i * 0.18
            idx += 1

    # Initialize radii to a safe small value
    radii = np.full(n, 0.02)

    # 2. Force-Directed Optimization
    for step in range(10000):
        # Decay rate to allow settling
        alpha = max(0.01, 1.0 - step / 10000.0)
        forces = np.zeros_like(centers)

        # Increase radii slightly each step to maximize sum
        radii = np.minimum(radii * 1.0002, 0.5)

        # Calculate pairwise repulsive forces
        for i in range(n):
            for j in range(i + 1, n):
                diff = centers[i] - centers[j]
                dist = np.sqrt(np.sum(diff ** 2))
                min_dist = radii[i] + radii[j]
                
                if dist < min_dist:
                    # Repulsion force magnitude proportional to overlap
                    magnitude = (min_dist - dist) * 1.5
                    direction = diff / (dist + 1e-12)
                    forces[i] += direction * magnitude
                    forces[j] -= direction * magnitude

        # Enforce boundary constraints (push away from walls)
        for i in range(n):
            if centers[i, 0] < radii[i]:
                forces[i, 0] += (radii[i] - centers[i, 0]) * 5.0
            if centers[i, 0] > 1 - radii[i]:
                forces[i, 0] -= (centers[i, 0] - (1 - radii[i])) * 5.0
            if centers[i, 1] < radii[i]:
                forces[i, 1] += (radii[i] - centers[i, 1]) * 5.0
            if centers[i, 1] > 1 - radii[i]:
                forces[i, 1] -= (centers[i, 1] - (1 - radii[i])) * 5.0

        # Update centers
        centers += forces * alpha * 0.1

    # Final validation clamp
    centers = np.clip(centers, 0, 1)
    radii = np.maximum(radii, 0)

    return centers, radii, np.sum(radii)
