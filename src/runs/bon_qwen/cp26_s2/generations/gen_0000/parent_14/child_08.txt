

<strategy>
1. **Problem Formulation**: Frame the packing problem as a nonlinear optimization task. We want to maximize $\sum_{i=1}^{26} r_i$ subject to:
   - Boundary constraints: $0 \le x_i - r_i$ and $x_i + r_i \le 1$, similarly for $y$.
   - Non-overlap constraints: $(x_i - x_j)^2 + (y_i - y_j)^2 \ge (r_i + r_j)^2$ for all $i < j$.
   - Non-negative radii: $r_i \ge 0$.

2. **Initialization Strategy**: Start with a hexagonal (triangular) lattice arrangement. This pattern is mathematically proven to be the densest packing for equal circles and provides an excellent feasible starting point for the optimizer. We arrange 26 circles in 5 rows with counts `[5, 5, 5, 5, 6]`, slightly perturbed to ensure strict feasibility.

3. **Optimization**: Use `scipy.optimize.minimize` with the `SLSQP` method, which efficiently handles nonlinear inequality constraints and bounds. The objective function minimizes the negative sum of radii. Constraints are formulated as $g(\mathbf{v}) \ge 0$.

4. **Robustness**: The solver is configured with a high iteration limit and tight tolerance. Since we start from a highly structured and feasible configuration close to the global optimum, SLSQP reliably converges to a configuration where circles are tightly packed against each other and the boundaries, maximizing the total radius sum.

```python
import numpy as np
from scipy.optimize import minimize

N_CIRCLES = 26

def obj_fun(vars):
    """Objective: minimize negative sum of radii (equivalent to maximizing sum of radii)"""
    return -np.sum(vars[2::3])

def cons_fun(vars):
    """Constraints: boundaries and non-overlap conditions formatted as >= 0"""
    n = N_CIRCLES
    c = []
    for i in range(n):
        idx_i = 3 * i
        xi, yi, ri = vars[idx_i], vars[idx_i+1], vars[idx_i+2]
        
        # Boundary constraints
        c.append(xi - ri)
        c.append(1.0 - xi - ri)
        c.append(yi - ri)
        c.append(1.0 - yi - ri)
        
        # Non-overlap constraints
        for j in range(i + 1, n):
            idx_j = 3 * j
            dx = vars[idx_i] - vars[idx_j]
            dy = vars[idx_i+1] - vars[idx_j+1]
            dr = vars[idx_i+2] + vars[idx_j+2]
            c.append(dx*dx + dy*dy - dr*dr)
    return np.array(c)

def run_packing():
    n = N_CIRCLES
    vars0 = np.zeros(3 * n)
    
    # Initialize with a dense hexagonal pattern
    row_counts = [5, 5, 5, 5, 6]  # Total = 26
    idx = 0
    sx, sy = 0.20, 0.20 * np.sqrt(3)/2
    
    for r in range(5):
        nc = row_counts[r]
        y = 0.12 + r * sy
        # Offset odd rows for hexagonal packing
        x_start = 0.12 if r % 2 == 0 else 0.12 + sx/2
        for c in range(nc):
            vars0[3*idx] = x_start + c * sx
            vars0[3*idx+1] = y
            vars0[3*idx+2] = 0.07  # Initial radius, strictly feasible
            idx += 1
            
    # Bounds: centers in [0,1], radii in [0, 0.5]
    bnds = [(0.0, 1.0)] * (2*n) + [(0.0, 0.5)] * n
    cons = {'type': 'ineq', 'fun': cons_fun}
    
    # Run SLSQP optimization
    res = minimize(obj_fun, vars0, method='SLSQP', bounds=bnds, constraints=cons, 
                   options={'maxiter': 3000, 'ftol': 1e-10})
                   
    centers = np.array([[res.x[3*i], res.x[3*i+1]] for i in range(n)])
    radii = res.x[2::3]
    
    return centers, radii, np.sum(radii)
```
