The problem of packing 26 circles in a unit square to maximize the sum of radii is a non-convex optimization problem. Direct grid or hexagonal arrangements provide good baselines but rarely achieve the theoretical maximum due to boundary effects and discrete symmetries. 

Strategy:
1. **Parameterization**: Represent the system by a single vector of length $3N = 78$ containing $(x_i, y_i)$ for each center and $r_i$ for each radius.
2. **Initial Configuration**: Start with a perturbed $5 \times 5$ grid plus one central circle. This provides a feasible, reasonably dense starting point that breaks perfect symmetry, helping the optimizer escape trivial local minima.
3. **Augmented Lagrangian / Penalty Method**: Instead of hard constraints which can stall gradient-based optimizers, we use a quadratic penalty function. The objective becomes:
   $\text{Minimize } F = -\sum r_i + \mu \cdot P(\mathbf{c}, \mathbf{r})$
   where $P$ sums the squared violations of boundary and inter-circle distance constraints.
4. **Iterative Refinement**: We run `scipy.optimize.minimize` (L-BFGS-B) repeatedly, geometrically increasing the penalty parameter $\mu$. Early stages allow slight overlaps to guide circles into efficient configurations. Later stages enforce strict feasibility while pushing radii to their maximum possible values.
5. **Vectorization**: Pairwise distance and overlap calculations are fully vectorized using NumPy to ensure rapid gradient evaluations, critical for converging within a reasonable number of iterations.
6. **Bounds**: L-BFGS-B naturally handles box constraints for centers $[0,1]$ and radii $[0, 0.5]$, improving stability.

This method is robust, avoids manual force-tuning, and leverages high-performance library solvers to efficiently explore the configuration space.

import numpy as np
from scipy.optimize import minimize

def evaluate_cost(params, n, mu):
    """
    Computes the objective function: negative sum of radii + penalty for constraint violations.
    """
    c = params[:2*n].reshape(n, 2)
    r = params[2*n:]
    
    # Primary objective: maximize sum of radii
    cost = -np.sum(r)
    
    # Boundary constraint penalties
    cost += mu * np.sum(np.maximum(0, r - c[:, 0])**2)
    cost += mu * np.sum(np.maximum(0, c[:, 0] + r - 1)**2)
    cost += mu * np.sum(np.maximum(0, r - c[:, 1])**2)
    cost += mu * np.sum(np.maximum(0, c[:, 1] + r - 1)**2)
    
    # Pairwise non-overlap constraint penalties
    diff = c[:, np.newaxis, :] - c[np.newaxis, :, :]
    dists = np.linalg.norm(diff, axis=2)
    r_sum = r[:, np.newaxis] + r[np.newaxis, :]
    
    # Extract only upper triangle to avoid double counting and self-interaction
    idx = np.triu_indices(n, k=1)
    overlaps = np.maximum(0, r_sum[idx] - dists[idx])
    cost += mu * np.sum(overlaps**2)
    
    return cost

def run_packing() -> tuple[np.ndarray, np.ndarray, float]:
    n = 26
    np.random.seed(42)
    
    # Initialize with a slightly perturbed grid structure
    # 5x5 grid gives 25 circles, we add one in the center
    grid_x = np.arange(5) * 0.2 + 0.1
    grid_y = np.arange(5) * 0.2 + 0.1
    centers = np.array([[x, y] for y in grid_y for x in grid_x])
    centers = np.vstack([centers, [0.5, 0.5]])
    
    # Add random perturbation to break symmetry and avoid grid locking
    centers += np.random.randn(n, 2) * 0.015
    centers = np.clip(centers, 0.15, 0.85)
    
    # Initial radii slightly smaller than the grid limit (0.1) to ensure feasibility
    radii = np.ones(n) * 0.09
    
    # Flatten to 1D for the optimizer: [x0, y0, x1, y1, ..., r0, r1, ...]
    x0 = np.hstack([centers.flatten(), radii])
    
    # Box constraints for centers and radii
    bounds = [(0.0, 1.0)] * (2 * n) + [(1e-4, 0.5)] * n
    
    # Augmented Lagrangian schedule
    mu = 50.0
    for step in range(18):
        # L-BFGS-B efficiently handles bound constraints
        res = minimize(evaluate_cost, x0, args=(n, mu), method='L-BFGS-B', 
                       bounds=bounds, options={'maxiter': 2000, 'ftol': 1e-11})
        x0 = res.x
        
        # Increase penalty weight to strictly enforce constraints in later stages
        mu *= 3.5
        if mu > 100000:
            break
            
    centers_final = x0[:2*n].reshape(n, 2)
    radii_final = x0[2*n:]
    
    return centers_final, radii_final, np.sum(radii_final)
