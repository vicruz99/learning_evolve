To pack 26 circles in a unit square and maximize the sum of radii, we formulate this as a nonlinear optimization problem. The decision variables are the $(x, y)$ coordinates and radius $r$ for each of the 26 circles. 

**Objective:** Maximize $\sum r_i \iff$ Minimize $-\sum r_i$.

**Constraints:**
1. **Boundary:** Each circle must lie within $[0,1] \times [0,1]$. This translates to $x_i \ge r_i$, $y_i \ge r_i$, $1-x_i \ge r_i$, $1-y_i \ge r_i$.
2. **Non-overlap:** The distance between any two circle centers must be at least the sum of their radii: $(x_i-x_j)^2 + (y_i-y_j)^2 \ge (r_i+r_j)^2$.

**Optimization Strategy:**
- We use `scipy.optimize.minimize` with the SLSQP algorithm, which handles bounds and nonlinear inequality constraints effectively.
- To avoid local minima (common in packing problems), we run the optimizer from multiple diverse initial configurations: a 5x5 grid + center, a perturbed grid, a hexagonal layout, and a random layout.
- Constraints are vectorized for performance, computing all pairwise distances and boundary checks efficiently using NumPy broadcasting.
- The optimizer iteratively expands radii while shifting centers to maintain feasibility, converging to a high-sum packing.

This approach balances computational efficiency with the ability to explore the configuration space, typically yielding sums of radii well above the target of 2.636.

```python
import numpy as np
from scipy.optimize import minimize

N = 26

def objective(vars):
    # Maximize sum of radii => minimize negative sum
    # vars layout: x0, y0, r0, x1, y1, r1, ...
    return -np.sum(vars[2::3])

def constraint_bounds(vars):
    # Circles must be inside [0,1]x[0,1]
    # x - r >= 0, y - r >= 0, 1 - x - r >= 0, 1 - y - r >= 0
    centers = vars[:2*N].reshape(N, 2)
    radii = vars[2::3]
    vals = np.zeros(4*N)
    vals[0::4] = centers[:, 0] - radii
    vals[1::4] = centers[:, 1] - radii
    vals[2::4] = 1.0 - centers[:, 0] - radii
    vals[3::4] = 1.0 - centers[:, 1] - radii
    return vals

def constraint_overlap(vars):
    # d_ij^2 >= (r_i + r_j)^2
    centers = vars[:2*N].reshape(N, 2)
    radii = vars[2::3]
    diff = centers[:, np.newaxis, :] - centers[np.newaxis, :, :]
    d2 = np.sum(diff**2, axis=2)
    r_sum = radii[:, np.newaxis] + radii[np.newaxis, :]
    mask = np.triu(np.ones((N, N), dtype=bool), k=1)
    return d2[mask] - r_sum[mask]**2

def run_packing():
    bounds = [(0, 1)] * (2*N) + [(0, 0.5)] * N
    constraints = [
        {'type': 'ineq', 'fun': constraint_bounds},
        {'type': 'ineq', 'fun': constraint_overlap}
    ]
    
    best_result = None
    best_sum = -np.inf
    
    # Generate multiple starting configurations to avoid local minima
    starts = []
    
    # 1. Structured grid 5x5 + 1 center
    grid_pts = np.array([(i*0.2+0.1, j*0.2+0.1) for i in range(5) for j in range(5)])
    grid_pts = np.vstack([grid_pts, [0.5, 0.5]])[:N]
    starts.append(np.concatenate([grid_pts.ravel(), np.ones(N)*0.06]))
    
    # 2. Perturbed grid
    rng = np.random.RandomState(42)
    perturbed = grid_pts + rng.uniform(-0.03, 0.03, size=grid_pts.shape)
    starts.append(np.concatenate([perturbed.ravel(), np.ones(N)*0.065]))
    
    # 3. Hexagonal-ish packing
    hex_pts = []
    y = 0.12
    while len(hex_pts) < N:
        x = 0.1
        while len(hex_pts) < N and x < 0.9:
            hex_pts.append((x, y))
            x += 0.19
        y += 0.17
    hex_arr = np.array(hex_pts[:N])
    starts.append(np.concatenate([hex_arr.ravel(), np.ones(N)*0.06]))
    
    # 4. Random initial
    rand_centers = rng.uniform(0.15, 0.85, size=(N, 2))
    starts.append(np.concatenate([rand_centers.ravel(), np.ones(N)*0.05]))
    
    for x0 in starts:
        try:
            res = minimize(objective, x0, method='SLSQP', bounds=bounds,
                           constraints=constraints, options={'maxiter': 3000, 'ftol': 1e-12})
            cur_sum = -res.fun
            if cur_sum > best_sum:
                best_sum = cur_sum
                best_result = res
        except Exception:
            continue
            
    if best_result is None:
        best_result = minimize(objective, starts[0], method='SLSQP', bounds=bounds, constraints=constraints)
        
    vars_opt = best_result.x
    centers = vars_opt[:2*N].reshape(N, 2)
    radii = vars_opt[2::3]
    
    # Ensure non-negative radii
    radii = np.maximum(radii, 1e-9)
    
    return centers, radii, np.sum(radii)
```
