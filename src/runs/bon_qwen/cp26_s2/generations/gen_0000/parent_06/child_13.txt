The LP formulation is as follows:
- **Variables**: $r_1, \dots, r_{26} \ge 0$.
- **Objective**: Maximize $\sum r_i$.
- **Constraints**:
  1.  $r_i + r_j \le \text{distance}(c_i, c_j)$ for all pairs $i < j$ (non-overlap).
  2.  $r_i \le \min(x_i, 1-x_i, y_i, 1-y_i)$ for all $i$ (boundary containment).

We use a hexagonal lattice as an initial configuration because it is the densest packing in the plane, providing a strong starting point. We then employ a derivative-free optimizer (Nelder-Mead) to adjust the center coordinates, using the LP solution as the objective function value. import numpy as np
from scipy.optimize import minimize, linprog

def get_max_sum_radii(centers):
    """
    Solves the LP to find the maximum sum of radii for fixed centers.
    Returns (sum_radii, radii_array).
    """
    n = centers.shape[0]
    if n == 0:
        return 0.0, np.array([])
    
    # Objective: Maximize sum(r) <=> Minimize -sum(r)
    c = -np.ones(n)
    
    # Inequality constraints: A_ub @ r <= b_ub
    # 1. r_i + r_j <= dist(i, j) for all pairs i < j
    n_pairs = n * (n - 1) // 2
    A_ub = np.zeros((n_pairs, n))
    b_ub = np.zeros(n_pairs)
    
    idx = 0
    for i in range(n):
        for j in range(i + 1, n):
            # Distance between centers
            dist = np.linalg.norm(centers[i] - centers[j])
            A_ub[idx, i] = 1.0
            A_ub[idx, j] = 1.0
            b_ub[idx] = dist
            idx += 1
            
    # Bounds: 0 <= r_i <= distance to nearest wall
    bounds = []
    for i in range(n):
        x, y = centers[i]
        # Distance to nearest boundary
        r_max = min(x, 1.0 - x, y, 1.0 - y)
        if r_max < 0:
            r_max = 0.0 # Should not happen if centers are in [0,1]
        bounds.append((0.0, r_max))
        
    # Solve LP using HiGHS solver (default in recent scipy)
    res = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
    
    if res.success:
        return -res.fun, -res.x
    else:
        # Fallback in case of failure
        return 0.0, np.zeros(n)

def objective(centers_flat):
    """
    Objective function for the optimizer.
    Returns negative sum of radii (to minimize).
    """
    centers = centers_flat.reshape(-1, 2)
    sum_r, _ = get_max_sum_radii(centers)
    return -sum_r
