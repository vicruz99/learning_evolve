To maximize the sum of radii for 26 circles in a unit square, we formulate this as a continuous optimization problem. The objective is to maximize $\sum r_i$, which is equivalent to minimizing $-\sum r_i$. Constraints include boundary conditions (circles must stay within $[0,1]^2$) and non-overlap conditions (distance between centers $\ge$ sum of radii).

**Strategy:**
1. **Penalty-Based Optimization:** Direct constraint handling can be slow. We use a smooth penalty function that adds a quadratic cost for any boundary or overlap violations. This transforms the problem into an unconstrained (or bound-constrained) optimization.
2. **Sequential Penalty Annealing:** Start with a low penalty weight to allow the optimizer to freely explore configurations and increase radii. Gradually increase the penalty weight over multiple iterations. This forces the solution to become feasible while maintaining a high sum of radii.
3. **Multiple Randomized Initializations:** To escape local minima, we run the optimizer from several starting points. Initial positions are generated using a perturbed hexagonal lattice pattern, which naturally provides high packing density. Radii are initialized relatively large to bias the search towards larger circles.
4. **L-BFGS-B Solver:** This quasi-Newton method handles box constraints efficiently and scales well to ~80 variables (26 circles × 3 parameters each).
5. **Safety Post-Processing:** After optimization, we verify constraints. If any numerical violations exceed a tiny tolerance, we uniformly scale down radii slightly to guarantee strict validity for the checker function.

import numpy as np
from scipy.optimize import minimize

def compute_loss(params, n, penalty):
    """
    Computes the negative sum of radii plus a penalty for constraint violations.
    """
    centers = params[:2*n].reshape(n, 2)
    radii = params[2*n:]
    radii = np.maximum(radii, 0.0)
    
    # Objective: maximize sum of radii -> minimize negative sum
    loss = -np.sum(radii)
    violation = 0.0
    
    # Boundary constraints: circle must be inside [0,1]x[0,1]
    violation += np.sum(np.maximum(0.0, radii - centers[:, 0])**2)
    violation += np.sum(np.maximum(0.0, radii - centers[:, 1])**2)
    violation += np.sum(np.maximum(0.0, centers[:, 0] + radii - 1.0)**2)
    violation += np.sum(np.maximum(0.0, centers[:, 1] + radii - 1.0)**2)
    
    # Overlap constraints: distance between centers >= sum of radii
    diff = centers[:, np.newaxis, :] - centers[np.newaxis, :, :]
    dist = np.sqrt(np.sum(diff**2, axis=2))
    r_sum = radii[:, np.newaxis] + radii[np.newaxis, :]
    overlap = np.maximum(0.0, r_sum - dist)
    # Divide by 2 because overlap matrix is symmetric and diagonal is zero
    violation += 0.5 * np.sum(overlap**2)
    
    return loss + penalty * violation

def run_packing():
    n = 26
    best_loss = 1e9
    best_params = None
    
    # Try multiple seeds to escape local minima
    seeds = [42, 123, 7, 99, 2023]
    
    for seed in seeds:
        rng = np.random.RandomState(seed)
        
        # Initialize with a perturbed hexagonal grid for high density
        pts = []
        s = 0.115
        for i in range(10):
            for j in range(10):
                x = i * s + (j % 2) * s / 2
                y = j * s * np.sqrt(3) / 2
                if 0.02 <= x <= 0.98 and 0.02 <= y <= 0.98:
                    pts.append([x, y])
                    
        if len(pts) < n:
            pts.extend(rng.rand(20, 2) * 0.9 + 0.05)
            
        rng.shuffle(pts)
        centers_init = np.array(pts[:n])
        # Add small random noise to break symmetry
        centers_init += rng.rand(n, 2) * 0.005
        
        # Start with relatively large radii to encourage growth
        radii_init = np.ones(n) * 0.09
        params0 = np.concatenate([centers_init, radii_init])
        
        bounds = [(0.0, 1.0)] * (2 * n) + [(0.0, 0.5)] * n
        
        cur_params = params0
        # Sequentially increase penalty to enforce constraints
        penalties = [100, 500, 2000, 10000, 50000]
        for p in penalties:
            res = minimize(compute_loss, cur_params, args=(n, p), 
                          method='L-BFGS-B', bounds=bounds, 
                          options={'maxiter': 5000, 'ftol': 1e-15})
            cur_params = res.x
            
        cur_loss = compute_loss(cur_params, n, 50000)
        if cur_loss < best_loss:
            best_loss = cur_loss
            best_params = cur_params.copy()
            
    centers = best_params[:2*n].reshape(n, 2)
    radii = best_params[2*n:]
    radii = np.maximum(radii, 0.0)
    
    # Final validation & safety shrink if any minor numerical violations remain
    max_viol = 0.0
    for i in range(n):
        x, y = centers[i]
        r = radii[i]
        v = max(0, r - x)
        max_viol = max(max_viol, v)
        v = max(0, r - y)
        max_viol = max(max_viol, v)
        v = max(0, x + r - 1)
        max_viol = max(max_viol, v)
        v = max(0, y + r - 1)
        max_viol = max(max_viol, v)
        
    for i in range(n):
        for j in range(i + 1, n):
            dist = np.sqrt(np.sum((centers[i] - centers[j])**2))
            min_dist = radii[i] + radii[j]
            if dist < min_dist:
                max_viol = max(max_viol, min_dist - dist)
                
    # If violations exceed tolerance, uniformly scale down radii slightly
    if max_viol > 1e-8:
        shrink_factor = 1.0 - max_viol / (np.max(radii) + 1e-12)
        radii *= shrink_factor
        
    return centers, radii, np.sum(radii)
