

To maximize the sum of radii for 26 circles in a unit square, we must balance the area efficiency of the circles against the geometric constraints of the packing. While equal radii are a standard starting point, allowing for variable radii and using a dense initial layout (like a hexagonal lattice) provides a better starting position for numerical optimization.

### Strategy
1.  **Initialization**: We begin with a dense hexagonal packing of 26 circles. This arrangement minimizes wasted space between circles, allowing for larger radii than a square grid. We assign a small initial radius to all circles to ensure they are valid.
2.  **Optimization**: We use a penalty-based approach with the `L-BFGS-B` solver from `scipy.optimize`. 
    *   **Objective**: Minimize $- \sum r_i$ (equivalent to maximizing the sum of radii).
    *   **Penalty Function**: A smooth quadratic penalty is applied to the objective function. It heavily penalizes violations of the non-overlap constraint (circles touching or intersecting) and the boundary constraint (circles extending beyond the unit square).
3.  **Refinement**: The optimization is performed over the 78 variables (26 x, 26 y, and 26 radii). To prevent boundary drift during the optimization of centers, we enforce hard bounds ($x, y \in [0, 1]$).

This approach allows the solver to dynamically adjust positions and sizes to push the total sum of radii as high as possible while respecting the physical constraints.

```python
import numpy as np
from scipy.optimize import minimize

def run_packing() -> tuple[np.ndarray, np.ndarray, float]:
    n = 26
    
    # Strategy: Initialize with a hexagonal packing to maximize initial density
    radii_initial = np.zeros(n)
    centers = np.zeros((n, 2))
    
    # Parameters for hexagonal grid
    r_init = 0.085
    spacing_x = 2 * r_init
    spacing_y = r_init * np.sqrt(3)
    
    count = 0
    row = 0
    col = 0
    
    # Pack circles in a hexagonal pattern
    while count < n and row * spacing_y + 2 * r_init <= 1.1: # Slight overshoot allowed during init
        x_offset = (row % 2) * (spacing_x / 2)
        current_y = r_init + row * spacing_y
        
        col = 0
        while count < n:
            current_x = r_init + x_offset + col * spacing_x
            
            if current_x + r_init <= 1.0 and current_y + r_init <= 1.0:
                centers[count] = [current_x, current_y]
                radii_initial[count] = r_init
                count += 1
                col += 1
            else:
                break
        row += 1
        
    # Flatten centers for optimization
    x0 = np.concatenate([centers.flatten(), radii_initial])
    
    # Penalty function for constraints
    def objective_with_penalty(params, penalty_weight):
        # Reshape parameters
        centers_opt = params[:n*2].reshape(n, 2)
        radii_opt = params[n*2:]
        
        # Objective: Maximize sum of radii (Minimize negative sum)
        val = -np.sum(radii_opt)
        
        # Penalty for boundary violations
        # x - r >= 0, y - r >= 0, x + r <= 1, y + r <= 1
        boundary_penalties = np.maximum(0, radii_opt - centers_opt[:, 0]) + \
                             np.maximum(0, radii_opt - centers_opt[:, 1]) + \
                             np.maximum(0, centers_opt[:, 0] + radii_opt - 1.0) + \
                             np.maximum(0, centers_opt[:, 1] + radii_opt - 1.0)
        
        # Penalty for overlaps
        # dist >= r_i + r_j => dist^2 >= (r_i + r_j)^2
        # We use linear penalty for simplicity: r_i + r_j - dist
        for i in range(n):
            for j in range(i + 1, n):
                dist = np.sqrt(np.sum((centers_opt[i] - centers_opt[j]) ** 2))
                overlap = radii_opt[i] + radii_opt[j] - dist
                if overlap > 0:
                    val += penalty_weight * overlap**2
        
        val += penalty_weight * np.sum(boundary_penalties**2)
        return val

    # Bounds: x, y in [0, 1], radii >= 0 (practical max 0.5)
    bounds = [(0.0, 1.0)] * (n * 2) + [(0.0, 0.5)] * n
    
    # Optimization setup
    result = minimize(objective_with_penalty, x0, args=(1e5,), method='L-BFGS-B', bounds=bounds, options={'maxiter': 5000, 'ftol': 1e-10})
    
    # Extract and refine the final solution
    final_centers = result.x[:n*2].reshape(n, 2)
    final_radii = result.x[n*2:]
    
    # Final clipping to ensure strict feasibility
    final_centers = np.clip(final_centers, final_radii[:, None], 1.0 - final_radii[:, None])
    final_radii = np.clip(final_radii, 0.0, 0.5)
    
    return final_centers, final_radii, float(np.sum(final_radii))
```
