

<strategy>
1. **Initialization**: Start with a hexagonal lattice arrangement of 26 points. Hexagonal packing is known to be optimal for density in 2D. We arrange them in 5 staggered rows (alternating 6 and 5 circles) to maximize initial packing density.
2. **Scaling & Centering**: Shift and scale the initial points to sit comfortably inside the unit square $[0,1]^2$, leaving margin for expansion. Initial radii are set to a feasible small value ($r=0.05$).
3. **Optimization Formulation**: 
   - Variables: $z = [x_1, y_1, r_1, \dots, x_{26}, y_{26}, r_{26}]$ (78 dimensions).
   - Objective: Maximize $\sum r_i \Rightarrow$ Minimize $-\sum r_i$.
   - Constraints: 
     - Boundary: $r_i \le x_i \le 1-r_i$ and $r_i \le y_i \le 1-r_i$ for all $i$.
     - Non-overlap: $\sqrt{(x_i-x_j)^2 + (y_i-y_j)^2} \ge r_i + r_j$ for all $i < j$.
   - Bounds: $x_i, y_i \in [0, 1]$, $r_i \in [0, 0.5]$.
4. **Solver**: Use `scipy.optimize.minimize` with the `SLSQP` method, which handles nonlinear inequality constraints efficiently. We enforce all pairwise distance constraints (325 constraints) to guarantee global non-overlap during optimization. A tight tolerance (`ftol=1e-10`) and sufficient iterations (`maxiter=1000`) are set to converge to a high-quality local optimum.
5. **Post-processing**: Ensure radii are non-negative and extract the final configuration. The optimizer naturally pushes circles against each other and boundaries to maximize the sum of radii, typically yielding configurations close to the theoretical optimum (~2.63+).

import numpy as np
from scipy.optimize import minimize

def run_packing() -> tuple[np.ndarray, np.ndarray, float]:
    n = 26
    
    # 1. Initialize with a hexagonal lattice pattern
    centers = np.zeros((n, 2))
    idx = 0
    # 5 staggered rows provide a dense initial configuration
    for row in range(5):
        num_cols = 6 if row % 2 == 0 else 5
        for col in range(num_cols):
            if idx >= n:
                break
            # Hexagonal spacing
            x = col * 0.17
            y = row * 0.17 * np.sqrt(3) / 2.0
            if row % 2 == 1:
                x += 0.085
            centers[idx] = [x, y]
            idx += 1
            
    # Center and scale to fit inside [0.1, 0.9]x[0.1, 0.9] initially
    centers -= centers.mean(axis=0)
    max_dim = np.max(np.abs(centers))
    centers *= 0.75 / max_dim
    centers += 0.5
    
    # Initial feasible radii
    radii = np.full(n, 0.05)
    x0 = np.concatenate([centers.flatten(), radii])
    
    # Bounds for variables: x,y in [0,1], r in [0, 0.5]
    bounds = [(0.0, 1.0)] * (2 * n) + [(0.0, 0.5)] * n
    
    cons = []
    # Boundary constraints: circles must stay inside [0,1]^2
    for i in range(n):
        cons.append({'type': 'ineq', 'fun': lambda v, i=i: v[3*i] - v[3*i+2]})          # x_i - r_i >= 0
        cons.append({'type': 'ineq', 'fun': lambda v, i=i: 1.0 - v[3*i] - v[3*i+2]})   # 1 - x_i - r_i >= 0
        cons.append({'type': 'ineq', 'fun': lambda v, i=i: v[3*i+1] - v[3*i+2]})       # y_i - r_i >= 0
        cons.append({'type': 'ineq', 'fun': lambda v, i=i: 1.0 - v[3*i+1] - v[3*i+2]}) # 1 - y_i - r_i >= 0
        
    # Inter-circle non-overlap constraints
    for i in range(n):
        for j in range(i + 1, n):
            cons.append({
                'type': 'ineq', 
                'fun': lambda v, i=i, j=j: np.sqrt((v[3*i]-v[3*j])**2 + (v[3*i+1]-v[3*j+1])**2) - v[3*i+2] - v[3*j+2]
            })
            
    # Objective: maximize sum of radii -> minimize negative sum
    def objective(v):
        return -np.sum(v[2::3])
        
    # Run SLSQP optimization
    res = minimize(
        objective, 
        x0, 
        method='SLSQP', 
        bounds=bounds, 
        constraints=cons, 
        options={'maxiter': 1000, 'ftol': 1e-10, 'disp': False}
    )
    
    # Extract and post-process results
    centers_opt = res.x[:2*n].reshape((n, 2))
    radii_opt = res.x[2*n:]
    radii_opt = np.maximum(radii_opt, 0.0)  # Ensure non-negativity
    
    return centers_opt, radii_opt, float(np.sum(radii_opt))
