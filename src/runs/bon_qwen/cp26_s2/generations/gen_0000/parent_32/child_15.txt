

To maximize the sum of radii for 26 circles in a unit square, I will employ a numerical optimization approach that starts from a robust geometric initialization and iteratively optimizes the positions and sizes of the circles.

<strategy>
1.  **Initialization Strategy**: 
    *   Instead of a random start, I will use a **hexagonal (triangular) lattice** pattern. This is the densest possible packing for circles in 2D and provides an excellent starting point close to the global optimum.
    *   I will generate a hexagonal grid of 26 points, scaled and shifted to fit comfortably within the unit square.
    *   To account for the non-convex nature of the problem, I will use a **multi-start strategy**: the optimization will be run multiple times with different random perturbations to the initial grid positions to avoid local minima.

2.  **Optimization Algorithm**:
    *   **Objective Function**: Maximize $\sum r_i$. This is equivalent to minimizing $-\sum r_i$.
    *   **Constraints**:
        *   **Non-overlap**: Distance between any two circle centers $(x_i, y_i)$ and $(x_j, y_j)$ must be at least $r_i + r_j$.
        *   **Boundary**: Each circle must be fully inside $[0,1] \times [0,1]$. This implies $r_i \le x_i \le 1 - r_i$ and $r_i \le y_i \le 1 - r_i$.
    *   **Solver**: `scipy.optimize.minimize` with the `SLSQP` method, which handles non-linear inequality constraints and bounds efficiently.

3.  **Implementation Details**:
    *   Variables are flattened into a 1D array $[x_1, y_1, r_1, \dots, x_{26}, y_{26}, r_{26}]$.
    *   Constraints are defined as inequality functions $g(\mathbf{x}) \ge 0$.
    *   I will include a secondary "polishing" step using a repulsive force heuristic if the optimizer gets stuck, to ensure a high-quality result.
</strategy>

import numpy as np
from scipy.optimize import minimize

def run_packing():
    """
    Pack 26 circles in a unit square to maximize the sum of radii.
    Returns (centers, radii, sum_radii).
    """
    n = 26
    best_sum_r = -np.inf
    best_centers = None
    best_radii = None

    # Strategy: Multi-start optimization from hexagonal lattice configurations
    num_starts = 5
    
    for seed in range(num_starts):
        np.random.seed(seed)
        
        # 1. Generate Hexagonal Grid Initialization
        centers = generate_hex_grid(n)
        
        # 2. Perturb slightly to break symmetry and explore local minima
        # The perturbation should be small enough to keep it feasible but large enough to change topology
        jitter_scale = 0.02
        centers += np.random.uniform(-jitter_scale, jitter_scale, centers.shape)
        # Clip to keep centers inside, though radii are small initially so boundaries are not strictly hit yet
        centers = np.clip(centers, 0.01, 0.99)
        
        # Initial radii guess: small value to ensure feasibility at start
        radii_init = np.full(n, 0.02)
        
        # 3. Setup optimization variables
        # Vector: [x1, y1, r1, x2, y2, r2, ...]
        x0 = np.zeros(3 * n)
        for i in range(n):
            x0[3 * i] = centers[i, 0]
            x0[3 * i + 1] = centers[i, 1]
            x0[3 * i + 2] = radii_init[i]
        
        # Bounds: x, y in [0, 1], r in [0, 0.5]
        bounds = []
        for _ in range(n):
            bounds.append((0.0, 1.0)) # x
            bounds.append((0.0, 1.0)) # y
            bounds.append((0.0, 0.5)) # r
        
        # 4. Define Constraints
        constraints = []
        
        # Boundary Constraints: x >= r, x <= 1-r, y >= r, y <= 1-r
        # Formulated as g(x) >= 0
        for i in range(n):
            idx = 3 * i
            # x - r >= 0
            constraints.append({
                'type': 'ineq',
                'fun': lambda v, i=i: v[3 * i] - v[3 * i + 2]
            })
            # 1 - x - r >= 0
            constraints.append({
                'type': 'ineq',
                'fun': lambda v, i=i: 1.0 - v[3 * i] - v[3 * i + 2]
            })
            # y - r >= 0
            constraints.append({
                'type': 'ineq',
                'fun': lambda v, i=i: v[3 * i + 1] - v[3 * i + 2]
            })
            # 1 - y - r >= 0
            constraints.append({
                'type': 'ineq',
                'fun': lambda v, i=i: 1.0 - v[3 * i + 1] - v[3 * i + 2]
            })
            
        # Non-overlap Constraints: dist(i,j) >= ri + rj
        # Formulated as dist - (ri + rj) >= 0
        for i in range(n):
            for j in range(i + 1, n):
                constraints.append({
                    'type': 'ineq',
                    'fun': lambda v, i=i, j=j: \
                        np.sqrt((v[3 * i] - v[3 * j])**2 + (v[3 * i + 1] - v[3 * j + 1])**2) - (v[3 * i + 2] + v[3 * j + 2])
                })

        # 5. Run Optimization
        try:
            res = minimize(
                fun=lambda v: -np.sum(v[2::3]), # Maximize sum of radii
                x0=x0,
                method='SLSQP',
                bounds=bounds,
                constraints=constraints,
                options={'ftol': 1e-12, 'maxiter': 2000, 'disp': False}
            )
            
            if res.success:
                current_sum = -res.fun
                if current_sum > best_sum_r:
                    best_sum_r = current_sum
                    best_centers = np.array(res.x[::3], res.x[1::3]).T
                    best_radii = res.x[2::3]
        except Exception as e:
            # If optimization fails for a seed, try next one
            continue

    # Fallback if no success (unlikely with robust init)
    if best_centers is None:
        # Return a valid but suboptimal grid packing
        centers = generate_hex_grid(n)
        radii = np.full(n, 0.01)
        return centers, radii, np.sum(radii)

    return best_centers, best_radii, best_sum_r

def generate_hex_grid(n):
    """
    Generate coordinates for n circles in a hexagonal lattice pattern.
    """
    centers = []
    # Hexagonal packing density logic
    # We want to fit n circles. Estimate grid dimensions.
    # Rows will have alternating lengths roughly.
    # Let's just generate a dense triangular lattice and pick n points.
    
    # Basis vectors for triangular lattice
    # v1 = (1, 0), v2 = (0.5, sqrt(3)/2)
    # We want to cover the unit square.
    
    # Generate points on a coarse grid first to determine range
    # Let's create a grid of potential centers
    pts = []
    # Approximate spacing for 26 circles in unit square:
    # Area per circle approx 1/26 ~ 0.038. Radius ~ 0.11. Diameter ~ 0.22.
    # Spacing ~ 0.22.
    
    # Let's just use a simple algorithm to place points hexagonally
    # Row 0: y = r, x = r, 3r, 5r...
    # Row 1: y = r + r*sqrt(3), x = 2r, 4r... (shifted)
    
    # We don't know r yet, so we use a placeholder spacing s
    s = 0.25 
    
    row_idx = 0
    while len(centers) < n:
        y = row_idx * s * np.sqrt(3) / 2
        # Shift x for odd rows
        x_offset = (s / 2) if row_idx % 2 == 1 else 0
        
        x = x_offset
        while True:
            if x > 1.0:
                break
            
            # Add point if within bounds (with margin)
            if x >= 0 and x <= 1 and y >= 0 and y <= 1:
                centers.append([x, y])
            
            x += s
            if len(centers) >= n:
                break
        row_idx += 1
    
    centers = np.array(centers[:n])
    
    # Scale and shift to center in [0,1]x[0,1]
    # Find bounding box
    min_x, min_y = np.min(centers, axis=0)
    max_x, max_y = np.max(centers, axis=0)
    width = max_x - min_x
    height = max_y - min_y
    
    # Target bounds: leave some margin for radii, say 0.1 on each side
    # Or just scale to fit [0.1, 0.9]
    target_min = 0.1
    target_max = 0.9
    target_w = target_max - target_min
    target_h = target_max - target_min
    
    scale_x = target_w / width if width > 0 else 1
    scale_y = target_h / height if height > 0 else 1
    scale = min(scale_x, scale_y)
    
    # Center the scaled box
    new_min_x = (1 - scale * width) / 2
    new_min_y = (1 - scale * height) / 2
    
    centers_scaled = (centers - min_x) * scale + new_min_x
    centers_scaled[:, 1] = (centers[:, 1] - min_y) * scale + new_min_y
    
    return centers_scaled
