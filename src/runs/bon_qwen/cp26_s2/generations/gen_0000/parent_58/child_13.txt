For a fixed number of circles, the sum of radii is maximized when the circles are of equal size (or very close to it), due to the geometry of dense packings. Thus, I will optimize for equal radii $r$, which maximizes $\sum r_i = 26r$.

1. **Initialization**: Place centers on a perturbed hexagonal lattice, which approximates the densest circle packing in the plane.
2. **Iterative Expansion & Relaxation**: Gradually increase the radii while using a force-directed relaxation method to push overlapping circles apart and keep them within the unit square boundaries. This mimics physical pressure and naturally leads to a tight packing configuration.
3. **Escaping Local Minima**: Periodically inject small random perturbations ("jitter") to help the configuration escape suboptimal local arrangements during expansion.
4. **Local Optimization**: Use `scipy.optimize.minimize` with the Nelder-Mead method (derivative-free, robust for non-smooth objectives) to refine positions. The objective is to maximize the minimum feasible radius given the current center positions. Multiple random restarts ensure we find a high-quality local optimum.
5. **Validation & Adjustment**: Compute the final equal radius from the optimized centers, clip positions to ensure strict boundary compliance, and return the results.

import numpy as np
from scipy.optimize import minimize

def compute_min_radius(centers, n):
    """
    Compute the maximum equal radius that fits given the centers.
    Returns the minimum distance to any boundary or half-distance to any other circle.
    """
    min_r = 1.0
    for i in range(n):
        # Distance to square boundaries
        r_i = min(centers[i, 0], 1.0 - centers[i, 0], 
                  centers[i, 1], 1.0 - centers[i, 1])
        # Distance to other circles
        for j in range(i + 1, n):
            diff = centers[i] - centers[j]
            d = np.sqrt(np.sum(diff ** 2))
            r_i = min(r_i, d / 2.0)
        min_r = min(min_r, r_i)
    return min_r

def objective(pos, n):
    """Objective function to minimize (negative of max equal radius)."""
    centers = pos.reshape(-1, 2)
    return -compute_min_radius(centers, n)

def run_packing():
    np.random.seed(42)
    n = 26
    
    # 1. Hexagonal lattice initialization
    centers = np.zeros((n, 2))
    idx = 0
    for row in range(7):
        cols = 5 if row % 2 == 0 else 6
        for col in range(cols):
            if idx < n:
                x = 0.12 + col * 0.16 + (0.08 if row % 2 == 1 else 0)
                y = 0.12 + row * 0.14
                centers[idx] = [x, y]
                idx += 1
                
    radii = np.full(n, 0.03)
    
    # 2. Iterative expansion and force-directed relaxation
    for step in range(8000):
        radii *= 1.0008  # Slowly expand circles
        
        # Relaxation steps to resolve overlaps and boundary violations
        for _ in range(30):
            # Push overlapping circles apart
            for i in range(n):
                for j in range(i + 1, n):
                    diff = centers[i] - centers[j]
                    dist = np.sqrt(np.sum(diff ** 2))
                    if dist < radii[i] + radii[j] and dist > 1e-9:
                        push = (radii[i] + radii[j] - dist) / 2.0
                        centers[i] += diff / dist * push
                        centers[j] -= diff / dist * push
                        
            # Enforce boundary constraints
            for i in range(n):
                for d in range(2):
                    if centers[i, d] < radii[i]:
                        centers[i, d] = radii[i]
                    elif centers[i, d] > 1.0 - radii[i]:
                        centers[i, d] = 1.0 - radii[i]
                        
        # Periodic random jitter to escape local minima
        if step % 500 == 0:
            centers += np.random.normal(0, 0.005, centers.shape)
            centers = np.clip(centers, 0.01, 0.99)
            
    # 3. Local optimization with multiple restarts
    best_res = None
    best_val = np.inf
    
    for restart in range(5):
        if restart > 0:
            centers += np.random.normal(0, 0.01, centers.shape)
            centers = np.clip(centers, 0.01, 0.99)
            
        res = minimize(objective, centers.flatten(), args=(n,), 
                       method='Nelder-Mead', 
                       options={'maxiter': 150000, 'xatol': 1e-9, 'fatol': 1e-9})
        if res.fun < best_val:
            best_val = res.fun
            best_res = res
            
    centers = best_res.x.reshape(-1, 2)
    min_r = -best_val
    radii = np.full(n, min_r)
    
    # 4. Final boundary clamping and safety adjustments
    for i in range(n):
        for d in range(2):
            centers[i, d] = np.clip(centers[i, d], radii[i] + 1e-12, 1.0 - radii[i] - 1e-12)
            
    return centers, radii, np.sum(radii)
