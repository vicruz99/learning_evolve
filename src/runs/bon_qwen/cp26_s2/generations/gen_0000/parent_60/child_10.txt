

To maximize the sum of radii for 26 circles in a unit square, we use a two-stage optimization strategy. 

### Strategy
1. **Equal Radius Initialization and Optimization**: We first find the optimal configuration for 26 circles of equal radius $r$. This is equivalent to maximizing the minimum pairwise distance and the minimum distance to the boundary. We initialize the centers using a hexagonal lattice pattern and then refine their positions using `scipy.optimize.minimize` (SLSQP) to find the highest possible $r$ such that no overlaps or boundary violations occur.
2. **LP-Based Relaxation**: Once the optimal centers are established, we relax the equal-radius constraint. By solving a Linear Program (LP) where the objective is to maximize the sum of radii ($\sum r_i$) subject to the distance constraints imposed by the fixed centers, we identify the exact optimal radii. This often allows certain circles to grow slightly larger by filling gaps in the lattice, increasing the total sum.

The final solution satisfies all constraints, including non-overlap and boundary limits.

```python
import numpy as np
from scipy.optimize import minimize, linprog
import math

def run_packing():
    n = 26
    
    # Stage 1: Optimize Equal Radius Configuration
    # Variables: [x1, y1, ..., x26, y26, r]
    # Objective: Maximize r (minimize -r)
    
    def generate_initial_guess():
        centers = []
        r_init = 0.09
        dx = 2 * r_init
        dy = math.sqrt(3) * r_init
        x_offset = dx / 2
        i, j = 0, 0
        while len(centers) < n:
            x = j * dx + (i % 2) * x_offset
            y = i * dy
            centers.append([x, y])
            j += 1
            if j > 4: # Adjust row length for hex packing
                j = 0
                i += 1
        centers = np.array(centers[:n])
        # Normalize to fit in [0, 1]
        min_c = np.min(centers, axis=0)
        max_c = np.max(centers, axis=0)
        scale = 1.0 / np.max(max_c - min_c)
        centers = (centers - min_c) * scale
        centers *= 0.9 # Add margin
        return centers, r_init * scale

    centers_init, r_guess = generate_initial_guess()
    
    def objective(vars):
        return -vars[-1] # Maximize r
    
    def get_constraints(vars, centers, n):
        cons = []
        r = vars[-1]
        cx = vars[:2*n:2]
        cy = vars[1:2*n:2]
        
        # Boundary constraints: x_i >= r, 1-x_i >= r, etc.
        for i in range(n):
            cons.append({'type': 'ineq', 'fun': lambda v, i=i: v[2*i] - v[-1]}) # x_i >= r
            cons.append({'type': 'ineq', 'fun': lambda v, i=i: 1.0 - v[2*i] - v[-1]}) # 1-x_i >= r
            cons.append({'type': 'ineq', 'fun': lambda v, i=i: v[2*i+1] - v[-1]}) # y_i >= r
            cons.append({'type': 'ineq', 'fun': lambda v, i=i: 1.0 - v[2*i+1] - v[-1]}) # 1-y_i >= r
            
        # Overlap constraints: dist_ij >= 2r
        for i in range(n):
            for j in range(i + 1, n):
                cons.append({'type': 'ineq', 'fun': lambda v, i=i, j=j: 
                    (v[2*i] - v[2*j])**2 + (v[2*i+1] - v[2*j+1])**2 - 4 * v[-1]**2})
        return cons

    # Initial variables: [x1, y1, ..., x26, y26, r]
    initial_vars = np.concatenate([centers_init.flatten(), [r_guess]])
    constraints = get_constraints(initial_vars, centers_init, n)

    result = minimize(objective, initial_vars, method='SLSQP', constraints=constraints, 
                      options={'maxiter': 1000, 'ftol': 1e-12})
    
    best_r = result.x[-1]
    best_centers = result.x[:2*n].reshape(n, 2)

    # Stage 2: Optimize Sum of Radii (LP)
    # Maximize sum(r_i) s.t. r_i + r_j <= dist_ij, r_i <= dist_to_wall
    
    # Build LP matrix A_ub and b_ub for constraints: A_ub @ r <= b_ub
    # Constraints are: r_i + r_j <= d_ij and r_i <= d_wall_i
    
    A_ub = []
    b_ub = []
    
    # Pairwise constraints
    dist_matrix = np.sqrt(np.sum((best_centers[:, np.newaxis] - best_centers[np.newaxis, :])**2, axis=2))
    for i in range(n):
        for j in range(i + 1, n):
            row = np.zeros(n)
            row[i] = 1.0
            row[j] = 1.0
            A_ub.append(row)
            b_ub.append(dist_matrix[i, j])
            
    # Boundary constraints
    for i in range(n):
        row = np.zeros(n)
        row[i] = 1.0
        d_wall = min(best_centers[i, 0], 1.0 - best_centers[i, 0], 
                     best_centers[i, 1], 1.0 - best_centers[i, 1])
        A_ub.append(row)
        b_ub.append(d_wall)

    # Solve LP
    c_obj = -np.ones(n) # Minimize -sum(r_i)
    bounds = [(0, None) for _ in range(n)]
    
    lp_result = linprog(c_obj, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
    
    if lp_result.success:
        radii = lp_result.x
        sum_radii = np.sum(radii)
        return best_centers, radii, sum_radii
    else:
        # Fallback to equal radii if LP fails
        return best_centers, np.full(n, best_r), best_r * n
```
