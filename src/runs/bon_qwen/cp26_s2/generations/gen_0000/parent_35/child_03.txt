

To pack 26 circles in a unit square to maximize the sum of radii, a continuous optimization approach with penalty functions is most effective. This method treats the problem as a constrained non-linear optimization, where we minimize the negative sum of radii while penalizing boundary violations and circle overlaps.

### Strategy

1.  **Variable Representation**: The state of the system is defined by 26 circles, each having 3 variables (x, y, r). This results in a 78-dimensional optimization space.
2.  **Initialization**: To provide a high-quality starting point for the solver, we use a hexagonal (triangular) lattice arrangement. This packing is significantly denser than a simple grid and helps avoid local minima.
3.  **Objective Function**: We define an objective function to minimize. This function is composed of:
    *   The negative sum of all radii (to be maximized).
    *   A hard penalty for boundary violations (circles extending outside $[0, 1]$).
    *   A hard penalty for overlaps (distance between centers less than sum of radii).
4.  **Optimization Algorithm**: We use `scipy.optimize.minimize` with the L-BFGS-B method. This algorithm is efficient for large-scale problems and handles box constraints (bounding $x, y \in [0, 1]$ and $r \ge 0$) very effectively.
5.  **Convergence**: The solver iteratively adjusts positions and radii to expand the circles until they are as large as possible without violating the unit square or non-overlap constraints.

The final packing should yield a sum of radii close to or exceeding the target of 2.636.

```python
import numpy as np
from scipy.optimize import minimize

def run_packing() -> tuple[np.ndarray, np.ndarray, float]:
    """
    Optimizes the placement of 26 circles in a unit square to maximize the sum of radii.
    """
    n = 26
    
    # 1. Initialization: Hexagonal Lattice
    # Using a hexagonal pattern provides a high-density starting configuration.
    centers = []
    r_guess = 0.1
    row_y = r_guess
    
    row_count = 0
    while len(centers) < n:
        is_shifted = row_count % 2 != 0
        x = r_guess + (r_guess if is_shifted else 0)
        row_circles = 0
        
        while x <= 1 - r_guess:
            if len(centers) < n:
                centers.append([x, row_y])
            row_circles += 1
            x += 2 * r_guess
            
        row_y += r_guess * np.sqrt(3)
        row_count += 1
        
    centers = np.array(centers[:n])
    
    # 2. Setup Variables and Bounds
    # Flatten the state: (x1, y1, r1, x2, y2, r2, ...)
    initial_vars = np.zeros(3 * n)
    for i in range(n):
        initial_vars[3 * i] = centers[i, 0]
        initial_vars[3 * i + 1] = centers[i, 1]
        initial_vars[3 * i + 2] = r_guess
    
    bounds = []
    for i in range(n):
        bounds.extend([(0, 1), (0, 1), (0, 0.5)])
        
    # 3. Define Objective and Penalty Functions
    def objective(vars):
        centers_opt = np.zeros((n, 2))
        radii_opt = np.zeros(n)
        
        for i in range(n):
            centers_opt[i, 0] = vars[3 * i]
            centers_opt[i, 1] = vars[3 * i + 1]
            radii_opt[i] = vars[3 * i + 2]
            
        total_r = np.sum(radii_opt)
        penalty = 0.0
        
        # Boundary Penalties
        for i in range(n):
            x, y = centers_opt[i]
            r = radii_opt[i]
            if x < r:
                penalty += (r - x) ** 2
            if x > 1 - r:
                penalty += (x - (1 - r)) ** 2
            if y < r:
                penalty += (r - y) ** 2
            if y > 1 - r:
                penalty += (y - (1 - r)) ** 2
                
        # Overlap Penalties
        for i in range(n):
            for j in range(i + 1, n):
                dx = centers_opt[i, 0] - centers_opt[j, 0]
                dy = centers_opt[i, 1] - centers_opt[j, 1]
                dist = np.sqrt(dx ** 2 + dy ** 2)
                sum_r = radii_opt[i] + radii_opt[j]
                
                if dist < sum_r:
                    penalty += (sum_r - dist) ** 2
                    
        return -total_r + 100.0 * penalty

    # 4. Run Optimization
    result = minimize(objective, initial_vars, method='L-BFGS-B', bounds=bounds, 
                      options={'maxiter': 5000, 'ftol': 1e-10})
    
    # 5. Extract and Format Results
    final_centers = np.zeros((n, 2))
    final_radii = np.zeros(n)
    
    for i in range(n):
        final_centers[i, 0] = result.x[3 * i]
        final_centers[i, 1] = result.x[3 * i + 1]
        final_radii[i] = result.x[3 * i + 2]
        
    return final_centers, final_radii, np.sum(final_radii)
```
