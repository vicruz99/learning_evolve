

To maximize the sum of the radii of 26 circles within a unit square $[0,1] \times [0,1]$, we employ a hybrid optimization strategy. Since unequal radii can better fill the irregular gaps of a square container compared to equal radii, we use a "balloon inflation" heuristic combined with physical repulsion.

### Strategy
1.  **Hexagonal Initialization**: We place 26 centers in a dense hexagonal pattern, which provides a high initial packing density.
2.  **Iterative Inflation**: We gradually increase the radii of all circles. 
3.  **Overlap Resolution**: When circles overlap, we repel their centers along the line connecting them. The force is proportional to the overlap distance.
4.  **Boundary Constraints**: We ensure all circles remain within the unit square by reflecting centers that exceed boundaries.
5.  **Annealing**: A cooling factor reduces the movement step size over time, allowing the configuration to settle into a stable state where the sum of radii is maximized.

```python
import numpy as np
import math

def run_packing() -> tuple[np.ndarray, np.ndarray, float]:
    np.random.seed(42)
    n = 26
    centers = np.zeros((n, 2))
    radii = np.ones(n) * 0.01

    # Hexagonal initialization
    row_length = int(math.ceil(math.sqrt(n * 2 / math.sqrt(3))))
    cols = int(math.ceil(n / row_length))
    h = math.sqrt(3) / 2
    count = 0
    for r in range(cols):
        for c in range(row_length):
            if count >= n:
                break
            x = (c + 0.5 + (r % 2) * 0.5) * 0.15 + 0.05
            y = r * 0.15 + 0.05
            if x < 1 and y < 1:
                centers[count] = [x, y]
                count += 1
    if count < n:
        for i in range(count, n):
            centers[i] = [np.random.uniform(0.1, 0.9), np.random.uniform(0.1, 0.9)]

    # Inflation parameters
    growth_rate = 0.0005
    decay = 0.9998
    max_iter = 30000
    current_r = 0.05
    alpha = 0.05
    alpha_decay = 0.9999

    for _ in range(max_iter):
        current_r *= (1 + growth_rate)
        radii[:] = current_r
        alpha *= alpha_decay

        # Compute pairwise repulsion
        force = np.zeros_like(centers)
        for i in range(n):
            for j in range(i + 1, n):
                vec = centers[i] - centers[j]
                dist = np.linalg.norm(vec)
                min_dist = radii[i] + radii[j]
                if dist < min_dist and dist > 1e-8:
                    overlap = min_dist - dist
                    force[i] += (vec / dist) * overlap
                    force[j] -= (vec / dist) * overlap
        
        # Apply forces and boundary reflection
        centers += alpha * force
        centers = np.clip(centers, 0, 1)
        # Ensure boundary constraints are strictly met by pushing back
        for i in range(n):
            if centers[i, 0] < radii[i]: centers[i, 0] = radii[i]
            if centers[i, 0] > 1 - radii[i]: centers[i, 0] = 1 - radii[i]
            if centers[i, 1] < radii[i]: centers[i, 1] = radii[i]
            if centers[i, 1] > 1 - radii[i]: centers[i, 1] = 1 - radii[i]

    # Final validation and scaling
    min_r = float('inf')
    for i in range(n):
        r_i = float('inf')
        # Boundary check
        r_i = min(r_i, centers[i, 0], 1 - centers[i, 0], centers[i, 1], 1 - centers[i, 1])
        # Neighbor check
        for j in range(i + 1, n):
            dist = np.linalg.norm(centers[i] - centers[j])
            r_i = min(r_i, dist)
        radii[i] = r_i / 2

    total_sum = np.sum(radii)
    return centers, radii, total_sum
```
