1. **Structured Initialization**: We will start with a highly efficient hexagonal (staggered) grid. For 26 circles, a 5x5 grid is too loose, so we will distribute circles across staggered rows (e.g., 5-5-5-5-6) to utilize vertical space more effectively.
2. **Linear Programming (LP) for Radii**: For any fixed set of centers, the maximum possible radii can be found exactly by solving a Linear Programming problem. We maximize $\sum r_i$ subject to the constraints $r_i + r_j \le \text{dist}(c_i, c_j)$ and boundary constraints $r_i \le \min(x_i, 1-x_i, y_i, 1-y_i)$.
3. **Local Search on Centers**: To improve the objective further, we will use a "Simulated Annealing" or Hill Climbing approach on the center coordinates. By iteratively moving individual circles away from boundaries and neighbors, we create more "slack" for the radii to expand. We will also include random restarts to avoid local minima.

This strategy treats the problem as a joint optimization: optimizing the radii for a given configuration, then optimizing the configuration to allow for larger radii.

import numpy as np
from scipy.optimize import linprog
import random

def get_lp_constraints(centers, n):
    """
    Constructs the constraint matrix A_ub and vector b_ub for the Linear Programming problem.
    Constraints:
    1. r_i + r_j <= distance(i, j) for all pairs i < j
    2. r_i <= x_i
    3. r_i <= 1 - x_i
    4. r_i <= y_i
    5. r_i <= 1 - y_i
    6. r_i >= 0 (handled by bounds)
    
    Objective: Maximize sum(r_i) -> Minimize -sum(r_i)
    """
    # Number of variables: 26 radii
    n_vars = n
    A_ub = []
    b_ub = []

    # 1. Pairwise distance constraints: r_i + r_j <= dist
    for i in range(n):
        for j in range(i + 1, n):
            dist = np.sqrt(np.sum((centers[i] - centers[j]) ** 2))
            row = [0.0] * n_vars
            row[i] = 1.0
            row[j] = 1.0
            A_ub.append(row)
            b_ub.append(dist)

    # 2-5. Boundary constraints for each circle
    for i in range(n):
        x, y = centers[i]
        
        # r_i <= x
        row = [0.0] * n_vars
        row[i] = 1.0
        A_ub.append(row)
        b_ub.append(x)
        
        # r_i <= 1 - x
        row = [0.0] * n_vars
        row[i] = 1.0
        A_ub.append(row)
        b_ub.append(1.0 - x)
        
        # r_i <= y
        row = [0.0] * n_vars
        row[i] = 1.0
        A_ub.append(row)
        b_ub.append(y)
        
        # r_i <= 1 - y
        row = [0.0] * n_vars
        row[i] = 1.0
        A_ub.append(row)
        b_ub.append(1.0 - y)

    return np.array(A_ub), np.array(b_ub)

def solve_radii_lp(centers):
    """Solves for optimal radii given fixed centers using LP."""
    n = centers.shape[0]
    c_obj = -np.ones(n)  # Maximize sum r_i => Minimize -sum r_i
    
    A_ub, b_ub = get_lp_constraints(centers, n)
    bounds = [(0, None) for _ in range(n)]
    
    try:
        res = linprog(c_obj, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
        if res.success:
            return res.x, -res.fun
        else:
            # Fallback to small radii if LP fails
            return np.full(n, 0.001), 0.0
    except Exception:
        return np.full(n, 0.001), 0.0

def generate_hexagonal_init(n):
    """Generates a staggered hexagonal initialization for n circles."""
    centers = np.zeros((n, 2))
    
    # Determine rows for 26 circles: 5, 5, 5, 5, 6
    row_counts = [5, 5, 5, 5, 6]
    
    # Estimate radius for spacing
    # 6 circles in width 1 implies 2r approx 1/5 -> r approx 0.1
    # Let's start with r=0.08 to be safe and let optimizer expand
    r = 0.08
    h = np.sqrt(3) * r
    
    idx = 0
    for row_idx, count in enumerate(row_counts):
        y = r + row_idx * h
        
        # Shift odd rows
        if row_idx % 2 == 1:
            x_start = r + r 
        else:
            x_start = r
            
        # Distribute x coordinates evenly within bounds if possible, 
        # but for hex grid we usually use step 2r
        # To fit 'count' circles, we might need to adjust step
        if count > 0:
            # Available width roughly 1 - 2r
            # Step size
            if count == 1:
                x_step = 0 # single circle
            else:
                x_step = (1.0 - 2*r) / (count - 1) # Stretch to fit square better initially
            
            for k in range(count):
                if count == 1:
                    x = 0.5
                else:
                    x = r + k * x_step
                
                if idx < n:
                    centers[idx] = [x, y]
                    idx += 1
                    
    return centers

def run_packing() -> tuple[np.ndarray, np.ndarray, float]:
    np.random.seed(42)
    random.seed(42)
    
    n = 26
    
    # 1. Initialization
    centers = generate_hexagonal_init(n)
    
    # Initial LP solve
    radii, current_sum = solve_radii_lp(centers)
    
    best_centers = centers.copy()
    best_radii = radii.copy()
    best_sum = current_sum
    
    # 2. Local Search (Simulated Annealing / Hill Climbing on Centers)

    num_iterations = 5000
    step_size = 0.05
    
    for it in range(num_iterations):
        # Adapt step size: decrease over time
        current_step = step_size * (1.0 - it / num_iterations)
        
        # Pick a random circle to move
        i = random.randint(0, n - 1)
        
        # Save old position
        old_pos = centers[i].copy()
        
        # Generate new position (random perturbation)
        # Also try to push away from boundaries
        new_pos = old_pos + np.random.normal(0, current_step, 2)
        
        # Clamp to keep centers reasonably inside (though LP handles boundary radii)
        # It's better to allow centers near edge so radii can be 0, 
        # but usually optimal centers are away from edges.
        # Let's just clamp to [0, 1] to avoid extreme values
        new_pos = np.clip(new_pos, 0.0, 1.0)
        
        centers[i] = new_pos
        
        # Solve for radii
        try:
            radii, new_sum = solve_radii_lp(centers)
        except:
            centers[i] = old_pos
            continue
            
        if new_sum > best_sum:
            best_centers = centers.copy()
            best_radii = radii.copy()
            best_sum = new_sum
            # Occasionally reset centers to best to refine? 
            # No, we are exploring.
        else:
            # Accept with some probability (Simulated Annealing)
            # Or just reject (Hill Climbing). 
            # For this problem, pure Hill Climbing might get stuck.
            # Let's use a simple acceptance criteria: if it doesn't improve, revert.
            # But to escape local optima, we can accept worse moves.
            # Given the complexity, let's stick to Hill Climbing but with multiple restarts logic later?
            # Actually, just reverting is safer for validity.
            centers[i] = old_pos

    # 3. Refinement / Random Restarts
    # Try a few random restarts from the best found so far or random grid

    radii = best_radii.copy()

            old_pos = centers[i].copy()

            # Just random for now

            new_pos = np.clip(new_pos, 0.0, 1.0)

                radii, new_sum = solve_radii_lp(centers)

                    best_centers = centers.copy()
                    best_radii = radii.copy()

            except:
