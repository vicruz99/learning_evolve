## Strategy for Packing 26 Circles in a Unit Square

### Key Insight
The problem maximizes the **sum of radii** (not equal radii). This allows circles of different sizes, enabling a much better sum than equal-radius packing. The target 2.636/26 ≈ 0.1014 average radius suggests circles with diameter ~0.2, meaning ~5 circles fit along each side.

### Approach: LP + Simulated Annealing

1. **LP for Optimal Radii**: For any fixed set of positions, finding the optimal radii is a linear program:
   - Maximize sum(r_i)
   - Subject to: r_i ≤ distance to boundaries, r_i + r_j ≤ ||c_i - c_j||
   - This LP has 26 variables and ~429 constraints (very fast with HiGHS)

2. **Simulated Annealing on Positions**: 
   - Initialize with a hexagonal grid (densest 2D packing pattern)
   - Perturb random circle positions
   - Recompute optimal radii via LP
   - Accept/reject moves based on temperature schedule
   - Multiple restarts for robustness

3. **Why this works**:
   - Hexagonal grid starts near-optimal (packing density π/√12 ≈ 0.907)
   - SA explores position space while LP finds best radii for each position
   - Boundary circles naturally get larger radii (fewer constraints)
   - The LP automatically balances large corner/edge circles with interior ones

4. **Expected result**: Hexagonal arrangement with d≈0.2 gives radius≈0.1, sum≈2.6. SA fine-tunes to beat this.

import numpy as np
from scipy.optimize import linprog
import math


def compute_optimal_radii(centers):
    """Given fixed centers, solve LP to find radii maximizing sum."""
    n = len(centers)
    c = -np.ones(n)
    
    A_ub = []
    b_ub = []
    
    for i in range(n):
        x, y = centers[i]
        for b in [x, 1.0 - x, y, 1.0 - y]:
            row = np.zeros(n)
            row[i] = 1.0
            A_ub.append(row)
            b_ub.append(b)
    
    for i in range(n):
        for j in range(i + 1, n):
            dx = centers[i, 0] - centers[j, 0]
            dy = centers[i, 1] - centers[j, 1]
            dist = math.sqrt(dx * dx + dy * dy)
            row = np.zeros(n)
            row[i] = 1.0
            row[j] = 1.0
            A_ub.append(row)
            b_ub.append(dist)
    
    A_ub = np.array(A_ub)
    b_ub = np.array(b_ub)
    bounds = [(0.0, None)] * n
    
    result = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
    
    if result.success:
        return result.x, -result.fun
    else:
        r = 0.005
        return np.full(n, r), r * n


def generate_hex_grid(n, seed_val):
    """Generate hexagonal grid initialization."""
    rng = np.random.RandomState(seed_val)
    centers = np.zeros((n, 2))
    idx = 0
    
    spacing_x = 0.19
    spacing_y = spacing_x * math.sqrt(3) / 2.0
    
    row_sizes = [6, 5, 6, 5, 4]
    
    for row, size in enumerate(row_sizes):
        for col in range(size):
            if idx >= n:
                break
            x_offset = (row % 2) * spacing_x / 2.0
            x = 0.5 + (col - (size - 1) / 2.0) * spacing_x + x_offset
            y = 0.5 + (row - 2) * spacing_y
            
            x += rng.uniform(-0.03, 0.03)
            y += rng.uniform(-0.03, 0.03)
            
            x = max(0.01, min(0.99, x))
            y = max(0.01, min(0.99, y))
            
            centers[idx] = [x, y]
            idx += 1
    
    return centers


def run_packing():
    n = 26
    
    best_centers = None
    best_radii = None
    best_sum = 0.0
    
    restart_configs = [
        {"seed": 42, "temp": 0.05, "iters": 10000, "cool": 0.9996},
        {"seed": 123, "temp": 0.04, "iters": 12000, "cool": 0.9997},
        {"seed": 456, "temp": 0.06, "iters": 8000, "cool": 0.9995},
        {"seed": 789, "temp": 0.03, "iters": 15000, "cool": 0.9998},
        {"seed": 2024, "temp": 0.05, "iters": 10000, "cool": 0.9996},
    ]
    
    for rcfg in restart_configs:
        centers = generate_hex_grid(n, rcfg["seed"])
        
        radii, current_sum = compute_optimal_radii(centers)
        
        if current_sum > best_sum:
            best_sum = current_sum
            best_centers = centers.copy()
            best_radii = radii.copy()
        
        temp = rcfg["temp"]
        min_temp = 1e-10
        cool_rate = rcfg["cool"]
        iterations = rcfg["iters"]
        
        for it in range(iterations):
            i = np.random.randint(n)
            step = temp * 0.12
            new_centers = centers.copy()
            new_centers[i] += np.random.uniform(-step, step, 2)
            new_centers = np.clip(new_centers, 0.001, 0.999)
            
            radii_new, s_new = compute_optimal_radii(new_centers)
            
            delta = s_new - current_sum
            if delta > 0 or np.random.random() < np.exp(delta / max(temp, 1e-10)):
                centers = new_centers
                current_sum = s_new
                
                if current_sum > best_sum:
                    best_sum = current_sum
                    best_centers = centers.copy()
                    best_radii = radii_new.copy()
            
            temp *= cool_rate
            if temp < min_temp:
                break
    
    # Final verification LP
    final_radii, final_sum = compute_optimal_radii(best_centers)
    
    return best_centers, final_radii, final_sum
