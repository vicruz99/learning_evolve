

<strategy>
The goal is to maximize the sum of radii for 26 circles in a unit square. This is a non-linear optimization problem. A direct gradient-based optimization on all variables (centers and radii) is difficult due to non-convex constraints (distance between circles).

A robust strategy is to decouple the problem:
1.  **Fixed Centers, Optimal Radii (LP):** For any fixed set of centers, finding the maximum possible radii is a Linear Programming (LP) problem. The constraints are linear in radii: $r_i + r_j \le \text{dist}(C_i, C_j)$ and $r_i \le \text{dist}(C_i, \text{wall})$.
2.  **Optimize Centers:** We can optimize the centers to maximize the sum of radii obtained from the LP. This can be viewed as a force-directed layout or a local search where we move centers to relieve "pressure" (tight constraints).

**Algorithm:**
1.  **Initialization:** Place 26 circles in a hexagonal grid pattern to ensure good spacing initially.
2.  **Iterative Improvement (Force-Directed):**
    *   **Solve LP:** Compute the maximal radii for the current centers.
    *   **Compute Forces:** Identify "tight" constraints (where circles touch each other or walls). Apply repulsive forces to push touching circles apart and push wall-constrained circles away from walls (to allow them to grow).
    *   **Update Centers:** Move centers based on forces. Clip to $[0, 1]$.
    *   **Decay Step Size:** Reduce the step size over time to converge to a local optimum.
3.  **Final Polish:** Run a final LP to get the precise radii for the optimized centers.

This approach avoids the complexity of non-convex optimization solvers and leverages the speed of LP solvers. It effectively "inflates" the circles while pushing them apart to fit more area.
</strategy>

import numpy as np
from scipy.optimize import linprog
import math

def solve_radii_for_centers(centers):
    """
    Given centers, solve the LP to find maximum radii.
    Maximize sum(r_i)
    s.t.
      r_i + r_j <= dist(centers[i], centers[j])
      r_i <= x_i, r_i <= 1-x_i, r_i <= y_i, r_i <= 1-y_i
      r_i >= 0
    """
    n = centers.shape[0]
    
    # Objective: maximize sum(r) -> minimize -sum(r)
    c = np.ones(n) * -1.0
    
    # Constraints matrix A_ub * r <= b_ub
    # We will build lists of rows and values to be efficient
    A_ub_rows = []
    b_ub_vals = []
    
    # Pairwise constraints: r_i + r_j <= dist_ij
    # We only add constraints for pairs that are close enough to matter?
    # Actually for correctness we should add all, but for speed maybe skip far ones.
    # However, with N=26, 325 constraints is small. Add all.
    
    # Precompute distances
    dists = np.zeros((n, n))
    for i in range(n):
        for j in range(i + 1, n):
            d = np.linalg.norm(centers[i] - centers[j])
            dists[i, j] = d
            dists[j, i] = d
            
    for i in range(n):
        for j in range(i + 1, n):
            # r_i + r_j <= d
            row = np.zeros(n)
            row[i] = 1.0
            row[j] = 1.0
            A_ub_rows.append(row)
            b_ub_vals.append(dists[i, j])
            
    # Wall constraints
    for i in range(n):
        x, y = centers[i]
        
        # r_i <= x
        row = np.zeros(n)
        row[i] = 1.0
        A_ub_rows.append(row)
        b_ub_vals.append(x)
        
        # r_i <= 1 - x
        row = np.zeros(n)
        row[i] = 1.0
        A_ub_rows.append(row)
        b_ub_vals.append(1.0 - x)
        
        # r_i <= y
        row = np.zeros(n)
        row[i] = 1.0
        A_ub_rows.append(row)
        b_ub_vals.append(y)
        
        # r_i <= 1 - y
        row = np.zeros(n)
        row[i] = 1.0
        A_ub_rows.append(row)
        b_ub_vals.append(1.0 - y)
        
    A_ub = np.array(A_ub_rows)
    b_ub = np.array(b_ub_vals)
    
    # Bounds for r_i >= 0
    bounds = [(0, None) for _ in range(n)]
    
    # Solve
    # method='highs' is fast and robust in newer scipy
    res = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
    
    if res.success:
        return res.x
    else:
        # Fallback: return small radii if LP fails (shouldn't happen)
        return np.full(n, 0.01)

def run_packing():
    # 1. Initialization: Hexagonal Grid
    # We want to pack 26 circles.
    # Hexagonal packing density is high.
    # Let's try to fit a hexagonal lattice.
    # Approximate spacing s. Area per circle approx s^2 * sqrt(3)/2.
    # 26 * s^2 * 0.866 approx 1 => s^2 approx 1/22.5 => s approx 0.21.
    
    n = 26
    centers = np.zeros((n, 2))
    
    # Generate hexagonal grid points
    # Row spacing = s * sqrt(3)/2
    # Col spacing = s
    # Offset odd rows by s/2
    
    # Let's estimate s to fit 26 points.
    # Try s = 0.22
    s = 0.22
    row_height = s * math.sqrt(3) / 2
    
    idx = 0
    row = 0
    # Scan rows
    y = 0
    while idx < n:
        # Determine number of points in this row
        # x coordinates: 0, s, 2s... or s/2, 3s/2...
        # We want to fit within [0, 1]
        # Let's place them roughly centered or starting from 0.
        # Actually, optimization will move them. Just need a valid start.
        
        is_odd = (row % 2) == 1
        offset = s / 2 if is_odd else 0
        
        x = offset
        while x <= 1.0 and idx < n:
            if idx < n:
                centers[idx, 0] = x
                centers[idx, 1] = y
                idx += 1
            x += s
        y += row_height
        row += 1
        
    # If we didn't get 26, just fill remaining or adjust. 
    # With s=0.22, we should get enough.
    # If more than 26, trim.
    if len(centers) > n: # Wait, centers is fixed size.
        pass
    
    # Check if we filled all 26
    filled = np.sum(~np.isnan(centers[:, 0])) # Assuming 0 init is fine, but let's be safe
    # Actually centers initialized to 0.
    # Let's just re-verify count.
    # The loop above fills centers sequentially.
    
    # Better initialization: Random jitter around grid to break symmetry
    centers += np.random.uniform(-0.02, 0.02, centers.shape)
    centers = np.clip(centers, 0.0, 1.0)
    
    # 2. Iterative Optimization
    # Force directed relaxation
    num_iterations = 1000
    step_size = 0.05
    
    # Preallocate forces
    forces = np.zeros((n, 2))
    
    for it in range(num_iterations):
        # Solve LP to get optimal radii for current centers
        radii = solve_radii_for_centers(centers)
        
        # Calculate forces
        forces.fill(0.0)
        
        # Pairwise repulsion if touching
        # We can optimize this loop or just run it (26*26 is small)
        for i in range(n):
            for j in range(i + 1, n):
                dist = np.linalg.norm(centers[i] - centers[j])
                if dist < 1e-9:
                    dist = 1e-9
                    vec = np.array([np.random.random()-0.5, np.random.random()-0.5])
                else:
                    vec = centers[i] - centers[j]
                
                # Check if constraint is tight: r_i + r_j approx dist
                # Tolerance
                threshold = 1e-4
                if radii[i] + radii[j] > dist - threshold:
                    # Repulsive force
                    # Force magnitude could be proportional to "pressure"
                    # Simple unit vector is fine
                    force_mag = 1.0
                    dir_vec = vec / dist
                    forces[i] += dir_vec * force_mag
                    forces[j] -= dir_vec * force_mag
        
        # Wall repulsion (push away from walls if constrained)
        for i in range(n):
            x, y = centers[i]
            r = radii[i]
            
            # Left wall x=0, constraint r <= x
            if r > x - 1e-4:
                forces[i, 0] += 1.0
            # Right wall x=1, constraint r <= 1-x
            if r > (1.0 - x) - 1e-4:
                forces[i, 0] -= 1.0
            # Bottom y=0
            if r > y - 1e-4:
                forces[i, 1] += 1.0
            # Top y=1
            if r > (1.0 - y) - 1e-4:
                forces[i, 1] -= 1.0
                
        # Update centers
        centers += step_size * forces
        
        # Clip centers to [0, 1]
        centers = np.clip(centers, 0.0, 1.0)
        
        # Decay step size
        step_size *= 0.995
        
    # 3. Final Calculation
    final_radii = solve_radii_for_centers(centers)
    total_sum = np.sum(final_radii)
    
    # Return valid arrays
    # Ensure radii are non-negative (LP ensures this, but clip just in case)
    final_radii = np.maximum(final_radii, 0.0)
    
    return centers, final_radii, total_sum
