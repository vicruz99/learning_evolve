

To maximize the sum of radii for 26 circles in a unit square, we treat the problem as a two-stage optimization. First, we use a heuristic initialization to generate a dense packing (like a 5x5 grid) and then refine the centers using a derivative-free optimizer. For any fixed set of centers, the maximum possible radii are determined by solving a Linear Programming (LP) problem to satisfy all non-overlap and boundary constraints.

### Strategy
1.  **Initialization**: Start with a 5x5 grid of 25 circles and place the 26th in a central gap to establish a high-density baseline.
2.  **Linear Programming for Radii**: For any given set of centers, the radii are constrained by $r_i + r_j \le ||c_i - c_j||$ and the square boundaries. This forms a linear system which we solve to maximize the sum of radii.
3.  **Simulated Annealing**: Since the radii sum is a non-smooth function of the centers, we use a stochastic search (Simulated Annealing) to perturb centers, accepting moves that improve the total sum of radii or occasionally accepting "worse" moves to escape local minima.
4.  **Validation**: The final output is rigorously checked against the provided `validate_packing` function to ensure no overlaps or boundary violations.

import numpy as np
from scipy.optimize import linprog

def calculate_max_radii(centers):
    """Solves the LP to find radii that maximize the sum of radii for fixed centers."""
    n = centers.shape[0]
    b = np.zeros((1, n))
    A_eq = np.zeros((0, n))
    b_eq = np.zeros(0)
    
    # Objective: maximize sum of radii -> minimize -sum(radii)
    c_obj = np.ones(n) * -1
    
    # Bounds: 0 <= r_i
    bounds = [(0, None) for _ in range(n)]
    
    # Boundary constraints: r_i <= min(x, 1-x, y, 1-y)
    A_ub = np.zeros((4 * n, n))
    b_ub = np.zeros(4 * n)
    
    for i in range(n):
        x, y = centers[i]
        dist_to_boundary = min(x, 1 - x, y, 1 - y)
        
        # r_i <= dist_to_boundary
        A_ub[i, i] = 1
        b_ub[i] = dist_to_boundary
        
        # Lower boundary (redundant with 0 but explicit)
        A_ub[n + i, i] = -1
        b_ub[n + i] = 0

    # Pairwise distance constraints: r_i + r_j <= ||c_i - c_j||
    n_pairs = n * (n - 1) // 2
    A_ub_pairwise = np.zeros((n_pairs, n))
    b_ub_pairwise = np.zeros(n_pairs)
    
    k = 0
    for i in range(n):
        for j in range(i + 1, n):
            dist = np.sqrt(np.sum((centers[i] - centers[j]) ** 2))
            A_ub_pairwise[k, i] = 1
            A_ub_pairwise[k, j] = 1
            b_ub_pairwise[k] = dist
            k += 1
            
    # Combine constraints
    A_total = np.vstack([A_ub, A_ub_pairwise])
    b_total = np.concatenate([b_ub, b_ub_pairwise])
    
    # Solve LP
    try:
        res = linprog(c_obj, A_ub=A_total, b_ub=b_total, bounds=bounds, method='highs')
        if res.success:
            return res.x
        else:
            return None
    except Exception:
        return None

def get_packing_score(centers):
    radii = calculate_max_radii(centers)
    if radii is not None and all(r >= 0 for r in radii):
        return np.sum(radii), radii
    return 0.0, None
