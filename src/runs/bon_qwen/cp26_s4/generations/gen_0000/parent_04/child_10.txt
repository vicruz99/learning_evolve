To maximize the sum of radii for 26 circles in a unit square, we formulate this as a constrained nonlinear optimization problem. The key challenges are handling boundary constraints and non-overlap conditions efficiently.

1. **Variable Transformation**: Instead of optimizing $(x_i, y_i, r_i)$ directly and enforcing $r_i \le x_i \le 1-r_i$ explicitly, we parameterize positions using auxiliary variables $u_i, v_i \in [0, 1]$:
   $x_i = r_i + u_i(1 - 2r_i)$
   $y_i = r_i + v_i(1 - 2r_i)$
   This transformation automatically satisfies all boundary constraints for any $r_i \in [0, 0.5]$ and $u_i, v_i \in [0, 1]$, drastically reducing the number of explicit constraints.

2. **Optimization Setup**: 
   - **Objective**: Maximize $\sum r_i$ (minimize $-\sum r_i$).
   - **Constraints**: Only non-overlap conditions remain: $\sqrt{(x_i-x_j)^2 + (y_i-y_j)^2} \ge r_i + r_j$ for all $i < j$.
   - **Solver**: Use `scipy.optimize.minimize` with the `SLSQP` method, which handles inequality constraints well. We provide the analytical gradient for the objective to speed up convergence.
   - **Multi-restart**: Circle packing has many local optima. We run the optimizer ~10 times with different random initial configurations and keep the best result.

3. **Implementation Details**:
   - All helper functions are defined at the module level to comply with restrictions.
   - Constraint evaluation is vectorized using NumPy broadcasting for performance.
   - No lambda functions or closures are used.

```python
import numpy as np
from scipy.optimize import minimize

N_CIRCLES = 26

def get_positions_and_radii(vars):
    """Recover x, y, r from transformed variables u, v, r."""
    u = vars[0::3]
    v = vars[1::3]
    r = vars[2::3]
    # Transformation ensures x in [r, 1-r] and y in [r, 1-r]
    x = r + u * (1.0 - 2.0 * r)
    y = r + v * (1.0 - 2.0 * r)
    return x, y, r

def obj_fun(vars):
    """Objective: maximize sum of radii (minimize negative sum)."""
    _, _, r = get_positions_and_radii(vars)
    return -np.sum(r)

def obj_jac(vars):
    """Analytical gradient of the objective function."""
    jac = np.zeros_like(vars)
    jac[2::3] = -1.0
    return jac

def cons_fun(vars):
    """Constraint function: pairwise distances must be >= sum of radii."""
    x, y, r = get_positions_and_radii(vars)
    # Vectorized pairwise calculations
    dx = x[:, None] - x[None, :]
    dy = y[:, None] - y[None, :]
    dists = np.hypot(dx, dy)
    r_sum = r[:, None] + r[None, :]
    
    # Extract lower triangular part (i > j) to avoid duplicates and self-pairs
    mask = np.tril(np.ones((N_CIRCLES, N_CIRCLES), dtype=bool), -1)
    return dists[mask] - r_sum[mask]

def run_packing():
    best_sum = 0.0
    best_vars = None
    
    np.random.seed(42)
    # Multiple restarts to escape local optima
    for trial in range(10):
        # Perturb initial radius slightly per trial
        r_init = np.full(N_CIRCLES, 0.08 + trial * 0.002)
        u_init = np.random.rand(N_CIRCLES)
        v_init = np.random.rand(N_CIRCLES)
        
        # Flatten initial guess: u0, v0, r0, u1, v1, r1, ...
        vars0 = np.zeros(3 * N_CIRCLES)
        vars0[0::3] = u_init
        vars0[1::3] = v_init
        vars0[2::3] = r_init
        
        # Bounds: u, v in [0, 1], r in [0, 0.5]
        bounds = [(0.0, 1.0)] * N_CIRCLES + [(0.0, 1.0)] * N_CIRCLES + [(0.0, 0.5)] * N_CIRCLES
        
        cons = {'type': 'ineq', 'fun': cons_fun}
        
        res = minimize(obj_fun, vars0, method='SLSQP', jac=obj_jac, 
                       bounds=bounds, constraints=cons,
                       options={'maxiter': 5000, 'ftol': 1e-12, 'disp': False})
        
        current_sum = -res.fun
        if current_sum > best_sum:
            best_sum = current_sum
            best_vars = res.x.copy()
            
    # Reconstruct final packing
    x, y, r = get_positions_and_radii(best_vars)
    centers = np.column_stack((x, y))
    radii = np.maximum(r, 0.0)
    
    return centers, radii, np.sum(radii)
```
