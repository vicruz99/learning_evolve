To maximize the sum of radii for 26 circles in a unit square, we treat this as a non-linear programming problem. The objective is to maximize $\sum r_i$ subject to non-overlap constraints ($(x_i-x_j)^2 + (y_i-y_j)^2 \ge (r_i+r_j)^2$) and boundary constraints ($r_i \le x_i \le 1-r_i$, $r_i \le y_i \le 1-r_i$).

Key improvements to the packing strategy:
1.  **Heuristic Initialization**: Instead of random initialization which may be infeasible, we start with a dense, valid hexagonal-like grid pattern. This ensures the solver begins in a feasible region with a relatively high sum of radii, allowing it to focus on optimization rather than finding a feasible point.
2.  **Local Optimization (SLSQP)**: We use `scipy.optimize.minimize` with the SLSQP method to perform local search. To escape local minima, we run the optimization from multiple randomized initial configurations (restarted optimization).
3.  **Vectorized Constraints**: Pairwise overlap constraints are computationally expensive. We utilize NumPy broadcasting to compute all pairwise distances simultaneously, significantly accelerating the evaluation of constraints during optimization iterations.
4.  **Variable Radii**: Unlike standard packing problems with fixed sizes, we allow radii to vary. This flexibility is crucial for filling gaps and maximizing the total sum.

The `run_packing` function will:
- Initialize centers based on a perturbed grid.
- Define the objective (negative sum of radii) and constraints (boundary and overlap).
- Run the SLSQP optimizer multiple times.
- Track and return the best valid configuration found.

import numpy as np
from scipy.optimize import minimize

def run_packing():
    """
    Solves the circle packing problem to maximize the sum of radii for 26 circles in a unit square.
    """
    n = 26
    
    # Precompute upper triangle indices for overlap constraints to avoid redundant checks
    # We need indices i, j such that 0 <= i < j < n
    i_idx, j_idx = np.triu_indices(n, k=1)
    
    # Precompute indices for boundary constraints
    # x >= r, 1 - x - r >= 0, y >= r, 1 - y - r >= 0
    # These are linear and handled efficiently, but we can group them.
    # However, SLSQP handles vectorized constraint functions well.

    def objective(vars):
        # vars: [x_1...x_n, y_1...y_n, r_1...r_n]
        r = vars[2*n:]
        # Maximize sum of radii -> Minimize negative sum
        return -np.sum(r)

    def constraints(vars):
        x = vars[:n]
        y = vars[n:2*n]
        r = vars[2*n:]
        
        # 1. Boundary constraints (inequality >= 0)
        # x >= r  => x - r >= 0
        # x <= 1 - r => 1 - x - r >= 0
        # y >= r  => y - r >= 0
        # y <= 1 - r => 1 - y - r >= 0
        
        bound_vals = np.concatenate([
            x - r,
            1.0 - x - r,
            y - r,
            1.0 - y - r
        ])
        
        # 2. Overlap constraints (inequality >= 0)
        # dist^2 >= (r_i + r_j)^2
        # dist^2 - (r_i + r_j)^2 >= 0
        
        # Extract coordinates for pairs
        xi = x[i_idx]
        xj = x[j_idx]
        yi = y[i_idx]
        yj = y[j_idx]
        ri = r[i_idx]
        rj = r[j_idx]
        
        dx = xi - xj
        dy = yi - yj
        r_sum = ri + rj
        
        overlap_vals = (dx**2 + dy**2) - (r_sum**2)
        
        # Return combined constraints array
        return np.concatenate([bound_vals, overlap_vals])

    # Bounds for variables
    # x, y in [0, 1], r in [0, 0.5] (radius cannot exceed 0.5)
    bounds = [(0.0, 1.0)] * (2*n) + [(0.0, 0.5)] * n

    best_sum = -1.0
    best_centers = None
    best_radii = None

    # Number of random restarts to find global optimum
    num_restarts = 15

    for seed in range(num_restarts):
        np.random.seed(seed)
        
        # Initialization strategy:
        # Start with a valid dense packing (e.g., grid) and perturb it.
        # A 5x5 grid gives 25 circles. We need 26.
        # We can use a 6x5 grid pattern or just random valid points.
        # Let's try to place centers in a way that they are roughly spaced.
        
        # Generate random positions, but ensure they are not too close initially
        # Or use a grid.
        
        # Grid initialization
        # 6 rows, 5 cols?
        # Rows at y = 0.1, 0.3, 0.5, 0.7, 0.9 (5 rows)
        # Cols at x = 0.1, 0.3, 0.5, 0.7, 0.9 (5 cols)
        # Total 25 points. Add one more in a gap.
        
        # Better: Use a pseudo-random distribution that is valid.
        # Random x, y in [0,1]. Radius small.
        
        # Let's try a hexagonal-like packing initialization which is dense.
        # Radius approx 0.1.
        
        # Create a list of points
        points = []
        # Try to fill with grid
        step = 0.15
        for i in range(int(1/step) + 1):
            for j in range(int(1/step) + 1):
                if len(points) >= 26:
                    break
                # Add some jitter
                px = (i + 0.5) * step + np.random.uniform(-0.02, 0.02)
                py = (j + 0.5) * step + np.random.uniform(-0.02, 0.02)
                # Clamp
                px = np.clip(px, 0.1, 0.9)
                py = np.clip(py, 0.1, 0.9)
                points.append([px, py])
            if len(points) >= 26:
                break
        
        if len(points) < 26:
            # Fallback if grid didn't reach 26 (shouldn't happen with step 0.15)
            # Just random
            for _ in range(26 - len(points)):
                points.append([np.random.uniform(0.1, 0.9), np.random.uniform(0.1, 0.9)])
        
        centers_init = np.array(points[:26])
        radii_init = np.full(26, 0.08) # Start with small radius to ensure feasibility
        
        x0 = np.concatenate([centers_init[:, 0], centers_init[:, 1], radii_init])
        
        # Define constraints dictionary for SLSQP
        cons = ({'type': 'ineq', 'fun': constraints},)
        
        try:
            # Run optimization
            res = minimize(objective, x0, method='SLSQP', bounds=bounds, constraints=cons, 
                           options={'maxiter': 200, 'ftol': 1e-12, 'disp': False})
            
            if res.success:
                current_centers = np.column_stack((res.x[:n], res.x[n:2*n]))
                current_radii = res.x[2*n:]
                current_sum = np.sum(current_radii)
                
                # Validate solution strictly
                if current_radii.min() >= 0:
                    # Check boundaries
                    if (current_centers - current_radii >= -1e-9).all() and \
                       (current_centers + current_radii <= 1 + 1e-9).all():
                        # Check overlaps
                        # Vectorized check
                        # We need to check if dist >= r_i + r_j for all pairs
                        # Use broadcasting
                        cx = current_centers[:, 0]
                        cy = current_centers[:, 1]
                        r = current_radii
                        
                        # Compute pairwise squared distances
                        dx = cx[:, None] - cx[None, :]
                        dy = cy[:, None] - cy[None, :]
                        dist_sq = dx**2 + dy**2
                        
                        # Compute (r_i + r_j)^2
                        r_sum_sq = (r[:, None] + r[None, :])**2
                        
                        # Check upper triangle
                        # We want dist_sq >= r_sum_sq - tolerance
                        # Using 1e-9 tolerance
                        valid_pairs = (dist_sq >= r_sum_sq - 1e-9)
                        # Check if all pairs (i < j) are valid
                        # We can use triu
                        mask = np.triu(np.ones((n, n), dtype=bool), k=1)
                        if valid_pairs[mask].all():
                            if current_sum > best_sum:
                                best_sum = current_sum
                                best_centers = current_centers.copy()
                                best_radii = current_radii.copy()
        except Exception:
            continue

    # If no solution found (unlikely), return a safe fallback
    if best_centers is None:
        # Fallback: 26 circles of radius 0.05 in a grid
        # 5x5 grid is 25, add one
        xs = np.linspace(0.15, 0.85, 5)
        ys = np.linspace(0.15, 0.85, 5)
        centers_fallback = []
        radii_fallback = []
        cnt = 0
        for y in ys:
            for x in xs:
                centers_fallback.append([x, y])
                radii_fallback.append(0.08)
                cnt += 1
                if cnt == 26:
                    break
            if cnt == 26:
                break
        
        best_centers = np.array(centers_fallback)
        best_radii = np.array(radii_fallback)
        best_sum = np.sum(best_radii)

    return best_centers, best_radii, float(best_sum)
