

To maximize the sum of radii for 26 circles in a unit square, we employ a two-phase strategy: first, generating a dense hexagonal lattice configuration that optimizes the average radius, and second, refining the positions using a numerical optimization algorithm to maximize the objective function while satisfying all geometric constraints.

### Strategy

1.  **Hexagonal Lattice Initialization:**
    Hexagonal packing is the densest arrangement for equal circles. We generate a lattice of 26 points (arranged roughly in 6 rows to fit the aspect ratio of the square) and scale it to fit within the unit square. This provides a high-quality starting point for the optimizer.

2.  **Numerical Optimization:**
    We use a gradient-based solver (`scipy.optimize.minimize`) to maximize the sum of radii.
    - **Objective:** Maximize $\sum r_i$.
    - **Constraints:**
        - **Boundary:** $r_i \le x_i \le 1 - r_i$ and $r_i \le y_i \le 1 - r_i$.
        - **Non-overlap:** $(x_i - x_j)^2 + (y_i - y_j)^2 \ge (r_i + r_j)^2$.
        - **Non-negative radii:** $r_i \ge 0$.
    - **Method:** We use `SLSQP` (Sequential Least Squares Programming) which handles inequality constraints effectively. To ensure robustness, we run the optimization multiple times from the same heuristic starting point, as local minima are common in packing problems.

3.  **Validation:**
    The final configuration is validated to ensure no overlaps or boundary violations exist within a small tolerance.

### Implementation

```python
import numpy as np
from scipy.optimize import minimize
import math

def run_packing():
    """
    Pack 26 circles in a unit square to maximize the sum of radii.
    
    Returns:
        centers: np.array of shape (26, 2)
        radii: np.array of shape (26,)
        sum_radii: float
    """
    n = 26
    
    # 1. Generate Initial Configuration (Hexagonal Lattice)
    # We aim for a layout that is roughly square-shaped to fit the container well.
    # 6 rows with distribution [5, 4, 5, 4, 5, 3] = 26 circles is a good heuristic.
    # Or simpler: 5 rows of 5 (25) + 1, or 6 rows of 4 (24) + 2.
    # Let's try a 6-row hexagonal grid.
    
    centers_init = np.zeros((n, 2))
    radii_init = np.zeros(n)
    
    # Hexagonal packing parameters
    # We want to fit these into [0, 1] x [0, 1]
    # Let's create a lattice with spacing 1, then scale.
    
    row_counts = [5, 4, 5, 4, 5, 3] # Total 26
    # Check sum
    assert sum(row_counts) == n
    
    idx = 0
    rows = []
    for r_idx, count in enumerate(row_counts):
        row = []
        # Hexagonal offset: even rows start at 0, odd rows start at 0.5 (in lattice units)
        # But to keep it simple, let's just place them and scale later.
        # Vertical spacing sqrt(3)/2
        y_base = r_idx * math.sqrt(3) / 2
        for c in range(count):
            # Horizontal spacing 1. Offset odd rows by 0.5
            if r_idx % 2 == 1:
                x_base = c + 0.5
            else:
                x_base = c
            row.append([x_base, y_base])
        rows.append(row)
    
    # Flatten
    all_points = [p for row in rows for p in row]
    
    # Calculate bounding box of this lattice configuration
    xs = [p[0] for p in all_points]
    ys = [p[1] for p in all_points]
    
    min_x, max_x = min(xs), max(xs)
    min_y, max_y = min(ys), max(ys)
    
    width = max_x - min_x
    height = max_y - min_y
    
    # We need to fit this into a square of size (1 - 2*r).
    # But r is unknown. 
    # Let's assume a target radius r ~ 0.1. 
    # Available space ~ 0.8.
    # We can just normalize the points to fit in [0, 1] initially, 
    # and let the optimizer adjust.
    
    # Normalize points to [0, 1] range centered
    # Actually, better to fit them tightly into the square to start close to optimal.
    # Let's scale the lattice to fit in [0.1, 0.9] roughly.
    
    # Determine scale factor to fit in unit square with some margin
    # Let's fit the bounding box into [0, 1] x [0, 1]
    scale = 1.0 / max(width, height)
    
    # Shift and scale
    for i, p in enumerate(all_points):
        x = (p[0] - min_x) * scale
        y = (p[1] - min_y) * scale
        centers_init[i] = [x, y]
    
    # Initial radius estimate: 
    # If points are spread over [0,1], min distance is approx 2*r.
    # Lattice min distance was 1. Scaled by 'scale'.
    # So 2*r ~ scale * 1 => r ~ scale / 2.
    r_est = scale / 2.0
    # But we have boundary constraints. r should be smaller.
    # Let's start with a safe radius, say 0.05
    radii_init[:] = 0.05
    
    # 2. Optimization
    # Variables: [x1, y1, r1, x2, y2, r2, ...]
    # Total variables: 3 * n
    
    best_sum = 0
    best_centers = centers_init.copy()
    best_radii = radii_init.copy()
    
    # Run optimization multiple times to avoid local minima
    for trial in range(3):
        # Shuffle initial positions slightly or just reuse
        x0 = np.concatenate([centers_init.flatten(), radii_init])
        
        def objective(vars):
            # Maximize sum of radii => minimize -sum(radii)
            radii = vars[2::3]
            return -np.sum(radii)
        
        constraints = []
        
        # Boundary constraints: r <= x <= 1-r  =>  x - r >= 0, 1 - x - r >= 0
        # Similarly for y
        for i in range(n):
            idx_x = 3*i
            idx_y = 3*i + 1
            idx_r = 3*i + 2
            
            # x - r >= 0
            constraints.append({'type': 'ineq', 'fun': lambda v, i=i: v[idx_x] - v[idx_r]})
            # 1 - x - r >= 0
            constraints.append({'type': 'ineq', 'fun': lambda v, i=i: 1.0 - v[idx_x] - v[idx_r]})
            # y - r >= 0
            constraints.append({'type': 'ineq', 'fun': lambda v, i=i: v[idx_y] - v[idx_r]})
            # 1 - y - r >= 0
            constraints.append({'type': 'ineq', 'fun': lambda v, i=i: 1.0 - v[idx_y] - v[idx_r]})
            
            # r >= 0
            constraints.append({'type': 'ineq', 'fun': lambda v, i=i: v[idx_r]})
            
        # Overlap constraints: dist^2 >= (r1 + r2)^2
        # dist^2 - (r1 + r2)^2 >= 0
        for i in range(n):
            for j in range(i + 1, n):
                idx_xi, idx_yi, idx_ri = 3*i, 3*i+1, 3*i+2
                idx_xj, idx_yj, idx_rj = 3*j, 3*j+1, 3*j+2
                
                def overlap_constraint(v, i=i, j=j):
                    xi, yi, ri = v[idx_xi], v[idx_yi], v[idx_ri]
                    xj, yj, rj = v[idx_xj], v[idx_yj], v[idx_rj]
                    dist_sq = (xi - xj)**2 + (yi - yj)**2
                    rad_sum = ri + rj
                    return dist_sq - rad_sum**2
                
                constraints.append({'type': 'ineq', 'fun': overlap_constraint})
        
        # Bounds: x, y in [0, 1], r in [0, 1]
        bounds = []
        for i in range(n):
            bounds.append((0.0, 1.0)) # x
            bounds.append((0.0, 1.0)) # y
            bounds.append((0.0, 1.0)) # r (loose upper bound)

        try:
            res = minimize(objective, x0, method='SLSQP', bounds=bounds, constraints=constraints,
                           options={'maxiter': 1000, 'ftol': 1e-9})
            
            if res.success and -res.fun > best_sum:
                best_sum = -res.fun
                best_centers = np.zeros((n, 2))
                best_radii = np.zeros(n)
                for i in range(n):
                    best_centers[i, 0] = res.x[3*i]
                    best_centers[i, 1] = res.x[3*i+1]
                    best_radii[i] = res.x[3*i+2]
        except Exception as e:
            continue
            
    # 3. Post-processing / Validation
    # Clean up very small radii or negative values due to numerical error
    best_radii = np.maximum(best_radii, 1e-9)
    
    # Clamp centers to valid range based on radii
    for i in range(n):
        r = best_radii[i]
        best_centers[i, 0] = np.clip(best_centers[i, 0], r, 1.0 - r)
        best_centers[i, 1] = np.clip(best_centers[i, 1], r, 1.0 - r)
        
    return best_centers, best_radii, np.sum(best_radii)
```
