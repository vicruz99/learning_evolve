This is formulated as a Linear Programming problem. The constraints are that the sum of radii of any two circles must not exceed the distance between their centers ($r_i + r_j \le \|c_i - c_j\|$), and each radius must not exceed the distance to the nearest square boundary ($r_i \le \text{dist}(c_i, \text{boundary})$).
    *   **Position Optimization (Force-Based):** Once the radii are maximized for the current positions, the circles will be "jammed" against each other or the walls. To allow for larger radii in the next iteration, I will apply repulsive forces.
        *   If two circles are touching (active constraint), they repel each other.
        *   If a circle is touching a wall, it is pushed away from that wall.
        *   This movement creates "slack" (increases distances), allowing the LP step in the next iteration to assign larger radii.

3.  **Convergence:**
    The loop continues with a decaying step size until the changes in the sum of radii become negligible or the maximum number of iterations is reached.

4.  **Final Validation:**
    The final configuration is validated to ensure all circles are within the unit square and do not overlap, respecting numerical tolerances.

**Technical Details:**
*   **LP Solver:** `scipy.optimize.linprog` will be used due to its efficiency for the small number of variables (26) and constraints (~325).
*   **Force Calculation:** Forces are derived from the active constraints identified in the LP solution.
*   **Constraints Handling:** The boundary constraints for the LP are simplified into upper bounds for each radius variable ($r_i \le \min(x_i, 1-x_i, y_i, 1-y_i)$), while inter-circle constraints form the inequality matrix.

import numpy as np
import scipy.optimize as opt

def solve_radii_lp(centers):
    """
    Solves the Linear Programming problem to find the maximum sum of radii
    given fixed circle centers.
    
    Args:
        centers: np.array of shape (N, 2)
        
    Returns:
        radii: np.array of shape (N)
    """
    n = centers.shape[0]
    
    # Objective: Maximize sum(r_i) => Minimize sum(-r_i)
    c_obj = -np.ones(n)
    
    # Inequality constraints: A_ub * r <= b_ub
    # We only need to enforce r_i + r_j <= dist(i, j)
    # Boundary constraints are handled via bounds
    
    # Precompute distances
    # Dist matrix (N, N)
    diff = centers[:, np.newaxis, :] - centers[np.newaxis, :, :]
    dists = np.sqrt(np.sum(diff**2, axis=2))
    np.fill_diagonal(dists, np.inf) # No self-constraint
    
    # Build constraint matrix for r_i + r_j <= d_ij
    # Only upper triangle (i < j)
    rows, cols = np.triu_indices(n, k=1)
    
    A_ub = np.zeros((len(rows), n))
    b_ub = np.zeros(len(rows))
    
    for k, (i, j) in enumerate(zip(rows, cols)):
        A_ub[k, i] = 1.0
        A_ub[k, j] = 1.0
        b_ub[k] = dists[i, j]
    
    # Bounds for radii: 0 <= r_i <= distance_to_nearest_wall
    bounds = []
    for i in range(n):
        x, y = centers[i]
        # Distance to nearest wall
        d_wall = min(x, 1.0 - x, y, 1.0 - y)
        bounds.append((0.0, max(0.0, d_wall)))
        
    try:
        res = opt.linprog(c_obj, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
        if res.success:
            return res.x
        else:
            # Fallback if LP fails, return small valid radii
            return np.full(n, 1e-6)
    except Exception:
        return np.full(n, 1e-6)

def compute_forces(centers, radii):
    """
    Computes repulsive forces on centers based on active constraints.
    Active constraints are those where r_i + r_j is very close to distance.
    """
    n = centers.shape[0]
    forces = np.zeros((n, 2))
    epsilon = 1e-4
    
    # Pairwise forces
    for i in range(n):
        for j in range(i + 1, n):
            dx = centers[j, 0] - centers[i, 0]
            dy = centers[j, 1] - centers[i, 1]
            dist = np.sqrt(dx*dx + dy*dy)
            
            if dist < 1e-9:
                # Coincident centers, push random direction
                forces[i] += np.random.randn(2) * 10
                forces[j] -= np.random.randn(2) * 10
                continue
                
            r_sum = radii[i] + radii[j]
            
            # If circles are touching or overlapping (active constraint)
            if r_sum >= dist - epsilon:
                # Force direction: away from each other
                # Vector from j to i is (c_i - c_j). Normalized.
                nx, ny = (centers[i] - centers[j]) / dist
                forces[i] += np.array([nx, ny])
                forces[j] -= np.array([nx, ny])
                
    # Boundary forces
    for i in range(n):
        x, y = centers[i]
        r = radii[i]
        
        # Check boundaries
        # If r is limited by wall, push away
        # Left wall (x - r approx 0)
        if x - r < epsilon:
            forces[i, 0] += 1.0
        # Right wall (1 - x - r approx 0)
        if 1.0 - x - r < epsilon:
            forces[i, 0] -= 1.0
        # Bottom wall (y - r approx 0)
        if y - r < epsilon:
            forces[i, 1] += 1.0
        # Top wall (1 - y - r approx 0)
        if 1.0 - y - r < epsilon:
            forces[i, 1] -= 1.0
            
    return forces
