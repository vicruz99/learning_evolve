To maximize the sum of radii for 26 circles in a unit square, we treat this as a continuous optimization problem. The objective is to maximize $\sum r_i$ subject to non-overlap and boundary constraints. 

Key insights:
1. **Objective & Constraints**: Maximizing $\sum r_i$ is equivalent to minimizing $-\sum r_i$. Constraints are $(x_i-x_j)^2 + (y_i-y_j)^2 \ge (r_i+r_j)^2$ and $r_i \le \min(x_i, 1-x_i, y_i, 1-y_i)$.
2. **Penalty Method**: Instead of hard constraints which can be difficult for gradient-based optimizers, we use a penalty method. We add terms $\max(0, (r_i+r_j)^2 - \|c_i-c_j\|^2)^2$ and $\max(0, r_i - d_i)^2$ to the objective, where $d_i$ is the distance to the nearest boundary. Squared distances are used for smoothness.
3. **Continuation Strategy**: We start with a low penalty weight and a structured initial guess (grid). We iteratively increase the penalty weight, using the previous solution as the starting point. This guides the optimizer from a feasible configuration to a tightly packed optimal one.
4. **Optimization**: `scipy.optimize.minimize` with `L-BFGS-B` is used. It handles box constraints efficiently and uses quasi-Newton methods suitable for this smooth penalty formulation.
5. **Post-processing**: After optimization, we project centers onto the valid domain relative to their radii to guarantee strict compliance with the validation function's tolerance.

This approach is robust, deterministic (via fixed seed), and leverages gradient-based optimization to push the sum of radii beyond simple grid packings.

import numpy as np
from scipy.optimize import minimize

def _packing_objective(z, N, penalty):
    """
    Computes the objective function for circle packing optimization.
    Maximizes sum of radii while penalizing overlaps and boundary violations.
    """
    xs = z[:N]
    ys = z[N:2*N]
    rs = z[2*N:]

    # Primary objective: maximize sum of radii (minimize negative sum)
    val = -np.sum(rs)

    # Overlap penalty using squared distances for smoothness
    diff_x = xs[:, np.newaxis] - xs[np.newaxis, :]
    diff_y = ys[:, np.newaxis] - ys[np.newaxis, :]
    dist_sq = diff_x**2 + diff_y**2

    r_sum = rs[:, np.newaxis] + rs[np.newaxis, :]
    # Positive value indicates overlap: (r_i + r_j)^2 > dist^2
    sq_overlap = r_sum**2 - dist_sq

    triu_idx = np.triu_indices(N, k=1)
    p_overlap = np.sum(np.maximum(0, sq_overlap[triu_idx])**2)

    # Boundary penalty
    dist_bound = np.minimum(np.minimum(xs, 1.0 - xs), np.minimum(ys, 1.0 - ys))
    p_bound = np.sum(np.maximum(0, rs - dist_bound)**2)

    return val + penalty * (p_overlap + p_bound)

def run_packing():
    np.random.seed(42)
    N = 26

    # Initial configuration: structured grid inside the square
    grid_x = np.linspace(0.15, 0.85, 6)
    grid_y = np.linspace(0.15, 0.85, 5)
    cx, cy = np.meshgrid(grid_x, grid_y)
    centers = np.column_stack([cx.ravel(), cy.ravel()])[:N]
    radii = np.full(N, 0.02)

    # Flatten to optimization variable vector: [x0..x25, y0..y25, r0..r25]
    z0 = np.concatenate([centers[:, 0], centers[:, 1], radii])
    bounds = [(0.0, 1.0)]*N + [(0.0, 1.0)]*N + [(0.0, 0.5)]*N

    z_curr = z0
    # Continuation method: gradually increase penalty to enforce constraints
    penalties = [10.0, 100.0, 500.0, 2000.0, 5000.0]

    for p in penalties:
        # Small random perturbation helps escape local minima
        z_curr += np.random.normal(0, 0.0005, size=N*3)
        res = minimize(_packing_objective, z_curr, args=(N, p), method='L-BFGS-B', bounds=bounds,
                       options={'maxiter': 2000, 'ftol': 1e-15, 'gtol': 1e-10})
        z_curr = res.x

    # Extract results
    centers_opt = np.column_stack((z_curr[:N], z_curr[N:2*N]))
    radii_opt = z_curr[2*N:]

    # Ensure non-negative radii
    radii_opt = np.maximum(radii_opt, 0.0)
    
    # Project centers to strictly satisfy boundary constraints
    for i in range(N):
        cx, cy = centers_opt[i]
        r = radii_opt[i]
        centers_opt[i, 0] = np.clip(cx, r, 1.0 - r)
        centers_opt[i, 1] = np.clip(cy, r, 1.0 - r)

    return centers_opt, radii_opt, float(np.sum(radii_opt))
