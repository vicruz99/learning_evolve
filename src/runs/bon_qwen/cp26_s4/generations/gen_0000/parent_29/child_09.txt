

To maximize the sum of radii for 26 circles in a unit square, we use a local optimization approach. The problem is a non-convex Non-Linear Programming (NLP) task. We represent the state of each circle by its center $(x, y)$ and radius $r$. 

The strategy involves:
1.  **Initialization:** Placing 26 circles in a hexagonal lattice to achieve a dense, non-overlapping starting configuration.
2.  **Constraint Formulation:** 
    *   **Boundary:** $r \le x \le 1-r$ and $r \le y \le 1-r$.
    *   **Non-overlap:** $d_{ij} \ge r_i + r_j$ for all pairs $i, j$.
3.  **Optimization:** Using `scipy.optimize.minimize` with the `SLSQP` method to maximize the sum of radii ($\sum r_i$) while satisfying the geometric constraints.

The code implements this by flattening the circle parameters into a single vector and applying inequality constraints to enforce the packing rules.

```python
import numpy as np
from scipy.optimize import minimize

def run_packing() -> tuple[np.ndarray, np.ndarray, float]:
    """
    Packs 26 circles in a unit square to maximize the sum of radii.
    """
    n = 26
    
    # --- 1. Initialization (Hexagonal Lattice) ---
    centers = []
    s = 0.22 # Lattice spacing
    y_step = s * np.sqrt(3) / 2
    
    j = 0
    while len(centers) < n and j < 100:
        offset = (s / 2) if (j % 2 == 1) else 0
        i = 0
        while True:
            x = offset + i * s
            y = j * y_step
            if x <= 1.0 and y <= 1.0:
                centers.append([x, y])
            else:
                break
            i += 1
            if len(centers) >= n:
                break
        j += 1
    
    centers = np.array(centers[:n])
    # Start with a small feasible radius
    radii = np.full(n, 0.08)
    
    # Flatten variables: [x1, y1, r1, x2, y2, r2, ...]
    x0 = np.concatenate([centers.flatten(), radii])
    
    # --- 2. Objective Function ---
    # Minimize -sum(r) to maximize sum(r)
    def objective(vars):
        r = vars[2::3]
        return -np.sum(r)
    
    # --- 3. Constraints and Bounds ---
    bounds = []
    cons = []
    
    for i in range(n):
        # Box constraints for x, y, r
        bounds.extend([(0.0, 1.0), (0.0, 1.0), (0.0, 0.5)])
        
        # Boundary constraints: r <= coord <= 1 - r
        # x - r >= 0, 1 - x - r >= 0, y - r >= 0, 1 - y - r >= 0
        for k in range(2): # 0 for x, 1 for y
            idx_c = i * 3 + k
            idx_r = i * 3 + 2
            cons.append({'type': 'ineq', 'fun': lambda v, k=k, i=i: v[i*3+k] - v[i*3+2]})
            cons.append({'type': 'ineq', 'fun': lambda v, k=k, i=i: 1.0 - v[i*3+k] - v[i*3+2]})

    # Pairwise non-overlap constraints: dist^2 >= (r_i + r_j)^2
    for i in range(n):
        for j in range(i + 1, n):
            def make_overlap_const(i, j):
                def fun(v):
                    dx = v[i*3] - v[j*3]
                    dy = v[i*3+1] - v[j*3+1]
                    dr = v[i*3+2] + v[j*3+2]
                    return (dx*dx + dy*dy) - (dr*dr)
                return fun
            cons.append({'type': 'ineq', 'fun': make_overlap_const(i, j)})

    # --- 4. Optimization ---
    # We run multiple starts to avoid local minima.
    # We start with the lattice, and then use perturbed versions.
    best_vars = x0
    best_val = -np.inf

    for start in range(5):
        current_x0 = x0.copy()
        if start > 0:
            # Add small noise to centers
            noise = np.random.uniform(-0.01, 0.01, size=(n, 2))
            current_x0[0::3] += noise[:, 0]
            current_x0[1::3] += noise[:, 1]
            # Clamp to [0, 1]
            current_x0[0::3] = np.clip(current_x0[0::3], 0, 1)
            current_x0[1::3] = np.clip(current_x0[1::3], 0, 1)

        try:
            res = minimize(objective, current_x0, method='SLSQP', bounds=bounds, 
                           constraints=cons, options={'ftol': 1e-10, 'maxiter': 2000})
            
            if res.fun < best_val:
                best_val = res.fun
                best_vars = res.x
        except Exception:
            continue

    # --- 5. Formatting Output ---
    centers = best_vars[0::3].reshape((n, 2))
    radii = best_vars[2::3]
    total_sum = np.sum(radii)
    
    return centers, radii, total_sum
```
