

To maximize the sum of radii for 26 circles in a unit square, we use a two-phase approach: a heuristic initialization to establish a robust packing configuration, followed by a numerical optimization to refine the positions and radii for a maximum total.

<strategy>

Hexagonal packing is the densest way to pack equal circles in a plane, providing an excellent starting point that avoids the rigid constraints of a square grid. We calculate a base radius to ensure all circles fit within the unit square and overlap minimally or not at all.
2.  **Optimization Setup**: We define an objective function that maximizes the sum of radii by penalizing overlaps and violations of the unit square boundaries. The optimization uses a barrier function for overlaps and a quadratic penalty for boundary encroachments to guide the solver.
3.  **Numerical Solving**: Using `scipy.optimize.minimize` with the L-BFGS-B method, we adjust both the $(x, y)$ coordinates of the centers and the radii of the circles simultaneously. This allows the circles to grow and "squeeze" into available gaps, maximizing the total sum of radii beyond simple equal-radius packings.
4.  **Validation**: Finally, we normalize and clip the results to ensure all constraints are met and return the valid packing.

import numpy as np
from scipy.optimize import minimize

def run_packing():
    """
    Optimizes the placement and radii of 26 circles in a unit square
    to maximize the sum of radii.
    """
    n_circles = 26
    
    # --- Phase 1: Hexagonal Lattice Initialization ---
    # Calculate dimensions for hexagonal packing
    cols = 6
    rows = 5
    # Offset for hexagonal packing
    offset_x = 0.5
    spacing_x = 1.0 / (cols - 0.5)
    spacing_y = spacing_x * np.sqrt(3) / 2
    
    centers = []
    base_radius = spacing_x * 0.45  # Initial small radius
    
    for r in range(rows):
        for c in range(cols):
            if len(centers) == n_circles:
                break
            x = (c + 0.5) * spacing_x
            y = (r + 0.5) * spacing_y
            # Apply hexagonal offset
            if r % 2 == 1:
                x += offset_x * spacing_x
            # Ensure within bounds [0,1]
            x = np.clip(x, base_radius, 1 - base_radius)
            y = np.clip(y, base_radius, 1 - base_radius)
            centers.append([x, y])
        
        if len(centers) == n_circles:
            break
            
    centers = np.array(centers[:n_circles])
    radii = np.full(n_circles, base_radius)
    
    # --- Phase 2: Optimization ---
    def objective(params):
        """Objective function to maximize sum of radii."""
        c = params[:n_circles * 2].reshape(n_circles, 2)
        r = params[n_circles * 2:]
        
        penalty = 0.0
        
        # Boundary penalties
        for i in range(n_circles):
            x, y = c[i]
            rad = r[i]
            # Soft penalty for going outside bounds
            if x - rad < 0: penalty += 100 * (-(x - rad))**2
            if x + rad > 1: penalty += 100 * ((x + rad) - 1)**2
            if y - rad < 0: penalty += 100 * (-(y - rad))**2
            if y + rad > 1: penalty += 100 * ((y + rad) - 1)**2
            
        # Overlap penalties
        for i in range(n_circles):
            for j in range(i + 1, n_circles):
                dist = np.sqrt(np.sum((c[i] - c[j])**2))
                overlap = r[i] + r[j] - dist
                if overlap > 0:
                    penalty += 1000 * overlap**2
                    
        return -np.sum(r) + penalty

    # Bounds for parameters
    bounds = []
    # Bounds for centers (0, 1)
    for _ in range(n_circles):
        bounds.append((0, 1))
        bounds.append((0, 1))
    # Bounds for radii (0, 0.5)
    for _ in range(n_circles):
        bounds.append((0, 0.5))

    # Flatten initial state
    x0 = np.concatenate([centers.flatten(), radii])
    
    # Optimize
    result = minimize(objective, x0, method='L-BFGS-B', bounds=bounds)
    
    # --- Phase 3: Validation and Normalization ---
    final_centers = result.x[:n_circles * 2].reshape(n_circles, 2)
    final_radii = result.x[n_circles * 2:]
    
    # Adjust to ensure strict validity
    for i in range(n_circles):
        x, y = final_centers[i]
        r = final_radii[i]
        # Clamp to square
        r = min(r, x, 1-x, y, 1-y)
        final_radii[i] = max(0, r)
        final_centers[i] = [np.clip(x, 0, 1), np.clip(y, 0, 1)]

    # Resolve any remaining overlaps by shrinking radii
    for _ in range(50):
        changed = False
        for i in range(n_circles):
            for j in range(i + 1, n_circles):
                dist = np.sqrt(np.sum((final_centers[i] - final_centers[j])**2))
                required_sum = final_radii[i] + final_radii[j]
                if dist < required_sum:
                    # Scale down proportionally
                    ratio = dist / required_sum
                    final_radii[i] *= ratio
                    final_radii[j] *= ratio
                    changed = True
        if not changed:
            break
            
    # Re-check boundaries after shrinking
    for i in range(n_circles):
        x, y = final_centers[i]
        r = final_radii[i]
        r = min(r, x, 1-x, y, 1-y)
        final_radii[i] = max(0, r)

    return final_centers, final_radii, np.sum(final_radii)
