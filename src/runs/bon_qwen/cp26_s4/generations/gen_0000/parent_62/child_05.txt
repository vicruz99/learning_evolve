The problem asks to pack 26 circles in a unit square to maximize the sum of radii. This is a classic dense packing problem. The theoretical maximum for 26 equal circles in a unit square is known to be around $r \approx 0.1014$, yielding a sum of $\approx 2.636$. Hexagonal (honeycomb) arrangements are provably densest for infinite planes and work excellently for finite squares with minor boundary adjustments.

Strategy:
1. **Initial Configuration Generation**: Create multiple starting points to avoid local minima. 
   - A hexagonal lattice pattern, scaled and shifted to fit inside $[0.1, 0.9]^2$.
   - A perturbed uniform grid.
   - A random initialization.
2. **Constraint Formulation**: The non-overlap condition $\|c_i - c_j\| \ge r_i + r_j$ and boundary conditions $r_i \le x_i \le 1-r_i$, $r_i \le y_i \le 1-r_i$ are formulated as smooth inequality constraints: $\|c_i - c_j\|^2 - (r_i + r_j)^2 \ge 0$ and $x_i - r_i \ge 0$, etc. This avoids square roots and keeps constraints differentiable.
3. **Optimization**: Use `scipy.optimize.minimize` with the `SLSQP` method, which handles bound and inequality constraints efficiently. The objective is to maximize $\sum r_i$ (minimize $-\sum r_i$). We run the optimizer from each initial configuration and keep the best result.
4. **Robustness**: Multiple restarts ensure we escape poor local minima. The vectorized constraint computation speeds up gradient evaluation significantly. Bounds prevent radii from becoming negative or exceeding half the square diagonal.

This approach directly targets the known optimal geometry while allowing the optimizer to fine-tune positions and allow slight radius variations if beneficial.

import numpy as np
from scipy.optimize import minimize

N = 26

def _objective(x):
    """Objective function: minimize negative sum of radii."""
    return -np.sum(x[2*N:])

def _constraint_func(x):
    """
    Returns an array of constraint values. All must be >= 0.
    Includes pairwise non-overlap and boundary constraints.
    """
    centers = x[:2*N].reshape(N, 2)
    radii = x[2*N:]
    
    # Pairwise distance squared and radius sums using broadcasting
    diffs = centers[:, np.newaxis, :] - centers[np.newaxis, :, :]  # (N, N, 2)
    dist_sq = np.sum(diffs**2, axis=2)                             # (N, N)
    r_sums = radii[:, np.newaxis] + radii[np.newaxis, :]           # (N, N)
    
    # Upper triangular indices (i < j)
    i_idx, j_idx = np.triu_indices(N, k=1)
    pairwise_cons = dist_sq[i_idx, j_idx] - r_sums[i_idx, j_idx]**2
    
    # Boundary constraints: center +/- radius inside [0, 1]
    bnd_cons = np.concatenate([
        centers[:, 0] - radii,
        1.0 - centers[:, 0] - radii,
        centers[:, 1] - radii,
        1.0 - centers[:, 1] - radii
    ])
    
    return np.concatenate([pairwise_cons, bnd_cons])

def run_packing():
    # Bounds for variables: centers in [0, 1], radii in [1e-6, 0.5]
    bounds = [(0.0, 1.0)] * (2*N) + [(1e-6, 0.5)] * N
    cons = {'type': 'ineq', 'fun': _constraint_func}
    
    best_val = -np.inf
    best_x = None
    
    init_configs = []
    
    # 1. Hexagonal lattice initialization (dense packing template)
    pts = []
    r_est = 0.095
    dy = r_est * np.sqrt(3)
    dx = 2 * r_est
    y = r_est + 0.05
    for row in range(6):
        x_start = r_est + 0.05 + (row % 2) * (dx / 2)
        num_in_row = 5 if row % 2 == 0 else 6
        for col in range(num_in_row):
            if len(pts) >= N: break
            pts.append([x_start + col * dx, y])
        y += dy
    pts = np.array(pts[:N])
    # Normalize to fit comfortably inside the unit square
    pts = (pts - pts.min(axis=0)) / (pts.max(axis=0) - pts.min(axis=0)) * 0.8 + 0.1
    init_configs.append(np.concatenate([pts.ravel(), np.full(N, 0.09)]))

    # 2. Perturbed uniform grid
    np.random.seed(123)
    grid_x = np.linspace(0.1, 0.9, 6)
    grid_y = np.linspace(0.1, 0.9, 5)
    gx, gy = np.meshgrid(grid_x, grid_y)
    grid_pts = np.column_stack((gx.ravel(), gy.ravel()[:N])) + np.random.randn(N, 2)*0.02
    init_configs.append(np.concatenate([np.clip(grid_pts, 0.05, 0.95).ravel(), np.full(N, 0.07)]))

    # 3. Random initialization for diversity
    np.random.seed(99)
    rand_pts = np.random.rand(N, 2) * 0.8 + 0.1
    init_configs.append(np.concatenate([rand_pts.ravel(), np.full(N, 0.05)]))

    # Optimize from each starting configuration
    for x0 in init_configs:
        try:
            res = minimize(_objective, x0, method='SLSQP', bounds=bounds,
                           constraints=cons, options={'maxiter': 8000, 'ftol': 1e-10, 'disp': False})
            if not np.isnan(res.fun) and -res.fun > best_val:
                best_val = -res.fun
                best_x = res.x.copy()
        except Exception:
            continue
            
    # Ensure valid output shape
    centers = best_x[:2*N].reshape(N, 2)
    radii = best_x[2*N:]
    
    # Safety numerical clamping to strictly satisfy [0,1] bounds within tolerance
    centers = np.clip(centers, 1e-9, 1.0 - 1e-9)
    radii = np.clip(radii, 1e-9, 0.5)
    
    return centers, radii, best_val
