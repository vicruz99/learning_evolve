To solve the problem of packing 26 circles in a unit square to maximize the sum of radii, we employ an iterative optimization strategy combining Linear Programming (LP) with a gradient-based position update.

### Strategy Overview

1.  **Problem Decomposition**: The problem is non-convex due to the distance constraints. However, if circle centers are fixed, finding the optimal radii is a Linear Programming (LP) problem. We maximize $\sum r_i$ subject to boundary and pairwise distance constraints.
2.  **Initialization**: We start with a hexagonal grid configuration. This is a near-optimal density arrangement for equal circles and provides a strong starting point with high symmetry.
3.  **Iterative Optimization Loop**:
    *   **LP Solver**: For a fixed set of centers, we use `scipy.optimize.linprog` to compute the maximal possible radii.
    *   **Sensitivity Analysis (Forces)**: We identify "active constraints"—those that are tight (equality holds). In packing, these represent physical contacts.
        *   If circle $i$ touches circle $j$, the distance constraint is active. Moving them apart allows radii to grow. The "force" is repulsive, directed along the line connecting centers.
        *   If circle $i$ touches a boundary, the boundary constraint is active. Moving it away from the boundary allows its radius to grow. The "force" pushes toward the square's center.
    *   **Gradient Ascent**: We update the centers by moving them in the direction of the cumulative forces derived from these active constraints.
4.  **Refinement**: We run multiple restarts with random perturbations to escape local optima and ensure a robust solution.

### Technical Details
*   **Constraints**: The LP maximizes $\sum r_i$ subject to $r_i + r_j \le \|x_i - x_j\|_2$, $r_i \le x_i$, $r_i \le 1-x_i$, etc.
*   **Gradient Calculation**: We approximate the gradient of the objective function (sum of radii) with respect to center positions by summing unit vectors for all active constraints. This corresponds to the subgradient of the support function.
*   **Implementation**: We use `numpy` for vector operations and `scipy.optimize.linprog` for the LP sub-problems.

import numpy as np
from scipy.optimize import linprog

def generate_hex_centers(n):
    """Generates a hexagonal grid of centers for n circles."""
    centers = []
    # Estimate radius to fit in square roughly
    r_est = 0.1
    # Row height in hex packing
    dy = r_est * np.sqrt(3)
    # Col width
    dx = 2 * r_est
    
    y = r_est
    while len(centers) < n:
        x = r_est
        shift = (len(centers) // (int(1/dx) + 1)) % 2 * r_est
        if len(centers) > 0 and shift > 0:
            x += r_est
        
        while x < 1 - r_est and len(centers) < n:
            centers.append([x, y])
            x += dx
        y += dy
        if y > 1 - r_est:
            break
            
    return np.array(centers[:n])

def solve_packing_lp(centers):
    """
    Given fixed centers, solve LP to find max sum of radii.
    Returns radii, success flag, and dual variables (marginals).
    """
    n = len(centers)
    
    # Variables: r_1, ..., r_n
    # Maximize sum(r_i) => Minimize -sum(r_i)
    c = np.ones(n) * -1.0
    
    # Constraints A_ub * r <= b_ub
    # 1. Pairwise constraints: r_i + r_j <= dist_ij
    # 2. Boundary constraints: r_i <= x_i, r_i <= 1-x_i, r_i <= y_i, r_i <= 1-y_i
    
    A_ub = []
    b_ub = []
    
    # Pairwise
    for i in range(n):
        for j in range(i + 1, n):
            dist = np.linalg.norm(centers[i] - centers[j])
            row = np.zeros(n)
            row[i] = 1.0
            row[j] = 1.0
            A_ub.append(row)
            b_ub.append(dist)
            
    # Boundary
    for i in range(n):
        x, y = centers[i]
        # r_i <= x
        row = np.zeros(n)
        row[i] = 1.0
        A_ub.append(row)
        b_ub.append(x)
        
        # r_i <= 1 - x
        row = np.zeros(n)
        row[i] = 1.0
        A_ub.append(row)
        b_ub.append(1.0 - x)
        
        # r_i <= y
        row = np.zeros(n)
        row[i] = 1.0
        A_ub.append(row)
        b_ub.append(y)
        
        # r_i <= 1 - y
        row = np.zeros(n)
        row[i] = 1.0
        A_ub.append(row)
        b_ub.append(1.0 - y)
        
    A_ub = np.array(A_ub)
    b_ub = np.array(b_ub)
    
    # Bounds for r: r_i >= 0
    bounds = [(0, None) for _ in range(n)]
    
    try:
        res = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
        if res.success:
            return res.x, res.ineqlin.marginals
        else:
            return None, None
    except Exception:
        return None, None

def compute_forces(centers, radii, marginals):
    """
    Computes the force vector for each center based on active constraints.
    Active constraints have non-zero marginals.
    """
    n = len(centers)
    forces = np.zeros((n, 2))
    eps = 1e-7
    
    # Map marginals to constraints
    # Order: Pairwise (i,j) then Boundary (i, wall)
    
    marginal_idx = 0
    
    # Pairwise constraints
    for i in range(n):
        for j in range(i + 1, n):
            margin = marginals[marginal_idx]
            marginal_idx += 1
            
            if margin > 1e-6: # Active constraint
                # Constraint: r_i + r_j <= dist_ij
                # Sensitivity: increasing dist_ij increases sum of radii.
                # Gradient of dist_ij wrt x_i is (x_i - x_j) / dist_ij
                diff = centers[i] - centers[j]
                dist = np.linalg.norm(diff)
                if dist > eps:
                    force_vec = diff / dist
                    # The dual variable indicates the rate of change of objective.
                    # For minimization of -sum(r), dual is negative?
                    # linprog minimizes c^T x. c = -1.
                    # Shadow price y >= 0.
                    # Change in obj value = y * delta_b.
                    # Obj is -sum(r). If b increases (relaxed), sum(r) increases, obj decreases (more negative).
                    # So shadow price should be positive for relaxation improving obj?
                    # Actually, linprog marginals for <= constraints are >= 0.
                    # They represent the reduction in cost per unit increase in b.
                    # Since cost is negative sum, reduction in cost = increase in sum.
                    # So margin is positive magnitude.
                    
                    # Force direction: repulsive
                    forces[i] += margin * force_vec
                    forces[j] -= margin * force_vec
                    
    # Boundary constraints
    # For each circle i, 4 constraints: x, 1-x, y, 1-y
    for i in range(n):
        x, y = centers[i]
        
        # r_i <= x. If active, increasing x helps.
        # Gradient of x wrt x is 1.
        margin_x = marginals[marginal_idx]
        marginal_idx += 1
        if margin_x > 1e-6:
            forces[i][0] += margin_x * 1.0
            
        # r_i <= 1-x. If active, decreasing x helps (increasing 1-x).
        # Gradient of (1-x) wrt x is -1.
        margin_1x = marginals[marginal_idx]
        marginal_idx += 1
        if margin_1x > 1e-6:
            forces[i][0] += margin_1x * -1.0
            
        # r_i <= y. Increasing y helps.
        margin_y = marginals[marginal_idx]
        marginal_idx += 1
        if margin_y > 1e-6:
            forces[i][1] += margin_y * 1.0
            
        # r_i <= 1-y. Decreasing y helps.
        margin_1y = marginals[marginal_idx]
        marginal_idx += 1
        if margin_1y > 1e-6:
            forces[i][1] += margin_1y * -1.0
            
    return forces

def run_packing():
    n = 26
    best_sum = -1.0
    best_centers = None
    best_radii = None
    
    # Configuration parameters
    iterations = 300
    step_size = 0.005
    restarts = 5
    
    for restart in range(restarts):
        # Initialization
        if restart == 0:
            centers = generate_hex_centers(n)
        else:
            centers = np.random.rand(n, 2) * 0.8 + 0.1
            # Add some structure or just random? Random is fine for diversity.
            # Maybe jitter the hex grid
            centers = generate_hex_centers(n) + np.random.normal(0, 0.05, (n, 2))
            centers = np.clip(centers, 0.05, 0.95)
            
        # Optimization loop
        for it in range(iterations):
            # 1. Solve LP
            radii, marginals = solve_packing_lp(centers)
            
            if radii is None:
                break
                
            current_sum = np.sum(radii)
            
            if current_sum > best_sum:
                best_sum = current_sum
                best_centers = centers.copy()
                best_radii = radii.copy()
                
            # 2. Compute forces
            forces = compute_forces(centers, radii, marginals)
            
            # 3. Update centers
            centers = centers + step_size * forces
            
            # 4. Clip to valid range [0,1] (with margin)
            # Actually, boundaries are handled by constraints, but we should keep centers valid
            centers = np.clip(centers, 1e-5, 1.0 - 1e-5)
            
            # Annealing step size?
            if it % 50 == 0 and it > 0:
                step_size *= 0.9

    return best_centers, best_radii, best_sum
