2.  **Optimization Formulation:** We will use a penalty method approach to handle the constraints. We define an objective function that combines the negative sum of radii (to maximize) and a penalty term for constraint violations.
    *   **Objective:** $J = -\sum r_i + \lambda \cdot P(\text{centers}, \text{radii})$
    *   **Penalty $P$:** The sum of squared violations for boundary conditions and circle overlaps.
    *   **Boundary Penalty:** For each circle, penalize if $x < r$, $x > 1-r$, $y < r$, or $y > 1-r$.
    *   **Overlap Penalty:** For each pair of circles, penalize if distance $d < r_i + r_j$.
3.  **Solver:** We will use `scipy.optimize.minimize` with the `L-BFGS-B` method. This method supports box constraints (keeping centers within $[0,1]$ and radii non-negative) and is efficient for medium-sized problems.
4.  **Refinement:** We will start with a high penalty coefficient to ensure the optimizer respects constraints while increasing radii.

import numpy as np
from scipy.optimize import minimize

def run_packing() -> tuple[np.ndarray, np.ndarray, float]:
    n = 26
    
    # 1. Initialization: Hexagonal Grid
    # We place circles in a hexagonal pattern.
    # We use a small initial radius to ensure feasibility.
    r_init = 0.05
    centers = np.zeros((n, 2))
    radii = np.full(n, r_init)
    
    # Parameters for hex grid
    # Horizontal spacing = 2*r, Vertical spacing = sqrt(3)*r
    # We can fit roughly 1/r circles per side.
    # Let's distribute 26 circles in a grid.
    # 5 columns x 5 rows = 25, plus 1.
    # Let's try to pack them tightly in initialization.
    
    idx = 0
    row = 0
    # Start with a radius slightly larger to fill space, but valid? 
    # Actually, small radius is safer for initialization.
    
    while idx < n:
        y = r_init + row * np.sqrt(3) * r_init
        if y + r_init > 1.0:
            # If row goes out of bounds, break or handle?
            # With r=0.05, sqrt(3)*0.05 approx 0.0866.
            # 1/0.0866 approx 11.5 rows. Plenty of space.
            pass
            
        shift = r_init if row % 2 == 1 else 0
        col = 0
        while idx < n:
            x = r_init + col * (2 * r_init) + shift
            if x + r_init > 1.0:
                break # Move to next row
            
            centers[idx] = [x, y]
            idx += 1
            col += 1
        row += 1
        
    # Flatten variables for optimizer: [x1, y1, r1, x2, y2, r2, ...]
    # Shape (3*n,)
    x0 = np.empty(3 * n)
    for i in range(n):
        x0[3*i] = centers[i, 0]
        x0[3*i+1] = centers[i, 1]
        x0[3*i+2] = radii[i]

    # Bounds: x, y in [0, 1], r in [0, 0.5]
    # Using a small epsilon for r lower bound to avoid issues
    r_lower = 1e-6
    bounds = [(0.0, 1.0), (0.0, 1.0), (r_lower, 0.5)] * n

    # Penalty parameters
    lam = 10000.0  # High penalty to enforce constraints

    def objective(v):
        # Extract vars
        xs = v[0::3]
        ys = v[1::3]
        rs = v[2::3]
        
        # Objective: Maximize sum of radii -> Minimize negative sum
        obj_val = -np.sum(rs)
        
        # Penalty terms
        penalty = 0.0
        
        # Boundary Penalties
        # Left: x >= r  => violation if r - x > 0
        penalty += np.sum(np.maximum(0, rs - xs)**2)
        # Right: x <= 1-r => violation if x + r - 1 > 0
        penalty += np.sum(np.maximum(0, xs + rs - 1)**2)
        # Bottom: y >= r
        penalty += np.sum(np.maximum(0, rs - ys)**2)
        # Top: y <= 1-r
        penalty += np.sum(np.maximum(0, ys + rs - 1)**2)
        
        # Overlap Penalties
        # Check all pairs
        # Vectorized calculation for efficiency
        # xs, ys, rs shape (n,)
        # Diff matrices
        # We can iterate pairs since n=26 is small
        for i in range(n):
            for j in range(i + 1, n):
                dx = xs[i] - xs[j]
                dy = ys[i] - ys[j]
                dist = np.sqrt(dx*dx + dy*dy)
                sum_r = rs[i] + rs[j]
                
                if dist < sum_r:
                    overlap = sum_r - dist
                    penalty += overlap**2
        
        return obj_val + lam * penalty

    # Run optimization
    # Use L-BFGS-B as it handles bounds well
    res = minimize(objective, x0, method='L-BFGS-B', bounds=bounds, 
                   options={'maxiter': 2000, 'ftol': 1e-12, 'gtol': 1e-10})

    # Extract results
    x_opt = res.x[0::3]
    y_opt = res.x[1::3]
    r_opt = res.x[2::3]
    
    centers_opt = np.column_stack((x_opt, y_opt))
    
    # Sum of radii
    sum_radii = np.sum(r_opt)
    
    return centers_opt, r_opt, sum_radii
