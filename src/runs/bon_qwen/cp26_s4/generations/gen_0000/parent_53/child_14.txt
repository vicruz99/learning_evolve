The problem asks to maximize the sum of radii for 26 circles in a unit square. This is a non-convex optimization problem where circles can have different radii. 

**Strategy:**
1. **Mathematical Formulation**: We define variables $(x_i, y_i, r_i)$ for each of the 26 circles. The objective is to maximize $\sum r_i$. Constraints include:
   - Boundary constraints: $r_i \le x_i \le 1-r_i$ and $r_i \le y_i \le 1-r_i$
   - Non-overlap constraints: $(x_i-x_j)^2 + (y_i-y_j)^2 \ge (r_i+r_j)^2$ for all $i < j$
   - Non-negativity: $r_i \ge 0$
2. **Optimization Algorithm**: We use `scipy.optimize.minimize` with the `SLSQP` method, which efficiently handles nonlinear inequality constraints. Since SLSQP finds local optima, we run it multiple times with different initial configurations to increase the probability of finding a high-quality packing.
3. **Initialization Strategies**:
   - **Random Restarts**: Multiple random placements ensure we explore diverse configurations and escape symmetric saddle points.
   - **Structured Grid**: A hexagonal-like grid initialization is known to be dense and serves as a strong starting point for refinement.
4. **Robustness**: We clamp the final solution to strictly satisfy constraints within numerical tolerance and ensure radii are positive. Helper functions are defined at the top level without closures or lambdas as required.

import numpy as np
from scipy.optimize import minimize

N_CIRCLES = 26

def compute_objective(vars_):
    """Objective function: negative sum of radii (for minimization)"""
    n = N_CIRCLES
    radii = vars_[2*n:]
    return -np.sum(radii)

def compute_constraints(vars_):
    """Constraint function: returns array of constraint values (must be >= 0)"""
    n = N_CIRCLES
    centers = vars_[:2*n].reshape(n, 2)
    radii = vars_[2*n:]
    
    vals = []
    # Boundary constraints: x >= r, 1-x >= r, y >= r, 1-y >= r
    vals.extend(centers[:, 0] - radii)
    vals.extend(1.0 - centers[:, 0] - radii)
    vals.extend(centers[:, 1] - radii)
    vals.extend(1.0 - centers[:, 1] - radii)
    
    # Overlap constraints: dist^2 >= (r_i + r_j)^2
    # Vectorized pairwise distance calculation
    diff = centers[:, np.newaxis, :] - centers[np.newaxis, :, :]
    dist_sq = np.sum(diff**2, axis=2)
    r_sum_sq = (radii[:, np.newaxis] + radii[np.newaxis, :])**2
    
    # Lower triangular mask to consider each pair exactly once
    mask = np.tril(np.ones((n, n), dtype=bool), k=-1)
    vals.extend((dist_sq[mask] - r_sum_sq[mask]).flatten())
    
    return np.array(vals)

def run_packing():
    n = N_CIRCLES
    best_sum_r = 0.0
    best_solution = None
    
    # Bounds for variables: x,y in [0,1], r in [1e-8, 0.5]
    bounds = [(0.0, 1.0)] * (2 * n) + [(1e-8, 0.5)] * n
    cons = {'type': 'ineq', 'fun': compute_constraints}
    
    # Strategy 1: Multiple random restarts to explore configuration space
    for seed in range(15):
        np.random.seed(seed)
        cx = np.random.rand(n) * 0.7 + 0.15
        cy = np.random.rand(n) * 0.7 + 0.15
        r0 = np.ones(n) * 0.05
        x0 = np.concatenate([cx, cy, r0])
        
        res = minimize(compute_objective, x0, method='SLSQP', bounds=bounds,
                       constraints=cons, options={'maxiter': 5000, 'ftol': 1e-12, 'disp': False})
        
        if res.success and -res.fun > best_sum_r:
            best_sum_r = -res.fun
            best_solution = res.x
            
    # Strategy 2: Structured hexagonal-like grid initialization
    grid_x = np.linspace(0.1, 0.9, 5)
    grid_y = np.linspace(0.1, 0.9, 5)
    gx, gy = np.meshgrid(grid_x, grid_y)
    init_centers = np.column_stack((gx.flatten(), gy.flatten()))[:n]
    # Add small jitter to break symmetry and allow optimization to refine gaps
    init_centers += np.random.rand(n, 2) * 0.02 - 0.01
    r0 = np.ones(n) * 0.08
    x0 = np.concatenate([init_centers.flatten(), r0])
    
    res = minimize(compute_objective, x0, method='SLSQP', bounds=bounds,
                   constraints=cons, options={'maxiter': 5000, 'ftol': 1e-12, 'disp': False})
                   
    if res.success and -res.fun > best_sum_r:
        best_sum_r = -res.fun
        best_solution = res.x
        
    # Fallback in case optimization fails completely
    if best_solution is None:
        centers = np.zeros((n, 2))
        radii = np.ones(n) * 0.01
        return centers, radii, 0.26
        
    centers = best_solution[:2*n].reshape(n, 2)
    radii = best_solution[2*n:]
    
    # Ensure strict feasibility against numerical solver tolerances
    radii = np.maximum(radii, 1e-9)
    centers[:, 0] = np.clip(centers[:, 0], radii, 1.0 - radii)
    centers[:, 1] = np.clip(centers[:, 1], radii, 1.0 - radii)
    
    return centers, radii, float(np.sum(radii))
