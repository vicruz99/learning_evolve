1.  **Inner Problem (Radii Optimization):** For a fixed set of centers, finding the optimal radii is a Linear Programming (LP) problem. We want to maximize $\sum r_i$ subject to:
    *   Boundary constraints: $r_i \le x_i$, $r_i \le 1-x_i$, $r_i \le y_i$, $r_i \le 1-y_i$.
    *   Non-overlap constraints: $r_i + r_j \le \text{distance}(center_i, center_j)$ for all $i < j$.
    *   Non-negativity: $r_i \ge 0$.
    This LP can be solved very efficiently using `scipy.optimize.linprog`.

2.  **Outer Problem (Center Optimization):** The centers $(x_i, y_i)$ are the decision variables. The objective function is the optimal value of the LP described above. This function is non-convex and discontinuous in its derivatives, making standard gradient-based methods difficult. However, it is a bounded optimization problem ($x, y \in [0, 1]$). We can use a global optimization algorithm like **Differential Evolution** (`scipy.optimize.differential_evolution`) to search for the optimal center configuration. Differential Evolution is robust for non-smooth, multi-modal functions.

import numpy as np
from scipy.optimize import linprog
from scipy.optimize import differential_evolution
import math

def solve_lp_for_radii(centers):
    """
    Given fixed centers, solve the LP to maximize sum of radii.
    Centers shape: (n, 2)
    Returns: optimal_radii, sum_radii
    """
    n = centers.shape[0]
    
    # Objective: Maximize sum(r_i) => Minimize -sum(r_i)
    # c vector of length n
    c = -np.ones(n)
    
    # Constraints: A_ub @ r <= b_ub
    # We need to collect all inequalities.
    
    # 1. Boundary constraints: r_i <= x_i, r_i <= 1-x_i, r_i <= y_i, r_i <= 1-y_i
    # There are 4 constraints per circle.
    
    # 2. Non-overlap constraints: r_i + r_j <= dist(i, j)
    # There are n*(n-1)/2 constraints.
    
    # Total constraints: 4*n + n*(n-1)/2
    num_constraints = 4 * n + (n * (n - 1)) // 2
    
    # Preallocate arrays
    A_ub = np.zeros((num_constraints, n))
    b_ub = np.zeros(num_constraints)
    
    row_idx = 0
    
    # Boundary constraints
    for i in range(n):
        x, y = centers[i]
        
        # r_i <= x
        A_ub[row_idx, i] = 1.0
        b_ub[row_idx] = x
        row_idx += 1
        
        # r_i <= 1 - x
        A_ub[row_idx, i] = 1.0
        b_ub[row_idx] = 1.0 - x
        row_idx += 1
        
        # r_i <= y
        A_ub[row_idx, i] = 1.0
        b_ub[row_idx] = y
        row_idx += 1
        
        # r_i <= 1 - y
        A_ub[row_idx, i] = 1.0
        b_ub[row_idx] = 1.0 - y
        row_idx += 1
        
    # Overlap constraints
    # r_i + r_j <= dist
    for i in range(n):
        for j in range(i + 1, n):
            dist = math.sqrt((centers[i, 0] - centers[j, 0])**2 + 
                             (centers[i, 1] - centers[j, 1])**2)
            
            A_ub[row_idx, i] = 1.0
            A_ub[row_idx, j] = 1.0
            b_ub[row_idx] = dist
            row_idx += 1
            
    # Bounds for r_i: 0 <= r_i <= 0.5 (upper bound 0.5 is safe, square size 1)
    # Actually, tighter bound is min(x, 1-x, y, 1-y), but LP handles it.
    # linprog bounds: (lower, upper)
    bounds = [(0, 0.5) for _ in range(n)]
    
    # Solve LP
    # method='highs' is fast and robust
    res = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
    
    if res.success:
        optimal_radii = res.x
        sum_radii = -res.fun # Since we minimized -sum
        return optimal_radii, sum_radii
    else:
        # Fallback if LP fails (should not happen with r=0 feasible)
        return np.zeros(n), 0.0

def objective_function_flat(x_flat):
    """
    Objective function for differential evolution.
    Input: x_flat array of size 2*n (x1, y1, x2, y2, ...)
    Output: Negative sum of radii (to minimize)
    """
    n = 26
    centers = x_flat.reshape((n, 2))
    
    # Ensure centers are within [0, 1] just in case, though DE bounds handle it
    # But numerical noise might occur.
    centers = np.clip(centers, 0.0, 1.0)
    
    _, sum_radii = solve_lp_for_radii(centers)
    return -sum_radii

def run_packing():
    # Number of circles
    n = 26
    
    # Bounds for differential evolution: [0, 1] for all x and y coordinates
    # 26 circles * 2 coordinates = 52 variables
    bounds = [(0.0, 1.0)] * (2 * n)
    
    # Run Differential Evolution
    # popsize, maxiter, tol can be tuned.
    # We want a good solution, so we allow some iterations.
    # seed for reproducibility if needed, but randomness helps exploration.
    
    try:
        result = differential_evolution(
            objective_function_flat,
            bounds,
            seed=42, # Fixed seed for reproducibility
            popsize=20,
            maxiter=100,
            tol=1e-5,
            workers=1,
            polish=True # Run local optimization (L-BFGS-B) at the end
        )
        
        if result.success or not np.isnan(result.fun):
            optimal_centers_flat = result.x
            optimal_centers = optimal_centers_flat.reshape((n, 2))
            
            # Compute final radii using the LP solver
            optimal_radii, final_sum = solve_lp_for_radii(optimal_centers)
            
            return optimal_centers, optimal_radii, final_sum
        else:
