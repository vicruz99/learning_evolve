To maximize the sum of radii for 26 circles in a unit square, I employ a variable-radius packing approach using a coordinate transformation combined with a penalty-based optimization.

1. **Coordinate Transformation**: To automatically satisfy boundary constraints ($0 \le x \pm r \le 1$), I parameterize each circle's center as $x_i = r_i + u_i(1-2r_i)$ and $y_i = r_i + v_i(1-2r_i)$, where $r_i \in [0, 0.5]$ and $u_i, v_i \in [0, 1]$. This guarantees every circle stays within the square for any valid parameters, eliminating 104 explicit constraints.
2. **Objective & Constraints**: The goal is to maximize $\sum r_i$. The only remaining constraints are non-overlap conditions: $\text{dist}_{ij} \ge r_i + r_j$.
3. **Penalty Method**: I formulate a smooth penalty function for overlaps: $P = \lambda \sum_{i<j} \max(0, r_i+r_j - \text{dist}_{ij})^2$. The total objective to minimize is $-\sum r_i + P$.
4. **Optimization Strategy**: I use `scipy.optimize.minimize` with L-BFGS-B, which efficiently handles bounds and large-scale problems. I run a penalty-annealing schedule, gradually increasing the penalty weight $\lambda$ from 50 to 20000. This allows the optimizer to first expand radii and reposition circles, then strictly enforce non-overlap. Multiple random restarts ensure we escape poor local minima.
5. **Validation**: After optimization, I select the configuration with the highest sum of radii that passes a strict overlap check. The transformation ensures boundary validity by construction.

import numpy as np
from scipy.optimize import minimize

def packing_objective(vars_flat, lam, n):
    """
    Objective function to minimize: negative sum of radii + penalty for overlaps.
    Variables are interleaved as [r1, u1, v1, r2, u2, v2, ...]
    """
    r = vars_flat[0::3]
    u = vars_flat[1::3]
    v = vars_flat[2::3]
    
    # Transform back to coordinates. This guarantees boundary constraints.
    x = r + u * (1.0 - 2.0 * r)
    y = r + v * (1.0 - 2.0 * r)
    
    # Primary objective: maximize sum of radii -> minimize negative sum
    obj = -np.sum(r)
    
    # Vectorized distance and overlap calculation
    X_diff = x[:, np.newaxis] - x[np.newaxis, :]
    Y_diff = y[:, np.newaxis] - y[np.newaxis, :]
    R_sum = r[:, np.newaxis] + r[np.newaxis, :]
    
    dist = np.sqrt(X_diff**2 + Y_diff**2)
    overlap = R_sum - dist
    
    # Extract upper triangle to avoid double counting and self-comparison
    mask = np.triu(np.ones((n, n), dtype=bool), k=1)
    pos_overlap = np.maximum(0.0, overlap[mask])
    penalty = np.sum(pos_overlap**2)
    
    return obj + lam * penalty

def run_packing():
    n = 26
    
    # Initial configuration: 5x5 grid + 1 center circle
    init_x = []
    init_y = []
    for i in range(5):
        for j in range(5):
            init_x.append(0.1 + j * 0.2)
            init_y.append(0.1 + i * 0.2)
    init_x.append(0.5)
    init_y.append(0.5)
    
    r_init = 0.05
    # Compute initial u, v parameters
    u_init = (np.array(init_x) - r_init) / (1.0 - 2.0 * r_init)
    v_init = (np.array(init_y) - r_init) / (1.0 - 2.0 * r_init)
    
    # Flatten to [r1, u1, v1, r2, u2, v2, ...]
    x0 = np.empty(3 * n)
    x0[0::3] = r_init
    x0[1::3] = u_init
    x0[2::3] = v_init
    
    # Bounds for r, u, v
    bounds = [(0.0, 0.5), (0.0, 1.0), (0.0, 1.0)] * n
    
    best_sum = -1.0
    best_centers = None
    best_radii = None
    
    # Run multiple restarts to avoid local optima
    for seed in range(3):
        np.random.seed(seed)
        curr_x0 = x0.copy()
        # Add noise to positions (u, v) to break symmetry
        curr_x0[1::3] += np.random.uniform(-0.05, 0.05, n)
        curr_x0[2::3] += np.random.uniform(-0.05, 0.05, n)
        curr_x0[1::3] = np.clip(curr_x0[1::3], 0.0, 1.0)
        curr_x0[2::3] = np.clip(curr_x0[2::3], 0.0, 1.0)
        
        current_x = curr_x0
        # Annealing penalty schedule
        for lam in [50, 200, 1000, 5000, 20000]:
            res = minimize(packing_objective, current_x, args=(lam, n), method='L-BFGS-B', bounds=bounds, options={'ftol': 1e-12, 'maxiter': 2000})
            current_x = res.x
            
        r_temp = current_x[0::3]
        u_temp = current_x[1::3]
        v_temp = current_x[2::3]
        
        cx = r_temp + u_temp * (1.0 - 2.0 * r_temp)
        cy = r_temp + v_temp * (1.0 - 2.0 * r_temp)
        
        # Strict feasibility check
        valid = True
        for i in range(n):
            for j in range(i+1, n):
                d = np.sqrt((cx[i]-cx[j])**2 + (cy[i]-cy[j])**2)
                if d < r_temp[i] + r_temp[j] - 1e-9:
                    valid = False
                    break
            if not valid: break
            
        if valid:
            s = np.sum(r_temp)
            if s > best_sum:
                best_sum = s
                best_centers = np.column_stack((cx, cy))
                best_radii = r_temp
                
    # Fallback (highly unlikely given penalty schedule)
    if best_centers is None:
        r_temp = current_x[0::3]
        u_temp = current_x[1::3]
        v_temp = current_x[2::3]
        cx = r_temp + u_temp * (1.0 - 2.0 * r_temp)
        cy = r_temp + v_temp * (1.0 - 2.0 * r_temp)
        return np.column_stack((cx, cy)), r_temp, np.sum(r_temp)
        
    return best_centers, best_radii, best_sum
