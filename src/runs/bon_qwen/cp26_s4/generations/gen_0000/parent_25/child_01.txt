To pack 26 circles in a unit square $[0,1] \times [0,1]$ and maximize the sum of radii, we use a numerical optimization approach. This problem is a non-convex constrained optimization problem. We use `scipy.optimize.minimize` with the 'SLSQP' method to find a local optimum.

### Strategy:
1.  **Initialization:** Generate an initial configuration using a hexagonal lattice pattern. This arrangement is denser than a square grid and typically provides a better starting point for optimization. We scale the lattice to fit within the square for an estimated radius (e.g., $r \approx 0.09$).
2.  **Variables:** The optimization variables include the $(x, y)$ centers and radius $r$ for each of the 26 circles. Total variables = $3 \times 26 = 78$.
3.  **Objective Function:** Maximize the sum of radii. In the minimizer, we minimize the negative sum.
4.  **Constraints:**
    -   **Boundary:** Each circle must be within the square ($r \le x, y \le 1-r$).
    -   **Non-Overlap:** The distance between any two centers must be at least the sum of their radii ($d_{ij} \ge r_i + r_j$).
    -   **Non-negative Radii:** $r_i \ge 0$.
5.  **Execution:** Run the optimizer from the initialized state. If constraints are violated, the solver will adjust positions and sizes to satisfy them while increasing the radii.

import numpy as np
from scipy.optimize import minimize

def run_packing():
    """
    Packs 26 circles in a unit square to maximize the sum of radii.
    
    Returns:
        centers: np.array of shape (26, 2)
        radii: np.array of shape (26,)
        sum_radii: float
    """
    n_circles = 26
    
    # 1. Initialization: Hexagonal Lattice Pattern
    # We generate a set of points based on a hexagonal grid.
    # This helps in finding a dense packing configuration quickly.
    
    # Estimate a starting radius to fit circles in the square
    # A rough estimate for 26 circles in a hex pattern in unit square
    r_est = 0.09
    
    centers = []
    radii = []
    
    # Generate hexagonal rows
    # Row height in hex packing is r * sqrt(3)
    row_height = r_est * np.sqrt(3)
    col_width = 2 * r_est # Distance between centers in a row
    
    # We try to fit rows vertically
    y_curr = r_est
    row_idx = 0
    
    while y_curr + r_est <= 1.0:
        # Shift x for odd rows to create hexagonal staggering
        if row_idx % 2 == 0:
            x_curr = r_est
        else:
            x_curr = r_est + r_est # Shift by r (half of 2r spacing)
            
        while x_curr + r_est <= 1.0:
            if len(centers) < n_circles:
                centers.append([x_curr, y_curr])
                radii.append(r_est)
            
            x_curr += col_width
        
        y_curr += row_height
        row_idx += 1
    
    # If we didn't get 26 circles (unlikely with this logic for small r), 
    # or if we need to fill gaps, we can add random valid circles.
    # However, with r=0.09, we should easily fit 26.
    # Let's ensure we have exactly 26.
    while len(centers) < n_circles:
        # Random placement fallback with small radius
        # Try to place in empty space
        while True:
            x = np.random.uniform(0.1, 0.9)
            y = np.random.uniform(0.1, 0.9)
            # Check overlap with existing
            is_valid = True
            for cx, cy in centers:
                dist = np.sqrt((x-cx)**2 + (y-cy)**2)
                if dist < 2 * r_est: # Assume existing are r_est
                    is_valid = False
                    break
            if is_valid:
                centers.append([x, y])
                radii.append(r_est)
                break
        if len(centers) >= n_circles:
            break
            
    # Trim to exact number
    centers = centers[:n_circles]
    radii = radii[:n_circles]
    
    # Convert to numpy arrays
    init_centers = np.array(centers)
    init_radii = np.array(radii)
    
    # Flatten variables for optimizer
    # Variables: [x1, y1, r1, x2, y2, r2, ...]
    x0 = np.hstack([init_centers.flatten(), init_radii])
    
    # 2. Objective Function
    def objective(vars):
        # Maximize sum of radii -> Minimize negative sum
        radii_part = vars[2::3]
        return -np.sum(radii_part)
    
    # 3. Constraints
    constraints = []
    
    # Boundary constraints: r <= x <= 1-r, r <= y <= 1-r
    # x - r >= 0  => -x + r <= 0 (ineq) -> but scipy expects fun(x) >= 0 for 'ineq'
    # Let's use fun(x) >= 0
    # x - r >= 0
    # 1 - x - r >= 0
    # y - r >= 0
    # 1 - y - r >= 0
    
    for i in range(n_circles):
        idx_x = i * 3
        idx_y = i * 3 + 1
        idx_r = i * 3 + 2
        
        # x - r >= 0
        constraints.append({
            'type': 'ineq',
            'fun': lambda v, i=i: v[idx_x] - v[idx_r]
        })
        # 1 - x - r >= 0
        constraints.append({
            'type': 'ineq',
            'fun': lambda v, i=i: 1.0 - v[idx_x] - v[idx_r]
        })
        # y - r >= 0
        constraints.append({
            'type': 'ineq',
            'fun': lambda v, i=i: v[idx_y] - v[idx_r]
        })
        # 1 - y - r >= 0
        constraints.append({
            'type': 'ineq',
            'fun': lambda v, i=i: 1.0 - v[idx_y] - v[idx_r]
        })
        # r >= 0
        constraints.append({
            'type': 'ineq',
            'fun': lambda v, i=i: v[idx_r]
        })

    # Overlap constraints: dist(i,j) >= ri + rj
    # dist^2 - (ri + rj)^2 >= 0
    for i in range(n_circles):
        for j in range(i + 1, n_circles):
            idx_xi, idx_yi, idx_ri = i*3, i*3+1, i*3+2
            idx_xj, idx_yj, idx_rj = j*3, j*3+1, j*3+2
            
            def dist_constraint(v, i=i, j=j):
                xi, yi, ri = v[idx_xi], v[idx_yi], v[idx_ri]
                xj, yj, rj = v[idx_xj], v[idx_yj], v[idx_rj]
                
                # Avoid negative radius issues in logic if solver goes weird, 
                # but constraint r>=0 handles it.
                # Calculate squared distance
                d_sq = (xi - xj)**2 + (yi - yj)**2
                sum_r = ri + rj
                # Constraint: d >= sum_r  => d^2 >= sum_r^2
                # Note: if sum_r < 0 (impossible here), this logic might flip, but r>=0.
                return d_sq - sum_r**2

            constraints.append({
                'type': 'ineq',
                'fun': dist_constraint
            })

    # 4. Optimization
    # Use SLSQP method which handles constraints
    # Bounds for variables to keep search space reasonable?
    # x, y in [0, 1], r in [0, 0.5]
    bounds = []
    for i in range(n_circles):
        bounds.extend([(0.0, 1.0), (0.0, 1.0), (0.0, 0.5)])
        
    result = minimize(
        objective,
        x0,
        method='SLSQP',
        bounds=bounds,
        constraints=constraints,
        options={'maxiter': 1000, 'ftol': 1e-9}
    )
    
    # 5. Extract results
    best_vars = result.x
    best_centers = np.zeros((n_circles, 2))
    best_radii = np.zeros(n_circles)
    
    for i in range(n_circles):
        best_centers[i] = [best_vars[i*3], best_vars[i*3+1]]
        best_radii[i] = best_vars[i*3+2]
        
    sum_radii = np.sum(best_radii)
    
    return best_centers, best_radii, sum_radii

if __name__ == "__main__":
    centers, radii, total = run_packing()
    print(f"Sum of radii: {total}")
    print(f"Min radius: {np.min(radii)}, Max radius: {np.max(radii)}")
