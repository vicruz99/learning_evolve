The problem asks to maximize the sum of radii of 26 circles packed in a unit square. This is a non-convex optimization problem. A robust and efficient approach is to decouple the problem into two levels:
1. **Given fixed centers**, the maximum radii that satisfy non-overlap and boundary constraints can be found by solving a Linear Program (LP). The constraints are linear in radii: $r_i \ge 0$, $r_i \le \text{boundary distance}_i$, and $r_i + r_j \le \text{distance}(c_i, c_j)$. Maximizing $\sum r_i$ under these linear constraints is straightforward with `scipy.optimize.linprog`.
2. **Optimize centers** to maximize the LP objective. Since the LP objective is a function of centers, we can use a derivative-free optimizer like Powell's method over the $2N=52$ center coordinates. The centers are bounded within $[0,1]^2$.

This alternating/bilevel strategy is highly effective because the LP gives the exact optimal radii for any configuration, turning the problem into a smooth-ish landscape over centers. Multiple random restarts (including a hexagonal grid initialization) ensure we escape local minima and find a near-global optimum. The approach avoids custom force-directed schemes that require tuning, relying instead on standard, well-tested numerical optimization.

```python
import numpy as np
from scipy.optimize import linprog, minimize

def compute_lp_sum_radii(centers):
    """
    Given fixed circle centers, compute the maximum possible radii such that
    circles do not overlap and stay within the unit square.
    Solves a Linear Program to maximize sum(r_i).
    """
    N = centers.shape[0]
    c_obj = -np.ones(N)  # linprog minimizes, so we minimize -sum(r)
    
    # Boundary constraints: r_i <= min(x, 1-x, y, 1-y)
    bounds_vals = np.minimum(centers, 1.0 - centers).min(axis=1)
    
    # Pairwise Euclidean distances
    diff = centers[:, np.newaxis, :] - centers[np.newaxis, :, :]
    dists = np.sqrt(np.sum(diff**2, axis=2))
    
    # Indices for upper triangle of distance matrix (i < j)
    i_idx, j_idx = np.triu_indices(N, k=1)
    M = len(i_idx)
    
    # Construct A_ub for LP: A_ub @ r <= b_ub
    # First N rows: r_i <= bounds_vals[i]
    # Next M rows: r_i + r_j <= dist(i,j)
    A_ub = np.zeros((N + M, N))
    A_ub[:N, :N] = np.eye(N)
    A_ub[N:, i_idx] += 1.0
    A_ub[N:, j_idx] += 1.0
    
    b_ub = np.concatenate([bounds_vals, dists[i_idx, j_idx]])
    
    # Solve LP
    res = linprog(c_obj, A_ub=A_ub, b_ub=b_ub, bounds=[(0, None)] * N, method='highs')
    if not res.success:
        # Fallback in case of numerical issues
        return 0.0, np.zeros(N)
    return -res.fun, res.x

def objective_function(x, N):
    """Objective for the center optimizer: negative sum of optimal radii."""
    centers = x.reshape(N, 2)
    s, _ = compute_lp_sum_radii(centers)
    return -s

def run_packing():
    N = 26
    best_sum = -1.0
    best_centers = None
    best_radii = None
    
    bounds_centers = [(0.0, 1.0)] * (2 * N)
    
    # Generate initial configurations
    inits = []
    
    # 1. Hexagonal grid initialization (highly efficient starting point)
    h_pts = []
    for r in range(6):
        for c in range(5):
            x = (c + (r % 2) * 0.5) * 0.2 + 0.05
            y = r * 0.2 + 0.05
            if len(h_pts) < N:
                h_pts.append([x, y])
    inits.append(np.array(h_pts[:N]))
    
    # 2. Random initializations to escape local minima
    for _ in range(3):
        pts = np.random.rand(N, 2) * 0.8 + 0.1
        inits.append(pts)
        
    # Optimization loop over restarts
    for pts in inits:
        try:
            res = minimize(objective_function, pts.flatten(), method='Powell', 
                           bounds=bounds_centers, args=(N,), options={'maxiter': 200, 'ftol': 1e-9})
            curr_sum = -res.fun
            if curr_sum > best_sum:
                best_sum = curr_sum
                best_centers = res.x.reshape(N, 2)
                _, best_radii = compute_lp_sum_radii(best_centers)
        except Exception:
            continue
            
    # Final validation projection & radii recomputation
    best_centers = np.clip(best_centers, 0.0, 1.0)
    best_sum, best_radii = compute_lp_sum_radii(best_centers)
    
    return best_centers, best_radii, best_sum
```
