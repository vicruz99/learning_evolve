    *   For a fixed set of circle centers, the problem of finding optimal radii to maximize their sum, subject to non-overlap and boundary constraints, is a **Linear Programming (LP)** problem.
    *   The constraints are: $r_i \ge 0$, $r_i \le \text{dist}(center_i, \text{boundary})$, and $r_i + r_j \le \text{dist}(center_i, center_j)$.
    *   We can use `scipy.optimize.linprog` to solve this LP efficiently for any given configuration of centers.

2.  **Outer Optimization (Positions)**:
    *   The outer problem is to find the centers $(x_i, y_i)$ that maximize the optimal sum of radii returned by the LP.
    *   Since the LP objective value is a non-smooth function of the centers, we use a derivative-free optimization algorithm. **Basin-hopping** combined with a local search (like **Nelder-Mead**) is effective for escaping local optima in high-dimensional spaces.
    *   Alternatively, **Differential Evolution** is very robust but might be slower; however, for 52 variables (26 circles $\times$ 2 coords), it is feasible. We will use `differential_evolution` with a reasonable population size and iterations to ensure a good global search.

def get_max_radii_sum(centers):
    """
    Given centers of n circles, solves the LP to find radii that maximize sum(r_i)
    subject to non-overlap and boundary constraints.
    
    Args:
        centers: np.array of shape (n, 2)
        
    Returns:
        sum_radii: float
        radii: np.array of shape (n)
    """
    n = centers.shape[0]
    
    # Calculate upper bounds for radii based on distance to square boundaries
    # r_i <= x_i, r_i <= 1 - x_i, r_i <= y_i, r_i <= 1 - y_i
    x = centers[:, 0]
    y = centers[:, 1]
    
    ub_radii = np.minimum(np.minimum(x, 1 - x), np.minimum(y, 1 - y))
    # Ensure non-negative upper bounds
    ub_radii = np.maximum(ub_radii, 0.0)
    
    # LP Problem:
    # Maximize sum(r_i)  <=> Minimize -sum(r_i)
    # Subject to:
    #   r_i + r_j <= distance(center_i, center_j) for all i < j
    #   0 <= r_i <= ub_radii[i]
    
    # Objective function coefficients for minimization
    c = np.ones(n) * -1.0
    
    # Inequality constraints A_ub @ r <= b_ub
    # We need a row for each pair (i, j) with i < j
    num_pairs = n * (n - 1) // 2
    A_ub = np.zeros((num_pairs, n))
    b_ub = np.zeros(num_pairs)
    
    idx = 0
    # Precompute distances to avoid recomputing inside loop if needed, 
    # but direct computation is fast enough for n=26
    for i in range(n):
        for j in range(i + 1, n):
            dx = centers[i, 0] - centers[j, 0]
            dy = centers[i, 1] - centers[j, 1]
            dist = np.sqrt(dx*dx + dy*dy)
            
            # Constraint: r_i + r_j <= dist
            A_ub[idx, i] = 1.0
            A_ub[idx, j] = 1.0
            b_ub[idx] = dist
            idx += 1
            
    # Bounds for each variable r_i: (0, ub_radii[i])
    bounds = [(0, ub) for ub in ub_radii]
    
    try:
        # Solve LP
        # method='highs' is efficient and available in recent scipy
        res = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
        
        if res.success:
            optimal_radii = res.x
            # Due to numerical noise, ensure radii are non-negative and satisfy bounds strictly?
            # The solver should handle it, but let's clip just in case
            optimal_radii = np.maximum(optimal_radii, 0.0)
            # Also ensure r_i <= ub_radii (solver bounds should enforce this)
            optimal_radii = np.minimum(optimal_radii, ub_radii)
            
            sum_r = np.sum(optimal_radii)
            return sum_r, optimal_radii
        else:
            # If LP fails, return 0
            return 0.0, np.zeros(n)
    except Exception:
        return 0.0, np.zeros(n)

    sum_r, _ = get_max_radii_sum(centers)
