

<strategy>
The goal is to pack 26 circles into a unit square to maximize the sum of their radii. A greedy local optimization approach is effective here. 

1.  **Initialization**: Start with a configuration of centers that provides a reasonable density, such as a grid or a perturbed hexagonal packing. This avoids getting stuck in trivial local minima with zero or very small radii.
2.  **Iterative Optimization**: 
    -   **Radius Calculation**: For a fixed set of centers, the problem of finding optimal radii is a Linear Programming (LP) problem. We maximize $\sum r_i$ subject to non-overlap constraints ($r_i + r_j \le \text{dist}(c_i, c_j)$) and boundary constraints ($r_i \le \text{dist to walls}$).
    -   **Force Calculation**: Using the dual variables (marginals) from the LP solution, we can compute a "force" on each center. The dual variables represent the sensitivity of the objective function to the constraints. If a distance constraint is active (circles touching), the dual variable indicates how much the sum of radii would increase if the circles moved apart. We calculate a gradient (force vector) for each center that pushes circles apart and pushes them away from walls they are constrained by.
    -   **Position Update**: We move the centers in the direction of these forces to relax constraints and allow radii to grow. We use an adaptive step size and clamp coordinates to the unit square.
3.  **Refinement**: We run this loop for many iterations, potentially with multiple random restarts to find the global optimum or a very high-quality local optimum.

This method effectively turns the geometric packing problem into an iterative optimization process where circles "repel" each other based on the tightness of their constraints.
</strategy>

```python
import numpy as np
from scipy.optimize import linprog

def run_packing():
    """
    Packs 26 circles in a unit square to maximize the sum of radii.
    Uses an iterative optimization approach:
    1. Fix centers, solve LP for max sum of radii.
    2. Compute gradient (forces) on centers using dual variables (marginals).
    3. Update centers to reduce constraint tightness (move apart).
    """
    np.random.seed(42) # For reproducibility, though restarts add randomness
    N = 26
    iterations = 3000
    best_sum = -1.0
    best_centers = None
    best_radii = None

    # Precompute pair indices for constraints
    pairs = []
    for i in range(N):
        for j in range(i + 1, N):
            pairs.append((i, j))
    num_pairs = len(pairs)
    
    # LP Structure Setup
    # Objective: Minimize -sum(r)  => Maximize sum(r)
    c_obj = -np.ones(N)
    
    # Inequality Constraints Matrix A_ub such that A_ub @ r <= b_ub
    # Rows 0 to num_pairs-1: Pair constraints r_i + r_j <= dist
    # Rows num_pairs to end: Wall constraints r_i <= x_i, etc.
    
    A_ub_pairs = np.zeros((num_pairs, N))
    for idx, (i, j) in enumerate(pairs):
        A_ub_pairs[idx, i] = 1.0
        A_ub_pairs[idx, j] = 1.0
        
    A_ub_walls = np.zeros((4*N, N))
    for i in range(N):
        # 4 wall constraints per circle
        A_ub_walls[4*i, i] = 1.0      # Left:  r <= x
        A_ub_walls[4*i+1, i] = 1.0    # Right: r <= 1-x
        A_ub_walls[4*i+2, i] = 1.0    # Bottom:r <= y
        A_ub_walls[4*i+3, i] = 1.0    # Top:   r <= 1-y
        
    A_ub = np.vstack([A_ub_pairs, A_ub_walls])
    bounds = [(0, None) for _ in range(N)]

    # Run multiple restarts to avoid local optima
    num_restarts = 5
    
    for restart in range(num_restarts):
        # 1. Initialize Centers
        # Use a grid-like structure perturbed by noise for better initial density
        centers = np.zeros((N, 2))
        
        # Try to pack them in a grid pattern first, then randomize slightly
        # 5x5 grid is 25 points.
        # We can try to fit 26.
        
        # Let's try a specific dense pattern or just random
        # Random is safer to explore different topologies
        if restart == 0:
            # Structured start: 5 rows
            k = 0
            for r_idx in range(5):
                for c_idx in range(5):
                    centers[k, 0] = 0.1 + c_idx * 0.2
                    centers[k, 1] = 0.1 + r_idx * 0.2
                    k += 1
            # 26th circle at center? (0.5, 0.5) is occupied.
            # Place at (0.5, 0.2) - between rows?
            centers[25, 0] = 0.5
            centers[25, 1] = 0.25
        else:
            # Random start within [0.1, 0.9] to avoid boundary issues initially
            centers = np.random.uniform(0.15, 0.85, (N, 2))
            
        # Optimization Loop
        current_centers = centers.copy()
        
        # Adaptive step size
        step_size = 0.05
        
        for t in range(iterations):
            # 2. Solve LP for Radii
            # Update RHS vector b_ub
            b_ub = np.zeros(num_pairs + 4*N)
            
            # Pair distances
            for idx, (i, j) in enumerate(pairs):
                dist = np.sqrt(np.sum((current_centers[i] - current_centers[j])**2))
                # Avoid zero distance to prevent division by zero in gradient
                if dist < 1e-9:
                    dist = 1e-9
                b_ub[idx] = dist
            
            # Wall bounds
            for i in range(N):
                x, y = current_centers[i]
                b_ub[num_pairs + 4*i] = x       # Left
                b_ub[num_pairs + 4*i+1] = 1-x   # Right
                b_ub[num_pairs + 4*i+2] = y     # Bottom
                b_ub[num_pairs + 4*i+3] = 1-y   # Top
                
            try:
                res = linprog(c_obj, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
                if res.success:
                    radii = res.x
                    current_sum = -res.fun
                    
                    # Track best
                    if current_sum > best_sum:
                        best_sum = current_sum
                        best_centers = current_centers.copy()
                        best_radii = radii.copy()
                    
                    # 3. Compute Forces (Gradients)
                    # Marginals correspond to rows in A_ub
                    # res.ineqlin.marginals contains dual variables
                    marginals = res.ineqlin.marginals
                    
                    forces = np.zeros((N, 2))
                    
                    # Pair forces
                    for idx, (i, j) in enumerate(pairs):
                        # Dual variable lambda_ij
                        # Check if active (marginal > epsilon)
                        lam = marginals[idx]
                        if lam > 1e-6:
                            # Vector from j to i
                            v = current_centers[i] - current_centers[j]
                            dist = np.sqrt(np.sum(v**2))
                            if dist > 1e-9:
                                unit_v = v / dist
                                # Force on i is +lam * unit_v (push away from j)
                                # Force on j is -lam * unit_v (push away from i)
                                forces[i] += lam * unit_v
                                forces[j] -= lam * unit_v
                                
                    # Wall forces
                    # Marginals for walls are at indices num_pairs + 4*i ...
                    for i in range(N):
                        base_idx = num_pairs + 4*i
                        # Left wall (r <= x): marginal mu_L. 
                        # Increasing x relaxes constraint -> Force +x direction
                        forces[i, 0] += marginals[base_idx]
                        
                        # Right wall (r <= 1-x): marginal mu_R.
                        # Increasing x tightens constraint -> Force -x direction
                        forces[i, 0] -= marginals[base_idx+1]
                        
                        # Bottom wall (r <= y): marginal mu_B.
                        # Increasing y relaxes constraint -> Force +y direction
                        forces[i, 1] += marginals[base_idx+2]
                        
                        # Top wall (r <= 1-y): marginal mu_T.
                        # Increasing y tightens constraint -> Force -y direction
                        forces[i, 1] -= marginals[base_idx+3]
                        
                    # Normalize forces? 
                    # Forces can be large if many constraints active.
                    # A simple scaling or just direct application with step size.
                    
                    # Update centers
                    current_centers += step_size * forces
                    
                    # Project back to [0, 1]
                    current_centers = np.clip(current_centers, 0, 1)
                    
                    # Decay step size slowly
                    step_size *= 0.999

            except Exception:
                # If LP fails, break or continue
                break
                
    # Final validation and return
    # Re-solve LP for the best centers to ensure radii are consistent
    if best_centers is not None:
        current_centers = best_centers
        # Re-run LP one last time to be safe
        b_ub = np.zeros(num_pairs + 4*N)
        for idx, (i, j) in enumerate(pairs):
            dist = np.sqrt(np.sum((current_centers[i] - current_centers[j])**2))
            b_ub[idx] = max(dist, 1e-9)
        for i in range(N):
            x, y = current_centers[i]
            b_ub[num_pairs + 4*i] = x
            b_ub[num_pairs + 4*i+1] = 1-x
            b_ub[num_pairs + 4*i+2] = y
            b_ub[num_pairs + 4*i+3] = 1-y
            
        try:
            res = linprog(c_obj, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
            if res.success:
                best_radii = res.x
                best_sum = -res.fun
        except:
            pass # Keep previous best

    return best_centers, best_radii, best_sum
```
