To pack 26 circles in a unit square maximizing the sum of radii, we formulate it as a nonlinear optimization problem. We use `scipy.optimize.minimize` with the `SLSQP` method, which handles inequality constraints efficiently. 

Key design choices:
1. **Parameterization**: Concatenate centers `[x_i, y_i]` and radii `[r_i]` into a single vector `theta` of length 78.
2. **Objective**: Maximize $\sum r_i$ (minimize $-\sum r_i$).
3. **Constraints**: 
   - Boundary: $r_i \le x_i \le 1-r_i$ and $r_i \le y_i \le 1-r_i$ (4N inequalities).
   - Non-overlap: $\sqrt{(x_i-x_j)^2+(y_i-y_j)^2} \ge r_i+r_j$ for all $i<j$ (325 inequalities). Formulated as $d_{ij}^2 - (r_i+r_j)^2 \ge 0$ to keep it differentiable and algebraic.
4. **Initialization**: Start from a perturbed $6 \times 5$ grid with small radii to guarantee feasibility. Run 5 random restarts to mitigate local optima.
5. **Performance**: Precompute upper-triangular indices for overlap constraints. Vectorize distance calculations. Use strict bounds for coordinates and radii.
6. **Robustness**: All helper functions are top-level. No closures or lambdas. Deterministic seed for reproducibility.

```python
import numpy as np
from scipy.optimize import minimize

N = 26
TRIU_INDICES = np.triu_indices(N, k=1)

def objective(theta):
    radii = theta[2*N:]
    return -np.sum(radii)

def constraints(theta):
    centers = theta[:2*N].reshape((N, 2))
    radii = theta[2*N:]
    
    c = []
    # Boundary constraints: r <= x <= 1-r  =>  x - r >= 0, 1 - x - r >= 0
    c.append(centers[:, 0] - radii)
    c.append(1 - centers[:, 0] - radii)
    c.append(centers[:, 1] - radii)
    c.append(1 - centers[:, 1] - radii)
    
    # Overlap constraints: dist^2 >= (r_i + r_j)^2
    diffs = centers[:, None, :] - centers[None, :, :]
    dist_sq = np.sum(diffs**2, axis=2)
    r_sum = radii[:, None] + radii[None, :]
    
    c.append(dist_sq[TRIU_INDICES] - r_sum[TRIU_INDICES]**2)
    
    return np.concatenate(c)

def run_packing():
    bounds = [(0.0, 1.0), (0.0, 1.0), (1e-4, 0.5)] * N
    cons = {'type': 'ineq', 'fun': constraints}
    
    best_val = -np.inf
    best_x = None
    
    np.random.seed(42)
    for _ in range(5):
        # Perturbed grid initialization
        rows, cols = 5, 6
        centers = np.zeros((N, 2))
        idx = 0
        for r in range(rows):
            for c in range(cols):
                if idx < N:
                    centers[idx, 0] = (c + 0.5) / cols + np.random.randn() * 0.05
                    centers[idx, 1] = (r + 0.5) / rows + np.random.randn() * 0.05
                    idx += 1
        centers = np.clip(centers, 0.1, 0.9)
        radii = np.full(N, 0.04)
        x0 = np.concatenate([centers.flatten(), radii])
        
        res = minimize(objective, x0, method='SLSQP', bounds=bounds, constraints=cons, options={'maxiter': 1500, 'ftol': 1e-9})
        
        if -res.fun > best_val:
            best_val = -res.fun
            best_x = res.x
            
    centers = best_x[:2*N].reshape((N, 2))
    radii = best_x[2*N:]
    return centers, radii, np.sum(radii)
```
