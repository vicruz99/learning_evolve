A better strategy is to use a "hybrid" packing: place a set of larger circles in a perturbed grid to leave gaps, and then fill those gaps with smaller circles. 

My approach uses a two-phase optimization:
1.  **Initialization:** Create a base grid of circles. We will start with a 5x5 grid but remove some circles to create space, then fill that space with multiple smaller circles. A configuration of ~21 large circles and ~5 small circles might be efficient.
2.  **Optimization:** Use a physics-based relaxation (L-BFGS-B) to maximize the sum of radii. The circles will "repel" each other and expand until they hit the boundaries or each other. By starting with a well-spaced initial configuration, the optimizer can converge to a local optimum where circles are tightly packed with varying sizes.

The key insight is that smaller circles are more "efficient" per unit of space (area $\propto r^2$, value $\propto r$), so having a distribution of sizes allows us to utilize the gaps in a large-circle packing, increasing the total sum of radii beyond the equal-circle limit.

import numpy as np
from scipy.optimize import minimize

def get_distance_matrix(centers):
    """Compute pairwise distance matrix."""
    n = centers.shape[0]
    diff = centers[:, np.newaxis, :] - centers[np.newaxis, :, :]
    return np.sqrt(np.sum(diff**2, axis=2))

def objective(params, n):
    """
    Objective function to maximize sum of radii.
    We minimize the negative sum.
    params = [x1, y1, r1, x2, y2, r2, ..., xn, yn, rn]
    """
    centers = params[0::3].reshape(n, 2)
    radii = params[1::3]
    # We want to maximize sum(radii), so minimize -sum(radii)
    return -np.sum(radii)

def constraints(params, n):
    """
    Define constraints:
    1. Circles inside unit square
    2. Circles do not overlap
    """
    centers = params[0::3].reshape(n, 2)
    radii = params[1::3]
    
    cons = []
    
    # Boundary constraints: x - r >= 0, 1 - x - r >= 0, same for y
    # x - r >= 0 => x - r
    for i in range(n):
        x, y = centers[i]
        r = radii[i]
        cons.append({'type': 'ineq', 'fun': lambda p, i=i: p[3*i] - p[3*i+2]}) # x - r
        cons.append({'type': 'ineq', 'fun': lambda p, i=i: 1 - p[3*i] - p[3*i+2]}) # 1 - x - r
        cons.append({'type': 'ineq', 'fun': lambda p, i=i: p[3*i+1] - p[3*i+2]}) # y - r
        cons.append({'type': 'ineq', 'fun': lambda p, i=i: 1 - p[3*i+1] - p[3*i+2]}) # 1 - y - r
        cons.append({'type': 'ineq', 'fun': lambda p, i=i: p[3*i+2]}) # r >= 0

    # Overlap constraints: dist(i, j) >= r_i + r_j
    # dist^2 >= (r_i + r_j)^2
    # dist^2 - (r_i + r_j)^2 >= 0
    for i in range(n):
        for j in range(i + 1, n):
            xi, yi = centers[i]
            xj, yj = centers[j]
            ri, rj = radii[i], radii[j]
            
            # Note: accessing params directly in lambda can be tricky with closures
            # Using a helper function or passing indices is safer
            
            def make_constraint(i, j):
                def constraint_func(p):
                    ci = p[3*i], p[3*i+1]
                    cj = p[3*j], p[3*j+1]
                    ri_val = p[3*i+2]
                    rj_val = p[3*j+2]
                    dist_sq = (ci[0]-cj[0])**2 + (ci[1]-cj[1])**2
                    sum_r = ri_val + rj_val
                    return dist_sq - sum_r**2
                return constraint_func

            cons.append({'type': 'ineq', 'fun': make_constraint(i, j)})

    return cons

            # y - r >= 0

        # Only penalize positive overlap

    # Let's do a quick check and fix if NaN or huge violations.
    
    sum_r = np.sum(final_radii)
