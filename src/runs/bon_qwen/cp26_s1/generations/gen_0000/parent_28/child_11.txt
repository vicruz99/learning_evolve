The problem is formulated as maximizing the sum of radii $\sum r_i$ subject to non-overlap and boundary constraints. For any fixed set of centers, the maximal radius of each circle is determined by the minimum distance to the square boundaries and half the distance to the nearest other center. This transforms the problem into optimizing the center coordinates to maximize $\sum_i \min(\text{dist}_i(\text{boundary}), \frac{1}{2}\min_{j \neq i} \|c_i - c_j\|)$.

This objective function is continuous but non-differentiable due to the min operators. To solve it robustly:
1. **Global Optimization**: Use `scipy.optimize.differential_evolution` to explore the 52-dimensional search space (26 centers × 2 coordinates). This handles the multiple local minima inherent in packing problems.
2. **Local Refinement**: Follow DE with `scipy.optimize.minimize` using the `Powell` method to polish the solution and exploit the continuous nature of the objective near optima.
3. **Constraint Handling**: Bound coordinates to $[0, 1]$ during optimization. The radii computation inherently respects boundary and separation constraints. Clipping is applied to prevent numerical drift.
4. **Efficiency**: The pairwise distance computation is $O(N^2)$ with $N=26$, which is negligible. The DE population and iterations are tuned for a balance of speed and accuracy.

```python
import numpy as np
from scipy.optimize import differential_evolution, minimize

def get_sum_radii(centers):
    """Compute maximal valid radii for given centers and return their sum."""
    centers = np.clip(centers, 0.0, 1.0)
    n = centers.shape[0]
    radii = np.full(n, np.inf)
    
    # Boundary constraints
    for i in range(n):
        r = min(centers[i, 0], 1.0 - centers[i, 0], 
                centers[i, 1], 1.0 - centers[i, 1])
        radii[i] = r
        
    # Pairwise separation constraints
    for i in range(n):
        for j in range(i + 1, n):
            d = np.sqrt(np.sum((centers[i] - centers[j])**2))
            half_d = d * 0.5
            if half_d < radii[i]:
                radii[i] = half_d
            if half_d < radii[j]:
                radii[j] = half_d
                
    return np.sum(radii), radii

def objective(x):
    """Objective function for optimization: negative sum of radii."""
    centers = x.reshape(-1, 2)
    s, _ = get_sum_radii(centers)
    return -s

def run_packing():
    n = 26
    bounds = [(0.0, 1.0)] * (2 * n)
    
    # Global search using Differential Evolution
    result_de = differential_evolution(
        objective,
        bounds,
        seed=42,
        popsize=15,
        maxiter=500,
        tol=1e-8,
        polish=False,
        mutation=(0.5, 1.5),
        recombination=0.9
    )
    
    # Local refinement using Powell's method
    res_local = minimize(
        objective,
        result_de.x,
        method='Powell',
        options={'xtol': 1e-9, 'ftol': 1e-9, 'maxiter': 10000}
    )
    
    best_centers = res_local.x.reshape(-1, 2)
    # Clip final centers to be strictly within bounds
    best_centers = np.clip(best_centers, 0.0, 1.0)
    
    total_sum, final_radii = get_sum_radii(best_centers)
    
    return best_centers, final_radii, total_sum
```
