To maximize the sum of radii for 26 circles in a unit square, I will use a force-directed optimization strategy. This approach treats the circles as repelling particles, allowing the algorithm to "inflate" the radii until the configuration reaches a stable, jammed state where no further growth is possible without violation of constraints.

### Strategy
1.  **Initialization**: Place 26 circles with small radii (0.02) at random positions within the square to ensure an initial valid, non-overlapping state.
2.  **Iterative Growth**: In each iteration, uniformly scale up the radii.
3.  **Repulsion Resolution**: After each growth step, apply repulsive forces to resolve overlaps. Circles push each other apart based on the depth of overlap, and boundary forces push circles back inside the unit square.
4.  **Validation**: A configuration is only accepted if all constraints (boundary and non-overlap) are satisfied within a small tolerance ($10^{-6}$).
5.  **Local Search**: If the radii cannot be grown further (a local maximum), the algorithm perturbs the centers to escape the local optimum and attempts to find a denser arrangement.
6.  **Tracking**: The best valid configuration is continuously updated and returned at the end.

                    if yi + ri > L: forces[i, 1] -= 50.0 * (yi + ri - L)
                    
                    for j in range(i + 1, N):
                        dx = curr_centers[i, 0] - curr_centers[j, 0]
                        dy = curr_centers[i, 1] - curr_centers[j, 1]
                        dist_sq = dx*dx + dy*dy
                        if dist_sq < 1e-12:
                            rand_vec = np.random.rand(2) * 0.1
                            forces[i] += rand_vec
                            forces[j] -= rand_vec
                        else:
                            dist = np.sqrt(dist_sq)
                            req = curr_radii[i] + curr_radii[j]
                            if dist < req:
                                overlap = req - dist
                                ux, uy = dx/dist, dy/dist
                                f = 50.0 * overlap
                                forces[i, 0] += ux * f
                                forces[i, 1] += uy * f
                                forces[j, 0] -= ux * f
                                forces[j, 1] -= uy * f
                curr_centers += forces * 0.02
                curr_centers[:, 0] = np.clip(curr_centers[:, 0], 1e-6, L - 1e-6)
                curr_centers[:, 1] = np.clip(curr_centers[:, 1], 1e-6, L - 1e-6)
            
            # Revert to best valid state if perturbation failed
            valid_curr = True
            for i in range(N):
                if (curr_centers[i, 0] - curr_radii[i] < -1e-6 or 
                    curr_centers[i, 0] + curr_radii[i] > L + 1e-6 or
                    curr_centers[i, 1] - curr_radii[i] < -1e-6 or 
                    curr_centers[i, 1] + curr_radii[i] > L + 1e-6):
                    valid_curr = False; break
            if valid_curr:
                for i in range(N):
                    for j in range(i + 1, N):
                        dx = curr_centers[i, 0] - curr_centers[j, 0]
                        dy = curr_centers[i, 1] - curr_centers[j, 1]
                        dist = np.sqrt(dx*dx + dy*dy)
                        if dist < curr_radii[i] + curr_radii[j] - 1e-6:
                            valid_curr = False; break
                    if not valid_curr: break
            
            if not valid_curr:
                curr_centers = best_centers.copy()
                curr_radii = best_radii.copy()

    return best_centers, best_radii, best_sum
