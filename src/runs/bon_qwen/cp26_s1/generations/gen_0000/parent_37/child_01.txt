To pack 26 circles in a unit square and maximize the sum of radii, a heuristic approach is more effective than assuming a uniform grid. The strategy involves:
1.  **Initialization with a Dense Grid:** Start with a 5x5 grid of equal circles (radius 0.1). This provides a solid baseline sum of 2.5.
2.  **Perturbation and Optimization:** The 5x5 grid leaves small gaps at the intersections of four circles. By slightly reducing the radii of the grid circles and allowing them to move (perturbation), we can open up these gaps to fit a 26th circle.
3.  **Coordinate Descent (Local Search):** We will implement a local optimization loop. In each iteration, we attempt to increase the radius of a randomly selected circle as much as possible until it hits a boundary or another circle. 
4.  **Repacking and Filling:** The process will alternate between expanding existing circles and shifting centers to clear space for the 26th circle in the most promising gaps (typically near the center or edges of the grid).

import numpy as np

import math

def validate_packing(centers, radii):
    """
    Validate that circles don't overlap and are inside the unit square

    Args:
        centers: np.array of shape (n, 2) with (x, y) coordinates
        radii: np.array of shape (n) with radius of each circle

    Returns:
        True if valid, False otherwise
    """
    n = centers.shape[0]

    # Check for NaN values
    if np.isnan(centers).any():
        print("NaN values detected in circle centers")
        return False

    if np.isnan(radii).any():
        print("NaN values detected in circle radii")
        return False

    # Check if radii are nonnegative and not nan
    for i in range(n):
        if radii[i] < 0:
            print(f"Circle {i} has negative radius {radii[i]}")
            return False
        elif np.isnan(radii[i]):
            print(f"Circle {i} has nan radius")
            return False

    # Check if circles are inside the unit square
    for i in range(n):
        x, y = centers[i]
        r = radii[i]
        if x - r < -1e-12 or x + r > 1 + 1e-12 or y - r < -1e-12 or y + r > 1 + 1e-12:
            print(f"Circle {i} at ({x}, {y}) with radius {r} is outside the unit square")
            return False

    # Check for overlaps
    for i in range(n):
        for j in range(i + 1, n):
            dist = np.sqrt(np.sum((centers[i] - centers[j]) ** 2))
            if dist < radii[i] + radii[j] - 1e-12:  # Allow for tiny numerical errors
                print(f"Circles {i} and {j} overlap: dist={dist}, r1+r2={radii[i]+radii[j]}")
                return False

    return True
