

<strategy>
The problem of maximizing the sum of radii for $N$ circles in a unit square can be reformulated elegantly by decoupling center positions and radii. For any fixed configuration of centers, the maximum possible radius for each circle is determined by the nearest neighbor (either another circle or the boundary). Specifically, $r_i^{\max} = \min(x_i, 1-x_i, y_i, 1-y_i, \min_{j \neq i} \frac{\|c_i - c_j\|}{2})$. 

This insight reduces the problem to a 52-variable optimization over the centers only, where the objective is to maximize $\sum r_i^{\max}(C)$. The resulting radii automatically satisfy all non-overlap and boundary constraints by construction.

Strategy:
1. **Vectorized Radius Computation**: Implement a fast $O(N^2)$ function that computes optimal radii given centers using NumPy broadcasting.
2. **Global Search**: Use `scipy.optimize.differential_evolution` to explore the high-dimensional non-convex landscape of center positions. DE is robust for multimodal problems like circle packing.
3. **Local Refinement**: After DE finds a promising basin, apply `scipy.optimize.minimize` with the `Powell` method (derivative-free) to polish the solution and escape flat/non-smooth regions caused by the `min` operator in the objective.
4. **Constraints Handling**: The formulation inherently respects constraints. We add a tiny $\epsilon$-padding to boundaries during optimization to prevent degenerate zero-radius circles and ensure strict feasibility for the validator.
</strategy>

```python
import numpy as np
from scipy.optimize import differential_evolution, minimize

def compute_optimal_radii(centers: np.ndarray) -> np.ndarray:
    """
    Given fixed centers, compute the maximum possible radius for each circle
    such that no overlaps occur and all circles stay inside [0,1]x[0,1].
    """
    n = centers.shape[0]
    
    # Compute pairwise Euclidean distances efficiently
    diff = centers[:, np.newaxis, :] - centers[np.newaxis, :, :]
    dists = np.sqrt(np.sum(diff**2, axis=2))
    np.fill_diagonal(dists, np.inf)  # Ignore self-distance
    min_dists = np.min(dists, axis=1)
    
    # Compute maximum radius allowed by square boundaries
    b1 = centers[:, 0]
    b2 = 1.0 - centers[:, 0]
    b3 = centers[:, 1]
    b4 = 1.0 - centers[:, 1]
    boundary_limits = np.minimum(np.minimum(b1, b2), np.minimum(b3, b4))
    
    # Radius is limited by half the distance to the nearest circle
    # and by the distance to the nearest boundary
    radii = np.minimum(min_dists * 0.5, boundary_limits)
    return radii

def neg_sum_radii(x_flat: np.ndarray) -> float:
    """Objective function for optimization: minimize negative sum of radii."""
    centers = x_flat.reshape(-1, 2)
    # Prevent centers from hitting exact boundaries to avoid numerical issues
    centers = np.clip(centers, 1e-6, 1.0 - 1e-6)
    radii = compute_optimal_radii(centers)
    return -np.sum(radii)

def run_packing() -> tuple[np.ndarray, np.ndarray, float]:
    n_circles = 26
    bounds = [(0.0, 1.0)] * (2 * n_circles)
    
    # 1. Global optimization to find a good basin
    res_global = differential_evolution(
        neg_sum_radii,
        bounds,
        seed=42,
        maxiter=2500,
        popsize=30,
        tol=1e-9,
        polish=False  # Handled by local step below for better control
    )
    
    best_centers = res_global.x.reshape(n_circles, 2)
    
    # 2. Local refinement to escape non-smooth plateaus and maximize precision
    res_local = minimize(
        neg_sum_radii,
        best_centers.flatten(),
        method='Powell',
        tol=1e-12,
        options={'maxiter': 30000, 'ftol': 1e-15}
    )
    
    best_centers = res_local.x.reshape(n_circles, 2)
    best_radii = compute_optimal_radii(best_centers)
    total_sum = float(np.sum(best_radii))
    
    return best_centers, best_radii, total_sum
```
