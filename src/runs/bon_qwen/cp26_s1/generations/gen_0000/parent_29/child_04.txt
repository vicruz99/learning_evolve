To solve the problem of packing 26 circles in a unit square to maximize the sum of radii, we employ a two-stage optimization strategy combining Linear Programming (LP) with iterative center adjustment.

1.  **Linear Programming for Radii**: For a fixed set of circle centers, finding the maximum sum of radii is a Linear Programming problem. The constraints are:
    *   **Pairwise non-overlap**: $r_i + r_j \leq \text{dist}(c_i, c_j)$
    *   **Boundary containment**: $r_i \leq x_i$, $r_i \leq 1-x_i$, $r_i \leq y_i$, $r_i \leq 1-y_i$
    This is solved using `scipy.optimize.linprog` with the `highs` solver.

2.  **Gradient-Based Center Optimization**: The "shadow prices" (dual variables) from the LP solution indicate how much the objective (sum of radii) would increase if we relaxed a constraint. 
    *   **Repulsive Forces**: Positive dual variables for pairwise constraints indicate touching circles. We apply repulsive forces proportional to these duals to move centers apart, increasing distances and allowing radii to grow.
    *   **Boundary Forces**: Duals for boundary constraints indicate centers are too close to edges. Forces push centers back into the interior.

3.  **Initialization and Tuning**: We initialize centers on a structured grid and apply a "jitter" to avoid symmetry traps. The algorithm iterates through thousands of steps with an adaptive learning rate to converge on the maximum sum of radii.

4.  **Final Validation**: The resulting centers and radii are verified to ensure no overlaps and full containment within the unit square.

import numpy as np
from scipy.optimize import linprog

def run_packing() -> tuple[np.ndarray, np.ndarray, float]:
    n = 26
    # Initialize centers in a grid and add jitter
    centers = np.zeros((n, 2))
    cols = 6
    rows = 5
    y_step = 1.0 / (rows + 1)
    x_step = 1.0 / (cols + 1)
    
    for i in range(n):
        r = i // cols
        c = i % cols
        # Offset alternate rows for hexagonal packing structure
        offset = (x_step / 2) if r % 2 == 1 else 0
        centers[i, 0] = x_step * (c + 1) + offset
        centers[i, 1] = y_step * (r + 1)

    # Add small random jitter to break symmetry
    rng = np.random.default_rng(42)
    centers += rng.uniform(-0.01, 0.01, size=centers.shape)
    centers = np.clip(centers, 0.05, 0.95) # Keep away from exact boundaries initially

    # LP Matrices
    m_pairs = n * (n - 1) // 2
    m_bound = 4 * n
    A_ub = np.zeros((m_pairs + m_bound, n))
    
    # Pairwise constraints indices
    pair_idx = 0
    pair_constraints = []
    for i in range(n):
        for j in range(i + 1, n):
            A_ub[pair_idx, i] = 1.0
            A_ub[pair_idx, j] = 1.0
            pair_constraints.append((i, j, pair_idx))
            pair_idx += 1
            
    # Boundary constraints
    for i in range(n):
        row_offset = m_pairs
        A_ub[row_offset + 0, i] = 1.0 # r_i <= x_i
        A_ub[row_offset + 1, i] = 1.0 # r_i <= 1 - x_i
        A_ub[row_offset + 2, i] = 1.0 # r_i <= y_i
        A_ub[row_offset + 3, i] = 1.0 # r_i <= 1 - y_i

    c_obj = np.ones(n) # Maximize sum(r) -> Minimize -sum(r)
    
    learning_rate = 0.02
    decay = 0.9995
    
    for step in range(2000):
        # 1. Update LP bounds based on current centers
        b_ub = np.zeros(m_pairs + m_bound)
        
        for i, j, idx in pair_constraints:
            dist = np.sqrt(np.sum((centers[i] - centers[j])**2))
            b_ub[idx] = dist
            
        for i in range(n):
            row_offset = m_pairs
            b_ub[row_offset + 0] = centers[i, 0]
            b_ub[row_offset + 1] = 1.0 - centers[i, 0]
            b_ub[row_offset + 2] = centers[i, 1]
            b_ub[row_offset + 3] = 1.0 - centers[i, 1]

        # 2. Solve LP
        res = linprog(-c_obj, A_ub=A_ub, b_ub=b_ub, bounds=(0, None), method='highs')
        
        if not res.success:
            continue
            
        radii = res.x
        duals = res.ineqlin.marginal # Negative of shadow prices
        
        # 3. Compute Forces
        forces = np.zeros_like(centers)
        
        # Pairwise forces
        for i, j, idx in pair_constraints:
            # duals are negative of the actual shadow price in linprog output
            shadow = -duals[idx]
            if shadow > 1e-6:
                d = b_ub[idx]
                if d > 1e-9:
                    diff = centers[i] - centers[j]
                    dir_vec = diff / d
                    forces[i] += shadow * dir_vec
                    forces[j] -= shadow * dir_vec
                    
        # Boundary forces
        for i in range(n):
            row_offset = m_pairs
            # r_i <= x_i (Dual > 0 means pushing left is limiting)
            if -duals[row_offset + 0] > 1e-6:
                forces[i, 0] += 1.0 * (-duals[row_offset + 0])
            # r_i <= 1 - x_i
            if -duals[row_offset + 1] > 1e-6:
                forces[i, 0] -= 1.0 * (-duals[row_offset + 1])
            # r_i <= y_i
            if -duals[row_offset + 2] > 1e-6:
                forces[i, 1] += 1.0 * (-duals[row_offset + 2])
            # r_i <= 1 - y_i
            if -duals[row_offset + 3] > 1e-6:
                forces[i, 1] -= 1.0 * (-duals[row_offset + 3])

        # 4. Update Centers
        centers += learning_rate * forces
        centers = np.clip(centers, 1e-6, 1.0 - 1e-6)
        
        # 5. Decay learning rate
        learning_rate *= decay
        
    sum_radii = np.sum(radii)
    
    return centers, radii, sum_radii
