

<strategy>
The problem asks to pack 26 circles in a unit square to maximize the sum of their radii. This is a non-convex optimization problem due to the pairwise distance constraints. 

**Strategy:**
1. **Penalty Method:** Instead of using explicit inequality constraints which can be expensive to handle in many solvers, I will use a quadratic penalty method. The objective function will be `-(sum of radii) + weight * (boundary_violations^2 + overlap_violations^2)`. Minimizing this encourages large radii while penalizing constraint violations.
2. **Continuation:** Start with a low penalty weight to allow the optimizer to explore the configuration space freely, then gradually increase the weight. This helps the solution converge to a feasible packing where constraints are strictly satisfied.
3. **Initialization:** Initialize circles on a perturbed hexagonal grid. Hexagonal patterns are known to yield high packing densities. Random noise is added to break symmetry and escape trivial local minima.
4. **Multiple Restarts:** Run the optimization loop several times from different random initializations to improve the chances of finding a globally optimal or near-optimal configuration.
5. **Solver:** Use `scipy.optimize.minimize` with the `L-BFGS-B` method, which efficiently handles box constraints (circles must be within `[0,1]` and radii `>= 0`).
6. **Compliance:** All helper functions are defined at the top level. No lambda functions or closures are used. `functools.partial` is used to bind parameters to the loss function.
</strategy>

```python
import numpy as np
from scipy.optimize import minimize
from functools import partial

def compute_loss(v, n, weight):
    """
    Computes the penalized objective: -sum(radii) + penalty * violations
    """
    centers = v[:2*n].reshape(n, 2)
    radii = v[2*n:]
    
    # Boundary penalties: circles must stay within [0,1]^2
    viol_left = np.maximum(0, radii - centers[:, 0])
    viol_right = np.maximum(0, centers[:, 0] + radii - 1.0)
    viol_bottom = np.maximum(0, radii - centers[:, 1])
    viol_top = np.maximum(0, centers[:, 1] + radii - 1.0)
    bound_pen = np.sum(viol_left**2 + viol_right**2 + viol_bottom**2 + viol_top**2)
    
    # Overlap penalties: distance between centers must be >= sum of radii
    diff = centers[:, np.newaxis, :] - centers[np.newaxis, :, :]
    dists = np.sqrt(np.sum(diff**2, axis=2))
    r_sum = radii[:, np.newaxis] + radii[np.newaxis, :]
    
    # Ignore self-distances
    np.fill_diagonal(dists, np.inf)
    np.fill_diagonal(r_sum, -np.inf)
    
    viol_overlap = np.maximum(0, r_sum - dists)
    tri_idx = np.triu_indices(n, k=1)
    overlap_pen = np.sum(viol_overlap[tri_idx]**2)
    
    return -np.sum(radii) + weight * (bound_pen + overlap_pen)

def run_packing():
    n = 26
    best_sum = 0.0
    best_centers = None
    best_radii = None
    
    n_restarts = 5
    n_continuation_steps = 14
    init_weight = 100.0
    
    for _ in range(n_restarts):
        # Create a hexagonal-ish grid initialization
        xs = np.linspace(0.15, 0.85, 6)
        ys = np.linspace(0.15, 0.85, 5)
        pts = []
        for y in ys:
            for x in xs:
                pts.append([x, y])
                
        # Add random perturbation to break symmetry
        noise = np.random.uniform(-0.02, 0.02, size=(n, 2))
        centers = np.array(pts[:n]) + noise
        centers = np.clip(centers, 0.05, 0.95)
        radii = np.full(n, 0.09)
        
        x0 = np.concatenate([centers.flatten(), radii])
        bounds = [(0.0, 1.0)] * (2*n) + [(0.0, 0.5)] * n
        
        curr_x = x0.copy()
        weight = init_weight
        
        # Continuation method: gradually increase penalty weight
        for _ in range(n_continuation_steps):
            obj = partial(compute_loss, n=n, weight=weight)
            res = minimize(obj, curr_x, bounds=bounds, method='L-BFGS-B', 
                          options={'maxiter': 400, 'ftol': 1e-10})
            curr_x = res.x
            weight *= 1.4
            
        curr_centers = curr_x[:2*n].reshape(n, 2)
        curr_radii = curr_x[2*n:]
        curr_sum = np.sum(curr_radii)
        
        if curr_sum > best_sum:
            best_sum = curr_sum
            best_centers = curr_centers.copy()
            best_radii = curr_radii.copy()
            
    return best_centers, best_radii, best_sum
```
