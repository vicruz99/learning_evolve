To maximize the sum of radii for 26 circles in a unit square, we treat this as a continuous optimization problem. The radius of each circle is determined by its distance to the square boundaries and half the distance to its nearest neighbors. Direct optimization of this "min" function is non-smooth and prone to local optima. 

**Strategy:**
1. **Smooth Approximation:** Replace the non-smooth `min` operator with a soft-min (log-sum-exp) function. This creates a differentiable surrogate objective that closely approximates the true radius while allowing gradient-based optimization.
2. **Gradient-Based Optimization:** Use `scipy.optimize.minimize` with the `L-BFGS-B` algorithm. This method efficiently handles bound constraints (keeping centers within [0,1]) and scales well to the 52 variables (x, y for 26 circles).
3. **Multiple Random Restarts:** Run the optimizer from 10 different random initial configurations to escape poor local optima and increase the probability of finding a globally superior packing.
4. **Final Verification:** After optimization, compute the exact radii using the hard minimum constraint to ensure validity and report the final sum.

This approach leverages modern numerical optimization to tightly pack circles, naturally balancing boundary proximity and inter-circle spacing to maximize the objective.

import numpy as np
from scipy.optimize import minimize

def run_packing() -> tuple[np.ndarray, np.ndarray, float]:
    n = 26
    best_centers = None
    best_sum = 0.0
    
    # Smoothness parameter for log-sum-exp approximation of min
    alpha = 20.0
    
    def objective(vars):
        centers = vars.reshape(n, 2)
        
        # Compute pairwise distances (halved, since radius limit is half distance)
        diff = centers[:, np.newaxis, :] - centers[np.newaxis, :, :]
        dists = 0.5 * np.sqrt(np.sum(diff**2, axis=2))
        np.fill_diagonal(dists, np.inf)  # Ignore self-distance
        
        # Compute distances to boundaries
        b_x0 = centers[:, 0]
        b_x1 = 1.0 - centers[:, 0]
        b_y0 = centers[:, 1]
        b_y1 = 1.0 - centers[:, 1]
        boundaries = np.min(np.stack([b_x0, b_x1, b_y0, b_y1], axis=1), axis=1)
        
        # Combine neighbor and boundary distances
        # Shape: (n, n+1) where last column is boundary distance
        all_dists = np.stack([dists, boundaries[:, np.newaxis]], axis=-1)
        
        # Soft-min approximation: r ≈ max(d) - 1/α * log(sum(exp(-α*(d - max(d)))))
        m = np.max(all_dists, axis=1)
        r = m - (1.0 / alpha) * np.log(
            np.sum(np.exp(-alpha * (all_dists - m[:, np.newaxis])), axis=1)
        )
        
        return -np.sum(r)  # Minimize negative sum -> Maximize sum

    bounds = [(0.0, 1.0)] * (2 * n)
    
    # Run multiple restarts to avoid local optima
    for seed in range(10):
        np.random.seed(seed)
        x0 = np.random.uniform(0.2, 0.8, size=2 * n)
        
        res = minimize(
            objective, 
            x0, 
            method='L-BFGS-B', 
            bounds=bounds, 
            options={'maxiter': 3000, 'ftol': 1e-12, 'gtol': 1e-10}
        )
        
        centers = res.x.reshape(n, 2)
        
        # Compute exact radii for validation
        radii = np.full(n, 1.0)
        for i in range(n):
            r = min(centers[i,0], 1-centers[i,0], centers[i,1], 1-centers[i,1])
            for j in range(n):
                if i != j:
                    d = np.sqrt(np.sum((centers[i] - centers[j])**2))
                    r = min(r, d/2)
            radii[i] = r
            
        curr_sum = np.sum(radii)
        if curr_sum > best_sum:
            best_sum = curr_sum
            best_centers = centers.copy()
            
    # Final exact radius computation for the best configuration
    radii = np.full(n, 1.0)
    for i in range(n):
        r = min(best_centers[i,0], 1-best_centers[i,0], best_centers[i,1], 1-best_centers[i,1])
        for j in range(n):
            if i != j:
                d = np.sqrt(np.sum((best_centers[i] - best_centers[j])**2))
                r = min(r, d/2)
        radii[i] = r
        
    return best_centers, radii, np.sum(radii)
