

<strategy>
1. **Problem Formulation**: The task is a constrained nonlinear optimization problem. We maximize $\sum r_i$ subject to:
   - Boundary constraints: $r_i \le x_i \le 1-r_i$ and $r_i \le y_i \le 1-r_i$
   - Non-overlap constraints: $(x_i-x_j)^2 + (y_i-y_j)^2 \ge (r_i+r_j)^2$ for all $i < j$
   - Non-negativity: $r_i \ge 0$

2. **Optimization Approach**: 
   - Use `scipy.optimize.minimize` with the `SLSQP` method, which handles nonlinear inequality constraints and bounds efficiently.
   - Pack all variables into a single vector: $[x_1, y_1, r_1, x_2, y_2, r_2, \dots]$
   - Define constraint functions at the top level to avoid closures and lambdas, returning arrays of constraint values.
   - Objective function minimizes negative sum of radii (equivalent to maximizing sum).

3. **Initialization & Robustness**:
   - Circle packing has many local optima. Run the optimizer from multiple diverse starting configurations:
     - Hexagonal lattice (known to be near-optimal for dense packing)
     - Perturbed grid
     - Random placements
   - Track the best valid result across all seeds.
   - Set generous iteration limits and tight tolerances to converge to a high-quality solution.

4. **Post-Processing**:
   - Clamp centers to strict boundary feasibility $[r_i, 1-r_i]$ to absorb numerical drift.
   - Ensure radii are non-negative.
   - Return the best centers, radii, and their sum.
</strategy>

```python
import numpy as np
from scipy.optimize import minimize

N_CIRCLES = 26

def objective(v):
    """Minimize negative sum of radii (equivalent to maximizing sum of radii)."""
    return -np.sum(v[2::3])

def boundary_ineq(v):
    """Returns array of boundary constraint values. Must be >= 0."""
    out = np.zeros(4 * N_CIRCLES)
    for i in range(N_CIRCLES):
        b = 3 * i
        out[4 * i]     = v[b] - v[b + 2]           # x - r >= 0
        out[4 * i + 1] = 1.0 - v[b] - v[b + 2]     # 1 - x - r >= 0
        out[4 * i + 2] = v[b + 1] - v[b + 2]       # y - r >= 0
        out[4 * i + 3] = 1.0 - v[b + 1] - v[b + 2] # 1 - y - r >= 0
    return out

def distance_ineq(v):
    """Returns array of pairwise non-overlap constraint values. Must be >= 0."""
    m = N_CIRCLES * (N_CIRCLES - 1) // 2
    out = np.zeros(m)
    k = 0
    for i in range(N_CIRCLES):
        for j in range(i + 1, N_CIRCLES):
            bi, bj = 3 * i, 3 * j
            dx = v[bi] - v[bj]
            dy = v[bi + 1] - v[bj + 1]
            d2 = dx * dx + dy * dy
            rs = v[bi + 2] + v[bj + 2]
            out[k] = d2 - rs * rs
            k += 1
    return out

def run_packing() -> tuple[np.ndarray, np.ndarray, float]:
    best_sum = -1.0
    best_centers = None
    best_radii = None
    
    constraints = [
        {'type': 'ineq', 'fun': boundary_ineq},
        {'type': 'ineq', 'fun': distance_ineq}
    ]
    
    # x, y in [0, 1], radii in [1e-6, 0.5]
    bounds = [(0.0, 1.0)] * (2 * N_CIRCLES) + [(1e-6, 0.5)] * N_CIRCLES
    
    # Try multiple initial configurations to escape local optima
    seeds = [0, 1, 2, 3, 4]
    for seed in seeds:
        np.random.seed(seed)
        centers = np.zeros((N_CIRCLES, 2))
        
        if seed == 0:
            # Hexagonal lattice pattern
            rows = [6, 5, 6, 5, 4]
            dy, dx = 0.42, 0.36
            idx = 0
            for r_idx, cnt in enumerate(rows):
                y = r_idx * dy + 0.12
                for c_idx in range(cnt):
                    x = c_idx * dx + (0.52 if r_idx % 2 == 1 else 0.2)
                    centers[idx] = [x, y]
                    idx += 1
        elif seed == 1:
            # Structured grid
            for i in range(N_CIRCLES):
                centers[i] = [0.1 + (i % 6) * 0.16, 0.1 + (i // 6) * 0.2]
        else:
            # Random perturbed
            centers = np.random.rand(N_CIRCLES, 2) * 0.6 + 0.2

        radii = np.full(N_CIRCLES, 0.09 + seed * 0.002)
        x0 = np.concatenate([centers.flatten(), radii])
        
        try:
            res = minimize(objective, x0, method='SLSQP', bounds=bounds, 
                           constraints=constraints, options={'maxiter': 5000, 'ftol': 1e-12})
            
            cur_sum = np.sum(res.x[2::3])
            if cur_sum > best_sum:
                best_sum = cur_sum
                best_centers = res.x[:2 * N_CIRCLES].reshape(N_CIRCLES, 2)
                best_radii = res.x[2 * N_CIRCLES:]
        except Exception:
            continue

    # Fallback to a valid small packing if optimization completely fails
    if best_centers is None:
        centers = np.zeros((N_CIRCLES, 2))
        idx = 0
        for r_idx in range(5):
            cnt = 5 if r_idx < 4 else 1
            y = r_idx * 0.2 + 0.1
            for c_idx in range(cnt):
                centers[idx] = [0.1 + c_idx * 0.18, y]
                idx += 1
        return centers, np.full(N_CIRCLES, 0.05), 0.05 * N_CIRCLES

    # Clamp centers to strictly satisfy boundary constraints after optimization
    # (handles numerical drift near boundaries)
    for i in range(N_CIRCLES):
        r = best_radii[i]
        best_centers[i, 0] = np.clip(best_centers[i, 0], r, 1.0 - r)
        best_centers[i, 1] = np.clip(best_centers[i, 1], r, 1.0 - r)
        
    # Ensure radii are non-negative
    best_radii = np.maximum(best_radii, 0.0)
    
    final_sum = float(np.sum(best_radii))
    return best_centers, best_radii, final_sum
```
