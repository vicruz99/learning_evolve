The problem of maximizing the sum of radii for 26 circles in a unit square is a non-convex global optimization problem. A grid-based initialization is a strong candidate because circle packing is most efficient when circles are roughly equal in size and arranged in a lattice-like structure. However, for $N=26$, the grid might not be perfect (since 26 is not a square number), so perturbation and local search are necessary.

My strategy involves:
1.  **Objective Function Formulation**: Instead of optimizing radii directly with complex constraints, I will define the radius of each circle based on its position. For a given set of centers, the maximum valid radius for circle $i$ is determined by its distance to the boundaries and half the distance to the nearest neighbor. This ensures the packing is always valid (non-overlapping and inside the square) for any configuration of centers.
2.  **Initialization**: I will generate multiple starting configurations to increase the chance of finding a global optimum.
    *   **Random Starts**: To explore the search space.
    *   **Structured Starts**: A $5 \times 5$ grid (25 circles) with an extra circle placed in a gap or corner, perturbed slightly. A hexagonal lattice approximation is also good for density.
3.  **Optimization**: I will use `scipy.optimize.minimize` with the `Powell` method. Powell's method is a derivative-free conjugate direction method, making it robust for the non-smooth objective function (which involves `min` operations due to distance constraints). It handles the high dimensionality (52 variables for 26 circles) reasonably well.
4.  **Refinement**: After the optimizer runs, I will re-calculate the radii based on the final centers to ensure consistency and report the sum.

import numpy as np
from scipy.optimize import minimize

def run_packing() -> tuple[np.ndarray, np.ndarray, float]:
    """
    Optimizes the packing of 26 circles in a unit square to maximize the sum of radii.
    
    Returns:
        centers: np.ndarray of shape (26, 2)
        radii: np.ndarray of shape (26,)
        sum_radii: float
    """
    n_circles = 26
    
    def get_radii_and_sum(centers):
        """
        Computes the maximum valid radii for given centers and their sum.
        Radii are constrained by boundaries and pairwise distances.
        """
        # Centers shape (n, 2)
        # Distance to boundaries
        # x - r >= 0 => r <= x
        # 1 - x - r >= 0 => r <= 1 - x
        # same for y
        r_boundary = np.minimum(
            np.minimum(centers[:, 0], 1.0 - centers[:, 0]),
            np.minimum(centers[:, 1], 1.0 - centers[:, 1])
        )
        
        # Pairwise distances
        # Efficiently compute distance matrix
        # diffs shape (n, n, 2)
        diffs = centers[:, np.newaxis, :] - centers[np.newaxis, :, :]
        dists = np.sqrt(np.sum(diffs**2, axis=2))
        
        # Distance to nearest neighbor / 2
        # Ignore self distance
        np.fill_diagonal(dists, np.inf)
        min_neighbor_dist = np.min(dists, axis=1)
        r_neighbor = min_neighbor_dist / 2.0
        
        # Valid radius is the minimum of boundary constraint and neighbor constraint
        radii = np.minimum(r_boundary, r_neighbor)
        
        return radii, np.sum(radii)

    def objective(params):
        """
        Objective function to minimize: negative sum of radii.
        params is a flattened array of centers (x1, y1, x2, y2, ...)
        """
        centers = np.reshape(params, (n_circles, 2))
        
        # Clip centers to strictly inside [0, 1] to avoid zero radii or issues
        # Small epsilon ensures numerical stability
        epsilon = 1e-7
        centers = np.clip(centers, epsilon, 1.0 - epsilon)
        
        _, sum_r = get_radii_and_sum(centers)
        return -sum_r

                grid_points.append([x, y])

        # Actually, let's just take 26 random points on a grid structure.
        # Or simpler: 6x5 grid subset?
        
        # Let's try a hexagonal-ish perturbation of a grid
        # 5 rows.
        # Row counts: 5, 5, 5, 5, 6? No, 26.
        # Maybe 5, 6, 5, 5, 5?
        
        # Simple approach: Random points
        # But structured is better.
        
        # Config 1: Random
        np.random.seed(42)
        rand_centers = np.random.rand(n_circles, 2)
        configs.append(rand_centers.flatten())
        
        # Config 2: Perturbed Grid
        # Generate points on a grid, add small noise
        grid_x = np.linspace(0.1, 0.9, 5)
        grid_y = np.linspace(0.1, 0.9, 5)
        
        pts = []
        for i in range(25):
            pts.append([grid_x[i % 5], grid_y[i // 5]])
        
        # Add 26th point. Maybe at center (0.5, 0.5) - already there.
        # Let's place it at a corner gap?
        # Or just place 26 points evenly.
        # Let's just create a 6x5 grid (30 points) and pick 26?
        # Or 5 rows of roughly 5.2 points?
        
        # Let's try to place 26 points in a spiral or just random but dense
        # Let's try to construct a specific layout.
        # 5 rows.
        # Row 0: 5 points
        # Row 1: 6 points (shifted)
        # Row 2: 5 points
        # Row 3: 6 points? No, sum=26.

    best_sum = -1.0
    best_centers = None

    # Powell is robust for non-smooth
    for i, initial_params in enumerate(configs):
        try:
            res = minimize(objective, initial_params, method='Powell', 
                           options={'maxiter': 500, 'xtol': 1e-6, 'ftol': 1e-9})

    # Final refinement: re-calculate radii precisely from best centers
    if best_centers is not None:
        best_radii, final_sum = get_radii_and_sum(best_centers)
        
        # Sanity check and clipping

        best_centers = centers

        final_sum = np.sum(radii)

    return best_centers, best_radii, final_sum
