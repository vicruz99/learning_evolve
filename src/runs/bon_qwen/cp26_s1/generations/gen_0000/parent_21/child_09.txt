

<strategy>
The problem asks to maximize the sum of radii of 26 circles packed in a unit square. This is a non-convex optimization problem. A highly effective strategy is to decouple the problem into two parts:
1. For a fixed set of circle centers, the maximum radii are determined by a Linear Programming (LP) problem. The constraints are linear in radii: each radius is bounded by the distance to the four boundaries and by half the distance to every other center (or more precisely, $r_i + r_j \leq \|c_i - c_j\|$).
2. We optimize the center coordinates using a derivative-free global optimizer (Differential Evolution) followed by a local optimizer (Nelder-Mead/Powell). The objective function evaluates the LP to get the maximum sum of radii for those centers.

This approach is robust, mathematically exact for fixed centers, and leverages `scipy`'s optimized solvers. The LP has ~429 constraints and 26 variables, which `scipy.optimize.linprog` (with HiGHS solver) solves in milliseconds. Differential Evolution explores the 52-dimensional center space globally, and a local polish step refines the result to high precision. Initial seeding with a 5x5 grid configuration provides a strong starting point close to the expected optimum.
</strategy>

```python
import numpy as np
from scipy.optimize import linprog, differential_evolution, minimize

N_CIRCLES = 26

def compute_max_sum_radii(centers):
    """
    Given fixed centers, solve LP to find radii that maximize sum(r_i)
    subject to non-overlap and boundary constraints.
    """
    n = centers.shape[0]
    c = -np.ones(n)  # Minimize negative sum => Maximize sum
    
    # Constraints: A_ub @ r <= b_ub
    # 4 constraints per circle (boundary)
    # n*(n-1)/2 constraints (pairwise non-overlap)
    n_constr = 4 * n + n * (n - 1) // 2
    A_ub = np.zeros((n_constr, n))
    b_ub = np.zeros(n_constr)
    
    idx = 0
    for i in range(n):
        x, y = centers[i]
        # r_i <= x
        A_ub[idx, i] = 1.0
        b_ub[idx] = x
        idx += 1
        # r_i <= 1 - x
        A_ub[idx, i] = 1.0
        b_ub[idx] = 1.0 - x
        idx += 1
        # r_i <= y
        A_ub[idx, i] = 1.0
        b_ub[idx] = y
        idx += 1
        # r_i <= 1 - y
        A_ub[idx, i] = 1.0
        b_ub[idx] = 1.0 - y
        idx += 1
        
    # Pairwise distance constraints: r_i + r_j <= dist(i, j)
    # Vectorized distance calculation
    dists = np.linalg.norm(centers[:, None, :] - centers[None, :, :], axis=2)
    
    for i in range(n):
        for j in range(i + 1, n):
            A_ub[idx, i] = 1.0
            A_ub[idx, j] = 1.0
            b_ub[idx] = dists[i, j]
            idx += 1
            
    # Solve LP
    res = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=(0, None), method='highs')
    if res.success:
        radii = np.maximum(res.x, 0.0)  # Clamp numerical negatives
        return -res.fun, radii
    else:
        # Fallback in case of solver issues (highly unlikely)
        return 0.0, np.zeros(n)

def objective_flat(x_flat):
    """Objective function for optimizers (minimizing negative sum of radii)"""
    centers = x_flat.reshape(N_CIRCLES, 2)
    sum_r, _ = compute_max_sum_radii(centers)
    return -sum_r

def run_packing():
    # Bounds for center coordinates: [0, 1] for each x and y
    bounds = [(0.0, 1.0)] * (2 * N_CIRCLES)
    
    # Smart initialization: 5x5 grid + 1 center
    init_x = np.zeros(2 * N_CIRCLES)
    grid_size = 5
    idx = 0
    for i in range(grid_size):
        for j in range(grid_size):
            if idx >= N_CIRCLES:
                break
            init_x[idx] = (i + 0.5) / grid_size
            init_x[idx + 1] = (j + 0.5) / grid_size
            idx += 1
    # Fill remaining spots at center
    for k in range(idx, 2 * N_CIRCLES):
        init_x[k] = 0.5

    # Global optimization with Differential Evolution
    de_result = differential_evolution(
        objective_flat,
        bounds,
        seed=42,
        maxiter=350,
        popsize=20,
        mutation=(0.5, 1.0),
        recombination=0.9,
        tol=1e-9,
        x0=init_x,
        disp=False
    )
    
    # Local refinement with Nelder-Mead (handles non-smooth objective well)
    local_result = minimize(
        objective_flat,
        de_result.x,
        method='Nelder-Mead',
        tol=1e-10,
        options={'maxiter': 2000, 'xatol': 1e-10, 'fatol': 1e-10}
    )
    
    best_x = local_result.x
    final_centers = best_x.reshape(N_CIRCLES, 2)
    sum_radii, final_radii = compute_max_sum_radii(final_centers)
    
    # Ensure centers are strictly within bounds (numerical safety)
    final_centers = np.clip(final_centers, 0.0, 1.0)
    
    return final_centers, final_radii, sum_radii
```
