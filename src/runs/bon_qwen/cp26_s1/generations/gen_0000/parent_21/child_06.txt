To maximize the sum of radii for 26 circles in a unit square, I employ a hybrid optimization strategy that combines continuous non-linear optimization for center placement with exact linear programming for radius assignment.

1. **Continuous Center Optimization (L-BFGS-B)**: 
   The centers of the circles are optimized using a penalty-based objective function. We minimize $-\sum r_i + \lambda \cdot (\text{boundary violations} + \text{overlaps})$. Quadratic penalties enforce non-overlap and boundary constraints. A homotopy approach (gradually increasing the penalty weight $\lambda$) helps the optimizer escape shallow local minima and converge to a dense, valid configuration.

2. **Exact Radius Assignment (Linear Programming)**:
   Once a promising center configuration is found, the problem of finding the maximum sum of radii becomes a Linear Program. For fixed centers, the constraints $r_i + r_j \le \|c_i - c_j\|$ and $0 \le r_i \le \text{boundary limits}$ are linear. Solving this LP guarantees the absolute maximum sum of radii for those specific centers, often improving upon the approximate radii found during the continuous optimization phase.

3. **Multiple Restarts & Structured Initialization**:
   The optimizer is run multiple times with different initial conditions (a structured 5x5 grid + center point, plus random perturbations) to increase the probability of finding the global optimum or a very high-quality local optimum.

This two-stage approach efficiently navigates the non-convex landscape of circle packing while guaranteeing mathematical validity and optimality for the radius variables.

import numpy as np
from scipy.optimize import minimize, linprog

def objective(vars, n, w):
    """
    Objective function for center/radius optimization.
    Minimizes negative sum of radii plus penalty for constraint violations.
    """
    centers = vars[:2*n].reshape(n, 2)
    radii = vars[2*n:]
    obj = -np.sum(radii)
    
    # Boundary penalties: circle must stay inside [0,1]x[0,1]
    obj += w * np.sum(np.maximum(radii - centers[:,0], 0)**2)
    obj += w * np.sum(np.maximum(radii + centers[:,0] - 1, 0)**2)
    obj += w * np.sum(np.maximum(radii - centers[:,1], 0)**2)
    obj += w * np.sum(np.maximum(radii + centers[:,1] - 1, 0)**2)
    
    # Overlap penalties: distance between centers must be >= sum of radii
    diff = centers[:, np.newaxis, :] - centers[np.newaxis, :, :]
    dists = np.sqrt(np.sum(diff**2, axis=2))
    i, j = np.tril_indices(n, -1)
    overlaps = radii[i] + radii[j] - dists[i, j]
    obj += w * np.sum(np.maximum(overlaps, 0)**2)
    
    return obj

def get_radii_from_centers(centers):
    """
    Solves the exact LP to maximize sum of radii for fixed centers.
    Constraints: r_i + r_j <= distance(i,j), 0 <= r_i <= boundary_margin_i
    """
    n = centers.shape[0]
    
    # Maximum radius allowed by boundaries for each circle
    bounds_r = np.minimum(centers, 1 - centers).min(axis=1)
    
    # Pairwise distances
    diff = centers[:, np.newaxis, :] - centers[np.newaxis, :, :]
    dists = np.sqrt(np.sum(diff**2, axis=2))
    i, j = np.tril_indices(n, -1)
    
    # Construct LP: max sum(r) <=> min -sum(r)
    # Constraints: A_ub @ r <= b_ub
    A_ub = np.zeros((len(i), n))
    b_ub = dists[i, j]
    for k in range(len(i)):
        A_ub[k, i[k]] = 1.0
        A_ub[k, j[k]] = 1.0
        
    # Add boundary constraints: r_i <= bounds_r[i]
    A_ub = np.vstack([A_ub, np.eye(n)])
    b_ub = np.concatenate([b_ub, bounds_r])
    
    c = -np.ones(n)  # Minimize negative sum => Maximize sum
    res = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=(0, None), method='highs')
    
    if res.success:
        return res.x
    else:
        # Fallback to safe small radii if LP fails (rare)
        return np.full(n, 0.01)

def run_packing():
    n = 26
    # Bounds for optimization variables: x,y in [0,1], r in [0, 0.5]
    bounds_opt = [(0, 1)] * (2*n) + [(0, 0.5)] * n
    
    best_sum = -np.inf
    best_centers = None
    
    # Structured initial guess (5x5 grid + 1 center)
    init_centers = []
    for i in range(5):
        for j in range(5):
            init_centers.append([0.1 + i*0.2, 0.1 + j*0.2])
    init_centers.append([0.5, 0.5])
    init_centers = np.array(init_centers)
    
    # Multiple restarts to find global optimum
    for trial in range(15):
        if trial == 0:
            cx = init_centers.copy()
        else:
            # Randomized structured initialization
            cx = np.random.rand(n, 2) * 0.8 + 0.1
            
        r0 = np.full(n, 0.06)
        x0 = np.concatenate([cx.flatten(), r0])
        
        # Homotopy optimization: gradually increase penalty weight
        w_vals = [500.0, 5000.0, 20000.0]
        x_curr = x0
        for w in w_vals:
            res = minimize(objective, x_curr, args=(n, w), method='L-BFGS-B', bounds=bounds_opt, options={'maxiter': 1000, 'ftol': 1e-10})
            x_curr = res.x
            
        # Extract optimized centers
        opt_centers = x_curr[:2*n].reshape(n, 2)
        
        # Solve exact LP for radii given these centers
        opt_radii = get_radii_from_centers(opt_centers)
        current_sum = np.sum(opt_radii)
        
        if current_sum > best_sum:
            best_sum = current_sum
            best_centers = opt_centers.copy()
            
    # Final LP pass on the best centers to ensure strict optimality for radii
    final_radii = get_radii_from_centers(best_centers)
    
    return best_centers, final_radii, np.sum(final_radii)
