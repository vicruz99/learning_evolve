

<strategy>
1. **Initialization**: Place 26 circles in a hexagonal lattice pattern within the unit square. This arrangement naturally achieves high packing density and provides a strong starting point for optimization. Initial radius is set conservatively (0.08) to ensure validity, with positions calculated using hexagonal row/column offsets.
2. **Optimization Formulation**: Frame the problem as a non-linear constrained optimization. Variables consist of $(x_i, y_i, r_i)$ for each circle. Objective is to maximize $\sum r_i$ (equivalent to minimizing $-\sum r_i$).
3. **Constraints**:
   - **Boundary**: Each circle must satisfy $r_i \leq x_i \leq 1-r_i$ and $r_i \leq y_i \leq 1-r_i$.
   - **Non-overlap**: For all $i < j$, $(x_i - x_j)^2 + (y_i - y_j)^2 \geq (r_i + r_j)^2$. This squared distance constraint is smooth and differentiable.
   - **Bounds**: $0 \leq x_i, y_i, r_i \leq 1$.
4. **Solver**: Use `scipy.optimize.minimize` with the `trust-constr` method, which handles non-linear inequality constraints robustly. Constraints are vectorized for efficiency. Multiple iterations allow the solver to expand radii until circles press against each other and boundaries.
5. **Post-processing**: Clip coordinates and radii to strict bounds to eliminate negligible numerical violations, then return the result.
</strategy>

```python
import numpy as np
from scipy.optimize import minimize, NonlinearConstraint

N_CIRCLES = 26

def objective(vars):
    radii = vars[2 * N_CIRCLES:]
    return -np.sum(radii)

def constraints(vars):
    n = N_CIRCLES
    x = vars[:2 * n].reshape(n, 2)
    r = vars[2 * n:]
    
    # Boundary constraints: r - x >= 0, r - y >= 0, 1 - x - r >= 0, 1 - y - r >= 0
    c_bounds = np.concatenate([
        r - x[:, 0],
        r - x[:, 1],
        1.0 - x[:, 0] - r,
        1.0 - x[:, 1] - r
    ])
    
    # Non-overlap constraints: d^2 - (r_i + r_j)^2 >= 0
    dx = x[:, np.newaxis, 0] - x[np.newaxis, :, 0]
    dy = x[:, np.newaxis, 1] - x[np.newaxis, :, 1]
    dist_sq = dx**2 + dy**2
    
    rs = r[:, np.newaxis] + r[np.newaxis, :]
    rs_sum_sq = rs**2
    
    mask = np.triu(np.ones((n, n), dtype=bool), k=1)
    c_overlap = dist_sq[mask] - rs_sum_sq[mask]
    
    return np.concatenate([c_bounds, c_overlap])

def run_packing():
    n = N_CIRCLES
    
    # Hexagonal initialization for high initial density
    centers = np.zeros((n, 2))
    radii = np.ones(n) * 0.08
    
    idx = 0
    r_init = 0.08
    dy = r_init * np.sqrt(3)
    
    for row in range(8):
        y = r_init + row * dy
        x_start = r_init + (row % 2) * r_init
        for col in range(6):
            x = x_start + col * 2 * r_init
            if x > 1.0 - r_init:
                break
            if y > 1.0 - r_init:
                break
            if idx < n:
                centers[idx] = [x, y]
                idx += 1
                
    # Fill remaining slots if initialization yielded fewer circles
    while idx < n:
        centers[idx] = [0.5, 0.5]
        idx += 1
        
    x0 = np.concatenate([centers.ravel(), radii])
    
    # Setup constraint object
    cons = NonlinearConstraint(constraints, np.zeros_like(constraints(x0)), np.inf)
    bounds = [(0, 1)] * (2 * n) + [(0, 1)] * n
    
    # Run optimization
    res = minimize(
        objective, 
        x0, 
        method='trust-constr', 
        bounds=bounds, 
        constraints=cons, 
        options={'maxiter': 5000, 'verbose': 0, 'xtol': 1e-12}
    )
    
    best_x = res.x
    best_centers = best_x[:2 * n].reshape(n, 2)
    best_radii = best_x[2 * n:]
    
    # Ensure strict validity within numerical tolerance
    best_radii = np.maximum(best_radii, 0.0)
    best_centers = np.clip(best_centers, 0.0, 1.0)
    
    return best_centers, best_radii, float(np.sum(best_radii))
```
