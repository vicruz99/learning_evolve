## Strategy for Circle Packing Optimization

### Problem Analysis
We need to pack 26 circles in a unit square to maximize the sum of radii. The target is 2.636, meaning average radius ~0.1014. For comparison, a hexagonal packing density limit suggests circles of radius ~0.1054 could theoretically fit if perfectly arranged.

### Key Insights
1. **Hexagonal arrangement is optimal** for equal circles (density π/(2√3) ≈ 0.9069)
2. **Allowing unequal radii can help** fill gaps between larger circles
3. **Corner and boundary placement** is crucial - circles at corners waste less space

### Optimization Approach
1. **Initialization**: Create multiple hexagonal-like arrangements with different row configurations (e.g., 5-6-5-6-4, 6-5-6-5-4, etc.)
2. **Penalty Method**: Use Nelder-Mead optimization with a penalty function that:
   - Penalizes boundary violations (circle outside square)
   - Penalizes overlaps (distance < sum of radii)
   - Penalizes negative radii
   - Maximizes sum of radii as objective
3. **Multiple Restarts**: Try 50 different initial configurations to escape local optima
4. **Progressive Refinement**: Start with small radii and let optimization grow them naturally

### Implementation Details
- Use scipy.optimize.minimize with Nelder-Mead (derivative-free, handles non-convex problems well)
- Penalty weights: 1000 for constraint violations to ensure feasibility

import numpy as np
from scipy.optimize import minimize


def run_packing():
    """Pack 26 circles in a unit square to maximize sum of radii."""
    n = 26

    best_sum = 0.0
    best_centers = None
    best_radii = None

    # Try many different initial configurations
    for trial in range(50):
        centers, radii = generate_initial(n, trial)
        x0 = np.concatenate([centers.flatten(), radii])

        # Nelder-Mead optimization
        result = minimize(
            packing_objective,
            x0,
            args=(n,),
            method='Nelder-Mead',
            options={'maxiter': 300000, 'xatol': 1e-12, 'fatol': 1e-12}
        )

        centers_opt = result.x[:2 * n].reshape(n, 2)
        radii_opt = np.maximum(result.x[2 * n:], 0.0)

        # Validate the result
        if is_valid(centers_opt, radii_opt, n):
            s = np.sum(radii_opt)
            if s > best_sum:
                best_sum = s
                best_centers = centers_opt.copy()
                best_radii = radii_opt.copy()

    return best_centers, best_radii, best_sum


def packing_objective(x, n):
    """Objective function: maximize sum of radii with penalty for constraint violations."""
    centers = x[:2 * n].reshape(n, 2)
    radii = x[2 * n:]

    penalty = 0.0

    # Boundary penalties: circle must be inside [0,1]x[0,1]
    for i in range(n):
        cx, cy = centers[i]
        r = radii[i]
        margin_left = cx - r
        margin_right = 1.0 - cx - r
        margin_bottom = cy - r
        margin_top = 1.0 - cy - r

        for m in [margin_left, margin_right, margin_bottom, margin_top]:
            if m < 0:
                penalty += 1000.0 * m * m

    # Overlap penalties: circles must not overlap
    for i in range(n):
        for j in range(i + 1, n):
            dx = centers[i, 0] - centers[j, 0]
            dy = centers[i, 1] - centers[j, 1]
            dist = np.sqrt(dx * dx + dy * dy)
            overlap = radii[i] + radii[j] - dist
            if overlap > 0:
                penalty += 1000.0 * overlap * overlap

    # Negative radius penalty
    for i in range(n):
        if radii[i] < 0:
            penalty += 10000.0 * radii[i] * radii[i]

    # Objective: maximize sum of radii (minimize negative)
    return -np.sum(radii) + penalty


def generate_initial(n, trial):
    """Generate initial circle configuration based on hexagonal packing patterns."""
    np.random.seed(trial * 123 + 456)

    centers = np.zeros((n, 2))
    radii = np.ones(n) * 0.06

    # Different row configurations summing to 26
    configs = [
        [5, 6, 5, 6, 4],   # hexagonal staggered
        [6, 5, 6, 5, 4],
        [4, 6, 5, 6, 5],
        [5, 5, 6, 5, 5],
        [6, 6, 6, 6, 2],
        [5, 7, 5, 7, 2],
        [4, 5, 7, 5, 5],
        [7, 5, 5, 6, 3],
        [5, 6, 6, 5, 4],
        [6, 4, 6, 6, 4],
    ]

    config_idx = trial % len(configs)
    cols_per_row = configs[config_idx]
    num_rows = len(cols_per_row)

    idx = 0
    for row in range(num_rows):
        n_cols = cols_per_row[row]
        # Vertical spacing for hexagonal packing
        y = 0.08 + row * 0.18
        x_start = 0.06
        spacing = 0.17

        for col in range(n_cols):
            x = x_start + col * spacing
            # Offset odd rows for hexagonal arrangement
            if row % 2 == 1:
                x += spacing / 2.0
            centers[idx] = [x, y]
            idx += 1

    # Add small random perturbation to break symmetry
    perturbation = np.random.uniform(-0.015, 0.015, centers.shape)
    centers = np.clip(centers + perturbation, 0.04, 0.96)

    return centers, radii


def is_valid(centers, radii, n):
    """Validate that circles don't overlap and are inside the unit square."""
    # Check boundaries
    for i in range(n):
        cx, cy = centers[i]
        r = radii[i]
        if r < -1e-12:
            return False
        if cx - r < -1e-12 or cx + r > 1.0 + 1e-12:
            return False
        if cy - r < -1e-12 or cy + r > 1.0 + 1e-12:
            return False

    # Check overlaps
    for i in range(n):
        for j in range(i + 1, n):
            dx = centers[i, 0] - centers[j, 0]
            dy = centers[i, 1] - centers[j, 1]
            dist = np.sqrt(dx * dx + dy * dy)
            if dist < radii[i] + radii[j] - 1e-12:
                return False

    return True
