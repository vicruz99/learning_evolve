

To achieve the target sum of radii of 2.636, we must optimize the positions and sizes of the circles beyond a simple grid layout. The maximum density for circle packing is approximately 0.9069 (hexagonal packing). By using a penalty-based optimization method, we can navigate the non-convex constraints of the unit square to find a configuration that maximizes the sum of radii.

### Strategy

1.  **Variable Definition**: We define $26 \times 3 = 78$ variables, representing the $x$ and $y$ coordinates and the radius $r_i$ for each of the 26 circles.
2.  **Objective Function**: We minimize the negative sum of radii, equivalent to maximizing $\sum r_i$.
3.  **Penalty Method**: Instead of hard constraints, we use a penalty term to enforce boundaries and non-overlap:
    *   **Boundary Penalty**: Ensures circles stay within $[0, 1] \times [0, 1]$ by penalizing cases where $r > x$ or $x + r > 1$.
    *   **Overlap Penalty**: Penalizes cases where the distance between centers is less than the sum of their radii.
4.  **Initialization**: We start with a 5x5 grid (radius 0.1) to provide a dense baseline, then add the 26th circle.
5.  **Optimization Loop**: We use `scipy.optimize.minimize` (L-BFGS-B) to iteratively reduce the penalty and increase radii, using multiple restarts to escape local optima.

```python
import numpy as np
from scipy.optimize import minimize

def run_packing():
    n = 26
    
    def objective(x_vec):
        xs = x_vec[:n]
        ys = x_vec[n:2*n]
        rs = x_vec[2*n:]
        return -np.sum(rs)

    def penalty_term(x_vec):
        xs = x_vec[:n]
        ys = x_vec[n:2*n]
        rs = x_vec[2*n:]
        
        # Boundary penalties
        pen = np.sum(np.maximum(0, rs - xs)**2)
        pen += np.sum(np.maximum(0, rs - (1 - xs))**2)
        pen += np.sum(np.maximum(0, rs - ys)**2)
        pen += np.sum(np.maximum(0, rs - (1 - ys))**2)
        
        # Overlap penalties
        for i in range(n):
            for j in range(i + 1, n):
                dist_sq = (xs[i] - xs[j])**2 + (ys[i] - ys[j])**2
                r_sum = rs[i] + rs[j]
                overlap = np.maximum(0, r_sum - np.sqrt(dist_sq))
                pen += overlap**2
                
        return pen

    def combined(x_vec):
        return objective(x_vec) + 1000 * penalty_term(x_vec)

    bounds = [(0.0, 1.0)] * (2 * n) + [(0.0, 0.5)] * n
    
    best_vec = None
    best_score = np.inf
    
    for restart in range(5):
        # Initialize with a 5x5 grid
        rs = np.full(n, 0.101)
        if restart == 0:
            xs = np.repeat(np.linspace(0.1, 0.9, 5), 5)[:n]
            ys = np.tile(np.linspace(0.1, 0.9, 5), 5)[:n]
        else:
            xs = np.random.uniform(0.05, 0.95, n)
            ys = np.random.uniform(0.05, 0.95, n)
            
        x0 = np.concatenate([xs, ys, rs])
        
        res = minimize(combined, x0, method='L-BFGS-B', bounds=bounds, 
                       options={'maxiter': 1000, 'ftol': 1e-12})
        
        if res.fun < best_score:
            best_score = res.fun
            best_vec = res.x

    centers = best_vec[:2*n].reshape(n, 2)
    radii = best_vec[2*n:]
    sum_radii = np.sum(radii)
    
    return centers, radii, sum_radii
```
