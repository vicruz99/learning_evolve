

<strategy>
The problem asks to pack 26 circles in a unit square to maximize the sum of radii. This is a non-convex optimization problem. A robust strategy is to separate the optimization of centers and radii. 

1.  **Radii Optimization (Linear Programming):** For a fixed set of centers, finding the optimal radii that maximize the sum $\sum r_i$ subject to non-overlap and boundary constraints is a Linear Programming (LP) problem. This is fast and exact.
2.  **Centers Optimization (Local Search):** We need to find center coordinates that allow for large radii. We can use a "Repulsive Force" heuristic. 
    *   Initialize centers (e.g., in a hexagonal grid or random).
    *   Solve the LP to get current optimal radii.
    *   Identify "tight" constraints where $r_i + r_j \approx d_{ij}$ (circles touching) or $r_i \approx \text{dist to boundary}$.
    *   Apply repulsive forces between touching circles to push them apart, which relaxes the constraints and potentially allows radii to increase in the next iteration.
    *   Apply forces from boundaries to push centers towards the center of the square if they are constrained by the walls (since wall constraints limit radius based on distance to edge, moving towards center increases allowable radius).
    *   Iterate this process.
3.  **Implementation Details:**
    *   Use `scipy.optimize.linprog` for the LP part.
    *   Use a custom loop for the force-based center relaxation.
    *   Use multiple random restarts to avoid local minima.
    *   Finally, return the best configuration found.

This approach leverages the convexity of the radius sub-problem and uses physical intuition for the center placement.
</strategy>

import numpy as np
from scipy.optimize import linprog
import math

def solve_radii_lp(centers):
    """
    Given fixed centers, solve the LP to maximize sum of radii.
    
    Variables: r_1, ..., r_26
    Objective: Maximize sum(r_i)  <=> Minimize -sum(r_i)
    Constraints:
        1. r_i >= 0
        2. r_i <= x_i
        3. r_i <= 1 - x_i
        4. r_i <= y_i
        5. r_i <= 1 - y_i
        6. r_i + r_j <= distance(c_i, c_j) for all i < j
    """
    n = centers.shape[0]
    
    # Objective: minimize -sum(r_i)
    c = -np.ones(n)
    
    # Constraints matrix A_ub * r <= b_ub
    A_ub = []
    b_ub = []
    
    # Boundary constraints
    for i in range(n):
        x, y = centers[i]
        
        # r_i >= 0  ->  -r_i <= 0
        row = np.zeros(n)
        row[i] = -1.0
        A_ub.append(row)
        b_ub.append(0.0)
        
        # r_i <= x_i
        row = np.zeros(n)
        row[i] = 1.0
        A_ub.append(row)
        b_ub.append(x)
        
        # r_i <= 1 - x_i
        row = np.zeros(n)
        row[i] = 1.0
        A_ub.append(row)
        b_ub.append(1.0 - x)
        
        # r_i <= y_i
        row = np.zeros(n)
        row[i] = 1.0
        A_ub.append(row)
        b_ub.append(y)
        
        # r_i <= 1 - y_i
        row = np.zeros(n)
        row[i] = 1.0
        A_ub.append(row)
        b_ub.append(1.0 - y)

    # Pairwise constraints: r_i + r_j <= dist(i, j)
    for i in range(n):
        for j in range(i + 1, n):
            dist = np.sqrt(np.sum((centers[i] - centers[j]) ** 2))
            row = np.zeros(n)
            row[i] = 1.0
            row[j] = 1.0
            A_ub.append(row)
            b_ub.append(dist)
            
    A_ub = np.array(A_ub)
    b_ub = np.array(b_ub)
    
    # Bounds for r_i: [0, None] (LP solver handles lower bound 0, but we added -r_i <= 0)
    # linprog expects bounds as (lower, upper). 
    # Since we have -r_i <= 0, r_i >= 0 is handled. 
    # Explicit bounds:
    bounds = [(0, None) for _ in range(n)]
    
    # Solve
    res = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
    
    if res.success:
        return res.fun * -1, res.x # Return max sum, radii vector
    else:
        return 0.0, np.zeros(n)

def run_packing():
    """
    Run the packing optimization.
    """
    n = 26
    best_sum_radii = 0.0
    best_centers = None
    best_radii = None
    
    # Random seed for reproducibility in trials, but we want random restarts
    # We will run a few trials
    
    num_trials = 10
    
    for trial in range(num_trials):
        # Initialize centers
        # Try a hexagonal-ish grid or random
        # Random initialization inside [0.05, 0.95] to avoid immediate boundary issues
        np.random.seed(42 + trial)
        centers = np.random.uniform(0.05, 0.95, size=(n, 2))
        
        # Force based relaxation
        # We want to push centers apart if they are "touching" in the LP solution
        
        for step in range(500): # Max iterations
            # 1. Solve LP for current centers
            sum_r, radii = solve_radii_lp(centers)
            
            if step == 0 or sum_r > best_sum_radii:
                best_sum_radii = sum_r
                best_centers = centers.copy()
                best_radii = radii.copy()
                
                # If we reached a very high sum, maybe stop? 
                # Target is 2.636. Let's aim higher.
            
            # 2. Compute forces
            forces = np.zeros((n, 2))
            
            # Identify tight constraints
            # Pairwise
            for i in range(n):
                for j in range(i + 1, n):
                    dist = np.sqrt(np.sum((centers[i] - centers[j]) ** 2))
                    # If dist is very close to r_i + r_j, apply repulsion
                    # Threshold for "touching"
                    threshold = 1e-6
                    if dist < radii[i] + radii[j] + threshold:
                        # Repulsive force
                        if dist > 1e-9:
                            dir_vec = (centers[i] - centers[j]) / dist
                            # Force magnitude: stronger if overlap would occur
                            # Just a constant push
                            force_mag = 0.01 * (radii[i] + radii[j]) 
                            forces[i] += force_mag * dir_vec
                            forces[j] -= force_mag * dir_vec
            
            # Boundary forces
            # If a circle is constrained by a boundary (r_i approx dist to boundary),
            # moving towards center increases allowable r.
            for i in range(n):
                x, y = centers[i]
                r = radii[i]
                
                # Left wall: r <= x. If r approx x, push right.
                if r > x - 1e-6:
                    forces[i, 0] += 0.01
                # Right wall: r <= 1-x. If r approx 1-x, push left.
                if r > (1.0 - x) - 1e-6:
                    forces[i, 0] -= 0.01
                # Bottom wall: r <= y. If r approx y, push up.
                if r > y - 1e-6:
                    forces[i, 1] += 0.01
                # Top wall: r <= 1-y. If r approx 1-y, push down.
                if r > (1.0 - y) - 1e-6:
                    forces[i, 1] -= 0.01
            
            # 3. Update centers
            # Apply forces with a small step size
            # Adaptive step size?
            step_size = 0.005
            new_centers = centers + step_size * forces
            
            # Clip to [0, 1]
            new_centers = np.clip(new_centers, 0.0, 1.0)
            
            # Check if we should update centers
            # Only update if it doesn't decrease sum of radii drastically? 
            # Actually, moving centers might temporarily decrease sum if we move away from optimal, 
            # but forces are derived to improve it.
            # Let's just update.
            centers = new_centers

        # One final local refinement using random perturbations on best found so far
        # This helps escape local minima of the force method
        current_sum = best_sum_radii
        current_centers = best_centers.copy()
        current_radii = best_radii.copy()
        
        # Simple hill climbing
        for _ in range(1000):
            # Pick random circle to perturb
            idx = np.random.randint(n)
            # Perturbation magnitude decaying
            mag = 0.01 * (0.99 ** _)
            
            # Save old pos
            old_pos = current_centers[idx].copy()
            
            # Try random direction
            angle = np.random.uniform(0, 2 * np.pi)
            current_centers[idx] += mag * np.array([math.cos(angle), math.sin(angle)])
            current_centers[idx] = np.clip(current_centers[idx], 0.0, 1.0)
            
            new_sum, new_radii = solve_radii_lp(current_centers)
            
            if new_sum > current_sum:
                current_sum = new_sum
                current_radii = new_radii.copy()
                # Keep the move
                if current_sum > best_sum_radii:
                    best_sum_radii = current_sum
                    best_centers = current_centers.copy()
                    best_radii = current_radii.copy()
            else:
                # Revert
                current_centers[idx] = old_pos

    return best_centers, best_radii, best_sum_radii
