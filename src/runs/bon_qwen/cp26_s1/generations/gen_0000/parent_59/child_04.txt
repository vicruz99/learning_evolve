The goal is to maximize the minimum distance between any pair of centers and between centers and boundaries. This is a geometric dispersion problem. I will use a numerical optimizer (`scipy.optimize.differential_evolution`) to find centers that maximize the radius $t$ of a hypothetical packing of 26 equal circles. This phase ensures that the circles are well-separated, creating a "skeleton" for the final packing.

**Phase 2: Radius Optimization (Linear Programming)**
Once the optimal center positions are fixed, the problem of finding radii $r_i$ to maximize $\sum r_i$ subject to non-overlap ($r_i + r_j \le \|c_i - c_j\|$) and boundary constraints ($r_i \le \text{dist}(c_i, \partial [0,1]^2)$) becomes a Linear Programming (LP) problem. The objective function is linear, and all constraints are linear inequalities. I will solve this LP using `scipy.optimize.linprog`. This step allows circles to adopt different sizes, filling gaps with smaller circles and expanding others, which typically yields a higher sum of radii than the equal-radius baseline.

By decoupling the non-linear geometric constraints (centers) from the linear size constraints (radii), this approach provides a robust and computationally feasible solution.

import numpy as np
from scipy.optimize import differential_evolution, linprog

def run_packing() -> tuple[np.ndarray, np.ndarray, float]:
    """
    Pack 26 circles in a unit square to maximize sum of radii.
    """
    n = 26
    
    # Helper for the LP constraints
    def compute_lp_constraints(centers):
        # We want to maximize sum(r_i), so minimize -sum(r_i)
        # c vector for linprog (to minimize c^T * x)
        c_obj = np.zeros(n)
        c_obj[:] = -1.0  # Maximize sum(r) -> Minimize -sum(r)
        
        # Inequality constraints A_ub @ x <= b_ub
        # Variables x = [r_1, r_2, ..., r_n]
        
        A_ub = []
        b_ub = []
        
        # 1. Boundary constraints: r_i <= x_i, r_i <= 1-x_i, etc.
        for i in range(n):
            x, y = centers[i]
            dist_to_left = x
            dist_to_right = 1.0 - x
            dist_to_bottom = y
            dist_to_top = 1.0 - y
            
            min_dist = min(dist_to_left, dist_to_right, dist_to_bottom, dist_to_top)
            
            # r_i <= min_dist  =>  1*r_i <= min_dist
            row = np.zeros(n)
            row[i] = 1.0
            A_ub.append(row)
            b_ub.append(min_dist)
            
            # r_i >= 0 is handled by bounds in linprog
            
        # 2. Pairwise non-overlap constraints: r_i + r_j <= dist_ij
        # dist_ij = sqrt((xi-xj)^2 + (yi-yj)^2)
        for i in range(n):
            for j in range(i + 1, n):
                dist = np.sqrt(np.sum((centers[i] - centers[j])**2))
                
                # r_i + r_j <= dist
                row = np.zeros(n)
                row[i] = 1.0
                row[j] = 1.0
                A_ub.append(row)
                b_ub.append(dist)
                
        return np.array(A_ub), np.array(b_ub), c_obj

    # --- Phase 1: Optimize Centers ---
    # We try to maximize the minimum distance between points (dispersion problem)
    # This corresponds to finding the largest radius 't' for n equal circles.
    # Variables: x_1, y_1, ..., x_n, y_n, t
    # Maximize t
    # Constraints:
    #  t <= x_i <= 1-t
    #  t <= y_i <= 1-t
    #  (x_i - x_j)^2 + (y_i - y_j)^2 >= (2t)^2
    
    # We will minimize -t.
    # Since the distance constraint is non-convex (quadratic inequality), 
    # differential evolution is a good global optimizer to find a good starting configuration.
    
    def objective_dispersion(vars_flat):
        # vars_flat has size 26*2 + 1 = 53
        # Last element is t
        t = vars_flat[-1]
        centers = vars_flat[:-1].reshape((n, 2))
        
        # Penalty for t being negative or too large (though bounds handle this)
        if t < 0:
            return 1e9
            
        # Boundary constraints: t <= x <= 1-t => x in [t, 1-t]
        # If any center is too close to boundary relative to t, penalty.
        # Actually, we enforce t <= x_i and t <= 1-x_i etc.
        # So min(x_i, 1-x_i, y_i, 1-y_i) >= t
        min_dist_boundary = np.min(np.array([
            np.min(centers[:, 0]), np.min(1 - centers[:, 0]),
            np.min(centers[:, 1]), np.min(1 - centers[:, 1])
        ]))
        
        if min_dist_boundary < t:
            return 1e9 + (t - min_dist_boundary)**2
            
        # Pairwise distance constraints: dist_ij >= 2t
        # We check if any pair violates this.
        # To make it differentiable-ish or at least continuous, we can sum violations
        # But DE handles non-smooth well.
        # Let's just return -t if valid, else large penalty.
        
        # Check pairwise
        # Vectorized distance check might be faster but n=26 is small
        for i in range(n):
            for j in range(i+1, n):
                d = np.sqrt(np.sum((centers[i] - centers[j])**2))
                if d < 2*t:
                    return 1e9 + (2*t - d)**2
                    
        return -t # Minimize -t -> Maximize t

    # Bounds for x, y are [0, 1]. t is [0, 0.5].
    # However, to allow t to be optimized, we can bound t loosely.
    # But better to let x,y be in [0,1] and t determined by logic.
    # Actually, standard DE bounds are for each variable.
    # We can treat t as a variable to maximize, but constraints handle validity.
    # Let's bound t in [0, 0.2] roughly.
    
    bounds_dispersion = [(0, 1)] * (2 * n) + [(0, 0.2)]
    
    # Run differential evolution to find good centers
    # seed for reproducibility
    result_de = differential_evolution(objective_dispersion, bounds_dispersion, 
                                       popsize=30, maxiter=1000, tol=1e-7, 
                                       mutation=(0.5, 1), recombination=0.7, 
                                       seed=42)
    
    best_t = -result_de.fun
    best_centers = result_de.x[:-1].reshape((n, 2))
    
    # --- Phase 2: Optimize Radii via LP ---
    # With fixed centers, find radii to maximize sum.
    
    A_ub, b_ub, c_obj = compute_lp_constraints(best_centers)
    
    # Bounds for r_i: [0, 0.5] (theoretically max radius is 0.5)
    bounds_radii = [(0, 0.5)] * n
    
    # Solve LP
    # minimize c_obj^T r
    result_lp = linprog(c_obj, A_ub=A_ub, b_ub=b_ub, bounds=bounds_radii, method='highs')
    
    if result_lp.success:
        optimal_radii = result_lp.x
    else:
        # Fallback: if LP fails, use equal radii from Phase 1
        # best_t might be slightly optimistic due to numerical tolerance, 
        # so shrink it slightly to ensure validity.
        optimal_radii = np.full(n, best_t * 0.99)

    sum_radii = np.sum(optimal_radii)
    
    # Ensure centers are within [0,1] and radii non-negative (sanity check)
    # The optimization should have guaranteed this, but clipping just in case.
    best_centers = np.clip(best_centers, 0, 1)
    optimal_radii = np.clip(optimal_radii, 0, 0.5)
    
    return best_centers, optimal_radii, sum_radii

if __name__ == "__main__":
    centers, radii, total = run_packing()
    print(f"Sum of radii: {total}")
    print(f"Number of circles: {len(radii)}")
