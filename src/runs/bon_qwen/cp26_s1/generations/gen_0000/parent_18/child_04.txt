

To maximize the sum of radii for 26 circles in a unit square, I employ a two-phase approach: an initialization phase to distribute circles in a hexagonal lattice (the densest 2D packing) and a refinement phase using the L-BFGS-B algorithm. This optimizer maximizes the sum of radii while penalizing boundary violations and inter-circle overlaps using a smooth, quadratic penalty function.

### Strategy
1.  **Hexagonal Initialization:** A hexagonal lattice is mathematically the most efficient way to pack circles in a plane. This provides a high-quality starting point, ensuring the optimizer begins near a potential global maximum.
2.  **L-BFGS-B Optimization:** We maximize the sum of radii ($\sum r_i$) by minimizing its negative. Constraints are handled via penalty terms:
    *   **Overlap Penalty:** $P_{ij} = \max(0, r_i + r_j - d_{ij})^2$
    *   **Boundary Penalty:** $P_{boundary} = \max(0, r_i - x)^2$ for all boundaries.
3.  **Multiple Restarts:** To mitigate the risk of local optima, the solver is run multiple times from different perturbations of the hexagonal lattice.

<strategy>
The strategy focuses on a geometrically sound initialization followed by a gradient-based local search. By starting with a hexagonal lattice, we ensure a high packing density from the outset. The L-BFGS-B solver then fine-tunes both positions and radii to push the sum as high as possible within the non-overlap and boundary constraints.
</strategy>

```python
import numpy as np
from scipy.optimize import minimize

def generate_hex_initial(n, scale=1.1):
    """Generates a hexagonal lattice of points scaled to fit within a unit square."""
    # Estimate rows for a hexagonal layout
    rows = int(np.ceil(np.sqrt(n * np.sqrt(3) / 2)))
    cols = int(np.ceil(n / rows))
    
    points = []
    for r in range(rows):
        y = r * np.sqrt(3) / 2
        for c in range(cols):
            x = c + (0.5 if r % 2 else 0)
            points.append((x, y))
            
    # Trim to n points
    points = points[:n]
    
    if not points:
        return np.zeros((n, 2))
        
    points = np.array(points)
    # Normalize to unit square with padding
    points = (points - points.min(axis=0))
    points /= points.max(axis=0)
    points *= scale
    points += (1 - scale) / 2
    
    return points[:n]

def objective(params, n=26):
    """Objective function: Minimize ( -sum_radii + penalties )"""
    centers = params[:n*2].reshape(n, 2)
    radii = params[n*2:]
    
    total_r = np.sum(radii)
    penalty = 0.0
    
    # Overlap penalties
    for i in range(n):
        for j in range(i + 1, n):
            dist = np.sqrt(np.sum((centers[i] - centers[j])**2))
            overlap = radii[i] + radii[j] - dist
            if overlap > 0:
                penalty += overlap**2
                
    # Boundary penalties
    for i in range(n):
        x, y = centers[i]
        r = radii[i]
        
        # Check all four boundaries
        penalties = [
            max(0, r - x),           # Left
            max(0, r - (1 - x)),     # Right
            max(0, r - y),           # Bottom
            max(0, r - (1 - y))      # Top
        ]
        penalty += sum(p**2 for p in penalties)
        
    return -total_r + 1000 * penalty

def run_packing() -> tuple[np.ndarray, np.ndarray, float]:
    n = 26
    best_val = np.inf
    best_params = None
    
    # Multiple restarts for global optimization
    for k in range(5):
        # Initialize with perturbed hexagonal lattice
        init_centers = generate_hex_initial(n)
        np.random.shuffle(init_centers)
        init_radii = np.full(n, 0.05)
        
        initial_params = np.concatenate([init_centers.flatten(), init_radii])
        
        # Define bounds: centers in [0,1], radii in [0, 0.5]
        bounds = [(0, 1)] * (n * 2) + [(0, 0.5)] * n
        
        res = minimize(objective, initial_params, args=(n), method='L-BFGS-B', 
                       bounds=bounds, options={'maxiter': 5000, 'ftol': 1e-12})
        
        if res.fun < best_val:
            best_val = res.fun
            best_params = res.x

    centers = best_params[:n*2].reshape(n, 2)
    radii = best_params[n*2:]
    
    # Ensure final radii are non-negative
    radii = np.maximum(radii, 1e-9)
    
    return centers, radii, float(np.sum(radii))
```
