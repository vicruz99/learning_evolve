To maximize the sum of radii for 26 circles in a unit square, we formulate the problem as a non-linear optimization task. The objective is to maximize $\sum r_i$, which is equivalent to minimizing $-\sum r_i$. The constraints are:
1. Boundary constraints: $r_i \le x_i \le 1-r_i$ and $r_i \le y_i \le 1-r_i$
2. Non-overlap constraints: $\sqrt{(x_i-x_j)^2 + (y_i-y_j)^2} \ge r_i + r_j$ for all $i < j$
3. Non-negativity: $r_i \ge 0$

Given the non-convex nature of the problem, a single local optimizer may converge to a suboptimal local minimum. Therefore, we employ a multi-start strategy using `scipy.optimize.minimize` with the SLSQP method. We run 15 optimization trials with different random initializations (perturbed random positions within the square, initialized with small radii). Each trial attempts to push radii to their limits while satisfying constraints. 

To ensure robustness against numerical precision issues inherent in iterative solvers, we apply a tiny safety margin (`radii *= 0.9999999`) before validation. This guarantees strict compliance with the `1e-12` tolerance in the validator without significantly affecting the objective value. A grid-based fallback is included in case all optimizations fail.

Helper functions are defined at the top level to avoid closures and lambda functions, adhering to the constraints. The pairwise distance constraints are evaluated efficiently using vectorized NumPy operations.

import numpy as np
from scipy.optimize import minimize

def compute_objective(vars, n):
    """Objective: maximize sum of radii => minimize negative sum"""
    return -np.sum(vars[2::3])

def compute_constraints(vars, n):
    """
    Returns a 1D array of inequality constraints >= 0.
    Constraints: boundaries and pairwise non-overlap.
    """
    c = vars.reshape(n, 3)
    # Boundary constraints: x-r >= 0, 1-x-r >= 0, y-r >= 0, 1-y-r >= 0
    con = [
        c[:, 0] - c[:, 2],
        1.0 - c[:, 0] - c[:, 2],
        c[:, 1] - c[:, 2],
        1.0 - c[:, 1] - c[:, 2]
    ]
    
    # Pairwise constraints: dist_sq - (r_i + r_j)^2 >= 0
    dx = c[:, 0, np.newaxis] - c[np.newaxis, :, 0]
    dy = c[:, 1, np.newaxis] - c[np.newaxis, :, 1]
    dist_sq = dx**2 + dy**2
    rad_sum_sq = (c[:, 2, np.newaxis] + c[np.newaxis, :, 2])**2
    
    # Only upper triangular part to avoid duplicates and self-constraints
    mask = np.triu(np.ones((n, n), dtype=bool), k=1)
    con.append(dist_sq[mask] - rad_sum_sq[mask])
    
    return np.concatenate(con)

def run_packing():
    n = 26
    # Bounds: x in [0,1], y in [0,1], r in [0, 0.5]
    bounds = [(0.0, 1.0)] * n + [(0.0, 1.0)] * n + [(0.0, 0.5)] * n
    
    best_sol = None
    best_val = -np.inf
    
    # Multi-start optimization
    for seed in range(15):
        rng = np.random.RandomState(seed)
        x0 = rng.rand(3 * n)
        
        # Initialize centers away from edges, radii small
        x0[0::3] = 0.1 + 0.8 * x0[0::3]
        x0[1::3] = 0.1 + 0.8 * x0[1::3]
        x0[2::3] = 0.05 + 0.1 * rng.rand(n)
        
        cons = {'type': 'ineq', 'fun': compute_constraints, 'args': (n,)}
        
        try:
            res = minimize(compute_objective, x0, args=(n,), method='SLSQP', 
                           bounds=bounds, constraints=cons,
                           options={'maxiter': 1000, 'ftol': 1e-12, 'disp': False})
            
            centers = res.x.reshape(n, 3)[:, :2]
            radii = res.x.reshape(n, 3)[:, 2]
            
            # Apply tiny safety margin to guarantee validator tolerance compliance
            radii *= 0.9999999
            
            if validate_packing(centers, radii):
                val = np.sum(radii)
                if val > best_val:
                    best_val = val
                    best_sol = (centers, radii, val)
        except Exception:
            continue
            
    # Fallback solution if optimization fails
    if best_sol is None:
        centers = np.zeros((n, 2))
        radii = np.full(n, 0.02)
        idx = 0
        for r in range(6):
            for c in range(6):
                if idx < n:
                    centers[idx] = [0.1 + c*0.15, 0.1 + r*0.15]
                    idx += 1
        best_sol = (centers, radii, np.sum(radii))
        
    return best_sol
