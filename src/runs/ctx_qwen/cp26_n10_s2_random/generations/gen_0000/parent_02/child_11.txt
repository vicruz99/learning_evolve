This is solved using `scipy.optimize.linprog`. The objective is to maximize $\sum r_i$ subject to $r_i + r_j \leq d_{ij}$ (where $d_{ij}$ is the distance between centers) and boundary constraints $r_i \leq x_i$, etc.
2.  **Dual Sensitivity:** The sensitivity of the optimal sum of radii to the centers is given by the dual variables (marginals) of the LP solution. These duals indicate how much the sum of radii would increase if a specific constraint (distance or wall) were relaxed.
3.  **Gradient Descent/Ascent:** We interpret these duals as forces acting on the centers.
    *   **Repulsion:** If a distance constraint $r_i + r_j = d_{ij}$ is active (dual > 0), the circles push each other apart to create space for larger radii.
    *   **Wall Repulsion:** If a circle is touching a wall, it is pushed away from that boundary.
4.  **Optimization Loop:** We update the centers in the direction of these forces (gradient ascent on the sum of radii).
5.  **Initialization:** We use a hybrid initialization (a perturbed hexagonal lattice) to ensure a high-quality starting configuration, followed by multiple random restarts to escape local optima.

        b_ub[idx] = centers[i, 1]          # y

    """
    Computes the gradient of the sum of radii with respect to centers.
    """
    grad_centers = np.zeros_like(centers)
    
    # Pairwise terms
    idx = 0
    for i in range(n):
        for j in range(i + 1, n):
            lam = duals[idx]
            if lam > 1e-9:
                d = np.sqrt(np.sum((centers[i] - centers[j])**2))
                if d > 1e-9:
                    vec = centers[i] - centers[j]
                    force = (lam / d) * vec
                    grad_centers[i] += force
                    grad_centers[j] -= force

    # Boundary terms
    boundary_start = num_pairs

        mu_T = duals[boundary_start + 4*i + 3]
        
        grad_centers[i, 0] += mu_L - mu_R
        grad_centers[i, 1] += mu_B - mu_T
        
    return grad_centers
