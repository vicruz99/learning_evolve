

To maximize the sum of radii for 26 circles in a unit square, we utilize an iterative gradient ascent approach combined with Linear Programming (LP) sensitivity analysis. This allows us to optimize the radii and centers simultaneously while strictly adhering to boundary and non-overlap constraints.

### Strategy
1.  **Hexagonal Initialization**: Initialize the 26 circle centers in a staggered hexagonal grid pattern, which provides a higher packing density baseline than a standard square grid.
2.  **LP for Radii**: In each iteration, we solve an LP to find the optimal radii ($r_i$) for the current center positions ($c_i$). The LP maximizes $\sum r_i$ subject to $r_i + r_j \le \|c_i - c_j\|$ and boundary limits.
3.  **Gradient Descent on Centers**: We extract the dual variables (shadow prices) from the LP. These duals provide the exact sensitivity of the objective function to changes in the constraints. We use them to calculate the gradient of the total radius sum with respect to the centers, effectively pushing circles apart to allow them to grow.
4.  **Iterative Refinement**: We update the centers based on these gradients, applying a decaying step size to ensure convergence to a high-quality packing.

```python
import numpy as np
import cvxpy as cp

def run_packing() -> tuple[np.ndarray, np.ndarray, float]:
    n = 26
    
    # 1. Hexagonal Initialization
    # 5 rows with varying numbers of circles: 6, 5, 6, 5, 4 (Total 26)
    rows = [6, 5, 6, 5, 4]
    centers = []
    y = 0.5 / (len(rows) + 1)  # Initial y position
    
    for i, count in enumerate(rows):
        x_spacing = 1.0 / (count + 1)
        # Alternate x-offset for hexagonal staggering
        x_start = x_spacing * (1 if i % 2 == 0 else 0.5)
        x = x_start
        for j in range(count):
            centers.append([x, y])
            x += x_spacing
        y += (np.sqrt(3) / 2) * x_spacing

    centers = np.array(centers)
    step_size = 0.05
    
    for iteration in range(150):
        # 2. Compute distance matrix for current centers
        diffs = centers[:, np.newaxis, :] - centers[np.newaxis, :, :]
        dists = np.sqrt(np.sum(diffs**2, axis=2))
        
        # 3. Linear Programming to maximize sum of radii
        r = cp.Variable(n, nonneg=True)
        constraints = []
        
        # Boundary constraints
        for i in range(n):
            constraints.append(r[i] <= centers[i, 0])
            constraints.append(r[i] <= 1 - centers[i, 0])
            constraints.append(r[i] <= centers[i, 1])
            constraints.append(r[i] <= 1 - centers[i, 1])
            
        # Pairwise non-overlap constraints
        pair_duals = {}
        for i in range(n):
            for j in range(i + 1, n):
                # Store constraint reference to extract dual later
                constraint = cp.Constraint(r[i] + r[j] <= dists[i, j])
                constraints.append(constraint)
                pair_duals[(i, j)] = constraint

        objective = cp.Maximize(cp.sum(r))
        prob = cp.Problem(objective, constraints)
        prob.solve()
        
        current_sum = prob.value
        radii = np.array(r.value)

        # 4. Gradient Calculation using Dual Variables
        grads_x = np.zeros(n)
        grads_y = np.zeros(n)

        for i in range(n):
            # Extract boundary duals
            # Constraints order for i: 0->x_i, 1->1-x_i, 2->y_i, 3->1-y_i
            base_idx = i * 4
            mu_1 = constraints[base_idx].dual_value  # r_i <= x_i
            mu_2 = constraints[base_idx + 1].dual_value  # r_i <= 1 - x_i
            mu_3 = constraints[base_idx + 2].dual_value  # r_i <= y_i
            mu_4 = constraints[base_idx + 3].dual_value  # r_i <= 1 - y_i

            grads_x[i] += (mu_1 - mu_2)
            grads_y[i] += (mu_3 - mu_4)

            # Extract pairwise duals
            for j in range(n):
                if i == j: continue
                key = (min(i, j), max(i, j))
                if key in pair_duals:
                    lam = pair_duals[key].dual_value
                    if lam > 1e-8 and dists[i, j] > 1e-8:
                        d_vec = centers[i] - centers[j]
                        grads_x[i] += lam * d_vec[0] / dists[i, j]
                        grads_y[i] += lam * d_vec[1] / dists[i, j]

        # 5. Update Centers
        centers += step_size * np.column_stack([grads_x, grads_y])
        centers = np.clip(centers, 1e-5, 1 - 1e-5)
        step_size *= 0.98

    return centers, radii, float(np.sum(radii))
```
