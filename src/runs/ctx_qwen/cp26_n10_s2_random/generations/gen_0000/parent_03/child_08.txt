To solve the problem of packing 26 circles in a unit square to maximize the sum of radii, we employ a numerical optimization strategy. The problem is non-convex, so finding the global optimum is challenging. We will use `scipy.optimize.minimize` with the SLSQP method, which handles non-linear constraints.

### Strategy
1.  **Problem Formulation**:
    *   **Variables**: For each of the 26 circles, we optimize the center coordinates $(x_i, y_i)$ and the radius $r_i$. Total 78 variables.
    *   **Objective**: Maximize $\sum r_i$ (implemented as minimizing $-\sum r_i$).
    *   **Constraints**:
        *   **Boundary**: Each circle must be within the unit square: $r_i \le x_i \le 1-r_i$ and $r_i \le y_i \le 1-r_i$.
        *   **Non-overlap**: The distance between any two centers must be at least the sum of their radii: $(x_i - x_j)^2 + (y_i - y_j)^2 \ge (r_i + r_j)^2$.

2.  **Initialization**:
    *   To avoid poor local minima, we use multiple restart strategies.
    *   **Hexagonal Packing**: A structured initial guess based on a hexagonal lattice, which is the densest circle packing in the plane.
    *   **Random Packing**: Random initial positions to explore different configurations.
    *   We start with small radii to ensure the initial guess is valid, allowing the optimizer to expand the circles.

3.  **Optimization**:
    *   We vectorize the constraint calculations for efficiency.
    *   We run the optimizer multiple times with different seeds and select the best result.
    *   Bounds are set for coordinates $[0, 1]$ and radii $[0, 0.5]$.

4.  **Refinement**:
    *   The optimization is performed in a loop to ensure we find a high-quality packing. The best solution found across all attempts is returned.

import numpy as np
from scipy.optimize import minimize

def run_packing():
    n = 26

    # Objective function: minimize negative sum of radii
    def objective(vars):
        radii = vars[2::3]  # Extract radii (every 3rd variable)
        return -np.sum(radii)

    # Constraint function: returns values >= 0 for valid packing
    def constraint_func(vars):
        # Reshape variables to centers (n, 2) and radii (n,)
        # Structure: [x1, y1, r1, x2, y2, r2, ...]
        centers = vars[:n*2].reshape(n, 2)
        radii = vars[2::3]

        # Boundary constraints:
        # x - r >= 0, 1 - x - r >= 0, y - r >= 0, 1 - y - r >= 0
        x, y = centers[:, 0], centers[:, 1]
        boundary_constraints = np.concatenate([
            x - radii,
            1.0 - x - radii,
            y - radii,
            1.0 - y - radii
        ])

        # Pairwise non-overlap constraints:
        # (x_i - x_j)^2 + (y_i - y_j)^2 - (r_i + r_j)^2 >= 0
        # Vectorized computation using broadcasting
        # Compute squared distances between all pairs
        diffs = centers[:, np.newaxis, :] - centers[np.newaxis, :, :]
        dist_sq = np.sum(diffs**2, axis=2)

        # Compute squared sum of radii for all pairs
        r_sum = radii[:, np.newaxis] + radii[np.newaxis, :]
        r_sum_sq = r_sum**2

        # Constraint violation
        violations = dist_sq - r_sum_sq

        # Extract upper triangle (i < j) to avoid duplicates and self-constraints
        idx = np.triu_indices(n, k=1)
        pairwise_constraints = violations[idx]

        return np.concatenate([boundary_constraints, pairwise_constraints])

    # Bounds for variables
    # x, y in [0, 1], r in [0, 0.5]
    # Variables are ordered: x1, y1, r1, x2, y2, r2, ...
    bounds = [(0.0, 1.0), (0.0, 1.0), (0.0, 0.5)] * n

    best_result = None
    best_sum_radii = -np.inf

    def generate_initial_guess(seed=None):
        if seed is not None:
            np.random.seed(seed)
        
        # Try to create a hexagonal-like arrangement or random
        # Random positions within [0.1, 0.9] to stay away from boundaries initially
        centers = np.random.uniform(0.1, 0.9, size=(n, 2))
        radii = np.full(n, 0.01) # Small initial radius
        
        # Flatten to 1D array [x1, y1, r1, ...]
        vars = np.zeros(n * 3)
        for i in range(n):
            vars[3*i] = centers[i, 0]
            vars[3*i+1] = centers[i, 1]
            vars[3*i+2] = radii[i]
        return vars

    def generate_hex_grid_guess(seed=None):
        if seed is not None:
            np.random.seed(seed)
            
        # Hexagonal grid approximation
        # 5 rows
        rows = [6, 5, 5, 5, 5] # 26 circles
        pts = []
        # Row 0: 6 circles
        # Row 1: 5 circles shifted by half spacing
        # We'll place them roughly and let optimizer fix
        
        # Simple grid first
        pts = []
        # 5x5 grid
        for r in range(5):
            for c in range(5):
                pts.append([0.1 + c * 0.2, 0.1 + r * 0.2])
        # 26th point, maybe in a gap?
        # Just add a point at a random valid location or specific gap
        # Let's add at (0.5, 0.5) if not there, or perturb
        # Actually, 5x5 grid centers are 0.1, 0.3, 0.5, 0.7, 0.9
        # (0.5, 0.5) is occupied.
        # Let's add one more in a gap, e.g., (0.2, 0.2) is not a center in grid?
        # Grid centers: (0.1, 0.1), (0.3, 0.1)...
        # (0.2, 0.2) is between 4 circles.
        pts.append([0.2, 0.2])
        
        # If we have more than 26, truncate (we have 26)
        pts = pts[:n]
        
        # Scale down slightly to ensure valid start with small r
        # Actually, we will set r small, so positions don't matter much for validity
        # But good positions help convergence
        
        # Let's just use the points
        centers = np.array(pts)
        # Add some noise
        centers += np.random.normal(0, 0.01, centers.shape)
        # Clip to [0.1, 0.9]
        centers = np.clip(centers, 0.1, 0.9)
        
        radii = np.full(n, 0.01)
        
        vars = np.zeros(n * 3)
        for i in range(n):
            vars[3*i] = centers[i, 0]
            vars[3*i+1] = centers[i, 1]
            vars[3*i+2] = radii[i]
        return vars

    # Run optimization multiple times
    # We will try a few random restarts and one structured start
    seeds = [42, 123, 456, 789, 1011, 1213]
    
    # Structured start
    initial_guesses = [generate_hex_grid_guess(seed=s) for s in seeds]
    # Random starts

    for i, x0 in enumerate(initial_guesses):
        try:
            res = minimize(objective, x0, method='SLSQP', bounds=bounds,

            if res.success or (res.nit > 0): # Check if it did some work

        centers = np.array([[0.1 + c*0.2, 0.1 + r*0.2] for r in range(5) for c in range(5)][:n])
        radii = np.full(n, 0.1)
        # Adjust last one if needed?
        # This might be invalid if 26th is added improperly.
        # Let's just use small radii to be safe
        radii = np.full(n, 0.05)
        best_sum_radii = np.sum(radii)
    else:
        centers = best_centers
        radii = best_radii

    return centers, radii, best_sum_radii
