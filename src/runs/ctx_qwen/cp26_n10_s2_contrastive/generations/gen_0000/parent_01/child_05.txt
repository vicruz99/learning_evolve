

<strategy>
The problem asks to maximize the sum of radii of 26 circles packed in a unit square. This is equivalent to finding an arrangement of centers and radii that maximizes $\sum r_i$ subject to non-overlap and boundary constraints.

Key Insight:
For fixed centers, the problem of maximizing $\sum r_i$ becomes a Linear Programming (LP) problem:
Maximize $\sum r_i$
Subject to:
$r_i + r_j \le d_{ij}$ (non-overlap)
$0 \le r_i \le \min(x_i, 1-x_i, y_i, 1-y_i)$ (boundary)

This LP can be solved efficiently. The dual variables (Lagrange multipliers) of the pair constraints $r_i + r_j \le d_{ij}$ indicate how much the objective would increase if we increased the distance between circles $i$ and $j$. Specifically, the gradient of the optimal objective value with respect to center positions is given by:
$\nabla_{c_i} V = \sum_{j \ne i} \mu_{ij} \frac{c_i - c_j}{d_{ij}}$
where $\mu_{ij}$ are the dual variables.

Algorithm:
1. Initialize centers using a hexagonal grid pattern to ensure a dense, non-overlapping starting configuration.
2. Iteratively:
   a. Compute pairwise distances.
   b. Solve the LP to find optimal radii and dual variables for the current centers.
   c. Compute repulsive forces on centers proportional to the dual variables.
   d. Update centers in the direction of forces (gradient ascent), clipping to [0,1]^2.
   e. Decay the step size.
3. After convergence, solve the LP one last time to get the final radii.
4. Return centers, radii, and their sum.

This decomposition method (optimizing radii via LP, then optimizing centers via gradient ascent) is robust and avoids the pitfalls of non-convex solvers on the full problem.

import numpy as np
from scipy.optimize import linprog

def run_packing():
    """
    Pack 26 circles in a unit square to maximize the sum of radii.
    Uses an iterative LP + gradient ascent approach.
    """
    n = 26
    
    # Precompute pair indices for upper triangle of distance matrix
    i_idx, j_idx = np.triu_indices(n, k=1)
    n_pairs = len(i_idx)
    
    # Precompute A_ub matrix structure for LP (constant)
    # Each row has 1 at position i and 1 at position j
    A_ub = np.zeros((n_pairs, n))
    A_ub[np.arange(n_pairs), i_idx] = 1.0
    A_ub[np.arange(n_pairs), j_idx] = 1.0
    
    # Initialize centers in a hexagonal grid pattern
    centers = np.zeros((n, 2))
    cnt = 0
    dx = 0.18
    dy = dx * np.sqrt(3) / 2.0
    for row in range(10):
        for col in range(10):
            if cnt == n:
                break
            x = 0.1 + col * dx + (row % 2) * (dx / 2.0)
            y = 0.1 + row * dy
            if 0 <= x <= 1 and 0 <= y <= 1:
                centers[cnt] = [x, y]
                cnt += 1
        if cnt == n:
            break
            
    # Optimization loop
    alpha = 0.02  # Initial step size
    for it in range(400):
        # Compute pairwise distances
        diff = centers[:, np.newaxis, :] - centers[np.newaxis, :, :]
        dists = np.sqrt(np.sum(diff**2, axis=2))
        np.fill_diagonal(dists, 1e9)  # Large value for self-distances
        
        # Extract distances for constrained pairs
        dist_pairs = dists[i_idx, j_idx]
        
        # Compute boundary bounds for radii
        bounds_r = np.minimum(
            np.minimum(centers[:, 0], 1.0 - centers[:, 0]),
            np.minimum(centers[:, 1], 1.0 - centers[:, 1])
        )
        bounds_r = np.maximum(bounds_r, 1e-7)
        
        # Prepare LP bounds
        bounds_lp = [(0.0, b) for b in bounds_r]
        
        # Solve LP: max sum(r) => min -sum(r)
        res = linprog(-np.ones(n), A_ub=A_ub, b_ub=dist_pairs, bounds=bounds_lp, method='highs')
        
        if res.success:
            radii = res.x
            duals = res.ineqlfmarginals
        else:
            # Fallback if LP fails (rare)
            radii = bounds_r * 0.05
            duals = np.zeros(n_pairs)
            
        # Compute forces on centers based on dual variables
        forces = np.zeros_like(centers)
        
        # Unit vectors from j to i
        diff_pairs = centers[i_idx] - centers[j_idx]
        safe_dist = np.where(dist_pairs < 1e-12, 1e-12, dist_pairs)
        unit_vecs = diff_pairs / safe_dist[:, np.newaxis]
        
        # Accumulate forces: F_i += mu * unit_vec, F_j -= mu * unit_vec
        np.add.at(forces, i_idx, duals[:, np.newaxis] * unit_vecs)
        np.add.at(forces, j_idx, -duals[:, np.newaxis] * unit_vecs)
        
        # Update centers
        centers += alpha * forces
        centers = np.clip(centers, 0.0, 1.0)
        
        # Decay step size
        alpha *= 0.995
        
    # Final LP solve with converged centers
    diff = centers[:, np.newaxis, :] - centers[np.newaxis, :, :]
    dists = np.sqrt(np.sum(diff**2, axis=2))
    np.fill_diagonal(dists, 1e9)
    dist_pairs = dists[i_idx, j_idx]
    
    bounds_r = np.minimum(
        np.minimum(centers[:, 0], 1.0 - centers[:, 0]),
        np.minimum(centers[:, 1], 1.0 - centers[:, 1])
    )
    bounds_r = np.maximum(bounds_r, 0.0)
    bounds_lp = [(0.0, b) for b in bounds_r]
    
    res = linprog(-np.ones(n), A_ub=A_ub, b_ub=dist_pairs, bounds=bounds_lp, method='highs')
    radii = res.x
    sum_radii = np.sum(radii)
    
    return centers, radii, sum_radii
