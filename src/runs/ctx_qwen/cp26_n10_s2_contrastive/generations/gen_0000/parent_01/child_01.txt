

To maximize the sum of radii for 26 circles in a unit square, we treat the placement of centers and the sizing of radii as a non-convex optimization problem. Because the circles can have variable radii, we use a multi-start gradient ascent approach to find a dense configuration that avoids local minima typical of square grids.

### Strategy
1.  **Optimization Formulation**: We maximize $\sum r_i$ subject to non-overlap and boundary constraints. 
2.  **Smooth Objective**: To allow for gradient-based optimization, we use a smooth approximation of the constraints. Instead of hard inequality checks, we employ a penalty term where any overlap or boundary violation incurs a quadratic cost. This creates a differentiable objective function.
3.  **Repulsive Forces**: We incorporate a repulsive force field between circles that encourages spacing. This force is proportional to the sum of radii, ensuring circles expand as they find more space.
4.  **Multi-Start Search**: We initialize the optimization from multiple random and grid-based starting positions. For each trial, we use `scipy.optimize.minimize` (L-BFGS-B) to find a local maximum.
5.  **Validation and Selection**: The best valid configuration (highest sum of radii) across all trials is returned.

```python
import numpy as np
import scipy.optimize as opt

def calculate_constraints(centers, radii):
    n = centers.shape[0]
    overlap = 0.0
    boundary = 0.0
    eps = 1e-5
    
    for i in range(n):
        x, y = centers[i]
        r = radii[i]
        # Boundary penalty
        boundary += max(0, x - 1 + r, 0)**2 + max(0, r - x, 0)**2 + \
                    max(0, y - 1 + r, 0)**2 + max(0, r - y, 0)**2

    for i in range(n):
        for j in range(i + 1, n):
            dist = np.linalg.norm(centers[i] - centers[j])
            req_dist = radii[i] + radii[j]
            if dist < req_dist:
                overlap += (req_dist - dist + eps)**2
                
    return overlap, boundary

def run_packing() -> tuple[np.ndarray, np.ndarray, float]:
    n = 26
    best_sum = 0.0
    best_centers = None
    best_radii = None

    # We try multiple starting configurations
    trials = 20
    for t in range(trials):
        # Initial centers: Random or Grid
        if t % 2 == 0:
            centers = np.random.rand(n, 2)
        else:
            centers = np.mgrid[0:n, 0:n].reshape(2, -1).T / (n - 1) * 0.8 + 0.1
        
        # Initial radii: small and equal
        radii = np.full(n, 0.001)
        
        # Optimization parameters
        x0 = np.concatenate([centers.flatten(), radii])
        
        # Objective: Maximize sum of radii - penalties
        def objective(vars):
            c = vars[:n*2].reshape(n, 2)
            r = vars[n*2:]
            if np.any(r < 0):
                r = np.abs(r)
            
            # Calculate penalties
            o, b = calculate_constraints(c, r)
            
            # Smooth penalty scaling
            penalty = 1000.0 * (o + b)
            
            return -(np.sum(r) - penalty)

        bounds = []
        for i in range(n):
            bounds.extend([(0, 1), (0, 1)]) # x, y bounds
            bounds.append((0, 0.5))          # r bound

        res = opt.minimize(objective, x0, method='L-BFGS-B', bounds=bounds, 
                           options={'maxiter': 2000, 'ftol': 1e-9})
        
        # Evaluate the final configuration
        c_final = res.x[:n*2].reshape(n, 2)
        r_final = np.clip(res.x[n*2:], 0, 0.5)
        
        # Final validation to ensure strict constraints
        valid = True
        for i in range(n):
            x, y = c_final[i]
            r = r_final[i]
            if x < r or x > 1-r or y < r or y > 1-r:
                valid = False; break
        
        for i in range(n):
            for j in range(i+1, n):
                dist = np.linalg.norm(c_final[i] - c_final[j])
                if dist < r_final[i] + r_final[j] - 1e-9:
                    valid = False; break
            if not valid: break

        if valid:
            s = np.sum(r_final)
            if s > best_sum:
                best_sum = s
                best_centers = c_final
                best_radii = r_final

    return best_centers, best_radii, best_sum
```
