

<strategy>
The problem asks us to pack 26 circles in a unit square to maximize the sum of their radii. This is a non-convex optimization problem where circle sizes can vary. A highly effective strategy combines two steps:
1. **Position Optimization**: Use a global optimizer to find circle center coordinates that create a configuration allowing large radii.
2. **Radius Calculation**: For any fixed set of centers, finding the optimal radii that maximize their sum subject to non-overlap and boundary constraints is a **Linear Programming (LP)** problem. This avoids non-smooth distance penalties and gives exact, valid radii for any configuration.

We will use `scipy.optimize.differential_evolution` for global exploration of the 52-dimensional center space, guided by the LP-based objective. Differential Evolution is robust for non-smooth, multi-modal landscapes typical of packing problems. We'll seed it with hexagonal-like initial guesses to accelerate convergence. After DE finds a promising configuration, we'll refine it locally with `Nelder-Mead` (derivative-free) to squeeze out extra space. Finally, we solve the LP one last time to extract the exact optimal radii.

This approach separates the combinatorial geometry (handled by DE) from the continuous size allocation (handled exactly by LP), ensuring validity and high performance.

```python
import numpy as np
from scipy.optimize import linprog, differential_evolution, minimize
import math

N = 26
# Precompute pair indices for pairwise constraints
PAIRS = [(i, j) for i in range(N) for j in range(i + 1, N)]
NP = len(PAIRS)

def compute_sum_radii(centers):
    """
    Given fixed centers, solve LP to maximize sum of radii.
    Returns (max_sum, optimal_radii_array).
    """
    # Objective: minimize -sum(r) <=> maximize sum(r)
    c = -np.ones(N)
    
    # Bounds for each radius based on distance to square boundaries
    bounds = []
    for i in range(N):
        x, y = centers[i]
        r_max = min(x, 1.0 - x, y, 1.0 - y)
        bounds.append((0.0, max(0.0, r_max)))
        
    # Pairwise non-overlap constraints: r_i + r_j <= dist(i, j)
    A_ub = np.zeros((NP, N))
    b_ub = np.zeros(NP)
    
    for k, (i, j) in enumerate(PAIRS):
        dx = centers[i, 0] - centers[j, 0]
        dy = centers[i, 1] - centers[j, 1]
        d = math.hypot(dx, dy)
        A_ub[k, i] = 1.0
        A_ub[k, j] = 1.0
        b_ub[k] = d
        
    # Solve using the fast HiGHS solver
    res = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
    if res.success:
        return -res.fun, res.x
    return 0.0, np.zeros(N)

def neg_sum_radii(centers_flat):
    """Objective function for optimizers: negative sum of optimal radii."""
    centers = np.clip(centers_flat.reshape(-1, 2), 0.0, 1.0)
    s, _ = compute_sum_radii(centers)
    return -s

def run_packing():
    bounds_c = [(0.0, 1.0)] * (2 * N)
    
    # Generate structured initial guesses to guide DE
    init_guesses = []
    for seed in range(15):
        rng = np.random.RandomState(seed)
        centers = []
        # Hexagonal grid base
        for i in range(6):
            for j in range(5):
                if len(centers) >= N: 
                    break
                x = 0.15 + j * 0.17 + (i % 2) * 0.085
                y = 0.15 + i * 0.15
                centers.append([x, y])
        centers = np.array(centers[:N]) + rng.uniform(-0.05, 0.05, size=(N, 2))
        centers = np.clip(centers, 0.05, 0.95)
        init_guesses.append(centers.flatten())
        
    # Global optimization
    de_res = differential_evolution(
        neg_sum_radii, 
        bounds_c, 
        maxiter=250, 
        popsize=15,
        initial_guess=np.array(init_guesses),
        mutation=(0.5, 1.5), 
        recombination=0.7, 
        seed=42,
        tol=1e-7, 
        polish=False
    )
        
    best_flat = de_res.x
    best_val = -de_res.fun
    
    # Local refinement to escape local minima and fine-tune positions
    for _ in range(5):
        pert = best_flat + np.random.randn(2 * N) * 1e-3
        res = minimize(
            neg_sum_radii, 
            pert, 
            method='Nelder-Mead', 
            options={'maxiter': 1500, 'xatol': 1e-5, 'fatol': 1e-5}
        )
        if res.fun < best_val:
            best_flat = res.x
            best_val = -res.fun
            
    # Final exact radius computation for the optimized centers
    final_centers = best_flat.reshape(-1, 2)
    final_sum, final_radii = compute_sum_radii(final_centers)
    
    return final_centers, final_radii, final_sum
```
