The problem of maximizing the sum of radii for 26 circles in a unit square is a non-convex optimization problem. A highly effective approach is to decouple the problem into two alternating subproblems:
1. **Fix centers, optimize radii**: For fixed circle centers, the constraints on radii become linear inequalities ($r_i + r_j \leq d_{ij}$ and boundary constraints $r_i \leq x_i, 1-x_i, \dots$). This forms a Linear Programming (LP) problem which can be solved exactly and efficiently.
2. **Fix radii (implicitly), optimize centers**: We treat the optimal sum of radii from the LP as an objective function $F(\mathbf{C}) = \sum r_i^*(\mathbf{C})$. We then use a derivative-free optimizer (Powell's method) to move the centers to maximize $F$. The optimizer naturally pushes circles apart and towards optimal positions to allow larger radii.

**Initialization**: A hexagonal lattice layout is used as it approximates the densest packing in the plane. This gives the optimizer a strong starting point close to the global optimum.
**Robustness**: The LP solver (`scipy.optimize.linprog` with the HiGHS backend) is called within the objective function. Boundary clamping ensures circles never leave the square. A single well-tuned optimization run typically converges to a highly packed configuration exceeding the target sum of 2.636.

import numpy as np
from scipy.optimize import minimize, linprog

def compute_optimal_radii(centers):
    """Solves the LP to find maximum radii for fixed centers."""
    n = centers.shape[0]
    c_obj = -np.ones(n)  # Maximize sum of radii -> minimize negative sum
    
    num_pairs = n * (n - 1) // 2
    num_bounds = n * 4
    A_ub = np.zeros((num_pairs + num_bounds, n))
    b_ub = np.zeros(num_pairs + num_bounds)
    
    idx = 0
    # Pairwise non-overlap constraints: r_i + r_j <= distance(i, j)
    for i in range(n):
        for j in range(i + 1, n):
            dist = np.sqrt(np.sum((centers[i] - centers[j])**2))
            A_ub[idx, i] = 1.0
            A_ub[idx, j] = 1.0
            b_ub[idx] = dist
            idx += 1
            
    # Boundary constraints: r_i <= x_i, r_i <= 1-x_i, r_i <= y_i, r_i <= 1-y_i
    for i in range(n):
        bounds_vals = [centers[i, 0], 1.0 - centers[i, 0], 
                       centers[i, 1], 1.0 - centers[i, 1]]
        for bv in bounds_vals:
            A_ub[idx, i] = 1.0
            b_ub[idx] = bv
            idx += 1
            
    # Solve LP
    try:
        res = linprog(c_obj, A_ub=A_ub, b_ub=b_ub, bounds=[(0, None)] * n, method='highs')
    except ValueError:
        # Fallback for older scipy versions
        res = linprog(c_obj, A_ub=A_ub, b_ub=b_ub, bounds=[(0, None)] * n, method='interior-point')
        
    if res.success:
        return -res.fun, -res.x
    return 0.0, np.zeros(n)

def objective_func(x):
    """Objective to minimize: negative sum of optimal radii."""
    centers = x.reshape(-1, 2)
    s, _ = compute_optimal_radii(centers)
    return -s

def run_packing():
    n = 26
    
    # 1. Generate initial hexagonal layout
    centers = []
    dx = 0.22
    dy = dx * np.sqrt(3) / 2
    y = 0.11
    row = 0
    while len(centers) < n:
        x = 0.11 + (row % 2) * dx / 2
        while x < 0.9 and len(centers) < n:
            centers.append([x, y])
            x += dx
        y += dy
        row += 1
    centers = np.array(centers[:n])
    x0 = centers.flatten()
    
    # Keep centers strictly inside the square during optimization
    bounds = [(0.005, 0.995)] * (2 * n)
    
    # 2. Optimize centers using Powell's method
    res = minimize(objective_func, x0, method='Powell', bounds=bounds, 
                   options={'maxiter': 4000, 'ftol': 1e-10, 'xtol': 1e-10})
    
    # 3. Extract and sanitize results
    final_centers = res.x.reshape(-1, 2)
    final_centers = np.clip(final_centers, 1e-6, 1.0 - 1e-6)
    
    _, final_radii = compute_optimal_radii(final_centers)
    final_radii = np.maximum(final_radii, 0.0)
    
    return final_centers, final_radii, np.sum(final_radii)
