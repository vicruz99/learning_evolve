The previous solutions relied heavily on SLSQP with parameterized boundaries, which often gets trapped in local minima due to the non-convex nature of the packing problem and stiff gradients near boundaries. 

To break through the ~2.634 barrier and target >2.636, I will switch to a **Simulated Annealing (SA) on centers + Linear Programming (LP) for radii** approach. This decouples the problem:
1. For any fixed set of centers, the optimal radii maximizing their sum subject to non-overlap and boundary constraints can be found exactly and very quickly via LP.
2. SA explores the center space globally, accepting worse moves probabilistically to escape local optima.
3. The objective function `sum(r(centers))` is naturally handled by the LP oracle.
4. I will precompute the constant constraint matrix `A_ub` for the LP to make each evaluation extremely fast (~0.1ms), allowing ~100k+ iterations.
5. Multiple diverse initial configurations (hexagonal, grid, random) are tested, followed by a coordinate-descent polish phase to fine-tune the best configuration found.

This method is robust, avoids SLSQP's sensitivity to initial conditions, and systematically maximizes the sum of radii.

import numpy as np
from scipy.optimize import linprog

N = 26

def solve_lp(centers, A_ub, bounds_lp, n_cons, triu_idx):
    """Solves LP to find optimal radii for fixed centers maximizing sum(radii)."""
    b_ub = np.empty(n_cons)
    for i in range(N):
        x, y = centers[i]
        b_ub[4*i] = x
        b_ub[4*i+1] = 1.0 - x
        b_ub[4*i+2] = y
        b_ub[4*i+3] = 1.0 - y
        
    dx = centers[:, 0, np.newaxis] - centers[:, 0, np.newaxis].T
    dy = centers[:, 1, np.newaxis] - centers[:, 1, np.newaxis].T
    dists = np.sqrt(dx*dx + dy*dy)
    b_ub[4*N:] = dists[triu_idx]
    
    res = linprog(-np.ones(N), A_ub=A_ub, b_ub=b_ub, bounds=bounds_lp, method='highs')
    if res.success:
        return res.x
    return np.full(N, 1e-6)

def get_sum_r(centers, A_ub, bounds_lp, n_cons, triu_idx):
    """Returns optimal radii and their sum for given centers."""
    radii = solve_lp(centers, A_ub, bounds_lp, n_cons, triu_idx)
    return radii, np.sum(radii)
