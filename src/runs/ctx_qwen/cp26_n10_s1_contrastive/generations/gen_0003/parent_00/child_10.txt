

<strategy>
The current approach uses SLSQP for joint optimization of centers and radii, which can get trapped in local minima due to the non-convex pairwise distance constraints. A more robust strategy for circle packing is to decouple the problem:
1. **Fixed Centers -> Optimal Radii**: For any given set of center coordinates, the problem of finding radii that maximize the sum subject to non-overlap and boundary constraints is a **Linear Programming (LP)** problem. This can be solved exactly and extremely fast using `scipy.optimize.linprog` with the `highs` solver.
2. **Global Center Optimization**: We define an objective function that takes center coordinates, solves the LP for radii, and returns the negative sum of radii. We then use **Differential Evolution** to globally optimize the 52 center coordinates. DE handles the non-smooth, rugged landscape of the LP-based objective well.
3. **Local Refinement**: After DE finds a promising configuration, we run multiple local searches using **Nelder-Mead** (derivative-free) starting from the best solution and random perturbations to fine-tune the centers and escape any remaining local optima.
4. **Validation & Polish**: The final centers are fed back into the LP to get mathematically optimal radii. This guarantees strict feasibility and maximizes the sum of radii for those centers. We also add a fallback grid packing to ensure the function always returns a valid result.

This hybrid LP + Global Optimization approach is standard in computational geometry for packing problems and typically outperforms direct non-linear solvers like SLSQP on this task.
</strategy>

```python
import numpy as np
from scipy.optimize import linprog, differential_evolution, minimize

N = 26

def solve_radii_lp(centers):
    """
    Given fixed center coordinates, solves the LP to find radii that maximize sum(r_i).
    Constraints:
      1. r_i >= 0
      2. r_i <= distance to each boundary (x, 1-x, y, 1-y)
      3. r_i + r_j <= Euclidean distance between centers i and j
    Returns optimal radii array and the maximum sum of radii.
    """
    n = centers.shape[0]
    c = -np.ones(n)  # Minimize -sum(r_i) <=> Maximize sum(r_i)
    
    n_boundary = 4 * n
    n_pairwise = n * (n - 1) // 2
    n_constraints = n_boundary + n_pairwise
    
    A_ub = np.zeros((n_constraints, n))
    b_ub = np.zeros(n_constraints)
    
    idx = 0
    # Boundary constraints: r_i <= bound
    for i in range(n):
        x, y = centers[i]
        A_ub[idx, i] = 1.0; b_ub[idx] = x; idx += 1
        A_ub[idx, i] = 1.0; b_ub[idx] = 1.0 - x; idx += 1
        A_ub[idx, i] = 1.0; b_ub[idx] = y; idx += 1
        A_ub[idx, i] = 1.0; b_ub[idx] = 1.0 - y; idx += 1

    # Pairwise constraints: r_i + r_j <= dist(i,j)
    diff = centers[:, np.newaxis, :] - centers[np.newaxis, :, :]
    dists = np.sqrt(np.sum(diff**2, axis=2))
    for i in range(n):
        for j in range(i + 1, n):
            A_ub[idx, i] = 1.0
            A_ub[idx, j] = 1.0
            b_ub[idx] = dists[i, j]
            idx += 1
            
    bounds = [(0.0, None)] * n
    
    try:
        res = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs', options={'disp': False})
        if res.success:
            return res.x, -res.fun
    except Exception:
        pass
        
    # Fallback in case LP fails
    return np.full(n, 1e-5), 0.0

def objective_centers(x_flat):
    """
    Objective function for optimizing center positions.
    Computes optimal radii via LP and returns negative sum of radii.
    """
    centers = x_flat.reshape(N, 2)
    _, sum_r = solve_radii_lp(centers)
    return -sum_r

def run_packing():
    """
    Optimizes circle packing for N=26 in a unit square.
    Returns (centers, radii, sum_radii).
    """
    # Bounds for center coordinates: [0, 1] x [0, 1]
    bounds = [(0.0, 1.0)] * (2 * N)
    
    best_x = None
    best_sum = -np.inf
    
    # Phase 1: Global search with Differential Evolution
    # DE is robust for non-smooth objectives like this LP-wrapped function
    try:
        res_de = differential_evolution(
            objective_centers, bounds,
            popsize=15, maxiter=120, tol=1e-7,
            seed=42, polish=False, mutation=(0.8, 1.2), recombination=0.8
        )
        best_x = res_de.x.copy()
        best_sum = -res_de.fun
    except Exception:
        best_sum = 0.0

    # Phase 2: Local refinement with Nelder-Mead
    # DE may not converge to high precision; Nelder-Mead polishes the landscape
    for seed in range(20):
        np.random.seed(seed)
        if seed == 0 and best_x is not None:
            x0 = best_x.copy()
        else:
            # Generate diverse starting points via perturbation or random
            if best_x is not None:
                x0 = best_x + np.random.randn(2 * N) * 0.025
            else:
                x0 = np.random.rand(2 * N)
            x0 = np.clip(x0, 0.0, 1.0)
            
        try:
            res_local = minimize(
                objective_centers, x0, method='Nelder-Mead',
                options={'maxiter': 10000, 'xatol': 1e-7, 'fatol': 1e-9}
            )
            if -res_local.fun > best_sum:
                best_sum = -res_local.fun
                best_x = res_local.x.copy()
        except Exception:
            continue

    # Phase 3: Final LP solve to extract optimal radii for the best centers
    if best_x is not None:
        centers = best_x.reshape(N, 2)
        radii, final_sum = solve_radii_lp(centers)
    else:
        # Fallback valid configuration (dense grid)
        centers = np.zeros((N, 2))
        idx = 0
        for i in range(5):
            for j in range(5):
                centers[idx] = [0.1 + 0.2 * i, 0.1 + 0.2 * j]
                idx += 1
        centers[25] = [0.5, 0.5]
        radii, final_sum = solve_radii_lp(centers)
        
    # Ensure non-negative radii and proper shapes
    radii = np.maximum(radii, 0.0)
    centers = np.clip(centers, 0.0, 1.0)
    
    return centers, radii, float(final_sum)
```
