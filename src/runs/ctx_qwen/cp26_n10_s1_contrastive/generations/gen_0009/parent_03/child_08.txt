The strategy focuses on a hybrid optimization approach combining Simulated Annealing (SA) on circle centers with Linear Programming (LP) for radius optimization, followed by Sequential Least Squares Programming (SLSQP) for high-precision refinement.

1. **Fast LP Evaluation**: Precompute the constant constraint matrix `A_ub` for the LP. At each SA step, only the right-hand side `b_ub` (boundary and pairwise distances) needs updating. This speeds up LP calls significantly, enabling thousands of evaluations without bottleneck.
2. **Diverse Initializations**: Generate hexagonal lattice patterns with various row counts, rotations, and scales, plus force-directed layouts to cover the configuration space broadly.
3. **Simulated Annealing on Centers**: Optimize centers directly. The objective is the optimal sum of radii computed via LP. SA includes adaptive step size, temperature cooling, and periodic random shocks to escape local minima.
4. **Parameterized SLSQP Refinement**: Convert the best center/radius configuration to a `(r, u, v)` parameterization where `x = r + u*(1-2r)` and `y = r + v*(1-2r)`. This automatically satisfies boundary constraints, reducing the constraint set to only pairwise non-overlap conditions. Run SLSQP with multiple restarts and perturbations to polish the solution.
5. **Robustness**: Handle numerical tolerances carefully, ensure strict feasibility checks, and use top-level functions without closures or lambdas as required.

N = 26
I_IDX, J_IDX = np.triu_indices(N, k=1)
NUM_PAIRS = N * (N - 1) // 2
NUM_CONS = 4 * N + NUM_PAIRS

# Precompute constant constraint matrix for LP to speed up evaluations
A_LP = np.zeros((NUM_CONS, N))
for i in range(N):
    A_LP[i, i] = 1.0          # r_i <= x_i
    A_LP[N + i, i] = 1.0      # r_i <= 1 - x_i
    A_LP[2*N + i, i] = 1.0    # r_i <= y_i
    A_LP[3*N + i, i] = 1.0    # r_i <= 1 - y_i

        A_LP[k, j] = 1.0
        k += 1

    b_ub = np.zeros(NUM_CONS)
    for i in range(N):
        x, y = centers[i]
        b_ub[i] = x
        b_ub[N + i] = 1.0 - x
        b_ub[2*N + i] = y
        b_ub[3*N + i] = 1.0 - y

    u = np.clip((centers[:, 0] - r) / denom, 0.0, 1.0)
    v = np.clip((centers[:, 1] - r) / denom, 0.0, 1.0)
    params = np.empty(3 * N)
    params[0::3] = r
    params[1::3] = u
    params[2::3] = v
    return params

def from_params(params):
    r = params[0::3]
    u = params[1::3]
    v = params[2::3]
    x = r + u * (1.0 - 2.0 * r)
    y = r + v * (1.0 - 2.0 * r)
    return np.column_stack((x, y)), r

def cons_func(params):
    r = params[0::3]
    u = params[1::3]
    v = params[2::3]
    x = r + u * (1.0 - 2.0 * r)
    y = r + v * (1.0 - 2.0 * r)

    dy = y[:, np.newaxis] - y[np.newaxis, :]

    rs = r[:, np.newaxis] + r[np.newaxis, :]
    return d2[I_IDX, J_IDX] - rs[I_IDX, J_IDX]**2

def obj_func(params):
    return -np.sum(params[0::3])

    row = 0
    for cnt in pattern:
