The goal is to find a configuration where circles are packed as densely as possible, pushing the radii to the maximum feasible values under non-overlap and boundary constraints.

### Strategy
1.  **Hexagonal Initialization**: We start by placing 26 circles in a hexagonal lattice pattern. Hexagonal packing is the densest packing for equal circles in the plane. We calculate positions for a hexagonal grid and truncate or adjust to fit exactly 26 circles within the unit square. This provides a high-quality starting point compared to a random or square grid arrangement.
2.  **Force-Directed Optimization**: We use a force-directed layout algorithm (similar to simulated annealing or a repulsion-based optimizer) to refine the positions. 
    *   **Repulsion**: Circles that overlap or are too close exert a repulsive force on each other, pushing them apart.
    *   **Expansion**: We iteratively increase the radii of the circles. If overlaps occur, the repulsion forces adjust the centers.
    *   **Boundary Repulsion**: Circles are pushed away from the boundaries of the square if they protrude.
3.  **Sum of Radii Maximization**: While maintaining a valid packing, the algorithm attempts to grow the radii. Since the sum of radii is maximized when the packing is dense, this process naturally drives the solution towards the target.
4.  **Numerical Refinement**: We use `scipy.optimize` to fine-tune the positions and radii, maximizing the sum of radii while treating overlap and boundary violations as constraints (or penalties).

import numpy as np
import scipy.optimize as opt
import math

def get_hexagonal_init(n, r):
    """
    Generate initial positions for n circles in a hexagonal pattern.
    """
    centers = []
    y = r
    row_idx = 0
    
    while len(centers) < n:
        # Shift for odd rows in hexagonal packing
        if row_idx % 2 == 0:
            x = r
        else:
            x = 2 * r # Shifted by one radius (distance 2r between centers, shift r means centers at 2r if starting at r? 
                      # Actually, if row 0 centers at r, 3r... row 1 centers at 2r, 4r...
                      # Wait, distance between (r, y0) and (2r, y1) must be >= 2r.
                      # dy = sqrt(3)r. dx = r. dist = sqrt(r^2 + 3r^2) = 2r. Correct.
        
        while x <= 1 - r:
            centers.append((x, y))
            x += 2 * r
        
        # Move to next row
        y += math.sqrt(3) * r
        row_idx += 1
        
        # If y goes out of bounds, break (though loop condition handles n)
        if y + r > 1 + 1e-6:
            break
            
    # Trim to exactly n
    centers = centers[:n]
    return centers

def compute_violations(centers, radii):
    """
    Compute overlap and boundary violations.
    Returns a scalar sum of squared violations.
    """
    n = centers.shape[0]
    violation = 0.0
    
    # Boundary violations
    for i in range(n):
        x, y = centers[i]
        r = radii[i]
        
        # Left
        if x - r < 0:
            violation += (x - r) ** 2
        # Right
        if x + r > 1:
            violation += (x + r - 1) ** 2
        # Bottom
        if y - r < 0:
            violation += (y - r) ** 2
        # Top
        if y + r > 1:
            violation += (y + r - 1) ** 2
            
    # Overlap violations
    for i in range(n):
        for j in range(i + 1, n):
            dist = np.sqrt(np.sum((centers[i] - centers[j]) ** 2))
            sum_radii = radii[i] + radii[j]
            if dist < sum_radii:
                violation += (sum_radii - dist) ** 2
                
    return violation

    # While maximizing sum of radii.

    x0 = np.hstack([centers.flatten(), radii])

    # A penalty method is often robust for packing.

    # x, y in [0, 1]
    # r in [0, 0.5] (max possible radius)
    
    bounds = []

    return best_centers, best_radii, sum_radii
