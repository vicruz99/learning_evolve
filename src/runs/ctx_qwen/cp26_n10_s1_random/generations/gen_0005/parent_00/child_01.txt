While equal-radius packings are well-studied, allowing radii to vary typically yields a significantly higher sum because smaller circles can fill gaps between larger ones.

1. **LP Formulation for Fixed Centers**: For any fixed set of center coordinates, the problem of maximizing $\sum r_i$ subject to non-overlap ($r_i + r_j \le d_{ij}$) and boundary constraints ($r_i \le \text{dist}(c_i, \partial)$) is a Linear Program. This can be solved exactly and efficiently using `scipy.optimize.linprog` with the `highs` solver.
2. **Simulated Annealing (SA) on Centers**: Since the LP objective value is a function of the centers, we treat the centers as optimization variables. We use Simulated Annealing to explore the center configuration space. At each step, we perturb one circle's position, solve the LP to get the new optimal sum of radii, and accept/reject the move based on the SA criterion. This decouples center optimization from radius assignment, avoiding the non-smoothness and balance issues of joint optimization.
3. **Initialization & Tuning**: We start with a hexagonal lattice pattern (known to be near-optimal for dense packing) scaled to fit the square. 4. **Robustness**: The LP always has a feasible solution (e.g., all radii = 0), so the solver won't fail. We handle exceptions gracefully and use bounds to keep centers strictly inside the square.

import numpy as np
from scipy.optimize import linprog

def solve_lp_radii(centers):
    """
    Solves the Linear Program to maximize sum of radii for fixed center positions.
    Constraints: r_i + r_j <= distance(i, j) for all pairs, and r_i <= distance to boundary.
    """
    n = centers.shape[0]
    x, y = centers[:, 0], centers[:, 1]
    
    # Upper bounds for each radius based on distance to the square boundaries
    ub = np.minimum(np.minimum(x, 1.0 - x), np.minimum(y, 1.0 - y))
    bounds = [(0.0, b) for b in ub]
    
    # Pairwise non-overlap constraints: r_i + r_j <= dist(i, j)
    i_idx, j_idx = np.triu_indices(n, k=1)
    n_pairs = len(i_idx)
    A_ub = np.zeros((n_pairs, n))
    b_ub = np.zeros(n_pairs)
    
    for k in range(n_pairs):
        i, j = i_idx[k], j_idx[k]
        A_ub[k, i] = 1.0
        A_ub[k, j] = 1.0
        b_ub[k] = np.hypot(x[i] - x[j], y[i] - y[j])
        
    try:
        # Maximize sum(r) <=> Minimize -sum(r)
        res = linprog(-np.ones(n), A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
        if res.success:
            return res.x, -res.fun
    except Exception:
        pass
    return np.zeros(n), 0.0

def run_packing() -> tuple[np.ndarray, np.ndarray, float]:
    n = 26
    rng = np.random.default_rng(42)
    
    # 1. Initialize with a hexagonal lattice pattern
    # This provides a dense, structurally sound starting configuration
    r0 = 0.13
    pts = []
    y = r0
    row = 0
    while len(pts) < n + 10:
        shift = r0 if row % 2 == 1 else 0.0
        x = r0 + shift
        while x + r0 <= 1.0:
            pts.append([x, y])
            x += 2.0 * r0
        y += np.sqrt(3) * r0
        row += 1
    centers = np.array(pts[:n])
    
    # Normalize and center within the unit square with a margin
    cx_min, cy_min = centers.min(axis=0)
    cx_max, cy_max = centers.max(axis=0)
    centers = (centers - [cx_min, cy_min]) / ([cx_max, cy_max] - [cx_min, cy_min])
    centers = centers * 0.82 + 0.09
    
    # Evaluate initial configuration
    best_c = centers.copy()
    best_r, best_s = solve_lp_radii(centers)
    
    # 2. Simulated Annealing to optimize center positions
    # The objective landscape is piecewise smooth; SA effectively navigates it
    T = 0.06
    decay = 0.9996
    n_steps = 10000
    
    for step in range(n_steps):
        # Perturb a randomly selected circle
        i = rng.integers(n)
        step_sz = T * 0.04
        move = rng.uniform(-step_sz, step_sz, 2)
        
        new_c = centers.copy()
        new_c[i] = np.clip(new_c[i] + move, 1e-4, 0.9999)
        
        # Solve LP for the new configuration
        r, s = solve_lp_radii(new_c)
        if r is not None:
            delta = s - best_s
            # Acceptance criterion
            if delta > 0 or rng.random() < np.exp(delta / T):
                best_s = s
                best_r = r.copy()
                best_c = new_c.copy()
                centers = new_c.copy()
                
            # Cool down temperature
            T *= decay
            if T < 1e-5:
                T = 1e-5
                
    # 3. Final safety scaling to guarantee strict numerical validity
    # The checker allows ~1e-12 tolerance; scaling by 0.999999 ensures no false overlaps
    best_r *= 0.999999
    
    return best_c, best_r, float(np.sum(best_r))
